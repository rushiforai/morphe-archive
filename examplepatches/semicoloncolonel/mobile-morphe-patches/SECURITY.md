# Security policy

## Supported versions

Only the latest release receives fixes. Morphe Manager updates the patch bundle from this repository, so update the source in Morphe Manager before you report a problem.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through the **Report a vulnerability** button on the [Security tab](https://github.com/semicoloncolonel/mobile-morphe-patches/security) of this repository.

Include the app and version, the patches you applied, and the steps to reproduce the problem.

## What counts as a security problem

- A patch that sends personal data somewhere it should not go, or that weakens the app's own security.
- A patch marked as blocking analytics or tracking that lets that traffic through.
- A problem with the patch bundle, its release files, or the build and release workflows.

A patch that stops working after an app update is a regular bug. Please open a normal issue for it.

## Scope

This project does not control the patched apps, their servers, or Morphe Manager. Report problems in those to their developers.
