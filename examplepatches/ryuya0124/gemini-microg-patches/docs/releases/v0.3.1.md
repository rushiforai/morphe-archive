# v0.3.1

Fixes the clone-installation setup underlying Issue #8 and corrects custom-permission references left behind after official Clone app processing.

- Map owned permission references in Manifest attributes, DEX constants and static field strings to the same fixed clone namespace as official Clone app. Keep declarations/protection levels under the official patch's control.
- Validate final clone names, permission isolation/reference consistency and provider collisions before signing/installation in the CLI workflow. Manager users must still set external Clone app options explicitly; see docs/setup-en.md.
- Reject the three unsupported historical account experiments with actionable messages.
- Validate fresh patch output/result JSON, preserving the previous successful APK on patch failures.
- Fix cached process-name branches that bypassed normalization and caused widget-receiver Dagger crashes. Preserve labels when rewriting return paths and verify all first/cached/seeded paths against actual APK code.
- Clarify the historical microG 7.0.0 patch title and add English setup/Android SDK requirements.

Before release, verified on a dedicated API36 Google APIs emulator as normal shell UID2000 without root commands: duplicate-permission failure with original Google present and after user-only removal; baseline Lens authorization denial then corrected authorization; successful coexistence installation and launcher routing with original Google disabled. Host configuration rejection tests also passed. See docs/testing/issue-8-emulator.md for evidence and reproducible commands.

Inputs remain Google 17.72.17.ve.arm64 and Gemini 1.0.995038376, both minSdk32. Android12/API31 and the reporter's physical OnePlus8 are not verified/supported by this input pair. No account/chat or actual Lens processing was tested in the emulator. No Google APKs or signing keys are included in the release.

The final emulator run completed all 26 assertions, including baseline widget crash reproduction and no clone fatal crash after the fix. Host options/experiment checks completed 9 assertions. All were completed before publication.

## Android 12 follow-up verification

After publication, the same v0.3.1 patch implementation also passed 26 regression assertions on Android 12 / API 31 using the original Google API 30 nodpi and Gemini API 29 variants of these same versions. Their minimum SDKs were not lowered. The API 32 requirement above describes the default local input artifacts, not a minimum imposed by this patch bundle.
