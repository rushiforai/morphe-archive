# v0.3.2

Morphe's default patch selection now creates installable Google and Gemini clones without Expert mode or manual Clone app options.

- Add default **Automatic Clone Setup** to create the fixed `.morphe` package and isolate declared permissions and provider authorities. Existing bytecode/Manifest permission fixes remain enabled.
- Remove the official Clone app dependency and option flags from normal build commands. Existing selections that also enable official Clone app work with its untouched defaults or previous true/true options while Automatic Clone Setup remains selected. Custom package names remain unsupported and fail before output replacement.
- Preserve permission protection levels, original APK minimum SDKs and existing signing keys.
- Make the target Android user explicit during CLI installation; user0 is the default and Secure Folder uses `ANDROID_USER=150`.

Before publication: default-only builds and APK verification passed; 11 release-MPP configuration assertions passed; both Android12/API31 and API36 emulators completed all 26 before/after regression assertions. The MPP contains all 26 JVM classes in Android DEX. [Verification and scope](https://github.com/ryuya0124/gemini-microg-patches/blob/main/docs/testing/default-clone.md).

Use original supported APK variants and keep the default selection including Automatic Clone Setup. [Setup guide](https://github.com/ryuya0124/gemini-microg-patches/blob/main/docs/setup-en.md). The Google Android11+ nodpi APK includes resources; split inputs still need their matching resource split. Install Google clone, Gemini clone and microG in the same Android profile. The three historical account experiments must stay disabled.

Emulator account login/chat and the reporter's OnePlus8 were not tested. No Google APKs or signing keys are included in this release.

The existing-key builds were also applied to SM-S948Q / Android17 Secure Folder user150 with installed-APK hashes, signatures, cloned Lens permission and preserved app data verified. The user confirmed that Gemini remained signed in and returned a chat reply after the update.
