# v0.3.8

- Support the current Morphe Manager (2.7.1 or later). Update Morphe Manager before patching.
- Patch the Google app with much less memory: about 300 MB instead of over 1 GB, so patching works on phones with little memory. Use the single APK file of the Google app; a split bundle (.apks/.apkm) still needs more memory while Morphe Manager merges it.
- Reduce the “Conversation requires an update” warning that stops some existing chats from continuing. This is not fully fixed yet, and the warning can still appear.
