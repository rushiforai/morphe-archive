# Gemini microG patches 0.1.0

初回のMorpheパッチバンドルリリースです。

## ダウンロード

Assetsの `gemini-microg-patches-0.1.0.mpp` を使用してください。JVMクラスとAndroid用DEX、Morpheのバンドル情報を含みます。元APKや署名キーは含みません。

## Morpheへの追加

Morpheの「Sources → ＋ → Remote」で以下を登録します。

`https://github.com/ryuya0124/gemini-microg-patches`

または `.mpp` をダウンロードし、Localから追加します。

## 修正内容

- microGのアカウント同期・ログイン・初回権限要求
- クローンのプロセス名不一致とアカウント同期ループの修正
- Geminiランチャーの呼び出し先をクローンGoogleへ変更
- Secure FolderでのWeb転送と利用不可エラー(19)の回避

## 対象と使用条件

- Google `17.54.18.ve.arm64` / Gemini `1.0.958859967`
- microG `app.revanced.android.gms` 7.0.0
- Morphe Patcher 1.12.0向けにビルド
- 独自パッチに加えて、公式Morphe patches 1.41.0の **Clone app** を有効にし、`updatePermissions=true` と `updateProviders=true` を設定してください。ManagerではExpert modeで複数ソースから選択します。
- Googleのxxhdpi splitのパッケージ変更と同一キー署名も必要です。3つのAPKを再現する手順はREADMEの `scripts/build-all.sh` → `scripts/sign-apks.sh` を参照してください。
- Account Switch Lock Bypass / Account Sync Binder Loop Fix / Account ID Fallback for Cloneは無効のまま使用します。

通常領域とSamsung Secure Folder（user 150）でログイン・利用成功を確認済みです。MPPの構造・全クラスのDEX収録・Desktopからの読み込みを検証します。Android版ManagerでのインポートからAPK作成までの一連の操作は未確認です。
