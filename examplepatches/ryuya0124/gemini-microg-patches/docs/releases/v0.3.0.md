# v0.3.0

Google 17.72.17.ve.arm64に対応。GeminiのGoogleクローン検出宣言漏れを修正し、更新時のフック候補をDexKitで探索するホスト解析ツールを追加しました。

- Gemini連携先変更パッチが、クローン版GoogleをManifest queriesに追加するリソース処理へ依存するよう変更。検出宣言は1件に保ちます。
- Standalone Supportはsplit APK制約の除去であり、Googleアプリ本体が別途必要であることを説明に明記。
- 新版のWeb転送条件と23レジスタのMainActivityに対応。別のnullable Boolean条件を書き換えないよう命令構造・分岐先を検証。
- DexKit 2.3.0の9探索ルール、JSONレポート、版間比較、同一入力キャッシュを追加。MPP/端末にはDexKitを含めません。
- Geminiの入力版は1.0.995038376のまま。元Googleなしの条件でのIssue #7再現・解消は未確認。

検証: 元APK3点からのビルド、既存DEX検証、trampoline分岐対応、修正前/後のManifest検証、DexKit旧版/新版探索とキャッシュ使用。セキュアフォルダ実機結果は確認後に追記します。
