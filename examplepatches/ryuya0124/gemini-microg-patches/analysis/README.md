# 過去の解析資料

`legacy/` はGoogle 17.54.18のログイン調査に使用したKotlinスクリプトです。旧パスや難読化名が含まれるため、通常ビルドには使用しません。実行するときは入力パスを修正してください。

保守対象の検証コードは `scripts/kotlin/`。生ログ・DEX・画面・旧APKはローカルの `local/archive/` に保管しています。

今後の調査は [フック解析ガイド](../docs/hook-analysis.md) と `scripts/inspect-hooks.sh` を使用してください。旧スクリプトの難読化名を新版の根拠として流用しないでください。
