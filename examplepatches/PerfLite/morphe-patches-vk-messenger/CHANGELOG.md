# Changelog

## [1.0.0] - 2026-10-29

### Нововведения
- **Обход защит и проверок подписи:** снята проверка оригинальной подписи в `AuthBridge` и `DeviceState`, обезврежен нативный анти-тампер в `libvkmedia.so` (поиск по сигнатуре, а не по смещению).
- **Push-уведомления:** подмена `X-Android-Package` / `X-Android-Cert` для получения FCM на переподписанном APK.
- **Телеметрия:** полная блокировка MyTracker.
- **Обход детекта VPN:** снятие ограничений при подключении через VPN/прокси.
- **Клонирование приложения:** пакет переименован в `com.vk.im.morphe` для установки рядом с оригиналом, исправлен Tracer, отключён AccountManager, провайдеры и authorities переименованы.
- **Без уведомления о «взломе»:** клон больше не попадает под встроенный детектор VK «опасное приложение» (application `taskAffinity` отличается от имени пакета).
- **Свои цвета иконки:** перекраска плашки, пузыря и точек лончер-иконки, включая adaptive-слой.
- **Стабильность:** полная поддержка актуальной версии «VK Мессенджер» 1.329 (versionCode 34779).
