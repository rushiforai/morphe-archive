# Pilahito Atresplayer Patches

A community patch bundle for Atresplayer, maintained by Pilahito. It targets Atresplayer 5.8.0 (`com.a3.sgt`).

This repository provides patches for Morphe; it does not distribute the Atresplayer APK. Use the patch with a copy of the app you are entitled to use.

## Add this source

Add `https://github.com/pilahito/atresplayer-patches` in Morphe Manager, or use the button below.

<a href="https://morphe.software/add-source?github=pilahito/atresplayer-patches">
  <img src=".github/assets/add-to-morphe.svg" alt="Add source in Morphe Manager" height="48">
</a>
