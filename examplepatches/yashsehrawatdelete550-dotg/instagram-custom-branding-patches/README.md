# Instagram Custom Branding patches for Morphe

Experimental custom patch source for Instagram with three options:
- **Custom app name** — preset names or your own label.
- **Custom app icon** — replace known launcher PNG resources from a PNG path.
- **Custom splash text** — keep, replace, or hide splash branding and choose a color.

## Build status
GitHub Actions builds the patch bundle when changes are pushed. Check the **Actions** tab and confirm the build succeeds before using the output. A successful compile does not prove compatibility with every Instagram version; test before installing.

## Use in Morphe Manager
After a successful build, download the generated `.mpp` artifact from Actions and add it through Morphe Manager's local source option. A remote source link should only be shared after a compatible release and bundle manifest are published.

This is an independent community project, not an official Morphe project.
