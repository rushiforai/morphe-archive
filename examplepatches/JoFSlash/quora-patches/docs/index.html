Morphe patch bundle

Quora without the ads.

Community patches for the Quora Android app. Hide promoted answers and sponsored posts, and stop the app from sending analytics.

Source on GitHub

Or add this URL as a patch source in Morphe Manager: https://github.com/JoFSlash/quora-patches

Patches

Remove ads

Hides promoted answers, sponsored posts and Google ads in the feed and on question pages, and blocks requests to ad servers.

Disable analytics

Turns off Firebase Analytics, Crashlytics, Firebase Performance and Facebook app events, and stops the advertising ID from being collected.

Supported versions

  • Quora 3.2.42
  • Quora 3.2.30

How to install

  1. Install Morphe Manager from the official Morphe website.
  2. Tap Add to Morphe above, or add the repository URL as a patch source.
  3. Pick Quora, let Morphe download a supported version, and apply the patches.
  4. Uninstall the Play Store version of Quora before installing the patched app.

Patching is done by Morphe, the open-source patcher. Learn more and get Morphe Manager at morphe.software.
