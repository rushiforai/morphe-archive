## ❓ About

Material 3 interface patches for [IronFox](https://github.com/ironfox-oss/IronFox) (`org.ironfoxoss.ironfox`).

First stage: **Material 3 settings** (tonal rounded cards, primary section titles, no dividers). More screens will follow.

### 🛠️ Building locally

- Run `./gradlew buildAndroid`
- The built patches .mpp file is found in `patches/build/libs/patches-*.mpp`
- Patch the mpp file using [Morphe-Desktop](https://github.com/MorpheApp/morphe-desktop)
  like any other patch bundle.

See the [Morphe documentation](https://github.com/MorpheApp/morphe-documentation) for more information.
