# heltonricardo patches

Patches for apps I use, for Morphe.

Add this URL as a source in Morphe Manager: https://github.com/heltonricardo/morphe-patches

## Patches

### Waze

- **Hide route balloons**: removes the street name balloons shown along the route on the map.

## Building locally

Run `./gradlew :patches:buildAndroid`. The bundle is `patches/build/libs/patches-*.mpp`.
