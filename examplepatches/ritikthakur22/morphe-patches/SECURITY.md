## Reporting a Vulnerability

We take the security and integrity of **CRDY Patches** seriously. If you discover a security vulnerability or sensitive information disclosure, please report it responsibly.

### How to Report

- **Email**: Reach out to the maintainer at [188522288+ritikthakur22@users.noreply.github.com](mailto:188522288+ritikthakur22@users.noreply.github.com).
- **GitHub Security Advisory**: Alternatively, submit a private advisory through the repository's **Security** tab under **Advisories** -> **Report a vulnerability**.

Please include:
1. Detailed description of the vulnerability and its potential impact.
2. Steps to reproduce or proof-of-concept code.
3. Affected versions and modules (e.g. `shared`, `shared-youtube`, `patches`).

### Response Timeline

- You will receive an initial response acknowledging your report within 48 hours.
- A fix will be developed, tested, and published in an upcoming release.
- We will coordinate public disclosure after the patch has been released.
