# DMM VR動画プレイヤー 使用說明

給 Meta Quest 上的 DMM VR動画プレイヤー用。

## 安裝前要知道的

- **只支援 9.0.0。** patch 是把程式碼寫進 app 的 `libil2cpp.so` 固定位置，每一版的位置都不一樣，
  其他版本會直接套用失敗，不會裝出壞掉的 app。
- **不能直接蓋掉官方版。** patch 過的 APK 簽章不同，要先在頭盔上移除商店版再安裝。移除時，下載到
  頭盔裡的影片會跟著刪掉，裝好後要重新下載；登入和已購買的影片不受影響。商店只會給最新版，
  所以移除後不一定拿得回 9.0.0。
- **帳號要在商店取得過這個 app。** app 啟動時會向 Meta 確認你的帳號擁有它，沒有的話會自己關掉。
- **不能用 Clone app。** Meta 的授權是綁在 package name 上，改了名字就查不到授權，app 一打開就會
  自己關掉，所以沒辦法跟商店版並存。
- **最簡單的打包方式：** 把 Morphe Manager 裝在頭盔上，選 app 時用「Use installed app」，直接拿頭盔上的
  商店版打包，不用另外找 APK。打包好要安裝時，照提示先移除商店版。
- **patch 更新時，拿已安裝的 patch 版重新打包就好：** Hand tracking 會先把舊版 patch 改過的地方還原成原版，
  再套上新版，所以同樣用「Use installed app」選頭盔上的 patch 版即可，不需要原版 APK，也不用再裝回商店版。
- **用電腦打包的話，要先把 APK 取出來：** Quest 的 app 沒有地方可以下載，要在移除商店版**之前**，從頭盔上
  把它的 APK 取出來留著（頭盔要開開發者模式、接上電腦）：

  ```bash
  adb pull "$(adb shell pm path com.dmm.app.oculusgearplayer | sed 's/package://' | tr -d '\r')" "DMM VR_9.0.0.apk"
  ```

  打包好的 APK 用 adb、SideQuest 之類的方式側載到頭盔，裝好後在 app 列表的「未知來源」裡。
- **頭盔要開啟手部追蹤：** 在頭盔設定的動作追蹤裡打開手部追蹤。

## 手勢追蹤

- **怎麼用：** 放下控制器，等系統切換成手勢，再打開 app。射線從你最後捏合的那隻手射出，
  拇指和食指捏一下就等於按扳機，可以點選單、播放器的按鈕。
- **剛打開時沒有射線：** 先捏一下，app 知道你用哪隻手之後射線就會出現。要換手，用另一隻手捏一下。
- **手掌朝向自己時不會點擊：** 那是 Quest 叫出系統選單的手勢，這段時間 app 收不到捏合。
- **只有扳機有對應的手勢：** 搖桿、A/B 鍵、握把沒有手勢可以替代，快轉、倒轉、暫停、返回請用畫面上的按鈕。
- **控制器照樣能用：** 拿起控制器就跟原本一樣。
