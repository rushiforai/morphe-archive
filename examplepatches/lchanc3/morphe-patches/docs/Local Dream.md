# Local Dream 使用說明

## 安裝前要知道的

- **只支援 3.0.0-alpha.3。** Local Dream 有經過混淆，每一版的內部名稱都不一樣，沒驗證過的版本
  很可能套不上去。
- **不能直接蓋掉官方版，而且移除官方版會連模型一起刪掉。** patch 過的 APK 簽章不同，要先移除官方版，
  下載過的模型（動輒好幾 GB）會跟著消失，裝好後要重新下載。不想重下的話，用 Morphe 的 Clone app
  patch 另外裝一份。

## 批次放大

- **怎麼用：** 在「Image Upscale」畫面點 + 選圖時一次選兩張以上，就會開啟批次放大畫面。只選一張
  的話跟原本一樣。
- **要先有模型：** 批次畫面不能下載模型。第一次用請先選一張圖，從魔杖按鈕下載模型，之後批次畫面才
  選得到。模型和倍率預設沿用上一次的選擇。
- **按「Start」才會處理：** 處理中可以隨時按「Stop」，已完成的會保留，按「Resume」接著做剩下的和失敗的。
  處理中螢幕會保持亮著；手動關掉螢幕也會繼續跑，但有些廠牌的省電機制可能還是會把 app 停掉，
  遇到的話把 Local Dream 的電池設定改成不限制。
- **結果在按「Save」或「Save all」之前只是暫存：** 離開批次畫面、或是再選一批圖，沒存的結果就沒了（離開前會問）。
  存到相簿的 `Pictures/LocalDream`，檔名是原檔名加上倍率，例如 `IMG_1234_x4.jpg`。
- **檔名變成一串數字？** 系統的相片挑選器為了隱私不會告訴 app 真正的檔名，只給一串編號，存下來就會是
  `1000040691_x4.jpg`。要保留原檔名，在挑選器右上角的選單點「瀏覽」，改從檔案裡選圖。
- **檢視：** 左右滑或點下方縮圖切換；兩指縮放、點兩下放到 1:1 看細節；按住「Hold for original」可以在同一個
  位置比對原圖。
- **連線裝置模式不支援批次：** 用另一台裝置的模型時，選多張只會處理第一張。
- **照片方向：** 批次放大會依照片的 EXIF 轉正再處理，所以直拍的照片結果也是直的（原本的單張放大不會）。
