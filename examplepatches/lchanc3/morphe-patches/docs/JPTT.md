# JPTT 使用說明

## 安裝前要知道的

- **不能直接蓋掉官方版。** patch 過的 APK 簽章不同，要先移除官方版，或是用 Morphe 的 Clone app patch 另外裝一份。
- **Disable Play license check 一定要勾。** 沒勾的話，app 一打開或用到一半就會跳出
  「Something went wrong」，只能按 Close 關掉。
- **用 Clone app 時，它的 Update providers 和 Update permissions 都要開**，不然裝不起來。
  開了 Update providers 之後拍照上傳會壞掉，所以 **Fix photo upload in clones** 也要勾。

## 常見問題

- **切到別的 app 就斷線：** 是手機的省電設定把背景連線切掉了，不是 patch 或 PTT 的問題。
  到「應用設定 → JPTT → 省電策略」改成「無限制」，電池最佳化也關掉；Clone 版和官方版要各設
  一次。**Reconnect on return** 只是讓你切回來時馬上重連，不能防止斷線。
- **文章列表一直卡在「載入中」：** PTT 新增的畫面控制碼 JPTT 看不懂，3.8.5 也只修好一部分，
  所以 **Fix article list loading** 在 3.8.5 還是要勾。
- **PTT 十月的介面改版可能讓 JPTT 卡住：** PTT 預計 10/04 與 10/18 更改標題列和列表左下角的
  文字（例如「文章選讀」改成「文章列表」），而 JPTT 是靠這些文字判斷目前在哪個畫面。改版後
  進看板、收信、我的最愛都可能卡住，要等 JPTT 官方更新，patch 目前擋不住。

## 功能說明

- **設定在哪裡：** JPTT「設定」的最後一頁「Morphe」。Morphe Manager 裡填的數字只是預設值，
  裝好後可以在這裡改，不用重新打包；圖片快取上限要重新啟動應用程式才生效。這一頁也能匯出、匯入
  JPTT 的全部設定（不含帳號密碼）。
- **搜尋紀錄長按：** 在看板內的搜尋對話框長按關鍵字，可以刪除這筆、清除全部，或建立桌面捷徑。
  捷徑會直接打開看板並套用那個搜尋，外面「最近搜尋」分頁建立的捷徑也一樣；需要 Android 8 以上。
- **圖片連結：** 只改預覽圖，文章裡的連結不變。imgur 的影片（`.mp4`、`.gifv`）只會顯示一張
  靜止畫面，多張圖的相簿只顯示第一張。
- **去除廣告：** 廣告完全不會被請求，而不是下載後再藏起來，所以不會留下空白版位。
