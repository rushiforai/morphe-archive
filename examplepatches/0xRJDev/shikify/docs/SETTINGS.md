# Shikify Settings

Open Boost Settings → Shikify Settings, immediately below Morphe. The classic Appearance screen has a shortcut. A replacement settings homepage can also expose its native/classic settings fallback.

- Glass & appearance: glass toggle, dialog blur, blur strength, glass tint, side panel, empty screens, notices, floating menus, inline flairs and search page.
- Comments & gestures: dynamic header, remembered thread position, comment and post swipes, haptic feedback and full swipe travel.
- Media viewers: explains stock black backgrounds, image/gallery pills and native video controls. Old dimming preferences are retained in storage but no longer used.
- Performance: blur refresh interval. Larger intervals reduce capture work and do not change the display refresh rate.
- Loading: parallel loading, no startup queue, instant login, smaller first page and improved online check. Restart Boost for these to apply.

A switch only appears when its patch was selected. HTTP/2 Reddit connection, Sliding screen transitions and Use system font are chosen when you patch and have no switch.

Colours and light/dark appearance follow the activity that opens settings. Back returns from a subpage to the root, then to Boost. Changes apply on return to the relevant screen; switches only control selected runtime patches. Compiled theme/layout edits require repatching to remove. Existing values are retained; the duplicate native Appearance controls have been consolidated here.

Morphe and Patcheddit remain separate sources, so keep their patches selected when rebuilding.
