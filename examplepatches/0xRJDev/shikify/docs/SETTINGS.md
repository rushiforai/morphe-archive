# Shikify Settings

Open Boost Settings → Shikify Settings, immediately below Morphe. The classic Appearance screen has a shortcut. A replacement settings homepage can also expose its native/classic settings fallback.

- Glass & appearance: glass toggle, dialog blur, blur strength, glass tint, side panel, empty screens, notices, floating menus, inline flairs and search page. Blur strength and glass tint are dimmed while glass is off.
- Comments & gestures: dynamic header, remembered thread position, comment and post swipes, haptic feedback and full swipe travel.
- Media viewers: explains stock black backgrounds, image/gallery pills and native video controls. Dimming preferences from older versions still apply, though they no longer have a setting.
- Performance: blur refresh interval. Larger intervals reduce capture work and do not change the display refresh rate.
- Loading: parallel loading, no startup queue, instant login, smaller first page and improved online check. Changing a switch offers a restart dialog. Restart applies the saved changes, and Later keeps them for the next launch.

Notices, Floating menus, Inline flairs, Search page and the Loading switches only appear when their patch was selected. HTTP/2 Reddit connection, Sliding screen transitions and Use system font are chosen when you patch and have no switch.

Material loading animation is selected when patching and has no switch. It uses expressive shapes for feed and comment loading, pull-to-refresh, load-more wheels, subreddit search, album loading, video buffering and circular progress dialogs. Download, web-page and poll progress retain their native bars.

Colours and light/dark appearance follow the activity that opens settings. Back returns from a subpage to the root, then to Boost. Changes apply on return to the relevant screen; switches only control selected runtime patches. Compiled theme/layout edits require repatching to remove. Existing values are retained; the duplicate native Appearance controls have been consolidated here.

Morphe and Patcheddit remain separate sources, so keep their patches selected when rebuilding.
