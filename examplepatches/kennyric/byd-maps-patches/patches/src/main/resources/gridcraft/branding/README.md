# GridCraft branding artwork

The supplied Microsoft Excel logo is converted into an adaptive launcher icon: the full-colour
logo sits on a white background with its longest side at 48dp, inside the 66dp safe circle of the
108dp canvas. The logo's white "X" is the monochrome layer used for themed icons (36dp). A
192×192 legacy launcher PNG is included. `sources.json` records the original filename and SHA-256
digest.
