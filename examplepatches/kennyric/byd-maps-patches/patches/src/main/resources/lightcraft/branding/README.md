# LightCraft branding artwork

The supplied Adobe Lightroom icon is converted into an adaptive launcher icon. The light-blue
"Lr" glyph (#31A8FF) becomes a 432×432 foreground (18dp inset in the 108dp canvas, original
proportions kept) that also serves as the monochrome layer. The background is the icon's solid
navy (#001E36). A 192×192 legacy launcher PNG is included. `sources.json` records the original
filename and SHA-256 digest.
