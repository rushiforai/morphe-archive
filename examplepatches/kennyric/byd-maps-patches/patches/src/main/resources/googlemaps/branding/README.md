# Google Maps branding artwork

The six transparent PNGs supplied for this patch are bundled byte-for-byte.
`sources.json` records their filenames and SHA-256 hashes. Each style can be
selected on a light (#FAFAFA) or dark (#171A21) Android drawable background.
Android scales the foreground within an 25.9259% inset on its 108dp adaptive icon
canvas; no artwork is redrawn or recolored. The supported Maps target requires
Android 10 or newer, so only an adaptive launcher icon is needed.

Google Maps and the associated marks belong to their respective owner.
These are user-selected launcher variants and do not imply affiliation.
The existing Maps patch credit remains in the repository documentation.
