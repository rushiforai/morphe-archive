# AliExpress

**App version:** 8.180.1 · **Build:** 80005998 · **Original file:** APK

[Download original app](../guides/downloads.md#local-original-inputs){ .md-button .md-button--primary }

Select the supplied single APK in Morphe Manager. Version 8.180.0 build 80005997 remains supported as well.

## Patches

| Patch | Default | What it does |
| --- | --- | --- |
| **Disable analytics** | On | Stops usage statistics and affiliate link reports. |
| **Disable update prompts** | On | Removes automatic update dialogs. The Version row in Settings still checks manually. |
| **Enable image saving** | On | Shows the save button in the full-screen image viewer. |
| **Fix dark mode** | On | Fixes screens and web pages the built-in Dark mode leaves white. Requires Android 10 or later. |
| **GmsCore support** | On | Signs in through GmsCore instead of Google Play Services. Requires GmsCore to be installed. |
| **Remove promotional popups** | On | Stops coupon offers opening over Home and search results. |
| **Remove promotions and games** | On | Removes campaign and coupon offers, channel-only deals, registration gift prompts, games, coin offers and entries, and the Fast & Free tab. |
| **Remove sponsored items** | On | Removes paid placements from search results and product feeds. |
| **Skip splash promotions** | On | Skips the full-screen promotion shown at launch. |
| **Spoof signature** | On | Restores product loading on patched installs. |

## Before using

The new promotion filter targets 8.180.1 build 80005998 and has not been released yet. Removing identifiable paid placements does not establish that the remaining server ranking is unbiased.

The signature spoof keeps product loading and account functions working after patching. Google sign-in needs a compatible GmsCore installation. Versions 8.180.0 build 80005997 and 8.180.1 build 80005998 are supported. Use the matching original file for each version.
