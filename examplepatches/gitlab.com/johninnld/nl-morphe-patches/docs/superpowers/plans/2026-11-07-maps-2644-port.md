# Maps 26.44 port

Date: 2026-11-07
Branch: `port/maps-2644`

## Why

The Dutch App Patches Maps bundle is derived against 26.43.05.1002020710.
Only **Use the system voice for navigation** declares 26.44.06.1006895251.
On 26.44, 20 of 28 patches fail at fingerprint resolution or at the first
hard-coded 26.43 class/field.

## Confirmed roots

### Account sheet / Customization

`CustomizationScreenPatch.kt` resolves the 26.43 row holder `Lolm;` and the
row builder `Lbqxa;` / `Lbqwy;`. In 26.44:

- `Lolm;` is now an unrelated interface.
- the settings row holder is `Lomf;`
- the row model/builder is `brdm` / `brdk`
- the action type enum is `brdj`: `a` INCOGNITO, `b` CUSTOM, `c` SETTINGS,
  `d` PRIVACY_ADVISOR, `e` HELP_AND_FEEDBACK
- the context field is `nxh`, not `nwm`

The same change breaks `Account sheet cleanup`, `Trim account menu`,
`Remove sign-in prompts` and every dependent patch.

### Speed cameras

`Speed cameras` fails through `BytecodePatch@920269192`; the root fingerprint
must be located before its dependents (`Flock cameras`, `Avoid Flock cameras`,
`Waze alerts`, `Zoom controls`, `Power saving mode`) can run.

## Method

1. Keep `26.43` working; select class names by `context.packageMetadata.versionName`.
2. For each root, add a 26.44 branch with the new class/field names.
3. Replace hard-coded class names with structural fingerprints where possible.
4. Test each patch individually with the CLI on the 26.44 APKM, then all 28.
5. Only then add 26.44 to `Constants.COMPATIBILITY_MAPS` for the whole bundle.
