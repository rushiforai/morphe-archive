# Stickman privacy and Angry Birds 2 paid-content follow-up

Owner validation identified that the paid Shop button was hidden in Angry Birds 2 while GUIShopScreen.Init still explicitly activated the paid content when opened from the gem counter. The initializer also explicitly hid Bonus. The revised native plan changes those two visibility arguments and initializes the active tab to Bonus before those calls; the existing click/switch/visible-tab hooks remain. Paid Treasure Pass reward widgets are hidden through their two paid-only setters, and SetTicketButton hides its purchase button. Free rewards, quests, entitlements and reward-claim calculations are not changed. Friends was owner-approved as-is: both its native plan and the shared ELF writer remain byte-for-byte unchanged at source level from f9d253754252.

Stickman ad entries are now replaced completely, including their null-listener branch. Both token getters are blocked using the SDK's existing no-token completion adapter. This token control is a dependency of both Hide ads and Disable tracking. The local AndroidX Unity Ads initializer is retained because in this input it only establishes local context and timing, and removing that context can break SDK construction; it is not an independent upload in the inspected body.

Explicit Facebook app events are stopped at enqueue, flush, the private/public timer flush boundary and persistence. Authentication APIs remain outside those replacements. Native metadata verifies void and AnalyticsResult/Boolean return contracts. The game analytics identity initializer disables Unity's native UGS analytics flag, game event enqueue and flush are suppressed, Unity Services analytics collection/record/custom-data/flush entries are suppressed, and legacy Unity analytics event/transaction calls report AnalyticsDisabled rather than a fabricated success. Archived-event flush reports false. Gameplay time/FTUE state and PlayFab account/save/inventory APIs are not replaced. Versus core SDK tracking/flush entry bodies are already no-ops in this input; its reward-related paths are kept unchanged.

Every native edit requires the exact original ARM64 library digest and all preimages before writing. Boolean and enum constants were verified from the shipped metadata, and the SDK no-token adapter was verified in original smali. Native scratch directories were removed. Complete grouped verification and real-input/native/DEX checks are required before a new immutable signed review MPP. Owner phone validation remains the acceptance and four-game release gate.

The final pass helper hides both the ticket buy button and its VIP overlay button. Complete verification passed, followed by the canonical Android gate after the final overlay payload adjustment. Stickman and Angry Birds 2 were rebuilt successfully from their real original APKS using existing CLI validation in FULL bytecode mode, without installation. Rebuilt Stickman DEX and native entries were inspected; final AB2 native payload, initializer arguments, paid widgets, ELF layout and content-pack catalog were verified. These preflights do not replace normal Morphe phone acceptance. Compact receipts and logs are retained in `.tools/artifacts/stickman-ab2-followup-20261123/`.
