## Structural findings (jadx decompilation of both inputs)

Both inputs keep the audited 2.4.0 shapes:

- The framework queue publication is native: `PlaybackService` calls
  `Landroid/media/session/MediaSession;->setQueue(Ljava/util/List;)V` (null and list paths),
  built from `MediaSessionCompat$QueueItem` rows.
- The browser root (`media browser: empty root for ` diagnostic, UID lookup through
  `getPackagesForUid`, object return) and the UID-checked children/search caller
  (boolean, no parameters) are unchanged.
- The shared browse permission predicate is a non-static `boolean(String)` calling
  `getApplicationInfo(package, 0)` plus `Set.contains`, admitted by the own package, a Google
  car-host allowlist, or the system-app flag. Orpheon adds one branch that also admits
  `com.waze` when the Play Store installed it; the audited shape is unchanged.
- Children (`d(String, result)`) and the search dispatch (a `Runnable` containing
  `onSearch must call detach() or sendResult() before returning for query=`) share the same
  UID-checked caller, in `defpackage/d35` (Myspoti 2.4.1) and `defpackage/if5` (Orpheon).

## Changes

- **Android Auto Up next** accepts Myspoti 2.4.1 / 1175 and Orpheon 1.0.0-beta.1 / 1173.
  Orpheon is declared as a separate compatibility entry with its own signer, selected through
  the original-input variant mechanism. The native-queue branch now keys on the set
  {2.4.0, 2.4.1, 1.0.0-beta.1}; 2.3.0 keeps the audited queue export, whose reflected members
  were only ever verified on 2.3.0 and are not claimed for the new inputs.
- **Gearslip personal library** is replaced by **Allow any Android Auto host**, following the
  repository's Flitsmeister/Waze pattern: default on, no options, no trusted-host whitelist.
  It prepends admission to the discovered browse permission predicate, guarded by its own
  marker; the browser root and children/search caller still prove UID ownership of the claimed
  package, and the shared `androidAutoHostVisibility` resource patch adds package visibility.
  The `gearslip-myspoti` extension is removed with it. When Up next already governs admission
  with its own (possibly restricted) host list, the new patch leaves that policy in place;
  whichever of the two runs later stacks deterministically, so an explicit Up next host list
  always decides browsing.
- **Custom branding** accepts the Orpheon package with the same bundled icons and name option.
- Documentation, catalogue mapping and the branding matrix follow: Myspoti page at 2.4.1/1175,
  a new bilingual Orpheon page, download rows, and the Gearslip music guide naming the new patch.
