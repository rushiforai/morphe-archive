# Gboard 18.8 beta — what every feature does

One entry per patch in the bundle, grouped the way Gboard's **Patches** screen groups them.
"Where it lives" = where the switch or row appears after patching.

---

## Voice typing

### Rambler voice typing
Adds Google's server-side **Rambler** as a second voice engine: Gboard settings → **Voice typing**,
next to Standard voice typing (which Parakeet renames to *Parakeet*). Rambler uploads your speech,
returns finished text, and carries out spoken edits ("make this shorter"). Standard/Parakeet stays
the default; nothing switches on its own. Requirement for the six Rambler features below.

### Rambler personal dictionary
Adds **Voice dictionary** under Voice typing: Gboard's own voice-correction list (add, import,
export). Every dictation sends the list to Rambler so it spells those names and words correctly.

### Rambler contact names
Fills that same voice-correction list with your contacts' names. Needs Gboard's contacts permission
and Rambler personal dictionary. Deleted names are not re-added; new contacts arrive on the next
Rambler start. Tells Google which of your contacts you dictated.

### Rambler custom instructions
Adds **Custom instructions** under Voice typing → Rambler. Your text is *appended* to Rambler's own
instructions (not a replacement), applied to style only — spelling, punctuation, vocabulary, tone —
for example "Write every number in digits."

### Rambler cursor-aware editing
Sends Rambler the text **after** the cursor too, so spoken edits reach the whole field and dictating
mid-text fits in. With a selection, only the selection is sent and the rewritten result is selected
again, ready for the next edit.

### Rambler stop after silence
Rambler finishes by itself after 3 s of silence and keeps the text, like tapping ✓. Adjustable
(3/5/8/10 s) or switchable off under Voice typing → Rambler → Stop after silence.

### Rambler toolbar & revert extras (18.8)
Three Rambler paths, enabled when this patch is selected:
- **Overflow menu** — adds the overflow button to the floating Rambler toolbar (`kxm`), where the
  secondary toolbar actions live.
- **Keep rewritten text on revert** — when you revert from the full transcript to the cleaned-up
  text, keep the rewritten version instead of discarding it.
- **Lite edit history** — passes edit history into a Jetson Lite request; it has no effect unless the
  Lite path is active.

### Rambler automatic retry (18.8)
Turns on Rambler’s stock automatic retry for eligible recognition errors. Rambler can reuse audio
from the current dictation and may send it to Google again. This patch is selected by default and
requires Rambler voice typing. Toolbar and revert extras are separately selectable.

**Spoken emoji matching** remains out of this patch set. In both original 18.8 APKs, the locale
gate is read when constructing the matcher. A dex reference scan found no reads of the matcher
from the Rambler transcript path and no reads of the other three emoji matching flags. This
does not establish a working path that an override could enable.

**Parakeet equivalents** would belong in independent local patches. Parakeet already keeps the last
partial if the final decode is empty, and its dictionary path can confirm a correction with a
second decode using a different hotword set. An identical retry on the same audio has no proven
benefit. A useful recovery patch would need a distinct local decoding strategy and a failing sample
to validate it. Spoken emoji commands could be evaluated separately at final transcript commit, with
explicit phrases and locale tests to protect literal dictation.

### Advanced voice typing (NGA)
Enables Gboard's NGA dictation stack: `enable_nga`, the consolidated speech-stack features, split
feature-module install and SODA long-form dictation.

**The patch now bundles the dictation payload.** Gboard refuses NGA without
`libdictation_jni.so` ("Dictation is not enabled because native split is not loaded"), and that
library normally ships in the Play feature split `dictation_feature_split`. It cannot be placed in
`lib/<abi>` (the APK declares `extractNativeLibs=false` and the packager deflates added entries), so
it travels as `assets/dictation/arm64-v8a/libdictation_jni.so`; the extension extracts it, marks it
read-only (Android refuses a writable file), loads it, and points Gboard's readiness alias at
`integrated_shared_object`. Both ABIs are bundled (arm64 4.17 MB, armeabi-v7a 2.95 MB, each from the matching Play bundle).

**The Standard page's switches moved into the patch settings.** Gboard's stock
`enable_enhanced_voice_typing*` rows only exist on the Standard page, which the Parakeet patch
repoints, so leaving them there promised behaviour the substituted engine does not provide. They are
hidden from that page and offered under **Patches → AI & Voice → Standard voice typing settings**
(writing Gboard's own default preferences).

**There is no third "Advanced" entry.** Gboard 18.8's "Dictation type" selector
(`setting_voice_unified.xml`) has exactly two entries: **Rambler** (`dictation_type_jetson`, the
advanced/agentic engine) and **Standard** (`dictation_type_traditional`). "Advanced voice typing"
names the engine behind Rambler, not a row. With this patch (and the payload bundled) the Rambler
dictation type can use it when the engine is eligible. The marker exposes Google TTS/Scribe
package queries. Two legacy sub-patches are excluded
because their 18.8 targets are stale; stock Chinese input is unaffected.

### Rambler app context
Sends Rambler the name of the app you are dictating in and the field's hint, so tone can follow a
chat, an e-mail or a search, and Custom instructions can depend on the app. Privacy cost: Google
learns which app you type in.

### Use Bluetooth microphone
Shows Gboard's own **Voice typing → Use Bluetooth microphone** row, which stock hides because
`enable_use_bluetooth_setting` is false. Two switches matter and they do different things:
- the **patch** (and its extension switch) makes the row visible by exposing the stock flag;
- the **stock row** then decides routing, via `anis.c(Context)` and Gboard's own Android-version and
  input-device checks (wired/USB preferred, car devices can be excluded).

Making the row appear does not prove the recording comes from the headset; that needs a real
input-capable headset and device evidence.

### Parakeet voice typing
Adds **Parakeet voice typing** under Voice typing. After downloading NVIDIA Parakeet (Moondream's
Parakeet Ultra or TDT v3), the microphone key transcribes **on the phone** and detects the language
per sentence — Dutch, English and 23 more — without switching keyboards. Also gives the patched
Gboard the Parakeet launcher icon.

### Parakeet personal dictionary
Lets Parakeet use the same Voice dictionary: it favours those words while listening and only accepts
a sound-alike correction when a second listen agrees. Needs a ~2 MB spelling model. Requires Parakeet
voice typing **and** Rambler personal dictionary (they share the list).

## Writing and text

### AI Writing Tools
Turns on Gboard's **Writing tools** (the magic-wand chip): rewrite and tone changes on selected text,
in every language and keyboard. A re-signed build normally never receives the flags or the v2 intent
routing; the patch forces the flags and repairs three init points.

**Proofread / Auto Fix is not part of the 18.8 port.** 18.6.3 routed it through a builder that 18.8
replaced with a flag-built intent set, and the old acceptance shim returns immediately here. Auto Fix
is outside this port, and whether a Proofread entry appears at all is unverified — do not treat it
as working.

### Enable OCR / Scan Text
Adds Gboard's **Scan Text** camera entry point and runs OCR with an engine bundled in the patch, so
it works without Play Services (which refuse a re-signed client). **Latin script only.**

### Simple Calculator
Type `12*(3+4)` in any field and the suggestion row shows the equation and its answer, scrollable for
longer expressions.

### Toolbar Editing Buttons
Adds **Select All, Copy, Cut, Paste** to the toolbar/menu next to the existing buttons.

## Clipboard

### Clipboard Enhancements
Controls **retention time**, **item limit**, **preview lines**, **countdown/creation-time labels**,
**order index** and **column count** of Gboard's clipboard history, and unlocks the grid layout.

### Web Clipboard
Adds the **phone-hosted Web Clipboard**: a local web page (FTP/HTTP server on the phone) where you
can read and push clipboard items from a desktop browser, with pairing, a Quick Settings tile and
optional LAN access.

### Incognito Mode Toggle
Adds an **Incognito** toggle to the access-point toolbar and lets you decide whether clipboard
history and voice typing are available while incognito is on.

### Beta features (18.8)
Five gates that Gboard 18.8 ships off by default, each with its own switch under **Patches → More
settings → Beta features**, plus a master switch:
1. **Plain-text quick-paste chip** — a second clipboard chip that pastes a plain-text clip in one tap.
2. **Floating clipboard chip** — shows the clipboard chip on a floating keyboard.
3. **Invisible resize band** — drag anywhere on the edge of a floating keyboard to resize it.
4. **Emoji2 provider** — uses the newer Emoji2 provider instead of the legacy one.
5. **New swipe-to-remove confirmation** — redesigned dialog when you swipe a suggestion away.

### Hidden flags (18.8)
Three flags Gboard keeps for internal builds, forced through Gboard's **own override store** so they
apply to the running keyboard without a restart (Patches → More settings → Hidden flags):
**app-specific word biasing** (`enable_dcontext_biasing`), **app-specific suggestion bar**
(`enable_dcontext_suggestion_bar`) and **square normalised search radius**
(`square_normalized_search_radius`).

## Keyboard look and layout

### Custom Theme
Lets Gboard's own theme screen **import custom ZIP themes** and browse downloadable theme packs
(verified by checksum). Adds the INTERNET permission; needs the signature bypass.

### Frosted Glass
Live **background blur** plus transparency for the keyboard, separate background/key opacity, and an
option to extend the blur into the navigation bar. Blur needs Android 12+.

### Rounded Keyboard Panel
Chooses **which corners** of the keyboard panel are rounded and sets top/bottom radii separately,
for whatever theme is active.

### Key Shape Selection
Restores Gboard's **Key shape** option in theme details, so a theme's keys can use the theme's own
shape instead of being forced square.

### G Logo on Spacebar
Shows a **built-in icon, your own PNG/WebP/JPEG, or a colored glyph on the spacebar**; size, single
color and hiding the language label are configurable.

### AMOLED dark keyboard
Makes the dark keyboard background **pure black** (including the wallpaper-following dynamic theme).
Light mode and the light theme are untouched. There is **no separate AMOLED tile** in Gboard's theme
picker; it recolours the dark palette that the dynamic theme uses.

1. When patching in Morphe Manager, make sure **AMOLED dark keyboard** is selected. If it was not,
   re-patch with it enabled and install the update.
2. In patched Gboard, open **Settings → Theme**, choose **Dynamic Color**, and tap **Apply**.
3. Turn on Android's dark theme, then reopen the keyboard in a text field.

**What to look for:** the background behind and between the keys is pure black (`#000000`); key faces
may stay grey or tinted. For an A/B test, switch Android back to light mode and reopen the keyboard —
the same theme returns to its light palette.

### Cursor trackpad mode
**Long-press the space bar** to use the cursor trackpad, with a lock mode for continued movement.

### Key Shape / layout extras
The **Keys, Layout & Symbols** group also carries the globe-key ignore interval, English uppercase
toggle, Zhuyin bottom-row weights, emoji/sticker/GIF footer order, emoji size, access-point count and
accessibility layout — those rows only appear when their patch is part of the build (see the note at
the end).

## System and plumbing

### Add Gboard Signature Bypass
Disables Gboard's own **APK signature whitelist** so a re-signed build passes the checks that look at
the signer (themes, some server features).

### Change package name
Installs the patched build as **`app.morphe.android.inputmethod.latin`**, side by side with the stock
Gboard most phones cannot replace. On by default.

### Custom branding
Sets the **app name and launcher icon**. The default is **Gboard Parakeet/Rambler** and the bundled
Parakeet icon. The name is what you see in Android's keyboard list. A fresh selection in Morphe
includes every public Gboard patch. Existing Morphe selections and option values stay saved.
The curated Hidden Flags start on and retain explicit Off choices. Bluetooth microphone routing
still follows Gboard's own Voice typing switch.

## Settings visibility

Patches settings shows menus for patches applied to the APK. A group with no available entries is
hidden. Options in an installed patch keep their toggles so the feature can be switched back on.
Configure Parakeet through **Voice typing → Parakeet voice typing**. Its dictation selector chooses
the recognizer and no longer opens the stock Standard voice settings page.

The follow-up build passed the grouped-settings and retry policy tests. Offline application to the
original arm64 and armeabi-v7a APKs confirmed that retry and toolbar extras carry independent
markers and that selecting retry alone emits the Rambler flag hook. With Parakeet selected, both
patched APKs retain the Rambler selector and the dedicated Parakeet settings entry. The stock
Standard submenu has no rows. The owner also reports verifying the feature set on a physical
OnePlus 15, including the AMOLED dark palette. The earlier AOSP emulator run remains separate
AMOLED evidence. The new default selections and launcher branding are a separate build check.
