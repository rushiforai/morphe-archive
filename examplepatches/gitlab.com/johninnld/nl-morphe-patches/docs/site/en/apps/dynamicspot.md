## Patches

| Patch | Default | What it does |
| --- | --- | --- |
| **Fix PairIP startup** | On | Restores the captured PairIP startup data and disables the integrity, license and VM checks so a patched app starts normally. |
| **Unlock Pro** | On | Unlocks the locally enforced Pro features (settings, animations, colors, music controls and battery-event rows), removes ads and skips the onboarding paywall without creating a Play purchase. |
| **Remove promotions** | On | Removes the BLYTZA card, rating row and nags, special offers and promotional notifications. |
| **Stop automatic app selection** | On | Newly installed apps are no longer added to the notification apps list in the background; you enable each app yourself. |
| **AMOLED theme** | On | True black dark mode for AMOLED screens. |

## Before using

Use the original 3.02 build 200155 APKM archive (Android 12L or newer) and select the complete archive, not just the base APK. The island popup itself is already black; the AMOLED patch changes the settings screens.

Unlock Pro does not create a purchase or entitlement on Google Play. The lockscreen live-activities list keeps its six-app limit; that limit also applies to the paid app in this build.

Validated on a phone with all five patches, including startup, locally gated settings and the removal of promotional surfaces.
