# Spotify

Use Spotify's native Android Auto browser with compatible car hosts, including DriveDeck.

**App version:** 9.2.0.2053 · **Build:** 148387875 · **Original file:** APKS

[Use your original APKS](../guides/downloads.md#local-original-inputs){ .md-button .md-button--primary }

Select the complete original archive in Morphe Manager, including the native-library and display splits. The base APK alone is not installable.

## Patches

| Patch | Default | What it does |
| --- | --- | --- |
| **Android Auto support** | On | Allows compatible car hosts to connect to Spotify's car service and browse Home, Recently played and Library. |

## Before using

Sign in to Spotify on the phone first. Only Android Auto support is offered for this version. Open a category and select an item to start playback in the car.

Keep the same Morphe signing key when updating an existing patched installation to preserve app data.
