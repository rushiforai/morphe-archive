# Fennec branding artwork

The supplied Firefox logo is converted into an adaptive launcher icon: the round logo sits on a
white background at 60dp, inside the 66dp safe circle of the 108dp canvas. The monochrome layer
used for themed icons is the fox and flame with the globe cut out (56dp). A 192×192 legacy
launcher PNG is included. `sources.json` records the original filename and SHA-256 digest.
