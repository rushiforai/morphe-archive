# Titanium Browser branding artwork

The supplied Chrome logo is converted into an adaptive launcher icon: the round logo sits on a
white background at 58dp, inside the 66dp safe circle of the 108dp canvas, so its transparent
separators read as white. The logo's silhouette is the monochrome layer used for themed icons
(52dp). A 192×192 legacy launcher PNG is included. `sources.json` records the original filename
and SHA-256 digest.
