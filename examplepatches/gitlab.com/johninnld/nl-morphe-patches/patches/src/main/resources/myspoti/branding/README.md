# Myspoti branding artwork

Six PNG images supplied for this patch are resized with Lanczos resampling:
192×192 for the legacy launcher and 432×432 for the adaptive foreground.
Adaptive foregrounds use an 18dp inset in the 108dp icon canvas. Their
background color comes from the source image's top-left pixel. The bundled
`sources.json` records each original filename and SHA-256 digest.

The Spotify name and logo belong to their respective owner. These choices
are user-selected launcher artwork and do not imply affiliation. Myspoti
remains the upstream application: https://github.com/kota-zo/myspoti (GPL-3.0).
No Myspoti source is copied or relicensed by this resource patch.
