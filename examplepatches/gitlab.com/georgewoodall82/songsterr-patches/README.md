# Songsterr Patches

Community Morphe patches for Songsterr Guitar Tabs & Chords (`com.songsterr`).

## ❓ About

Unlocks Songsterr Plus/Premium for free (multi-speed, solo/mute, loop, offline, no Plus paywall). Developed against 7.1.3 (2012282384).

### How to use these patches

Click here to add these patches to Morphe: https://morphe.software/add-source?gitlab=georgewoodall82/songsterr-patches

### 🛠️ Building locally

- Run `./gradlew buildAndroid`
- The built patches .mpp file is found in `patches/build/libs/patches-*.mpp`
- Patch the mpp file using [Morphe-Desktop](https://github.com/MorpheApp/morphe-desktop)
  like any other patch bundle.

See the [Morphe documentation](https://github.com/MorpheApp/morphe-documentation) for more information.
