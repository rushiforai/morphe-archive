# X Shim

This project shims legacy APIs (Piko) by adding a lightweight compatibility layer, such as restoring or remapping deprecated (or removed) code. This allows for partial backward compatibility without extensive refactoring of Piko.

> [!IMPORTANT]
> - **This compatibility shim is not a silver bullet! Root permission may be required (LSPosed CorePatch)**.
> - As this is a research project currently under development, it may not work in its current state.
> - This research project is provided "as is" without any warranty or guarantee of functionality, stability, or safety. **Use at your own risk**.

## Usage

[![Add to Morphe Manager](https://img.shields.io/badge/Add%20to-Morphe%20Manager-blue?style=for-the-badge)](https://morphe.software/add-source?gitlab=inotia00/x-shim)

1. Install [Morphe Manager](https://morphe.software) on your Android device.
2. Click the badge above or add `https://gitlab.com/inotia00/x-shim` as a patch source.
3. Enable `Expert mode` in settings.
4. Make sure the Piko patch is enabled.
5. Download original APKM file from **ApkMirror**.
6. Select the app and apply patches in Morphe Manager.

> [!IMPORTANT]
> - `Abstract shim layer` patch requires a JSON file generated by [ProGuard Patches](https://gitlab.com/inotia00/proguard-patches).
> - If generated mock data for the app version you want to patch exists in the [Piko Proguard Mock](https://gitlab.com/inotia00/piko-proguard-mock) repository, the patch will download it.
> - If you are offline or the generated mock data is not available, you must extract the JSON file via [ProGuard Patches](https://gitlab.com/inotia00/proguard-patches) and then enter the file path in the `Abstract shim layer` patch options (Root permission is required to get the JSON file).
