# RuStore patches for Morphe

Selectable privacy patches for the official RuStore Android app.

## Install

Add the [Morphe source](https://morphe.software/add-source?github=Freeman022026/rustore-privacy-patches) or use this source URL:

```text
https://raw.githubusercontent.com/Freeman022026/rustore-privacy-patches/main/patches-bundle.json
```

Use the official APK for the supported version, select patches, then patch and install with Morphe Manager. Allow notifications and background operation for automatic updates.

Morphe can reapply bundle updates to its saved APK. A new RuStore version requires its matching official APK.
