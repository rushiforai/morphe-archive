## Features

- **Privacy first** — removes trackers, analytics and crash reporting from supported apps.
- **Ad blocking** — blocks ads and unwanted content in supported apps.
- **Anti-detection** — disables developer-options, root, emulator and Play Integrity checks so patched apps run cleanly on modified devices.
- **Security tooling** — bypasses certificate pinning for intercepted TLS inspection.
- **Always up to date** — patches are rebuilt against the latest stable app versions.

## Getting Started

You'll need [Morphe Manager](https://github.com/MorpheApp/morphe-manager) (or [Morphe CLI](https://github.com/MorpheApp/morphe-cli)).

### Morphe Manager

#### Option A: One-click import (requires v1.11.0 or later)

Tap [this link](https://morphe.software/add-source?github=RabehX/rabehx-patches) to import RabehX Patches directly into Morphe Manager in just a click!

#### Option B: Manual import

1. Open the **Morphe Manager** app.
2. On the main screen, tap the **folder icon** in the bottom-left corner.
3. Tap the **"+"** icon next to **Patch Sources**.
4. On the *Add patch source* screen, select the **Remote** tab (selected by default).
5. Set the patch source URL to the following, then tap **Add**:

```
https://github.com/RabehX/rabehx-patches
```

> [!TIP]
> After importing, pick the app you want to patch, select the patches you need, and let Morphe build the modified APK.
