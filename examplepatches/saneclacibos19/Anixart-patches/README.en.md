### Always show other sources

This patch for Anixart 10.5 shows **Search for other options** even when the app would list only official services. The button starts Anixart's built-in search. The patch does not change network settings or guarantee that a provider's videos are reachable.

## 📱 Compatibility

- **Current release:** v2.1.1
- **App:** Anixart
- **Version:** 10.5
- **Patches:** Always show other sources, Remove ads

For Anixart 10.0, use the previous [v1.0.0 release](https://github.com/Error404rt/Anixart-patches/releases/tag/v1.0.0).

## 🚀 Installation

1. Install the original **Anixart 10.5**.
2. Open Morphe Manager.
3. Click [Open in Morphe](https://morphe.software/add-source?github=saneclacibos19/Anixart-patches) or add https://github.com/saneclacibos19/Anixart-patches manually.
4. Select **Always show other sources** and **Remove ads**.
5. Build and install the patched application.

## 🛠️ Development

This project uses the Morphe Patches Template and is built through GitHub Actions.

To build the MPP locally:

```bash
./gradlew buildAndroid
```

The output file is generated under patches/build/libs/patches-*.mpp.
