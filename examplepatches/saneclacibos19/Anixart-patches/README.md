### Always show other sources

Патч для Anixart 10.5 добавляет кнопку «Искать другие варианты» к результатам поиска, даже когда приложение показывает только официальные сервисы. Кнопка запускает штатный поиск. Патч не меняет сетевые настройки и не гарантирует доступность видео у конкретного источника.

## 🚀 Установка

1. Установите оригинальный **Anixart 10.5**.
2. Откройте Morphe Manager.
3. Нажмите [Open in Morphe](https://morphe.software/add-source?github=saneclacibos19/Anixart-patches) или добавьте вручную https://github.com/saneclacibos19/Anixart-patches.
4. Проверьте, что выбраны **Always show other sources** и **Remove ads**.
5. Соберите и установите пропатченное приложение.

## 🛠️ Разработка

Проект использует Morphe Patches Template и собирается через GitHub Actions.

Локальная сборка MPP:

```bash
./gradlew buildAndroid
```

Готовый файл появляется в patches/build/libs/patches-*.mpp.
