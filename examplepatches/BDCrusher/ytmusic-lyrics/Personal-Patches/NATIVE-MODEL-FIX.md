# Native Lyrics model correction — 0.2.3-beta.1

The phone screenshots reject 0.2.2-beta.3. Its Litho view listener/enabled/alpha workaround did not change the native Elements button state or action order. Its separately registered generic panel omitted the Music palette binding and mini-player snap state, producing the black video-sized sheet. Earlier compilation and simulations did not establish correct phone behavior.

## Current implementation

Both editions now hook Music's action-bar presenter immediately before its native Elements renderer. The patch resolves this from the exact VideoActionBarPresenter log string and structural method/field contracts. The native committed watch-response video ID gates availability; the existing shared repository still starts retrieval before any panel opens.

The actual `akrn` Elements payload is serialized, boundedly transformed, and parsed by the app's own protobuf parser with its generated extension registry. Its native action model is at fields 172660663/1/168777401/5/389155117. Generic actions use 10/461054335. The disabled Lyrics model has field14=3 (DISABLED), and field38 contains its unavailable toast. Clearing these restores the same absent/default enabled state used by normal native actions. Existing title, quote icon, native tonal/mono pill style, size, accessibility and all unrelated fields remain intact. Missing onTap gets the normal 169495254 wrapper and showEngagementPanel command extension138681778, WATCH identifier field10, exact tag `music_watch_lyrics_panel`. Existing native onTap is preserved. The actual Lyrics action moves immediately after the Like/Dislike action; there is no extra label, button, custom click listener or drawable tint.

Late availability resets the native presenter's dedup cache and refreshes it from its own committed watch response. Track identity, source result availability and feature enablement gate the edit. Clearing availability refreshes the original model. Unknown state, malformed or ambiguous structure fails closed with bounded diagnostics.

The app's registered native Lyrics definition is preferred. When a video has no native Lyrics definition, the patch clones its registered `music-related-panel` Music presentation, preserves the native background style37=4 (`USING_ENTITY_COLOR`) and entity key41, retains native header controls while replacing only its title, removes Related body content, and assigns the normal Music Lyrics identity. It requires those palette contracts rather than guessing a color. Both paths request native packed snap field21={4} (`BELOW_THE_MINI_PLAYER`) and allowReplace field20=true. Native command dispatch, panel controller, header, close/back and layout own the presentation. The transparent existing Better Lyrics renderer attaches only to the current native Lyrics model's content FrameLayout. Old global title/decor installation and view-level button overriding are disabled.
