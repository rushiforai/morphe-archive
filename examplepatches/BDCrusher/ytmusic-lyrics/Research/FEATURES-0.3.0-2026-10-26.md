## Shaders

Compared with Shaders 1.5.1 commit `88be3b81450b8d66bd8af445bf6062caac7d2747`. Uses actual Kawarp 1.3.1 and ALTCHA 2.5.0, pinned tarball integrity and original licenses. This is an Android host adaptation, not the browser extension injected into a phone.

Native artwork/background callbacks and the native engagement-panel identity/root own noninteractive surfaces inside the actual containers. Covers retain native layout, outline, visibility, scale and gestures. Native video hides its poster; the cover surface follows that visibility rather than covering or sampling music video. Lyrics backgrounds work without personal lyrics. Still artwork remains underneath on failure.

Independent animated cover, artwork background and background motion settings are under Morphe > Shaders, with speed, strength, saturation, dimming, transition, opacity, reduced motion and 24/30/60 FPS controls. Default is 30 FPS. Hidden/paused effects stop; reduced motion freezes them. Kawarp's own clock/rendering remains in charge. Animated-cover frames use the extension's 208x117 sampling, downsample2 and 250ms smoothing. Audio reaction, music-video sampling, browse/list effects, Tacet and floating windows are excluded.

Progressive MP4 files only; HLS is unused. New media requires unmetered Wi-Fi. Album loops sharing a media path share one file even when URL signatures differ. Atomic bounded downloads reject truncated/unsupported media; LRU defaults to512 MiB, adjustable128–2048 MiB. Temporary downloads are bounded separately. Graphics or media errors restore native still content.

## Permanent library and settings

Every source may offer results, including native YouTube and captions. One atomic schema2 payload per recording is retained indefinitely in app-private files. Valid timing determines syllable, word, line or plain quality; configurable source order breaks ties. Settings offer timing-first or source-first policies. Manual on-screen selection is separate. A refresh of the same winning variant cannot downgrade timing. Rich source metadata, agents, background vocals, timing, translations, credits and source URLs survive round trips. Failures do not erase saved lyrics. Atomic backups recover interrupted writes, and recognized positive legacy entries migrate lazily when their recording query is encountered. Legacy hash filenames do not reveal recording IDs, so unknown entries cannot be eagerly reassigned.

Native grouped preferences, switches, sliders/units, choices, reset actions and accessible16-entry source reordering remain directly under Lyrics. Shaders has its own page and storage controls. Storage cards show actual owned lyric, artwork, metadata and preference bytes; optional offline music/playlist metadata is separate. Lyric quality bars include counts and bytes. Colored segments open anchored callouts; text legends provide large accessible alternatives. Confirmed Clear saved lyrics also clears recognized legacy positives, preventing their return. Clear artwork cache never removes lyrics/music/settings/credentials. Storage failures remain readable in diagnostics.

## Playlist downloads

The new circular native header model follows the existing Download action, with a distinct stacked-list/download icon and accessible label. Original actions/commands remain intact. The displayed playlist supplies identity; currently playing media is never a fallback. Default leaves the real native whole-playlist command in control. External uses the existing selected app's ACTION_SEND text/plain review, including missing-app handling. In-app uses native authenticated browse/continuation futures and the existing local downloader. No API keys or private credentials are extracted and no playback queue is changed during enumeration.

Pages use the playlist shelf continuation, not the section continuation that loads recommendations. Partial/inaccessible lists and repeated tokens remain incomplete. Ordered positions, including duplicates/unavailable rows, persist atomically with individual outcomes. At most two downloads run, deduplicating audio files across positions. Typed completion callbacks retain failures for retry. Pause/resume/cancel-remaining keep completed files; interrupted batches offer review/resume on next open. Offline playlists reuse the existing local library/playback queue with original ordering. Private regression fixtures include20 first-page rows,100 continuation rows and an unavailable entry; the user's unlisted playlist identity is not exported publicly. Automated checks launch no real media downloads.
