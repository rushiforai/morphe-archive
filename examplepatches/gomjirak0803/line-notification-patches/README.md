Independent notification-control patches for **LINE `26.19.0`** (`jp.naver.line.android`, `versionCode 261900178`, `minSdk 30`), built for **Morphe Patcher 2.3.0**. This project is not authored by or affiliated with LINE, LY Corporation, or Morphe.

## Patches

All patches target `jp.naver.line.android` `26.19.0` (`261900178`) APKM. Including a patch in the APK is separate from enabling it: **every feature switch starts disabled inside LINE.** OpenChat, ServiceChat, call, and ongoing/foreground notifications are left untouched.

| Patch | Default | Behavior and scope |
| --- | --- | --- |
| **Notification settings** | `true` | Adds a localized **Notification patch settings** row below Profile in LINE's main Settings using LINE's own header, typography, and switch drawables. UI strings follow the app/system language across 7 locales (English default, Korean, Japanese, Traditional Chinese, Simplified Chinese, Thai, Indonesian; 77 keys), and adds a **Notification buttons** preset selector (including **Read · Quiet 1h · Reply** and a 1-hour local room snooze action). Supports Android 11–16 (`targetSdk 36` edge-to-edge window insets). |
| **Not Too Much Silent** | `true` | Converts LINE's existing **Mute / Unmute** toggle in the chat menu, **chat-list long-press menu**, and notification shade into a local silent mode: server push delivery stays enabled while this device posts on a silent `IMPORTANCE_LOW` channel (`line_notification_patches.silent.v1`). Includes opt-in **Alert on @mentions** (`@you` or `@All`) and **Alert on keywords** (up to 50 NFC case-insensitive keywords across text and file/location metadata) bypasses that use normal sound and vibration. Updates the chat-list muted bell icon and menu label locally without mutating LINE's stored model. Adds a localized **Hide notifications completely** menu item in the chat menu to invoke LINE's native mute + local suppression. Never bypasses OS-blocked notification channels. |
| **More Chat Info** | `true` | Renders a configurable number (`1–25`, default `25`) of recent local unread messages in chronological order using Android's public `Notification.MessagingStyle`, with LINE's native total unread count shown as `Room Name  [N]`. Distinguishes non-text attachments (`[Photo]`, `[Video]`, `[Sticker]`, `[Voice message]`, `[File] <filename>`, `[Location] <place>`, `[Contact]`, `[Call]`, `[Gift]`, `[Music]`) via `chat_history` metadata across notifications, heads-up/Brief popups (holding uncommitted pushes briefly until local save so initial popups show the resolved label), and LINE's chat list across all 7 locales. Includes opt-in **Show photo & sticker previews** (checks local `q41.a` / `f16.d` files first and loads uncached thumbnails on demand via LINE's built-in Glide loader through `LineCommonFileProvider`, making zero requests when off) and displays sender profile avatars in expanded notifications by reusing LINE's original notification icon (1:1) and reading LINE's local Glide cache only (`onlyRetrieveFromCache(true)`) for multi-sender group chats. |
| **No reply** | `true` | Disables system-generated contextual actions, generated replies, and smart-reply choices while keeping LINE's manual inline reply button and original `PendingIntent`. |
| **Mark as read** | `true` | Replaces the notification mute button on individual regular-chat notifications with a localized **Mark as read** action using LINE's native chat-list read updater (`tn3.e`) and room notification cleanup (`j34.h`). Marks the entire chat as read, holds the button until local storage catches up, and works independently of `More Chat Info`. Never added to multi-room summary notifications. |
| **Restore push registration** | `true` | **Included by default** for re-signed builds where Firebase Installations (`firebaseinstallations.googleapis.com`) rejects the re-signed certificate (`FisError: BAD CONFIG`). Replaces only the `X-Android-Cert` header value on the FIS request builder with LINE's original lineage-root SHA-1; does not modify Remote Config, LINE auth/messaging protocols, or Play Integrity. |

> Disabling **Not Too Much Silent** stops applying local quiet state and falls back to LINE's native settings. Rooms explicitly marked **Hide completely** also have LINE's native notifications turned off and remain off until unhidden.

## Usage in Morphe Manager

1. Use Morphe Manager supporting **Patcher 2.3.0** (verified on Morphe Manager `2.6.0`).
2. Open [Add source to Morphe Manager](https://morphe.software/add-source?github=gomjirak0803/line-notification-patches) or go to **Sources → + → Remote** and enter `https://github.com/gomjirak0803/line-notification-patches`. See [official Morphe patch sources guide](https://github.com/MorpheApp/morphe-manager/blob/main/docs/patch-sources.md).
3. For stable releases (`0.2.1+`), no **Experimental app versions** or **Pre-release patches** toggle is needed (enable **Pre-release patches** only if opting into `-dev` builds).
4. Supply your own official **LINE `26.19.0` (`261900178`) full APKM bundle** (do not use a standalone extracted `base.apk`) and apply the patches. All 6 patches are enabled by default (every in-app switch still starts disabled); enable **Expert mode** only if you want to deselect individual patches ([official Expert mode guide](https://github.com/MorpheApp/morphe-manager/blob/main/docs/patching-expert-mode.md)).
5. Install the patched APK. Because the signature differs from official LINE, an in-place overwrite over official LINE will fail. **Back up your chats and verify account recovery methods before uninstalling official LINE.**
6. Open LINE → **Settings → Notification patch settings** (below Profile) and enable the switches you want.
   * Rooms already muted natively on an older version or another device are not bulk-migrated. Run **Unmute → Mute** once on that room to move it to local quiet mode.
   * The silent channel is created without sound, vibration, or heads-up; any subsequent user changes in Android notification settings are respected by the OS.

## Building from source (Windows x64)

Releases are produced via GitHub Actions (`Actions → Release → Run workflow` on `main`) using the pinned standalone Python build scripts (the template's npm semantic-release workflow is unused). Requires Python 3.11+:

```powershell
python scripts/bootstrap.py
python scripts/build.py
python scripts/validate.py
```

* `scripts/bootstrap.py`: Downloads pinned JDK 21.0.13+9, Kotlin 2.4.21, Morphe Desktop 2.1.1, and Android SDK tools into `.tools/` with SHA-256 verification and Zip Slip checks. Never downloads or installs LINE.
* `scripts/build.py`: Runs `NotificationPolicy` unit tests (224 assertions), `ExtensionRuntimeTest` JVM behavioral checks (279 checks across 45 scenarios), and all 29 Python unit tests (`test_*.py`), compiles the Java extension and Kotlin patches, converts to DEX with D8, packages `patches/build/libs/line-notification-patches-<version>.mpp`, and verifies patch loading via Morphe Desktop.
* `scripts/validate.py`: Requires the two pinned original APKM files in `apk/` (not distributed in this repo), applies all patches with `--validate --bytecode-mode FULL`, and executes `ApkContractTest` (3,198 contract assertions each for ARM64 & Universal, plus 3,134 for `Mark as read`-only, 3,156 for `More Chat Info`-only, and 3,176 for `Not Too Much Silent`-only). Does not sign or install.
* `scripts/sign_test.py`: Optional local helper to sign the validated ARM64 APK using a persistent local key under gitignored `.tools/signing/`.
* Standard Gradle build files (`./gradlew buildAndroid`) are also retained for environments with GitHub Packages credentials.

## Privacy, data handling, and limitations

* **Read-only local inspection & opt-in thumbnail loading**: Reads LINE's local SQLite databases (`naver_line`, `contact`) with `SQLiteDatabase.OPEN_READONLY` and reads sender avatars exclusively from LINE's local Glide cache (`onlyRetrieveFromCache(true)`). Only when opt-in **Show photo & sticker previews** is explicitly enabled does `More Chat Info` load uncached photo, video, or sticker thumbnails via LINE's built-in Glide loader (and wipes staged preview files when disabled). No external servers, telemetry, background polling, or chat log exports exist in the extension.
* **Native user-initiated server calls**: Toggling room notifications (`yl3.e.t`) or pressing **Mark as read** (`tn3.e.e`) invokes LINE's existing internal handlers on explicit user action, which triggers LINE's normal server sync. Because quiet mode keeps server push subscriptions enabled and silences locally, **other devices (PC, tablet, secondary phone) may still show that chat as notifications enabled.**
* **Privacy & lock screen**: Respects LINE's **Show message preview** setting (no message body lookup when disabled), keeps `VISIBILITY_PRIVATE` and `publicVersion` redaction, and rechecks active account and read boundaries before posting.
* **Debug logging**: `LineNotifyPatch` logs are disabled by default (`Log.isLoggable`) and output only fixed stage names—never account IDs, chat IDs, message text, or exception messages.
* **No ban-safety guarantee**: Minimizing patch scope does not mean LY/LINE's Terms of Service permit modified or re-signed clients. **No guarantee against account restriction or service disruption can be made.** Use at your own risk and maintain backups.
* **No proprietary assets distributed**: Original/patched LINE APKs, APKMs, signing keys, tokens, and private logs are never published in this repository or its releases.
