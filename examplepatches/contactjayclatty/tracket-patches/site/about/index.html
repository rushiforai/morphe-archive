04 / Project information

Independent by design.

An open-source patch repository, maintained separately from the Tracket application.

About Tracket Patches

Tracket Patches is a community-maintained Morphe source focused on a particular build of the Tracket Android application. Compatibility, source code and implementation limitations are documented openly so that readers can understand exactly what is included.

Independent project. This website and repository are not affiliated with Tracket, Google Play, or Morphe. The patches do not confer official purchase entitlements. Please consider supporting the original Tracket developer through the official app.
