Build requirements

Run python build.py with Python 3 and JDK 17+. The build downloads checksum-pinned Morphe desktop 1.18.1 and D8 8.3.37, compiles the source, and packages Java classes, Android DEX, and bundle name/version metadata. The release workflow loads the DEX with Manager 2.3.0’s patcher on Android 35 before publishing.

Python 3 + JDK 17
python build.py

This website does not rebuild or modify the Java patch. Build verification and runtime verification must be performed separately.

Release checklist

  1. Confirm what app version is actually supported by testing and inspecting compatibility.
  2. Update the bundle version in build.py, the release workflow, and patches-bundle.json.
  3. Build, inspect, and validate the exact artifact you intend to publish.
  4. Publish the corresponding GitHub release tag and matching asset filename.
  5. Confirm the manifest download link and the advertised version match the release.
  6. Update website metadata and documentation to describe the actual supported build.

Validation records

Keep a release record of bundle version, target app version, Morphe version, build environment, patch application result, Android test conditions (if tested), and artifact SHA-256.

Only publish checksum values calculated from the actual release asset. Do not imply end-to-end device testing occurred unless it did.
