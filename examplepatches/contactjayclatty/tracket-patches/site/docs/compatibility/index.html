Remote source shows Unnamed

Use the copyable direct metadata URL in Sources → + → Remote. Delete an older failed entry before re-adding. This route and local import have been confirmed working by a user; repository-shortcut failure has not been reproduced independently.

Manager bundle loading

Bundle 1.0.0 lacked Android DEX and bundle name/version metadata. Use 1.0.1, refresh the remote source, or import the new local bundle. The rebuilt DEX passed discovery with Manager 2.3.0’s patcher on Android 35.

What to check first

Confirm that the expected app version and bundle version match the repository's published metadata. Be clear about whether the failure happened while processing the bundle or after an APK was modified, since those are separate stages.

Unsupported application version

This patch targets Tracket 0.9.38. A mismatch is a compatibility limitation, not evidence that the same patch will safely work on a different build.

Missing method or changed helper

The original Android app uses version-specific obfuscated references. A missing fingerprint or renamed class can cause the current implementation to fail or behave differently.

Successful patch, but restricted account

A successful patcher log does not indicate a verified Google Play purchase. A server can independently reject an account's access. The official app and legitimate purchase route are the supported way to obtain paid functionality.

Modified APK does not launch

Runtime compatibility is not guaranteed by patcher success. Do not disable Android security features to force an install. Use the official app if a modified build fails.

Reporting an issue

Report the Tracket version, bundle version, Morphe version, relevant nonsensitive error messages, Android version if applicable, and a minimal reproduction. Remove personal data from logs.
