# Integrating this patch into southstar21-patches

Target repository: [`southstar21dev/southstar21-patches`](https://github.com/southstar21dev/southstar21-patches) (GPL-3.0, Morphe).
Audited against `main` @ `30af566` (v1.4.0, 2026-11-24). File paths below are relative to that repo's root.

The three source files are already laid out in this repo in the upstream directory structure — copy them over, then apply the small edits below.

## 1. Copy the sources

```
# from this repo's root
DEST=/path/to/southstar21-patches

mkdir -p "$DEST/extensions/spotify/src/main/java/app/southstar21/extension/spotify/lyricsblur"
cp extensions/spotify/src/main/java/app/southstar21/extension/spotify/lyricsblur/LyricsBlurPatch.java \
   "$DEST/extensions/spotify/src/main/java/app/southstar21/extension/spotify/lyricsblur/LyricsBlurPatch.java"

mkdir -p "$DEST/patches/src/main/kotlin/app/southstar21/patches/spotify/layout/lyricsblur"
cp patches/src/main/kotlin/app/southstar21/patches/spotify/layout/lyricsblur/LyricsBlurFingerprints.kt \
   "$DEST/patches/src/main/kotlin/app/southstar21/patches/spotify/layout/lyricsblur/LyricsBlurFingerprints.kt"
cp patches/src/main/kotlin/app/southstar21/patches/spotify/layout/lyricsblur/LyricsBlurPatch.kt \
   "$DEST/patches/src/main/kotlin/app/southstar21/patches/spotify/layout/lyricsblur/LyricsBlurPatch.kt"
```

No `build.gradle.kts` changes are needed: the Spotify extension module packages every Java file under its source dir into `extensions/spotify.mpe`, and the patch module auto-discovers patch declarations.

## 2. Register the verified target (one edit)

`patches/src/main/kotlin/app/southstar21/patches/spotify/shared/Constants.kt` — add the 9.2.4.2644 target:

```diff
         targets = listOf(
             // The hook targets an unobfuscated lifecycle method and the bar is found by its
             // resource id, so newer versions will probably work too, but only this is verified.
             AppTarget(
                 version = "9.2.0.2053"
             ),
+            // Lyrics blur is verified against this build (Compose lyrics, p.* names).
+            AppTarget(
+                version = "9.2.4.2644"
+            ),
             AppTarget(
                 version = null,
                 isExperimental = true
             )
         )
```

Notes:

- Keep the catch-all `AppTarget(version = null, isExperimental = true)` — without it the patch disappears for every other version instead of showing up as experimental.
- The shared `COMPATIBILITY_SPOTIFY` is used by all Spotify patches; adding the verified target blesses the whole bundle for 9.2.4.2644. If you only want Lyrics blur verified there, leave it — the other Spotify patch (Liquid Glass) is unaffected either way, and the catch-all already offered everything as experimental.
- `patches-list.json` is generated by the release workflow — do not hand-edit it.

## 3. Nothing else changes

- No `SpotifyHooks` change: the patch is applied directly in bytecode; the extension is called from smali, not from the activity hook. `markSpotifyPatchIncluded` is not needed and must not be called (the extension has no `isIncluded()` gate by design).
- No settings menu integration (Spotify has no in-app settings UI in this bundle).
- No `SpotifyHooks`-style `.registers` updates, no new permissions, no manifest changes.

## 4. Build & verify

For the full step-by-step verification (Morphe Manager flow: build → add source → patch → on-device test matrix; optional device-free Morphe CLI gate), see `docs/verification.md` in the source repo. Short version:

```
GITHUB_ACTOR=<you> GITHUB_TOKEN=<token> ./gradlew :patches:buildAndroid --no-daemon
# produces patches/build/libs/patches-<version>.mpp
```

Expected: `BUILD SUCCESSFUL`. Warnings about deprecated dexlib2 calls are fine (there are none left — the code uses `DexFormatter`). As in upstream's own CI, an optional device-free gate is the Morphe CLI: `patch -e "Lyrics blur"` on the APKM and inspect `result.json` (`success=true`, empty `failedPatches`, patch in `appliedPatches`) — see `docs/verification.md` §A.

Then, on a device with Morphe Manager:

1. Add the `.mpp` (or your bundle source), pick Spotify **9.2.4.2644** `.apkm`, enable **Lyrics blur** (+ **Debug logging** for the first run), patch, install.
2. Uninstall the Play Store Spotify first (patched builds are signed with a different key).
3. Play a synced song, open lyrics in fullscreen and Now Playing, and watch logcat:

   ```
   adb logcat -c
   adb logcat -s LyricsBlur:D AndroidRuntime:E *:S
   ```

   Expect alternating `active=false … synced=true` / `active=true synced=true` lines. Unsung lines blurred, current line sharp, 200 ms cross-fade.
4. Turn **Debug logging** off before shipping. `debugLogging` defaults to `false`, so a release build needs no change — it just must not be enabled in the bundle you test with.

## 5. Failure modes (safe by design)

| Symptom | Meaning | Where |
|---|---|---|
| `PatchException: …Lp/ksh0;…` | Fingerprint missed (different build or different `.access flags`) | before any dex is written — nothing is patched |
| `error: Lyrics blur: expected one call …, found 0/2` | Anchor changed/moved | patch aborts, APK untouched |
| `error: …uses vN, vM, expected v0, v15` | `mtc1.f` call site re-registered | patch aborts, APK untouched |
| `VerifyError` on opening lyrics | Register allocation wrong for this build | report with `FATAL EXCEPTION` + post-patch smali |
| No blur below Android 12 | by design | — |

## 6. Commit / release conventions (upstream)

- Branch from `dev`, PR into `dev` (`feat/lyrics-blur` → `integration/…` style).
- Commit message: `feat(Spotify): Lyrics blur for the unsung lines` (semantic-release drives the version bump and the changelog from these).
- **Do not** edit `CHANGELOG.md`, `patches-list.json`, or `patches-bundle.json` — all auto-generated.
- Add a row to the Patches table in `README.md` and a section like the other Spotify entries, plus bump the Spotify badge (`Spotify-9.2.4.2644`). Suggested row:

  `| [Lyrics blur](#lyrics-blur-spotify) | Blurs the lyrics lines that aren't being sung and keeps the current line sharp. Fade needs Android 12+. Only for synced lyrics by default. | • Only for synced lyrics<br>• Debug logging |`

- In the PR description, state that on-device verification for 9.2.4.2644 is (or is not) done — do not mark it verified without running the §4 checklist.
