# VI patch implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans inline.

**Goal:** Remove audited advertising/tracking, suppress advertising consent UI and deliver usable Pro article bodies through the shipped app API.
**Architecture:** Four independent/default-on public controls, with Disable tracking including Hide ads and Skip consent screens including both. Read full articles scopes its extra native header to the publisher's premium article GET routes and leaves real auth/billing state intact. Retain original methods behind narrow source-guarded edits and genuine callback/failure paths.
**Tech Stack:** Kotlin/dexlib, original/emitted smali graphs and bounded native execution, JW JavaScript activation fixtures, Morphe FULL APK/report/signature/decode checks.
**Spec:** docs/superpowers/specs/2026-10-28-vi-design.md

## Global constraints
- `nl.vi`, version5.13.52/code910/minSdk32, original Play APKS; signer `3d508fb86865e48353a506426baa57319215103dc9bcc5b8f34fa870ebe492be`.
- Original base APK SHA256 `01d3bcbe0551da17e04c697ca0e7a6965cc07db4a55b510d334a730572d64974`; reuse existing original decode/indexes under SSD research. Do not import dexrefs.py, which rebuilds indexes.
- Native Scope.PREMIUM/header delivery succeeded for the two recorded Pro samples; keep usable Pro entries. Filtering is the fallback if reliable delivery cannot be implemented, not a cosmetic Pro-flag change.
- Preserve actual Authentication.isPro, NextAuth/IAP, receipt/billing/session state, purchases/restore, functional push/Auth/live scores/media licensing, preferences and real callbacks/errors. No fake consent or sent/delivered work.
- Work in the existing isolated SSD worktree, one local JVM; no phone install/reset or live acceptance claim. Keep all previous177 code/extension/native payloads unchanged except the containing DEX.
- No key, generated header, raw article body, user token or proprietary source copied into Git or output logs. Public proof consists of fingerprints, request paths and response shapes.

## Review focus
- Additional article headers cannot reach unrelated origins/endpoints/verbs; genuine Pro/IAP paths and request coroutine resume/error behavior stay valid.
- Article ID and by-path variants select premium content without altering account state, including clock zones/DST and native failures. Delivered content must reach the native parser/UI.
- Interstitial cancellation/cache/rapid taps retain exactly-once real navigation; display/banner suppression cannot leave reserved rows or a hanging callback.
- Explicit remote JW pre/mid/post/VMAP schedules and plugin configurations cannot bypass the audited activation gates; content setup/license/loading/error/resume remain native.
- Provider-time/restored measurement, identifier callbacks and manual consent re-entry cannot restart collection or fake consent; age-gate/functional shared services remain.
