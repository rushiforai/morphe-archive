## Video and advertisement callback safety

**Seen:** regular player loading first obtains token, then play response; it checks null, `canPlay`, IP restriction and credential requirements before building content (`.../VideoPlayerViewModel$loadData$1.smali:606,695,749-900`). VMAP is a separate step after that. Original no-ad branch at **1605-1633** uses null VMAP response and continues to content construction and `MetadataResult.Success` at **2023-2049**. `createAdvertisingConfig` has a supported null-URL branch returning an empty `AdvertisingConfig` (`VideoPlayerViewModel.smali:405-433`). **Inferred candidate:** force only this existing no-ad VMAP/config path; preserve token/play/metadata/DRM work and successful content publication. Do not return prematurely from the suspend loader or return a wrong model/Unit.

**Seen:** app mapper `PlayerStateMapperKt` registers Bitmovin ad-break start/finish, ad started/finished and quartile callbacks. AdBreakFinished sets `RtlPlayerState.adActive=false`, calls `PlayerEventListener.onAdBreakEnded` and the session tracker (`smali_classes5/nl/rtl/videoplayer/playerstate/PlayerStateMapperKt.smali:1513-1576,3197-3228`). Local UI JS maps ad/error/finished/skipped/break events; Bitmovin UI clears ad state on finished/skipped/error/source unload (`probe/assets/main-release.js:1`, `bitmovinplayer-ui.js:1`). `yu5.onAdsManagerLoaded` registers IMA event/error listeners; `cv5` handles loaded/completed state; legacy `av5` handles ad errors (`smali/yu5.smali:123,141,216,229`; `cv5.smali:1996,2125,2165`; `av5.smali:401`). **Inferred:** do not suppress callbacks after scheduling an ad; use the original no-ad input/config branch before scheduling.

**Seen:** DPG GAM and Xandr already query the consent adapter for custom permission `ad-free` and, when true, send **`Lrc;`** to `Lrd.a(Lqd;)V` instead of loading (`smali/pb0.smali:2323-2406`; `smali_classes5/ob0.smali:1382-1450`). `rc` extends failure/result type `pd` and describes an ad-free experience (`smali/rc.smali:1,82`). App callback `kg.a` routes `pd` to failure callback, emits height **0**, and sets completed state **true** (`smali/kg.smali:282-392`). **Inferred candidate:** reuse this exact scoped skip/result behavior, or filter AdItemModel before composition with matching layout handling. A bare `loadAd` no-op can strand height/loading state. Do not make every consent/custom-permission query return true.

**Seen:** Prebid request `oo9.a` suspends using `Lom1` and resumes through `bn8` callback (`oo9.smali:753-801`). **Inferred:** if suppressing a request at this level, return the correct completed no-demand result or retain callback/cancellation handling; leaving the request callback uncalled hangs its awaiting pipeline. Prefer the earlier placement/no-ad branch where possible.

**Seen:** a Bitmovin network callback repairs invalid Widevine-license URL/Authorization and always returns `CompletableFuture.completedFuture(HttpRequest)` (`VideoPlayerViewModel.smali:1430-1550`). This is functional DRM, not tracking, and must be retained. Never replace a required Future with null or blanket-block `api.rtl.nl`/media traffic.

## Candidate anchors, reuse and required regression evidence
