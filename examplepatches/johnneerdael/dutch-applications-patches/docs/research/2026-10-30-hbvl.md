The supplied HBVL split set supports the same four controls as Nieuwsblad
22.0.0 and DS Nieuws 22.0.0: Hide ads, Disable tracking, Skip consent screens,
and Hide Premium banner. The implementation ports the complete Nieuwsblad
controls with HBVL's own package and signing identity. The exact additional Shop
host `interactief.hbvl.be` comes from HBVL's shipped `domain_host_4` string.

## Comparison and selected controls

The independent original/retained-method inventory in
`tests/mediahuis_originals.json` contains 1,181 Nieuwsblad method contracts.
Every one exists in the HBVL base and has exactly the same canonical instruction
hash. This includes all 90 direct patch boundaries, onboarding state accessors,
account/billing/push preservation checks, SDK menu builders, group rendering,
and the original premium-card helpers. The existing verifier separately checks
switch case keys and destinations; it also passes on original HBVL.

The complete embedded reader asset `assets/index.android.bundle` is byte-for-byte
identical to Nieuwsblad, SHA-256
`6a56bf9f5104fb4c56e7f8d0bb9b04c790c54e230b304f73707c5f06af926fbd`.
The same four precise reader telemetry edits can therefore retain its existing
promise, initialization, event and timer contracts.

| Control | Matching shipped boundary and behavior |
| --- | --- |
| Hide ads | Three Kaching request/preroll methods return the SDK's actual `AdsAndTrackingDisabled` singleton. Sponsored-content, identified NYT and footer Shop groups use the same precise predicates and component-flow handling. |
| Disable tracking | Eighty native telemetry/identifier boundaries, collection-disabled manifest flags, eight advertising/referrer permissions, and four reader telemetry edits. Push delivery, account and billing bodies remain pinned. Includes Hide ads. |
| Skip consent screens | Four automatic consent/PayOrOk/coachmark boundaries; persist onboarding completion after installing the original navigation graph using the genuine settings setter. Includes Disable tracking and Hide ads. |
| Hide Premium banner | Three existing remote-config predicates hide paywall/subscription promotion. Article authorization, account entitlements and billing remain unchanged. |

The shared footer Shop predicate accepts an optional exact publisher hostname.
HBVL adds `interactief.hbvl.be`; Nieuwsblad and DS retain identical default
emitted instructions. The component must still be a singleton HTML group with
the exact `HTML | Webshop feed large` name, `data-allow-resize`, HTTPS, no URL
userinfo or explicit port, the exact `/optiext/optiextension.dll` path and a
nonblank `ID`. The host addition is supported by shipped domain configuration;
a corresponding live HBVL server widget has not been observed. Synthetic HBVL
fixtures adapt the existing captured Mediahuis renderer shape and test own-brand
positive, near-match and editorial cases. No Jobat/Zimmo-specific predicates
exist in the current sibling patch family.

## Validation

`python3 tests/verify_hbvl.py .local/tubantia-hbvl-20261030/hbvl/decoded`
passes all 1,181 original contracts, original switch mappings, the full reader
asset, manifest assumptions and precise publisher-promotion fixtures.

The HBVL verifier reuses the already pinned Nieuwsblad instruction and switch
contracts because their equality was established from this shipped HBVL base;
it replaces only the expected manifest package. This avoids duplicating the
same large snapshot while retaining checks independent of Kotlin patch source.

The complete Android patch bundle builds successfully with JDK 21 and the
installed Android SDK. The initial local failures were missing build environment
values: the Morphe settings plugin requires GitHub credentials and Maps key
generation requires the configured shared key. Existing authenticated owner
credentials and the prior generated Maps key were passed through the build
subprocess environment; no project build settings or credentials files changed.

The emitted APK matrix passes for each of the four individual controls and all
four together. Each run checks successful exclusive patch selection, the APK
signature, 1,181 original/retained method contracts, actual switch mappings,
manifest/permission changes, exact promotion fixtures and modified reader
