## Transport and native analytics

The existing `MainActivity$MyWebViewClient` receives both `shouldInterceptRequest` overloads. Allowed requests delegate to its actual `android.webkit.WebViewClient` superclass. `MainActivity.onCreate`, the original client assignment and complete existing navigation, history, start and finished callback bodies remain intact. The single finished-entry call performs optional cleanup without replacing the callback.

The policy parses HTTP/HTTPS with Android `Uri`, normalizes hosts with `Locale.ROOT`, and fails open for absent/invalid/non-HTTP inputs. Collector matches use exact host or dot-delimited subdomain boundaries:

- `insight.ftm.nl`: Matomo page/error/event instrumentation.
- `eventor.ftm.nl`: optional Eventor event uploads and ID updates.
- `glitchtip.ftm.nl`: Sentry/GlitchTip error collection.
- `diffuser-cdn.app-us1.com`: ActiveCampaign tracking loader/collector.

On exact `www.ftm.nl` and `www.ftm.eu`, `/activecampaign/event/create/view_comments/{numericId}` is separately blocked. Its observed consumer records comments visibility without a functional result consumer. Matching uses the encoded path and ASCII digits; encoded separators/digits, route extensions, query lookalikes and suffix-spoof hosts are preserved.

Only these static `MessagingAnalytics` methods are prefixed: `deliveryMetricsExportToBigQueryEnabled()Z` and `shouldUploadScionMetrics(Bundle)Z` return false; `logToScion(String,Bundle)V`, `logToFirelog(MessagingClientEvent.Event,Intent,TransportFactory)V`, and `setUserPropertyIfRequired(Bundle)V` return void. The observed methods export notification metrics/conversion properties. The Intent overload, setters, FirebaseMessaging, Installations, display/channel handling and token delivery are retained. Manifest flags are nonduplicated `delivery_metrics_exported_to_big_query_enabled=false` and `firebase_analytics_collection_deactivated=true`.

Native request filtering is installed before website scripts execute. The page-finished cleanup removes only `eventor_initialized`, `eventor_sessionId`, `eventor_userId`, `eventor_prev_at` and `eventor_prev_loggedIn`, on the two exact production hosts, with denied-storage errors handled locally. It does not replace the Storage API, poll, write consent, or change `FTM.user`, account state, `app_data` or native preferences. Temporary local ID creation before page completion remains possible.
