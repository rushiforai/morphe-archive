# Originele apps downloaden

Download het originele bestand voor je app en selecteer het in Morphe Manager om de patches toe te passen. Vergelijk de versie en het buildnummer met je app-pagina. Gebruik bij APKM en APKS het volledige archief.

[Bekijk de gedeelde downloadmap](https://buzzheavier.com/gnmtadlpn31g){ .md-button }
