# Woorden uit deze uitleg

| Begrip | Betekenis |
| --- | --- |
| API | Een manier waarop software met een dienst communiceert om inhoud op te vragen of gegevens te versturen. |
| BFF | Backend for Frontend: het aanspreekpunt op de server waarmee een app inhoud ophaalt en de levering daarvan afstemt. |
| CITS | Een verkeersdienst die via een verbinding posities en waarschuwingen uitwisselt. Bij Flitsmeister staat welke uitwisseling blijft werken. |
| FCD | Een onderdeel dat verkeersgegevens verzamelt. In de onderzochte code van Flitsmeister bundelt het GPS-gegevens, tijdstippen, snelheid en rijrichting. |
| FCM | Firebase Cloud Messaging, voor het afleveren van pushmeldingen. Analyse van die meldingen is een afzonderlijke functie. |
| Native | Gebouwd in de app of het platform zelf, in plaats van in een extern geladen webpagina. In technische onderzoeken kan het ook machinecode betekenen die door compilatie is gemaakt. De betekenis hangt af van de context. |
| UDS-header | Een blijvende herkenningscode voor tracking door de uitgever, die met een verzoek meegaat. Het NU.nl-onderzoek maakt onderscheid tussen deze code en de headers die de dienst nodig heeft. |
| Analytics | Meten en analyseren van gedrag, zoals geopende schermen of afgespeelde video's. |
| Attributie | Een handeling, installatie of aankoop toeschrijven aan een campagne of herkomst. |
| Publieksmeting | Tellen of schatten wie inhoud gebruikt en om hoeveel mensen het gaat. De methode kan meettags en onderzoekspanels combineren. |
| Collector | Code of een dienst die meetgegevens verzamelt. Dat kan code in de app zijn of een onderdeel op de server. |
| Endpoint | Een serveradres dat verzoeken ontvangt. Een adres om code te laden of instellingen op te halen heeft een andere rol dan een adres waar gebeurtenissen naartoe gaan. |
| Consent management platform (CMP) | Software die privacykeuzes toont, doorgeeft of vastlegt. |
| Cookie / lokale opslag | Manieren waarop webinhoud waarden bewaart. Dat kunnen herkenningscodes zijn. Dat een app iets opslaat, bewijst op zichzelf geen tracking. |
| Event / gebeurtenis | Een registratie dat een handeling plaatsvond, eventueel met context en codes. |
| Geofence | Een afgebakend geografisch gebied. Een app kan iets laten gebeuren wanneer een apparaat dat gebied binnenkomt of verlaat. |
| Hash | Een berekende weergave van een waarde. Dezelfde invoer kan bij herhaling herkenbaar blijven. |
| Identifier / ID | Een herkenningslabel voor bijvoorbeeld een account, installatie of sessie. |
| Pseudoniem | Herkenbaar aan een label in plaats van een direct leesbare identiteit. Gegevens kunnen nog steeds aan elkaar te koppelen zijn. |
| SDK | Software Development Kit: herbruikbare software die een ontwikkelaar in een app opneemt. |
| Sessie | Een periode waarin je de app of dienst gebruikt. De app of dienst bepaalt welke handelingen bij één sessie horen. |
| Telemetrie | Informatie over gebruik, werking of prestaties die een app of dienst doorgeeft. Kijk naar de precieze velden en het doel om te begrijpen wat er wordt gemeten. |
| WebView | Een ingebouwde browser in een Android-app. Die kan naast inhoud ook externe scripts laden. |

Bij [hoe tracking werkt](../learn/how-tracking-works.md) zie je deze begrippen samen in een voorbeeld. De [trackerprofielen](../trackers/index.md) leggen uit wat de genoemde diensten doen.
