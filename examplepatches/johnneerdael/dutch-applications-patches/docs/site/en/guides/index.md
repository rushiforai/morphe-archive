# Use the patches

[Download the original app files](downloads.md) for the supported versions.

Start with [installation](install.md), then [choose the changes you want](choose-patches.md). The patches have the same names here as in Morphe Manager, so you can find the right option.

For a patched app that is missing from the car launcher, follow [installation for Android Auto](android-auto.md). It includes the tested KingInstaller workflow and download links for KingInstaller and Shizuku.

If something fails, use [troubleshooting](troubleshooting.md). To understand how apps collect data, go to [Learn about tracking](../learn/index.md).

Need privileged access for an installer or utility? Start with [Shizuku setup and selected implementations](shizuku.md). For a television, use [Shizuku on Android TV](shizuku-tv.md).
