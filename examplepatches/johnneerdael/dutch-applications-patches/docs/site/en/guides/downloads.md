## Use your own original input {#local-original-inputs}

If you use your own original input instead of a hosted download, use an unmodified APKS archive exported from your own installation, matching the version and build on the app page. Include `base.apk` and every installed split APK in the archive. Select that complete archive in Morphe Manager. A base APK alone can omit the native libraries or resources needed to run the app.
