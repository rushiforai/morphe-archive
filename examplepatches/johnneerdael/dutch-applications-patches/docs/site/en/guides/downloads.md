# Download original apps

Download the original file for your app and select it in Morphe Manager to apply the patches. Match the version and build number on the app page. For APKM and APKS downloads, use the complete archive.

[Browse the shared download folder](https://buzzheavier.com/gnmtadlpn31g){ .md-button }
