# Security Policy

## Scope

This project contains bytecode patches for Telegram. It does not collect user credentials or authentication tokens.

## Reporting a security issue

If you find a security-sensitive issue in the patch source or build configuration, report it privately to the repository maintainer rather than publishing exploit details in a public issue.

When reporting, include the affected file, commit or release, reproduction steps, and relevant logs with secrets removed.

Do not include account credentials, session data, API keys, signing keys, or private APKs.

## Supported versions

Security fixes are evaluated against the Telegram version currently supported by this repository. Compatibility with other Telegram releases is not implied.
