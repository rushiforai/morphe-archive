# Twitch の使い方

対象は **公式 Twitch 32.0.0（3200006）・31.9.0（3109006）（どちらも Android 12L 以上）** と **30.7.2（3007026、Android 8.0 以上）** です。30.7.2 は、31.x を入れられない Android 12 以下の端末のために残しています。

## 導入

1. Morphe Manager に Sabopura Morphe Patches を追加します（[README](../README.md) の導入方法）。
2. 公式 Twitch の APK / APKS / APKM / XAPK を選びます。改造済みの APK は使わないでください。
3. 使いたいパッチを選んで適用します。[パッチ一覧](#パッチ一覧) のとおり、機能ごとに選べます。初めてなら、選ばれた状態のままで構いません。
4. できた APK をインストールします。すでにパッチ版を入れている場合は、同じ署名鍵で更新してください。

## パッチ一覧

機能ごとに別のパッチなので、必要なものだけ選べます。`Ads:` などの接頭辞は、Morphe Manager の一覧で同じ種類が並ぶようにするためです。

## プレイヤーのボタン

動画のプレイヤー操作部（右上、共有ボタンのすぐ左）に、吹き出しの形のボタンが 1 つ追加されます。ライブ配信でも VOD でも出ます（縦型のクリップ用プレイヤーには出ません）。同じ設定画面は、Twitch の設定画面（プロフィールの歯車）の一番上の「パッチの設定」からも開けます。

- **タップ**：プレイヤーメニューを開きます。縦画面では下から、横画面・全画面では右側から出ます。
- **長押し**：弾幕をすぐにオン/オフします。アイコンの線に斜線が入っているときはオフです。

### プレイヤーメニュー

| 項目 | 内容 |
| --- | --- |
| 広告ブロック | オン/オフのスイッチと、止めた広告の数 |
| 弾幕 | オン/オフのスイッチと、弾幕の設定への入り口 |
| 再生速度 | 0.25〜2 倍を 1 タップで切り替え。画面に余裕があるときは、スライダーで細かく選べる。ライブでは 1 倍より速くすると遅れを取り戻したあと 1 倍に戻る |
| スリープタイマー | ダイヤルを指で回して最大 120 分。残り時間を表示。VOD では「この動画が終わったら」を選ぶと、その動画が終わったところで止まり、次の動画は始まらない |
| 操作 | 消音、画面ロック、戻る・進む（VOD とクリップ。秒数は設定で変更）、再読み込み、再生統計。VOD ではチャプターとチャット同期 |
| チャット | 過去チャットの取得、表示したメッセージの検索、ユーザー検索 |
| このチャンネルの設定 | 「このチャンネルの設定を覚える」スイッチ（チャットを開くと使える）。オンにすると、このチャンネルの音量（端末の音量に対する 0〜100%）も変えられる。覚えるのは音量・弾幕・VOD の速度・チャットの文字サイズ |
| 設定（右上の歯車のボタン） | 設定画面を開きます |

### 設定画面

設定は 1 つの画面にまとめています。変更はその場で保存されます。

- カテゴリー：広告／チャット／弾幕／プレイヤー／ホームと表示／アカウントとプライバシー／このパッチについて（中はタブで切り替えます）。それぞれの行に、オン・オフか、変更した項目の数が出ます。
- `Tools: Lifetime totals` を選んでいると、最初の画面の上に、止めた広告・ポイントボーナス・見た時間の累計が出ます。
- 右上の虫めがねで、設定を名前で検索できます。複数の語で絞り込めます。
- 弾幕とチャットの表示には、変えた結果がその場で分かる見本が付きます。画面に高さがあるときは、見本は上に固定されたまま、下の項目だけがスクロールします。
- メニューの順番と表示は「プレイヤー › 画面と操作」から編集できます。行を押さえたまま上下に動かして並べ替えます。画面の読み上げ（TalkBack）では「上へ移動」「下へ移動」の操作で、キーボードや十字キーでは決定キーの長押しで行を持ち上げ、上下キーで動かせます。
- タブレットなど画面の広い端末では、左にカテゴリー、右に項目が並びます。
- 前提のスイッチがオフの項目（たとえば「チャットの幅を変える」がオフのときの幅の項目）は薄く表示され、触れません。
- 設定・メニュー・通知の文は、日本語と英語があります。アプリ（またはスマホ）の言語が日本語なら日本語、それ以外なら英語で出ます。「このパッチについて」の「表示言語」で、日本語か English に固定できます（Twitch 自体の言語は変わりません）。
- 「このパッチについて」から、すべての項目を初期値に戻せます。履歴、VOD ごとの同期値、累計の記録は残ります。
- 「このパッチについて」の「設定の引っ越し」で、設定を文字として書き出し（共有またはコピー）、入れ直したあとや別の端末で貼り付けて読み込めます。ファイルは作らず、保存の権限も使いません。累計の記録と、カスタム URL のプロキシは運びません。
- 「このパッチについて」の「バージョン」に、パッチ集と Twitch のバージョンが出ます。
- 「このパッチについて」の「診断」には、アプリを起動してから、この版の Twitch でパッチが働けなかった箇所が、パッチ集・Twitch・Android のバージョンと端末の機種、適用したパッチの名前と一緒に出ます。不具合を報告するときは、ここでコピーした文を貼ってください（アカウントの情報は含みません）。
- 適用しなかったパッチの項目は表示されません。

チャット入力欄に追加される「＋」付きの笑顔のアイコンは、外部エモートの選択画面です（Twitch 純正の笑顔のアイコンの左）。エモートの画像が並び、お気に入り・チャンネル・グローバルのタブと検索があります。タップすると入力欄に入り（送信はしません）、長押しでお気に入りに出し入れします。入力欄で `:` に続けて打つと出る候補にも、エモートの画像が付きます。

## 機能一覧

| 機能 | 今回の動作 |
| --- | --- |
| 7TV / BTTV / FFZ エモート | グローバル・チャンネル別を取得。ライブと VOD の通常チャット行へ表示。アニメーション、7TV の重ね合わせ、Twitch 純正エモートへの重ね合わせに対応 |
| エモート入力 | 画像のグリッドの選択画面（お気に入り／チャンネル／グローバル、検索、長押しでお気に入り）。`:名前` の入力補完は画像つき。選択時は入力欄に挿入し、メッセージは自動送信しない |
| バッジ | 7TV / FFZ / Chatterino / BTTV / DankChat / Chatsen の公開バッジ。サービス別 ON/OFF。BTTV の SVG も表示 |
| 名前のペイント | 7TV の登録者が名前に付けているペイントで、チャットの名前を表示。グラデーション（線形・放射、角度、繰り返し）、画像（動く画像は静止画）、影（4 つまで）に対応。コロンと本文は元のまま。描けないペイントと、チャット欄より幅の広い名前は、元の名前の色で表示。その配信で 7TV を使って発言した人の分だけ届く |
| 代名詞 | Alejo の公開プロフィールに登録された値（2 つ目の代名詞を含む）を表示。未登録の値は推測しない |
| フィルター | NG 語句（本文が対象）、ログイン名・ユーザー ID の非表示、同一ユーザーによる 8 秒以内の同文連投を非表示 |
| ハイライト | 本文が語句に一致するメッセージ、指定したユーザー（ログイン名または数値 ID）の発言、自分のログイン名を含むメッセージを、指定色の帯で強調。新着の強調対象で振動（10〜1,000 ミリ秒） |
| チャットの表示 | 文字サイズ 70–160%、エモートとバッジの大きさ 50–200%、行間 25–300%、送信時刻と秒、交互の背景、表示名とログイン名が違うときは名前の後ろに「(ログイン名)」 |
| 過去チャット | robotty.de で収集済みの公開履歴を最大 500 件取得し、専用画面で検索・表示。Twitch のエモートと追加エモートは画像で表示（Twitch のエモートの画像は Twitch の配信元から取得）。一致した部分を強調し、行の長押しで本文をコピー |
| 表示したメッセージの履歴 | この端末で実際に表示した最大 1,000 件を検索。Twitch のエモートと追加エモートは画像で表示。保存はオフが初期値で、その場合はアプリを閉じると消える。オンにするとアプリの非公開領域に保存。画面から消去可能（確認あり） |
| 削除メッセージ | すでに受信した削除対象メッセージをローカルで残す。表示は「タップで表示（スポイラー）」か「取り消し線で表示」を選べる。「チャットの全消去を無視」をオンにすると、モデレーターがチャットを全消去しても表示中のメッセージを残す（タイムアウトと BAN は反映） |
| 配信プロキシ | 任意で PerfProd / Luminous / カスタム HTTPS にライブ配信の再生リストの取得先を変更。初期値は無効。広告ブロックが広告のない再生リストを Twitch から取得できなかったときの予備にも使う |
| 広告ブロック | `Ads:` の 5 つのパッチ（31.9.0・32.0.0）。アプリが自分で再生する広告（再生前・途中・VOD・音声・配信が要求する広告）、PbyP、表示広告（ネイティブと React Native の画面）を止め、配信に埋め込まれた広告は広告のない再生リストに差し替える。差し替えられないときは黒い画面で隠して消音（設定で変更可）。初期値は有効 |
| 再生操作 | 0.25–2 倍速（別の VOD・配信を開くと 1 倍に戻る）、前後 5–120 秒のシーク幅、再読み込み、再生位置・バッファ・ビットレート等の統計 |
| 消音 | プレイヤーメニューの「消音」で、端末の音量を変えずに再生中の配信や動画の音だけを消す。もう一度押すと戻る。ミニプレイヤーやバックグラウンド再生でも消音のままで、別の配信や動画を開くかプレイヤーを閉じると解除。チャンネルごとに覚えた音量は変えない |
| 画面ロック | プレイヤーメニューの「画面ロック」で、画面のタッチと戻る操作を受け付けなくする（再生と弾幕は続く）。画面の左上に出る鍵のボタンを約 1 秒長押しすると解除。プレイヤーが閉じたとき、アプリを離れたときは自動で解除。音量キーとホーム・アプリ切り替えはそのまま使える |
| スリープタイマー | ダイヤルで 1〜120 分を 1 分単位で指定し、その時間のあとに再生を一時停止（「+5」で 5 分延長、「オフ」で解除）。残り時間を表示。VOD では「この動画が終わったら」も選べる（別の動画や配信を開くと解除） |
| 動画の終わり | 「動画が終わったら次を自動再生しない」をオンにすると、VOD やクリップが終わっても「次の動画」のカウントダウンを出さず、何も再生しない。初期値はオフ。ライブ配信・レイド・ホームのプレビューは変わらない |
| VOD チャット同期 | VOD ごとに -120〜+120 秒を保存。正値は先のコメントを取得 |
| VOD チャプター | Twitch の公開ゲーム変更チャプターを取得し、選択した位置へシーク |
| ジェスチャー | プレイヤー左端の上下スワイプで明るさ、右端で音量。個別に有効化。プレイヤーを閉じると明るさは元に戻る |
| プレイヤーのレイアウト | 横画面の通常/分割チャット幅を個別に 10–70%、背景濃度を 0–100%、ミニプレイヤーを 50–200% に変更。元の表示へ戻すスイッチ付き |
| 戻るでプレイヤーを閉じる | 戻る操作でミニプレイヤーにせず、再生を止めてプレイヤーを閉じる。初期値はオフ。最小化ボタンと下へのスワイプは、これまでどおりミニプレイヤーになる |
| ホームの表示 | フォロー中カテゴリ、おすすめ配信、視聴の続き、オフライン欄を個別に非表示。配信カードを大きく表示する設定。31.9.0 以降のスマホの新しいホームでは、フォロー中カテゴリ・視聴の続き・オフライン欄の 3 つがそのまま効く（フォロー中を引っぱって更新すると反映）。配信カードの大きさと「おすすめ配信」は新しいホームでは効かないため、Twitch がタブレットなどで使う従来のホームに切り替えるスイッチ「従来のホーム画面を使う」を用意（初期値はオフ、アプリを開き直すと反映） |
| ナビゲーション | 標準の位置、上部（ステータスバーのすぐ下）、非表示を切替。設定を戻すと位置と表示状態を復元 |
| 表示の整理 | チャット/VOD の見出し、ランキング、ハイプトレイン、Bits、キャスト、クリップ作成、共有、配信の拡張機能、フォロー解除（フォロー中のチャンネルのハートなど）、サブスク、ギフトサブ、配信作成、入力欄、ピン留め、ストーリー、ブラウズタブ、広告なしプランの案内、チャットの案内を非表示。広告なしプランの案内は、31.9.0 以降のスマホの新しいホームの「フォロー中」にあるボタンも隠す（アプリを開き直すと反映）。`Chat: Hide highlights` を選ぶと、ギフトのバナー、Bits とギフトのランキング、ウォッチストリークの通知も隠せる。ハイプトレインやピン留めを隠しても投票・予想は表示。入力欄は横画面だけ隠す設定も用意 |
| リキャップ | 配信のリキャップ（配信のクリップをまとめたもの）を隠すスイッチ（初期値はオフ。ページを開き直すと反映）。従来のホーム画面のフィードに入るリキャップのカードと、チャンネルページのリキャップの棚が出なくなる。31.9.0 以降のスマホの新しいホームにある棚は隠せないため、隠すには「従来のホーム画面を使う」をオンにする。30.7.2 ではフィードのカードだけが対象 |
| ユーザー検索 | 正確なログイン名または数値 ID から公開プロフィールを調べ、Twitch 内で開く。見つからない場合と検索サービスに接続できない場合を分けて示し、結果から ID をコピーできる |
| ポイント自動回収 | Twitch がログイン状態・ポイント利用可否・BAN 状態を判定した後、受取可能なボーナス宝箱を回収。更新をまとめ、同じ宝箱の試行は状態更新時に30秒以上空けて最大3回。手動の受取操作は維持。「アカウントとプライバシー」のスイッチで止められる（初期値はオン） |
| 通知修正 | 再署名によるプッシュ登録失敗への対策。Firebase Installations の正規 HTTPS 登録・トークン更新先だけで証明書ヘッダーを補正。通知の権限や端末の省電力制限を変更する機能ではない |
| ログイン修正（任意） | Twitch の Play Integrity 提出を開始する処理を終了させる。通常ログインできる場合は選択不要。初期選択は無効 |

選ぶとすぐ働くのは、広告ブロック、弾幕（VOD を含む）、外部エモートと `:` の補完、削除メッセージの表示、起動画面の固まり解消、ポイントの自動受け取り、ログインせずに見る、修正・権限・別アプリのパッチです。プレイヤーメニューの操作、過去チャットなどの画面、エモートの選択画面は、使ったときだけ働きます。そのほかは、パッチを選んでも、設定でオンにする（または値を選ぶ）まで Twitch の動きを変えません。
設定は端末内にだけ保存します。フィルターは 1 行 1 件の文字列一致で、
英字の大小と全角・半角を正規化します。正規表現としては解釈しません。
弾幕の NG ワードだけは `/式/` の形で正規表現を書けます。極端に時間がかかる形（`(a+)+` など）と、文法が正しくない式は無視され、ほかの行はそのまま効きます。

## 接続先と動作上の制約

各外部サービスへ公開チャンネル名・公開ユーザー ID 等で問い合わせます。
チャット本文、Twitch の OAuth、Cookie、端末 ID を外部 API のリクエストへ転送する処理はありません。
Twitch のプロフィール・チャプター取得では、固定の公開 Client-ID を使い、認証情報を使いません。
広告ブロックは、視聴中の配信を開いたときと広告が入ったときに、Twitch の公開 GraphQL にチャンネル名だけを送って別の視聴形式のトークンを取得します（認証情報は送りません。ホームのプレビューでは行いません）。配信プロキシを設定した場合だけ、予備としてプロキシにも問い合わせます。
接続先には IP アドレスと問い合わせ対象が伝わります。

- 外部サービスの停止・仕様変更・未登録により、バッジや履歴が表示されないことがあります。
  復旧待ちの問い合わせには再試行間隔とキュー上限を設けています。
- 広告ブロックは Twitch 31.9.0・32.0.0 専用です。配信に埋め込まれた広告の差し替えは、Twitch が広告のない
  視聴形式を用意している間だけ働きます。サブスク限定の配信などで取得できないときは、黒い画面と消音になります。
- 広告ブロックの切り替えは、次に開いた画面から反映します。
- ポイント自動回収はアプリが受け取った宝箱だけが対象です。バックグラウンドでの
  視聴や受取の予約は行いません。成功・拒否・期限切れの状態では再要求しません。
  重複管理は最大128件・30分の端末メモリー内で行い、認証情報は追加保存しません。
- 起動直後のクラッシュが 3 回続くと、パッチの機能を自動で止めて案内します。設定は変わりません。設定画面から再開できます。
- 通知・ログイン修正はサーバーやGoogleサービスの仕様変更に影響されます。
  ログイン修正はMorpheでパッチを選択して再適用する方式で、アプリ内の切替ではありません。
- 再生操作は再生中のプレイヤーが対応する場合に使えます。ライブ配信は最新の位置より先へ進めないため、1 倍より速い再生は遅れを取り戻すまでで、終わると自動で 1 倍に戻ります。ライブではシーク（戻る・進む）は使えません。
- スリープタイマーは Twitch のプロセス内で動作します。OS がアプリを終了した後のアラーム予約ではありません。
- 「動画が終わったら次を自動再生しない」とスリープタイマーの「この動画が終わったら」は、Twitch が動画の終わりに出す「次の動画」とそのカウントダウンを出さないようにします（次の動画を選ぶ画面も出ません）。Twitch の設定にある「ビデオ自動再生」はホームのプレビュー用で、動画が終わったあとの自動再生は止まりません。
- VOD に公開チャプターがない場合は空になります。同期値の変更は次のコメント取得から反映します。
- 幅・ミニプレイヤーのサイズは動画を開き直すと反映します。ホームのフィルター・カード表示は
  Following の更新または開き直しで反映します。アプリ内ミニプレイヤーの拡大率は画面内に収まるよう制限します。

公開 API は [7TV](https://github.com/SevenTV/SevenTV)、
[BetterTTV](https://github.com/night/betterttv)、

## 確認した範囲

- 実際の Twitch 30.7.2 / 31.9.0 / 32.0.0 にパッチを当て、Android 16 のエミュレーターで起動と各機能の動作を確認しています。ログインせずに、実際のライブ配信と VOD も再生して確認しています。
- 31.9.0 は、ログインした実機（Galaxy S23、Android 17）でも確認しています。確認したのは、フォロー中の一覧、ライブ配信、チャットの装飾と追加エモート、弾幕（ライブと VOD）、再生前の広告の差し替え、ポイントのボーナスの自動受け取り、VOD のメニュー（再生速度・シーク・チャプター・チャット同期）、下のナビゲーションの整理、従来のホーム画面への切り替えです。
- ハイプトレイン・ピン留めを隠す動作は、検査用に残している 31.5.2 で確認したものです（対応版からは外しました）。31.9.0・32.0.0 では、パッチの中身の検査で代えています。
- 30.7.2 は Android 8.0 以降、31.9.0 と 32.0.0 は Android 12L 以降で動く版です。30.7.2 は、Android 11 のエミュレーターでも、ライブ配信・VOD・弾幕・チャットの装飾・メニュー・設定画面・過去チャット・ユーザー検索を確認しています（ログインなし、英語表示、明るい表示）。Android 8〜10 は実際には動かせていませんが、Android の lint で、Android 8.0 より新しい機能を保護なしで呼んでいないことを確かめています。
- クリップは、32.0.0 の縦型のクリップ用プレイヤーで再生を確認しています。このプレイヤーにはパッチのメニューボタンは出ず、弾幕も流れません（VOD のあとに開いても、VOD のコメントは流れません）。
- **Drops の受け取り、プッシュ通知、レイド、ログイン修正による認証は確認できていません。32.0.0 と 30.7.2 は、ログイン後の画面を確認できていません。**

新しい Twitch のバージョンに対応するときの手順は [保守手順](twitch-maintenance.md) を参照してください。
