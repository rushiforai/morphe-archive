# Twitch の使い方

対象は **公式 Twitch 31.7.0（3107006）・31.6.0（3106006）（どちらも Android 12L 以上）** と **30.7.2（3007026、Android 8.0 以上）** です。30.7.2 は、31.x を入れられない Android 12 以下の端末のために残しています。

## 導入

1. Morphe Manager に Sabopura Morphe Patches を追加します（[README](../README.md) の導入方法）。
2. 公式 Twitch の APK / APKS / APKM / XAPK を選びます。改造済みの APK は使わないでください。
3. 次のパッチを選んで適用します。
   - `Block ads`（31.6.0・31.7.0）、`Chat enhancements`、`Player enhancements`、`Show deleted messages`
   - `Danmaku chat`、`Auto claim channel points`、`Fix notifications`
   - `Fix login` は初期状態では選ばれていません。「このアプリ／OSはサポートされていません」と出てログインできない場合だけ選んでください。
4. できた APK をインストールします。すでにパッチ版を入れている場合は、同じ署名鍵で更新してください。

## プレイヤーのボタン

動画のプレイヤー操作部（右上、共有ボタンのすぐ左）に、吹き出しの形のボタンが 1 つ追加されます。同じ設定画面は、Twitch の設定画面（プロフィールの歯車）の一番上の「パッチの設定」からも開けます。

- **タップ**：プレイヤーメニューを開きます。縦画面では下から、横画面・全画面では右側から出ます。
- **長押し**：弾幕をすぐにオン/オフします。アイコンの線に斜線が入っているときはオフです。

### プレイヤーメニュー

| 項目 | 内容 |
| --- | --- |
| 弾幕 | オン/オフのスイッチと、弾幕の設定への入り口 |
| 再生速度 | 0.25〜2 倍を 1 タップで切り替え。ライブでは 1 倍より速くすると遅れを取り戻したあと 1 倍に戻る |
| スリープタイマー | 15〜120 分後に一時停止。残り時間を表示 |
| 操作 | 戻る・進む（VOD とクリップ。秒数は設定で変更）、再読み込み、再生統計。VOD ではチャプターとチャット同期 |
| チャット | 過去チャットの取得、表示したメッセージの検索、ユーザー検索 |
| すべての設定 | 設定画面を開きます |

### 設定画面

設定は 1 つの画面にまとめています。変更はその場で保存されます。

- カテゴリー：弾幕／チャット／エモートとバッジ／フィルターとハイライト／再生／レイアウト／ホーム／表示の整理／履歴とツール／このパッチについて
- 右上の虫めがねで、設定を名前で検索できます。
- タブレットなど画面の広い端末では、左にカテゴリー、右に項目が並びます。
- 前提のスイッチがオフの項目（たとえば「チャットの幅を変える」がオフのときの幅の項目）は薄く表示され、触れません。
- 「このパッチについて」から、すべての項目を初期値に戻せます。履歴と VOD ごとの同期値は残ります。
- 適用しなかったパッチの項目は表示されません。

チャット入力欄に追加される笑顔のアイコンは、外部エモートの選択画面です。

## 機能一覧

| 機能 | 今回の動作 |
| --- | --- |
| 7TV / BTTV / FFZ エモート | グローバル・チャンネル別を取得。ライブと VOD の通常チャット行へ表示。アニメーション、7TV の重ね合わせ、Twitch 純正エモートへの重ね合わせに対応 |
| エモート入力 | 追加の選択画面で検索・長押しでお気に入り。`:名前` の入力補完。選択時は入力欄に挿入し、メッセージは自動送信しない |
| バッジ | 7TV / FFZ / Chatterino / BTTV / DankChat / Chatsen の公開バッジ。サービス別 ON/OFF。BTTV の SVG も表示 |
| 代名詞 | Alejo の公開プロフィールに登録された値（2 つ目の代名詞を含む）を表示。未登録の値は推測しない |
| フィルター | NG 語句（本文が対象）、ログイン名・ユーザー ID の非表示、同一ユーザーによる 8 秒以内の同文連投を非表示 |
| ハイライト | 本文が語句に一致するメッセージを指定色で強調。新着の強調対象で任意の長さの振動 |
| チャットの表示 | 文字サイズ 70–160%、送信時刻と秒、交互の背景、表示名とログイン名が違うときは名前の後ろに「(ログイン名)」 |
| 過去チャット | robotty.de で収集済みの公開履歴を最大 500 件取得し、専用画面で検索・表示 |
| 閲覧履歴 | この端末で実際に表示した最大 1,000 件を検索。必要ならアプリの非公開領域に保存。画面から消去可能 |
| 削除メッセージ | すでに受信した削除対象メッセージをローカルで残し、タップで内容を表示 |
| 配信プロキシ | 任意で PerfProd / Luminous / カスタム HTTPS にライブ配信のプレイリスト取得先を変更。初期値は無効。広告ブロックが広告のない再生リストを Twitch から取得できなかったときの予備にも使う |
| 広告ブロック | `Block ads`。アプリが自分で再生する広告（再生前・途中・VOD・音声・配信が要求する広告）、PbyP、表示広告（ネイティブと React Native の画面）を止め、配信に埋め込まれた広告は広告のない再生リストに差し替える。差し替えられないときは黒い画面で隠して消音（設定で変更可）。初期値は有効 |
| 再生操作 | 0.25–2 倍速（別の VOD・配信を開くと 1 倍に戻る）、前後 5–120 秒のシーク幅、再読み込み、再生位置・バッファ・ビットレート等の統計 |
| スリープタイマー | 15 / 30 / 45 / 60 / 90 / 120 分後に再生を一時停止。解除・残り時間表示 |
| VOD チャット同期 | VOD ごとに -120〜+120 秒を保存。正値は先のコメントを取得 |
| VOD チャプター | Twitch の公開ゲーム変更チャプターを取得し、選択した位置へシーク |
| ジェスチャー | プレイヤー左端の上下スワイプで明るさ、右端で音量。個別に有効化。プレイヤーを閉じると明るさは元に戻る |
| プレイヤーのレイアウト | 横画面の通常/分割チャット幅を個別に 10–70%、背景濃度を 0–100%、ミニプレイヤーを 50–200% に変更。元の表示へ戻すスイッチ付き |
| ホームの表示 | フォロー中カテゴリ、おすすめ配信、視聴の続き、オフライン欄を個別に非表示。配信カードを大きく表示する設定 |
| ナビゲーション | 標準の位置、上部（ステータスバーのすぐ下）、非表示を切替。設定を戻すと位置と表示状態を復元 |
| 表示の整理 | チャット/VOD の見出し、ランキング、ハイプトレイン、Bits、キャスト、クリップ作成、共有、フォロー解除（フォロー中のチャンネルのハートなど）、配信作成、入力欄、ピン留め、ストーリー、探索タブ、チャットの案内を非表示。ハイプトレインやピン留めを隠しても投票・予想は表示。入力欄は横画面だけ隠す設定も用意 |
| ユーザー検索 | 正確なログイン名または数値 ID から公開プロフィールを調べ、Twitch 内で開く |
| ポイント自動回収 | Twitch がログイン状態・ポイント利用可否・BAN 状態を判定した後、受取可能なボーナス宝箱を回収。更新をまとめ、同じ宝箱の試行は状態更新時に30秒以上空けて最大3回。手動の受取操作は維持 |
| 通知修正 | 再署名によるプッシュ登録失敗への対策。Firebase Installations の正規 HTTPS 登録・トークン更新先だけで証明書ヘッダーを補正。通知の権限や端末の省電力制限を変更する機能ではない |
| ログイン修正（任意） | Twitch の Play Integrity 提出を開始する処理を終了させる。通常ログインできる場合は選択不要。初期選択は無効 |

バッジ、代名詞、履歴の永続保存、プロキシ、ジェスチャー、表示の変更は初期状態では無効です。広告ブロックは初期状態で有効です。
設定は端末内にだけ保存します。フィルターは 1 行 1 件の文字列一致で、
英字の大小と全角・半角を正規化します。正規表現としては解釈しません。

## 接続先と動作上の制約

各外部サービスへ公開チャンネル名・公開ユーザー ID 等で問い合わせます。
チャット本文、Twitch の OAuth、Cookie、端末 ID を外部 API のリクエストへ転送する処理はありません。
Twitch のプロフィール・チャプター取得では、固定の公開 Client-ID を使い、認証情報を使いません。
広告ブロックは、配信に広告が入ったときだけ、Twitch の公開 GraphQL にチャンネル名だけを送って別の視聴形式のトークンを取得します（認証情報は送りません）。配信プロキシを設定した場合だけ、予備としてプロキシにも問い合わせます。
接続先には IP アドレスと問い合わせ対象が伝わります。

- 外部サービスの停止・仕様変更・未登録により、バッジや履歴が表示されないことがあります。
  復旧待ちの問い合わせには再試行間隔とキュー上限を設けています。
- 広告ブロックは Twitch 31.6.0・31.7.0 専用です。配信に埋め込まれた広告の差し替えは、Twitch が広告のない
  視聴形式を用意している間だけ働きます。サブスク限定の配信などで取得できないときは、黒い画面と消音になります。
- 広告ブロックの切り替えは、次に開いた画面から反映します。
- ポイント自動回収はアプリが受け取った宝箱だけが対象です。バックグラウンドでの
  視聴や受取の予約は行いません。成功・拒否・期限切れの状態では再要求しません。
  重複管理は最大128件・30分の端末メモリー内で行い、認証情報は追加保存しません。
- 通知・ログイン修正はサーバーやGoogleサービスの仕様変更に影響されます。
  ログイン修正はMorpheでパッチを選択して再適用する方式で、アプリ内の切替ではありません。
- 再生操作は再生中のプレイヤーが対応する場合に使えます。ライブ配信は最新の位置より先へ進めないため、1 倍より速い再生は遅れを取り戻すまでで、終わると自動で 1 倍に戻ります。ライブではシーク（戻る・進む）は使えません。
- スリープタイマーは Twitch のプロセス内で動作します。OS がアプリを終了した後のアラーム予約ではありません。
- VOD に公開チャプターがない場合は空になります。同期値の変更は次のコメント取得から反映します。
- 幅・ミニプレイヤーのサイズは動画を開き直すと反映します。ホームのフィルター・カード表示は
  Following の更新または開き直しで反映します。アプリ内ミニプレイヤーの拡大率は画面内に収まるよう制限します。

## 確認した範囲

- 実際の Twitch 30.7.2 / 31.6.0 / 31.7.0 にパッチを当て、Android 16 のエミュレーターで起動と各機能の動作を確認しています。ログインせずに実際のライブ配信も再生して確認しています。
- チャット行の表示、弾幕、ハイプトレイン・ピン留めを隠す動作は、検査用に残している 31.5.2 で確認しています（対応版からは外しました）。31.6.0・31.7.0 では、パッチの中身の検査とメニュー・設定画面の確認で代えています。
- **ログイン後の画面（フォロー中のチャンネル、ポイントの受け取り、プッシュ通知、ログイン修正による認証）は、エミュレーターでは確認できていません。**

新しい Twitch のバージョンに対応するときの手順は [保守手順](twitch-maintenance.md) を参照してください。
