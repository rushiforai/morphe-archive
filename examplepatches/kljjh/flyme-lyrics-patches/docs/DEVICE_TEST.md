# 魅族真机验收

记录机型、Flyme / Android / YT Music 版本、官方补丁版本和附加补丁版本。自动测试不代表这些项目已经通过真机验收。

- 同时启用官方 Morphe 来源与本来源；本来源列表只有 Flyme status bar lyrics。
- 从原版 APK 同时选择官方 Third-party lyrics 与本附加补丁，确认修补和安装成功。
- 漏选官方 Third-party lyrics 时，应明确提示补选，不能静默成功。
- 开启官方第三方歌词及锁屏歌词，比较状态栏与锁屏文本，包括翻译、长句、换行和间奏。
- 暂停立即清除，恢复继续显示；媒体通知按钮、封面和渠道保持有效，无逐句提示音。
- 快速切歌、切换播放会话、无歌词歌曲、拖动进度和播放结束时没有旧歌词残留。
- 关闭官方锁屏歌词或第三方歌词后清除；重新开启后恢复。
- 后台、锁屏后解锁、应用重新发布通知后正常更新。
- 不支持 Flyme 标志的设备仍可使用官方歌词，不因附加补丁崩溃。

如失败，先检查官方锁屏歌词本身是否有效，再检查是否同时选了两个来源的补丁及系统通知设置。反馈可附错误日志，不要附账号或令牌。
