# Companion presence
Android 13–15 legacy presence API, Android 16 association-ID presence API. Exact-address association via system consent; no broad device discovery without user action. Only active saved profiles route to the same ACL/JobScheduler dispatch. No force-stop guarantee. Source compilation and device installation/presence tests are separate.
References: https://developer.android.com/reference/android/companion/CompanionDeviceService and https://developer.android.com/develop/connectivity/bluetooth/companion-device-pairing.
