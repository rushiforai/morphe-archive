01 / The mirror

Why his work is here

A takedown is not an argument, but it does remove the work from the place people were pointed at. This page documents what his patches do and where the source lives now.

Temporary, credited, removable

hoodles wrote and maintains this collection. His repository, github.com/hoo-dles/morphe-patches, was blocked by GitHub on 18 November 2026, and his signed release bundle was removed with it. The source survives because it was publicly mirrored before the takedown, and it is reproduced here on GitGud, outside GitHub, so the patches stay reachable while his own hosting is gone. The mirror also rebuilt and published 1.47.0 from that source.

This is a temporary mirror, not a fork and not an endorsement. No patch in it was written or modified by me. The code stays under his license, the GPLv3, and his LICENSE and NOTICE travel with it. If he asks for it to come down, or publishes somewhere new, the mirror comes down.

What is here: his patch sources, his license and notices, and a rebuilt 1.47.0 bundle. What is not here: his original signed release asset, which was lost with the repository, and any original or patched application package.

02 / His patches

78 patches, 57 apps

What each patch changes, in his own words, with the app versions he pinned. Where a patch lists no version it applies to any build. Descriptions come from his patches-list.json at v1.47.0.

Universal patches — 5

The ones that attach to any app rather than to a package:

  • Change package name — Appends ".morphe" to the package name by default. Changing the package name of the app can lead to unexpected issues.
  • Disable Pairip license check — Disables Play Integrity API (pairip) client-side license check. This patch does not bypass Play Integrity attestation or pairipcore virtualization.
  • Enable debug — Enables debugging on the app by setting android:debuggable="true".
  • Hide app icon — Hides the app icon from the Android launcher.
  • MicroG integration — Allows the app to work without root by using MicroG instead of Google Play Services.

His README additionally lists a universal Spoof signature patch; it is folded into the universal entries above at this version and is not a separate row in his 1.47.0 list.

03 / Using it

Add his patches

One tap, once the bundle is published. Morphe only accepts github.com and gitlab.com links, so the link points at a GitLab repository that holds nothing but the metadata — the bundle stays on GitGud.

STEP 01

Add the XiØN patches from GitGud

In Morphe Manager open Sources → + → Remote and paste https://gitgud.io/xiondigital/MorphePatches/-/raw/main/patches-bundle.json

STEP 02

The mirror built it, not you

His original signed release asset is gone, so the mirror rebuilt 1.47.0 from the mirrored sources. The build is published, and the one-tap link in step 03 works. It used JDK 17, Android SDK 36, and a GitHub token with read:packages for Morphe's Gradle registry. The rebuild is unsigned; its SHA-256 is recorded in hoodles/source.json and shown in the table above.

To build it yourself, the toolchain needs no system install: scripts/hoodles-bootstrap.sh puts JDK 17 and the Android SDK in .toolchain/, then scripts/hoodles-build.sh builds with them as soon as a read:packages token is in GITHUB_TOKEN.

STEP 03

Add his patches as a second source

Add to Morphe
Without the link, paste his source into Sources → + → Remote: https://gitgud.io/xiondigital/MorphePatches/-/raw/main/hoodles/source.json

The one-tap link is live. The page still checks the metadata when it loads, so the status reflects what GitLab serves. Morphe keeps one bundle per source, so his collection stays its own source beside the XiØN one; when both have patches for an app, Morphe asks which source to use.
