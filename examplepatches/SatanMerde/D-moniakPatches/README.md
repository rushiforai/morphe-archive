### 📖 Project Overview

**D-moniak Patches** is a third-party patch library for the **[Morphe](https://github.com/morpheapp)** framework. This project brings together **462 patches** for **96 popular Android apps and games**, clearly separated into **tested & functional patches** (verified on real hardware / emulator: Hungry Shark World, Movix, Moises, FCTV33, BandLab, AllTrails, Fossify Phone) and **experimental patches** (currently under development, AI-generated).

### 📲 How to Use in Morphe Manager

👉 **[Add D-moniak Patches to Morphe Manager (1-Click)](https://morphe.software/add-source?github=SatanMerde/D-moniakPatches)**

1. Open **Morphe Manager**.
2. Navigate to **Settings** > **Patch Sources**.
3. Add source: `SatanMerde/D-moniakPatches`.
4. Select your app or game (e.g. `com.ubisoft.hungrysharkworld`, **Beach Buggy Racing**, etc.).
5. Check the desired patches.
6. Tap **Patch** and install the modified APK.
