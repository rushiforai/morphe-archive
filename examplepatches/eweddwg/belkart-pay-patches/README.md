# Патчи для Белкарт Pay

Патчи [Morphe](https://morphe.software) для приложения Белкарт Pay (`com.belkartpay.belkartpay`).

Добавляют Белкарт Pay в системный кошелёк Android. После этого приложение можно открыть с плитки «Кошелёк» в быстрых настройках, с ярлыка на экране блокировки и через жесты быстрого запуска.

Нужен Android 11 или новее.

## Установка

1. Добавьте источник в Morphe: https://morphe.software/add-source?github=eweddwg/belkart-pay-patches
2. Пропатчите Белкарт Pay и установите APK.
3. Выберите Белкарт Pay приложением для бесконтактной оплаты по умолчанию.
4. Готово! Белкарт Pay доступен через системный кошелёк Android.
