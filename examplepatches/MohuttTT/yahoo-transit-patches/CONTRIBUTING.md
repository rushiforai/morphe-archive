# Contributing

Use the `dev` branch and conventional commits. Preserve the original icon shapes and colors; translate labels rather than replacing artwork. Keep station names, line names and addresses in Japanese. Do not commit APKs, credentials, SDK paths, build output or emulator state.

Validate changes against Yahoo! Transit 8.5.5 (478). Include meaningful checks for changed behavior and state the limits of device testing. Preserve the existing release workflow and let it generate release metadata.
