# Istruzioni repository Morphe

Le patch sono indipendenti. Non pubblicare su `main` modifiche di altre applicazioni durante una release selettiva.
Prima di modificare branch, cataloghi o pubblicare, consulta [docs/RELEASE-PROCEDURE.md](docs/RELEASE-PROCEDURE.md).
Conserva il lavoro locale, non inserire credenziali nei file versionati e verifica l'impatto prima di un merge.
