# Установка и использование

## Через Morphe Manager

1. Установите [Morphe Manager](https://morphe.software) на Android-устройство.
2. Добавьте источник патчей: <https://morphe.software/add-source?github=Basil-AS/ru-apps-patches>
3. Выберите приложение из списка, укажите APK исходного приложения и запустите патчинг.
4. Установите полученный APK.

Предварительные (pre-release) сборки доступны при включении соответствующей опции в настройках источника.

## Готовые сборки

Пропатченные APK прикладываются к релизам: <https://github.com/Basil-AS/ru-apps-patches/releases>.
Перед установкой удалите оригинальное приложение, если подпись отличается.

## Через Morphe Desktop

Скачайте файл `patches-*.mpp` из релиза и примените его в [Morphe Desktop](https://github.com/MorpheApp/morphe-desktop) как обычный набор патчей.

## Сообщить о проблеме

Создайте [issue](https://github.com/Basil-AS/ru-apps-patches/issues) по одному из шаблонов,
указав название и версию приложения и версию патчей.
