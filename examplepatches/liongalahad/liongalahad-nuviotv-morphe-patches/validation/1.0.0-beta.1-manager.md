## Android Manager

- AVD: Pixel_10, Google sdk_gphone16k_x86_64, Android 17 / API 37.
- Manager: 1.27.0; Patcher: 1.10.0; Fast bytecode processing; process runtime 896 MB.
- Official NuvioTV: 0.9.0-beta x86_64, SHA-256 `e3712cfd0cf4f0a25c1268ca6799abe68248f6ee4a4980974121f00b57f06712`.
- Existing public GitHub source updated to 1.0.0-beta.1 and displayed **7 patches**.
- The exact checksum-verified public download was also imported into Manager.
- Selected all 7 patches from one beta bundle, with the duplicate source selection disabled. Manager applied the patches, rebuilt and signed the output and displayed **Patching complete!**.
- Before publication, both the default selection and all-7 application also passed with the identical bundle.

Raw screenshots and UI hierarchy evidence remain in ignored `local/release-beta1/public/`. Testing used a read-only AVD overlay; no existing device data was cleared. The public result was not installed or tested on a physical TV.

## Other validation

The pre-merge dev and PR CI matrices both passed all four official APK variants. One initial PR job encountered a Robolectric dependency-download connection error; its rerun passed. Local release checks passed 295 extension tests, 9 patch tests, Android lint and Android DEX verification.
