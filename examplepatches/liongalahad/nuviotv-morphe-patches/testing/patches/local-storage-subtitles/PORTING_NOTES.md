# Porting notes

The playback overlay fingerprint targets Nuvio's optimized subtitle screen by the fixed `__off__` and `__unknown__` language sentinels plus the surrounding Compose structure. The option-builder fingerprint targets the stable `Subtitle` model accessor and language-display conversion sequence. The initial-focus fingerprint targets Nuvio's two `overlay_open focus=` branches and only redirects reopened local selections through the reliable language-rail focus path. Player-event, selected-addon, remembered-track, track-restore, preference identity, and Media3 `SubtitleConfiguration` fingerprints keep the private source synchronized with Nuvio's controller without adding feature-specific behavior to shared infrastructure. All fingerprints are version-pinned and must match exactly once.

The reserved internal language key sorts before ordinary languages, while Nuvio's fixed `None` row remains first. UI hooks rewrite only this key to `Local Storage`; imported model IDs encode the detected playback language and exact filename so Media3 receives a useful language tag and the existing secondary-label component can show the source filename. The action row is intercepted before Nuvio tries to select an empty subtitle URL.

The manifest adds a non-exported initialization provider and a non-exported translucent picker bridge activity. The bridge uses `ACTION_OPEN_DOCUMENT`, validates extension and bounded size, and copies through `ContentResolver` into a dedicated `filesDir` subdirectory. No persisted URI grant or broad storage permission is requested. Selection is posted after the picker finishes so Media3 refreshes only after playback regains focus; a manual selection cancels that pending post to prevent duplicate refreshes.

Imports and per-content selections are JSON values in the patch-private `morphe_patches` preferences. A key combines content ID, season, and episode. Last-used time is refreshed on selection and restoration. Startup cleanup removes imports unused for seven days, deletes their private file, and removes every selection mapping that references it.

Interaction with the two SDH patches remains generic. Removal already transforms every outgoing Media3 cue. Marking recognizes the language encoded in the imported model ID and samples `file:` URLs through the same bounded reader used for remote addon subtitles. Hook ordering is safe because the local title rewrite preserves a pre-existing ` SDH` suffix.

Imported selections deliberately bypass Nuvio's persistent addon preference. While an imported source is active, the patch skips Nuvio's saved track-restore routine after Media3 track updates; otherwise that routine both re-applies the saved built-in track and rewrites the visible selected-subtitle state even if its direct selection call is suppressed. The pending local Media3 override is applied before this restore point. Explicit internal, disabled, or other addon choices clear the active flag and continue through Nuvio's normal preference behavior.

For a future Nuvio version, revalidate subtitle model construction, language sorting, option click handling, controller identity changes, remembered-addon behavior, Media3 configuration creation, and MPV detection. Deliberate omissions are MPV injection, archive extraction, charset guessing beyond supported parser defaults, permanent subtitle libraries, and imports larger than 10 MB.
