# Porting notes

The playback overlay fingerprint targets Nuvio's optimized subtitle screen by the fixed `__off__` and `__unknown__` language sentinels plus the surrounding Compose structure. The option-builder fingerprint targets the stable `Subtitle` model accessor and language-display conversion sequence. The initial-focus fingerprint targets Nuvio's two `overlay_open focus=` branches and only redirects reopened local selections through the reliable language-rail focus path. Player-event, selected-addon, remembered-track, track-restore, preference identity, and Media3 `SubtitleConfiguration` fingerprints keep the private source synchronized with Nuvio's controller without adding feature-specific behavior to shared infrastructure. All fingerprints are version-pinned and must match exactly once.

The reserved internal language key sorts before ordinary languages, while Nuvio's fixed `None` row remains first. UI hooks rewrite only this key to `Local Storage`; imported model IDs encode the detected playback language and exact filename so Media3 receives a useful language tag and the existing secondary-label component can show the source filename. The action row is intercepted before Nuvio tries to select an empty subtitle URL.

The manifest adds a non-exported initialization provider and a non-exported translucent picker bridge activity. The bridge uses `ACTION_OPEN_DOCUMENT`, validates extension and bounded size, and copies through `ContentResolver` into a dedicated `filesDir` subdirectory. No persisted URI grant or broad storage permission is requested. Selection is posted after the picker finishes so the player has regained focus; a manual selection cancels that pending post to prevent duplicate selection.

Imports and per-content selections are JSON values in the patch-private `morphe_patches` preferences. A key combines content ID, season, and episode. Each import persists that key as `ownerContentKey`; menu merging, selection, duplicate replacement, and restoration all enforce an exact key match. Imports made by an older patch version remain hidden until their saved selection claims them for one content key. Last-used time is refreshed on selection and restoration. Startup cleanup removes imports unused for seven days, deletes their private file, and removes every selection mapping that references it.

Interaction with the two SDH patches remains generic. Removal already transforms every outgoing Media3 cue. Marking recognizes the language encoded in the imported model ID and samples `file:` URLs through the same bounded reader used for remote addon subtitles. Hook ordering is safe because the local title rewrite preserves a pre-existing ` SDH` suffix.

Imported selections deliberately bypass Nuvio's persistent addon preference. Nuvio's complete track-reconciliation routine still runs, so its audio and track bookkeeping are not interrupted. While an imported source is active, guards at the actual addon, internal, and disabled subtitle selectors block only stale automatic subtitle actions. Explicit internal, disabled, or other addon choices first pass through Nuvio's user-choice boundary, where the patch clears its private selection and then allows normal selection and preference behavior.

Nuvio 0.8.4 parses supported addon subtitles through a direct sidecar loader that preserves the current media source and playback buffer. Its text loader normally accepts HTTP URLs only, so the patch intercepts that single boundary for the actively selected import and returns text from the exact patch-owned private file. Unrelated `file:` paths and every remote URL continue through Nuvio unchanged. UTF-8, UTF-8 BOM, UTF-16LE and UTF-16BE inputs are decoded before parsing, and the original 10 MB import bound is enforced again while reading.

For a future Nuvio version, revalidate subtitle model construction, language sorting, option click handling, controller identity changes, remembered-addon behavior, Media3 configuration creation, and MPV detection. Deliberate omissions are MPV injection, archive extraction, charset guessing beyond supported parser defaults, permanent subtitle libraries, and imports larger than 10 MB.
