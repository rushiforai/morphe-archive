# Local Media

Patch ID: `local-media`.

Local Media adds a `Storage` choice beside `Saved` and `Cloud` in Library. Storage stays inside Nuvio's native Library screen, with native search, refresh, file cards and folder cards. Its search field reuses the complete Cloud search control and substitutes only the placeholder string, preserving the same text size, colors, focus state and typed-text behavior. The root view lists direct video files and first-level folders; folder cards show recursive playable-file counts and open a native file dialog. Selecting a file opens it in Nuvio's existing Media3 player.

The default location is `Movies/Nuvio`. Settings > Morphe > Playback > Local Storage contains only a visibility toggle and one actionable `Folder location` row. Local Storage defaults off. Turning it on without existing access immediately opens Android's required consent screen; once access is granted, the patch creates `Movies/Nuvio` automatically. There is no separate permission row. Pressing `Folder location` first tries Android's standard folder-tree contract, including every real installed handler visible through package discovery. Android TV's nonfunctional framework stub is rejected. If the TV has no real handler, the patch opens its own D-pad folder browser instead of claiming that no folder picker is installed. A standard tree choice keeps its persisted document grant; a choice made in the built-in browser uses the app's durable all-files grant. Both survive normal relaunches and reboots, but Android or the user can revoke access and uninstalling the app clears it.

Supported video extensions are MKV, MP4, M4V, WebM, AVI, MOV, MPEG, MPG, TS, M2TS and MTS. An SRT, VTT, ASS, SSA, TTML or DFXP file whose complete basename matches the video's basename is attached as a selectable subtitle track. For example, `Movie.mkv` matches `Movie.srt`; `Movie.en.srt` is deliberately not an exact match.

The patch owns its setting, folder grant, built-in fallback picker, in-place Library content, player handoff, sidecar matching, tests and documentation. A local player route deliberately has no catalogue `contentId`. Once that route reaches Media3's ended state, the patch exits the full-screen player and restores the same Storage selection view that launched it, instead of leaving a black paused frame or opening a metadata-details error. It does not implement downloads or alter Nuvio's Saved or Cloud data.
