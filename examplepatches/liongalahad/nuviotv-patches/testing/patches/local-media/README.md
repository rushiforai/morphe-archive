# Local Media

Patch ID: `local-media`.

Local Media adds a `Storage` choice beside `Saved` and `Cloud` in Library. Storage stays inside Nuvio's native Library screen, with native search, refresh, file cards and folder cards. Its search field reuses the complete Cloud search control and substitutes only the placeholder string, preserving the same text size, colors, focus state and typed-text behavior. The root view lists direct video files and first-level folders; folder cards show recursive playable-file counts and open a native file dialog. Selecting a file opens it in Nuvio's existing Media3 player. Its TV hold timer is anchored to the first select-key down event, so remotes that emit repeated zero-count down events cannot postpone the folder or file action until release.

The default location is `Movies/Nuvio`. Settings > Morphe > Playback contains a `Local Media` section with `Show local storage in Library`, followed at the bottom by one shared `Local storage path` row with no separate section. The path row remains visible when Local Media is installed, is greyed while every installed storage feature is off, and becomes actionable when Local Media or Local Downloads is on. Local Media defaults off. Turning it on without existing access immediately opens Android's required consent screen; once access is granted, the patch creates `Movies/Nuvio` automatically. There is no separate permission row. Pressing `Local storage path` first tries Android's standard folder-tree contract, including every real installed handler visible through package discovery. Android TV's nonfunctional framework stub is rejected. If the TV has no real handler, the patch opens its own D-pad folder browser instead of claiming that no folder picker is installed. A standard tree choice keeps its persisted document grant; a choice made in the built-in browser uses the app's durable all-files grant. Both survive normal relaunches and reboots, but Android or the user can revoke access and uninstalling the app clears it.

Supported video extensions are MKV, MP4, M4V, WebM, AVI, MOV, MPEG, MPG, TS, M2TS and MTS. An SRT, VTT, ASS, SSA, TTML or DFXP sidecar whose basename is the video basename, optionally followed by language and collision tags, is attached as a selectable subtitle track. For example, `Movie.mkv` matches `Movie.srt`, `Movie.en.srt`, and `Movie.en.2.srt`.

Long-pressing a root folder opens a native-feeling `Delete Folder` action while Select is still held. Each Storage card and file row owns a preview-key handler and uses Android's native long-press threshold, matching the working native holds elsewhere in Nuvio instead of waiting for the row's click callback at key-up. Long-pressing a direct file or a file inside a folder opens `Delete File` at that same threshold; the folder's file picker is temporarily removed so the action is visibly above it, and Back restores the picker in one press. Continued repeat events from the original held key are consumed until release, so opening an action never advances into confirmation by itself. Confirmed deletion removes the target video and all matched sidecars, and removes the containing root folder when no playable videos remain. A folder with another playable video is retained.

The patch owns its visibility setting, legacy path-key migration, folder grant, in-place Library content, player handoff, sidecar matching, tests and documentation. Generic shared settings infrastructure owns the storage-path row and fallback picker. A local player route deliberately has no catalogue `contentId`. Once that route reaches Media3's ended state, the patch exits the full-screen player and restores the same Storage selection view that launched it, instead of leaving a black paused frame or opening a metadata-details error. It does not implement downloads or alter Nuvio's Saved or Cloud data.
