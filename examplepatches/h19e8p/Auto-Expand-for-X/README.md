# h19e8p Patches

Unofficial [Morphe](https://github.com/MorpheApp) patches for X (Twitter) for Android 12.19.1, meant to be used together with [piko](https://github.com/crimera/piko).

X（旧 Twitter）の Android アプリ 12.19.1 向けの、Morphe 用のパッチ集です。[piko](https://github.com/crimera/piko) と一緒に当てて使うことを前提にしています。

非公式のパッチです。X Corp.、Morphe、piko とは関係ありません。

## パッチ

| パッチ | 内容 |
|---|---|
| **Auto expand hidden posts** | タイムラインの「ポストをさらに表示」の中身を、画面に出る前に裏で読み込み、ボタンを非表示にします。裏で読み込めなかったボタンは、画面に来た時に自動でタップします |
| **Feature flag tools** | 画面の部品や、画面を開いた時に X が読んだものから、関係しそうなフラグを探します。見つけたフラグは、piko のフラグの一覧に追加できます |
| **Undo and redo in the composer** | 投稿画面に「元に戻す」「やり直す」のボタンを足します |

どのパッチを当てても、X の「設定とプライバシー」に「h19e8p Patches」の設定画面が加わります。

## 対応バージョン

| アプリ | バージョン |
|---|---|
| X（`com.twitter.android`） | `12.19.1-release.0` |

動作を確かめたのは、上の版の X に、piko の既定のパッチと一緒に当てた場合だけです。

- 「Feature flag tools」でフラグを piko の一覧に追加するには、piko の「Hook feature flag」も当ててください。当てていない時は、フラグを探すことだけができます。
- ほかの版の X では、パッチが当たらないか、一部の働きだけが無効になります（「Auto expand hidden posts」は、裏の読み込みに必要な内部の名前が見つからない時は、自動でタップする動作だけになります）。

## Auto Expand for X（1.1.0 まで）から移る場合

このリポジトリは、以前は「Auto Expand for X」という名前で、パッチ 1 つだけを配っていました。2.0.0 からパッチ集「h19e8p Patches」になりました。

- Morphe Manager から、古い「Auto Expand for X」のソースを削除してください。古い「Auto expand hidden posts (standalone)」と新しい「Auto expand hidden posts」を一緒に選ぶと、パッチの適用に失敗します。
- 1.1.0 にあった Morphe Manager のパッチオプションは無くなりました。値は引き継がれないので、初期値から変えていた項目は、パッチを当てた後に設定画面で設定し直してください。
- 読み込み終わったボタンの記録と、診断ログの置き場所（`Download/AutoExpand`）は、そのまま引き継ぎます。

## 設定画面

X の「設定とプライバシー」→「h19e8p Patches」で開きます。当てたパッチの分だけ項目が出ます。

| 区分 | 項目 |
|---|---|
| ポストをさらに表示 | 下の「Auto expand hidden posts」の 4 つのスイッチ |
| フラグを探す | 要素から探す／フラグの読み取りを記録 |
| ストレージ | すべてのストレージを削除（キャッシュした画像や動画、通信のデータ、ウェブのデータを消して、X を再起動します。ログインや設定、下書きは消えません） |
| 情報 | アプリのバージョン／h19e8p Patches のバージョン |
| 適用されたパッチ | 3 つのパッチと、それぞれが適用済みか未適用か |

一番下の「初期値に戻す」で、ここで変えたスイッチをすべて初期値に戻します。設定は X のアプリ内の `shared_prefs/h19e8p_settings.xml` に保存します。

## Auto expand hidden posts

### しくみ

次の 3 つの決まりで動きます。

1. **画面に出る前に、裏で読み込みます。** タイムラインを開いた時に、「ポストをさらに表示」を押した時と同じ読み込みを、ボタンが画面に出る前に実行します。
2. **裏で読み込めなかったボタンは、画面に来た時に自動でタップします。** 読み込みの上限に達した後のボタン、裏の読み込みが働かない画面のボタン、裏で読み込んでも何も入らなかったボタンが対象です。ボタンの行が画面の端に入った時点で、止まって見えるのを待たずにタップします。
3. **隠すのは、読み込みが始まったボタンと、読み込み済みと記録したボタンだけです。** 画面に見えているボタンは、まだ読み込めていないものです。

X は、読み込んだ後もボタンを残し、もう一度押しても何も読み込まれません。そのため、読み込み終わったボタンは端末に記録し、X を起動し直した後も、読み込み直さずに隠します。

### 設定

| 項目 | 初期値 | 内容 |
|---|---|---|
| 画面に出る前に裏で読み込む | オン | タイムラインを開いた時に、ボタンの先のポストを裏で読み込みます。オフにすると、ボタンが画面に来た時の自動タップだけで読み込みます |
| 「ポストをさらに表示」を隠す | オン | 読み込みが始まったボタンと、読み込み済みと記録したボタンを非表示にします。オフにすると、読み込みは同じように行い、ボタンは残します |
| 動作時にトーストを表示する | オフ | 裏でポストを読み込んだ時、ボタンを隠した時、自動タップで読み込んだ時に、画面に短いメッセージを出します（同じメッセージは 2 秒に 1 回まで） |
| 診断ログを記録する | オフ | 処理の内容を `Download/AutoExpand/AutoExpand-Log.txt` に英語で追記します。1MB を超えると、それまでの分を `AutoExpand-Log.old.txt` として残し、新しいファイルに書き始めます（残すのは直前の 1 つ分なので、合わせて約 2MB までです）。X をアンインストールして入れ直すと、前のファイルには書き込めないため、`AutoExpand-Log-2.txt` のように番号を付けた別のファイルに記録します |

### 読み込みの上限

- 裏の読み込みと自動タップを合わせて、1 分に 10 回までです。上限に達した時は、枠が空くのを待ってから続けます。
- 自動タップは、1 つのボタンにつき 5 回までです。
- 裏の読み込みは、1 つのタイムラインで 30 回までです。アプリを再起動した時、X がタイムラインを作り直した時、または最後に裏で読み込んでから 10 分たった時に数え直します。それまでのボタンは、自動タップが読み込みます。

### 読み込まれないまま隠れる場合

「隠す」をオンにした時、ボタンが隠れたまま中身が読み込まれないのは、読み込みが始まったのに何も入らなかった場合だけです（読み込み済みのボタンか、通信の失敗）。見落としたくない場合は「隠す」をオフにしてください。読み込みは同じように行い、ボタンは表示したままにします。

### 自動タップの時の注意

- 読み込まれたポストは、ボタンがあった場所に入ります。勢いよくスクロールして通り過ぎた後だと、読んでいる位置より上に追加されます。トーストをオンにすると、「上にポストを追加しました」と表示されます。
- 読み込むたびにポストが増えている間は、同じボタンをタップし続けます。
- タップしても読み込みが始まらなかった時は、少し待ってもう一度タップします。それでも始まらなければ、ボタンを表示したままにするので、手でタップできます。
- 一覧の件数が読み取れない版では、ポストが増えたかを確かめられないため、1 つのボタンにつき 1 回だけタップします。

### 裏の読み込みが働く画面

ホーム、リスト、プロフィールのタイムラインで働くことを確認しています。ポストの詳細（返信の画面）では、返信の続きも裏で読み込みます。一覧の最後の行（続きを読み込むためのもの）は、裏では読み込みません。

### 読み込み終わったボタンの記録

X は、読み込み終わった後もボタンを残し、もう一度押しても何も読み込まれません。そのようなボタンを X の起動のたびに読み込み直さないように、読み込み終わったボタンを記録します。

- 保存先は X のアプリ内の設定ファイル（`/data/data/com.twitter.android/shared_prefs/autoexpand.xml`）です。ボタンの中身ではなく、見分けるためのハッシュ値を、最近の 500 件まで保存します。同じファイルに、診断ログの日付の見出しを最後に書いた日も残します。
- ポストの詳細（返信の画面）の返信の続きは、画面を開くたびにまた読み込めるようになるため、記録しません。
- root 化していない端末では、このファイルを見ることはできません。
- X をアンインストールするか、X のストレージを消去すると消えます。

## Feature flag tools

X の新しい機能の多くは、サーバーから届く「フラグ」で ON・OFF が決まります。このパッチは、ある画面や部品に関係しそうなフラグを探すための道具です。

- **要素から探す**：設定画面で押すと X に戻り、画面に「選択」のボタンが出ます。調べたい画面を開いて「選択」を押し、部品を押したまま動かして離すと、その部品に関係しそうなフラグの候補を出します。「操作」に切り替えると、ふだんどおり X を操作できます。
- **フラグの読み取りを記録**：設定画面で押すと X に戻り、画面に「リセット」と「表示」のボタンが出ます。「リセット」を押してから調べたい画面を開き、「表示」を押すと、その間に X が読んだフラグを出します。Compose で作られた画面でも使えます。
- 結果の画面では、タップで 1 件、長押しで複数を選び、piko のフラグの一覧に ON か OFF で追加できます。X を再起動すると反映されます。

候補は名前の手がかりから選んだもので、出てきたフラグが本当にその画面の機能を切り替えるとは限りません。

## Undo and redo in the composer

投稿画面の下のボタンの列（画像・GIF・投票などの並び）に、「元に戻す」と「やり直す」のボタンを足します。

- 本文の入力欄ごとに履歴を持ちます。スレッドでは、投稿ごとに別の履歴になります。
- 続けて打った文字は、0.6 秒以内ならひとまとめにして戻します。
- 履歴は、1 つの入力欄につき 200 回分までです。投稿画面を閉じると消えます。

## ビルド方法

必要なもの：

- JDK 17
- Android SDK（`local.properties` の `sdk.dir`、または環境変数 `ANDROID_HOME` で指定）
- `read:packages` 権限のある GitHub のトークン（Morphe の Gradle プラグインが GitHub Packages で公開されているため）。`~/.gradle/gradle.properties` に `gpr.user` と `gpr.key` として書くか、環境変数 `GITHUB_ACTOR` と `GITHUB_TOKEN` で渡します。

```
./gradlew buildAndroid
```

`patches/build/libs/patches-<バージョン>.mpp` ができます。Morphe Manager で使うのは `buildAndroid` の出力です（`build` の出力には Android 用の `classes.dex` が入りません）。
