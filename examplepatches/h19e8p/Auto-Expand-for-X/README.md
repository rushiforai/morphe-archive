# Auto Expand for X

A patch for X (Twitter) for Android that automatically loads the posts behind "Show more posts" and hides the button.

X（旧 Twitter）の Android アプリで、タイムラインに出る「ポストをさらに表示」の中身を自動で読み込み、ボタンを非表示にする [Morphe](https://github.com/MorpheApp) 用のパッチです。

非公式のパッチです。X Corp. および Morphe とは関係ありません。

## しくみ

次の3つの決まりで動きます。

1. **画面に出る前に、裏で読み込みます。** タイムラインを開いた時に、「ポストをさらに表示」を押した時と同じ読み込みを、ボタンが画面に出る前に実行します。
2. **裏で読み込めなかったボタンは、画面に来た時に自動でタップします。** 読み込みの上限に達した後のボタン、裏の読み込みが働かない画面のボタン、裏で読み込んでも何も入らなかったボタンが対象です。ボタンの行が画面の端に入った時点で、止まって見えるのを待たずにタップします。
3. **隠すのは、読み込みが始まったボタンと、読み込み済みと記録したボタンだけです。** 画面に見えているボタンは、まだ読み込めていないものです。

X は、読み込んだ後もボタンを残し、もう一度押しても何も読み込まれません。そのため、読み込み終わったボタンは端末に記録し、X を起動し直した後も、読み込み直さずに隠します。

## 対応バージョン

| アプリ | バージョン |
|---|---|
| X（`com.twitter.android`） | `12.19.1-release.0` |

動作を確認したのは上の版だけです。ほかの版では、次のようになります。

- 裏の読み込みに必要な内部の名前が見つからない場合は、その部分だけが無効になり、ボタンを自動でタップする動作になります。
- ボタンそのもの（`GapView`）が見つからない場合は、パッチの適用に失敗します。

## 使い方

1. [Releases](../../releases) から `.mpp` ファイルをダウンロードします。
2. Morphe Manager で、ダウンロードした `.mpp` をパッチのソースとして追加します。
3. X を選び、**Auto expand hidden posts (standalone)** を選択してパッチを当て、インストールします。

## オプション

Morphe Manager でパッチを選ぶ時に設定します。アプリ内に設定画面はありません。

| オプション | 既定 | 内容 |
|---|---|---|
| 画面に出る前に裏で読み込む | オン | タイムラインを開いた時に、ボタンの先のポストを裏で読み込みます。オフにすると、ボタンが画面に来た時の自動タップだけで読み込みます |
| 「ポストをさらに表示」を隠す | オン | 読み込みが始まったボタンと、読み込み済みと記録したボタンを非表示にします。オフにすると、読み込みは同じように行い、ボタンは残します |
| 動作時にトーストを表示する | オフ | 裏でポストを読み込んだ時、ボタンを隠した時、自動タップで読み込んだ時に、画面に短いメッセージを出します（同じメッセージは2秒に1回まで） |
| 診断ログを記録する | オフ | 処理の内容を `Download/AutoExpand/AutoExpand-Log.txt` に英語で追記します。1MB を超えると、それまでの分を `AutoExpand-Log.old.txt` として残し、新しいファイルに書き始めます（残すのは直前の1つ分なので、合わせて約 2MB までです）。X をアンインストールして入れ直すと、前のファイルには書き込めないため、`AutoExpand-Log-2.txt` のように番号を付けた別のファイルに記録します |

1.0.0 の「裏での取得を使わず、自動タップだけにする」は、1.1.0 で「画面に出る前に裏で読み込む」に置き換えました。自動タップだけにしていた場合は、「画面に出る前に裏で読み込む」をオフにしてください。

## 注意点

### 読み込みの上限

- 裏の読み込みと自動タップを合わせて、1分に10回までです。上限に達した時は、枠が空くのを待ってから続けます。
- 自動タップは、1つのボタンにつき5回までです。
- 裏の読み込みは、1つのタイムラインで30回までです。アプリを再起動するか、X がタイムラインを作り直すと数え直します。その後のボタンは、自動タップが読み込みます。

### 読み込まれないまま隠れる場合

「隠す」をオンにした時、ボタンが隠れたまま中身が読み込まれないのは、読み込みが始まったのに何も入らなかった場合だけです（読み込み済みのボタンか、通信の失敗）。見落としたくない場合は「隠す」をオフにしてください。読み込みは同じように行い、ボタンは表示したままにします。

### 自動タップの時の注意

- 読み込まれたポストは、ボタンがあった場所に入ります。勢いよくスクロールして通り過ぎた後だと、読んでいる位置より上に追加されます。トーストをオンにすると、「上にポストを追加しました」と表示されます。
- 読み込むたびにポストが増えている間は、同じボタンをタップし続けます。
- タップしても読み込みが始まらなかった時は、少し待ってもう一度タップします。それでも始まらなければ、ボタンを表示したままにするので、手でタップできます。
- 一覧の件数が読み取れない版では、ポストが増えたかを確かめられないため、1つのボタンにつき1回だけタップします。

### 裏の読み込みが働く画面

ホーム、リスト、プロフィールのタイムラインで働くことを確認しています。ポストの詳細（返信の画面）では、返信の続きも裏で読み込みます。一覧の最後の行（続きを読み込むためのもの）は、裏では読み込みません。

### 読み込み終わったボタンの記録

X は、読み込み終わった後もボタンを残し、もう一度押しても何も読み込まれません。そのようなボタンを X の起動のたびに読み込み直さないように、読み込み終わったボタンを記録します。

- 保存先は X のアプリ内の設定ファイル（`/data/data/com.twitter.android/shared_prefs/autoexpand.xml`）です。ボタンの中身ではなく、見分けるためのハッシュ値を、最近の500件まで保存します。同じファイルに、診断ログの日付の見出しを最後に書いた日も残します。
- ポストの詳細（返信の画面）の返信の続きは、画面を開くたびにまた読み込めるようになるため、記録しません。
- root 化していない端末では、このファイルを見ることはできません。
- X をアンインストールするか、X のストレージを消去すると消えます。

## ビルド方法

必要なもの：

- JDK 17
- Android SDK（`local.properties` の `sdk.dir`、または環境変数 `ANDROID_HOME` で指定）
- `read:packages` 権限のある GitHub のトークン（Morphe の Gradle プラグインが GitHub Packages で公開されているため）。`~/.gradle/gradle.properties` に `gpr.user` と `gpr.key` として書くか、環境変数 `GITHUB_ACTOR` と `GITHUB_TOKEN` で渡します。

```
./gradlew buildAndroid
```

`patches/build/libs/patches-<バージョン>.mpp` ができます。Morphe Manager で使うのは `buildAndroid` の出力です（`build` の出力には Android 用の `classes.dex` が入りません）。
