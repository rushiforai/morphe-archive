# Auto Expand for X

A patch for X (Twitter) for Android that automatically loads the posts behind "Show more posts" and hides the button.

X（旧 Twitter）の Android アプリで、タイムラインに出る「ポストをさらに表示」の中身を自動で読み込み、ボタンを非表示にする [Morphe](https://github.com/MorpheApp) 用のパッチです。

非公式のパッチです。X Corp. および Morphe とは関係ありません。

## できること

- タイムラインを開いた時に、「ポストをさらに表示」を押した時と同じ読み込みを、ボタンが画面に出る前に裏で実行します。
- X は、読み込むものが無くなった後もボタンを残します。そのため、裏の読み込みが動いている間は、ボタンの行を非表示にします。
- 裏の読み込みが使えない版の X では、自動でタップする動作に切り替わります。ボタンの行が画面の端に入った時点で、止まって見えるのを待たずにタップし、読み込みが始まったのを確かめてから行を隠します。その後も、読み込むたびにポストが増えている間は、隠したままタップを続けます。

## 対応バージョン

| アプリ | バージョン |
|---|---|
| X（`com.twitter.android`） | `12.19.1-release.0` |

動作を確認したのは上の版だけです。ほかの版では、次のようになります。

- 裏の読み込みに必要な内部の名前が見つからない場合は、その部分だけが無効になり、ボタンを自動でタップする動作になります。
- ボタンそのもの（`GapView`）が見つからない場合は、パッチの適用に失敗します。

## 使い方

1. [Releases](../../releases) から `.mpp` ファイルをダウンロードします。
2. Morphe Manager で、ダウンロードした `.mpp` をパッチのソースとして追加します。
3. X を選び、**Auto expand hidden posts (standalone)** を選択してパッチを当て、インストールします。

## オプション

Morphe Manager でパッチを選ぶ時に設定します。アプリ内に設定画面はありません。

| オプション | 既定 | 内容 |
|---|---|---|
| 「ポストをさらに表示」を隠す | オン | ボタンの行を非表示にします。自動タップの時は、読み込みが始まったのを確かめてから隠します |
| 診断ログを記録する | オフ | 処理の内容を `Download/AutoExpand/AutoExpand-Log.txt` に追記します。1MB を超えると、それまでの分を `AutoExpand-Log.old.txt` として残し、新しいファイルに書き始めます（残すのは直前の1つ分なので、合わせて約 2MB までです）。X をアンインストールして入れ直すと、前のファイルには書き込めないため、`AutoExpand-Log-2.txt` のように番号を付けた別のファイルに記録します |
| 動作時にトーストを表示する | オフ | 裏でポストを読み込んだ時、ボタンを隠した時、自動タップで読み込んだ時に、画面に短いメッセージを出します（同じメッセージは2秒に1回まで） |
| 裏での取得を使わず、自動タップだけにする | オフ | 裏の読み込みに問題がある時の予備です。オンにすると、どの版でも自動タップの動作になります |

## 注意点

### 「隠す」をオンにした時の副作用

裏の読み込みが動いている時、ボタンは、そのギャップの中身を実際に読み込んだかどうかに関係なく隠れます。そのため、次の場合は中身が読み込まれないまま、画面上では見えなくなります（自動タップの時は、読み込みが始まったのを確かめてから隠すので、この問題はありません）。

- **読み込みの上限に達した後に残ったギャップ**
  - 続けて読み込むのは5回までです。2分間読み込みが無ければリセットされます。
  - 1つのタイムラインで読み込むのは30回までです。アプリを再起動するか、X がタイムラインを作り直すと数え直します。
- **裏の読み込みが働かない画面のギャップ**：ホーム、リスト、プロフィールのタイムラインで働くことを確認しています。それ以外の画面は確認していません。

見落としたくない場合は「隠す」をオフにしてください。ボタンが表示され、手でタップして読み込めます。

### 自動タップの時の注意

- 読み込まれたポストは、ボタンがあった場所に入ります。勢いよくスクロールして通り過ぎた後だと、読んでいる位置より上に追加されます。トーストをオンにすると、「上にポストを追加しました」と表示されます。
- タップしても読み込みが始まらなかったギャップは、隠さずに残します。手でタップして読み込めます。
- タップは1つのギャップにつき5回まで、全体で1分に10回までです。上限に達した時は、枠が空くのを待ってからタップします。
- 一覧の件数が読み取れない版では、ポストが増えたかを確かめられないため、1つのギャップにつき1回だけタップします。

## ビルド方法

必要なもの：

- JDK 17
- Android SDK（`local.properties` の `sdk.dir`、または環境変数 `ANDROID_HOME` で指定）
- `read:packages` 権限のある GitHub のトークン（Morphe の Gradle プラグインが GitHub Packages で公開されているため）。`~/.gradle/gradle.properties` に `gpr.user` と `gpr.key` として書くか、環境変数 `GITHUB_ACTOR` と `GITHUB_TOKEN` で渡します。

```
./gradlew buildAndroid
```

`patches/build/libs/patches-<バージョン>.mpp` ができます。Morphe Manager で使うのは `buildAndroid` の出力です（`build` の出力には Android 用の `classes.dex` が入りません）。
