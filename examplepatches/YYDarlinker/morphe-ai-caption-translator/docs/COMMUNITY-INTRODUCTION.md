## Awesome Morphe Bundle Request

Action: Add Bundle

Repository URL: https://github.com/YYDarlinker/morphe-ai-caption-translator

Description:

Anchored AI Captions is an independently maintained, GPLv3 patch bundle for YouTube. It translates existing video subtitles using an OpenAI-compatible API configured by the user. It provides caption styling, configurable languages in the native Auto-translate menu, profiles, caching and diagnostics, plus an optional session-only caption-selection memory patch. It is designed to be selected alongside compatible official Morphe patches, not to replace them.

Release 1.4.0 publishes an MPP with two public patches and Manager-readable metadata. Recommended combination: official Morphe Patches 1.45.0, original YouTube 21.16.256, Android 9+. Historical target declarations include YouTube 21.13.164 and 21.07.247 with matching official bundles from 1.42.0. These are not claims of complete device testing for every combination. The repository distributes patch code, not pre-patched YouTube APKs.

## Reddit introduction

Title: Anchored AI Captions 1.4.0: YouTube subtitle translation with your own API

I maintain Anchored AI Captions, an independent open-source patch bundle compatible with Morphe. It translates a video's existing subtitles using an OpenAI-compatible API you configure. Select a target in YouTube's Auto-translate menu while AI captions are enabled; original subtitle selections do not call the translation API.

It supports regular videos, full-screen playback and Shorts, caption styling, API profiles, configurable target-language entries and diagnostics. An optional second patch remembers your caption selection across videos for the current app session.

Use Expert mode with the compatible official patch set. The recommended combination is official 1.45.0 + original YouTube 21.16.256 on Android 9+. You need existing video subtitles and your own API account; provider/network latency and token charges apply. This is not an audio transcription service, and perfect subtitle timing or every OEM scenario is not guaranteed.

Source, setup and limits: https://github.com/YYDarlinker/morphe-ai-caption-translator
