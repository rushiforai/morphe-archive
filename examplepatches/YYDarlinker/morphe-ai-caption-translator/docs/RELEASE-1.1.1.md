# 1.1.1 release

Publishes the user's current local build through the existing Morphe semantic-release workflow. Source phrases are validated at the current source cursor and mapped to native source intervals; coarse ASR tracks can request a verified same-video native word reference; media timing is projected from the player callback rather than an independently offset media position; normal startup batching is restored.

Runtime source is unchanged from the locally delivered patches-1.1.1.mpp. Test fixtures are updated for the new timed_words/source-phrase request format and normal startup contract. The existing release gates remain enabled. This is not a claim that interrupted emulator playback acceptance was completed. No simulator or paid provider testing is resumed for this release.
