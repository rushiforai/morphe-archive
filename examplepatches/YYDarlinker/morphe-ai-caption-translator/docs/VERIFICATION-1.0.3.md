# 1.0.3 修复交付说明

## 首要问题：自动翻译没有字幕

用户日志有 42 次 API 尝试、0 次 2xx，主要为 HTTP 400。这证明没有译文生成；原生字幕又已被接管，所以画面没有字幕。报告未保留供应商错误消息，不能仅凭报告断言唯一的服务端错误原因。

修复了请求的 JSON 提示、供应商参数兼容、一次可选参数降级、同配置失败阻断和持续错误提示。“测试 API”使用正式字幕的同一请求与解析协议，测试成功会恢复已停止会话。通过本地 MockWebServer 验证真实 HTTP 请求、响应解析、时间锚到显示逻辑；没有调用用户的付费 API。

## 明确分离两种模式

- 原字幕（包括英语自动生成）：原文、原 cue 时间、自建样式，零翻译 API，不额外请求校时轨。
- 自动翻译菜单里的语言：才调用用户 API，按选定目标语言翻译并以源时间锚显示。
- 预取 tlang 请求不等于用户选择，不得自行发起付费翻译。

## 其余四项

- 简体菜单：修复跳转绕过注入的问题；在共享元数据与旧列表返回处补充中文（简体），保留繁体；核查生成的字节码入口与跳转落点。
- 状态记忆：删除默认语言设置。每次进程冷启动首次选择语言，此后跨视频记住开关、语言、原字幕/翻译模式和原字幕 ASR 偏好。原字幕语言缺失时不偷偷选择别的语言或改成 AI 翻译。
- 图标：字幕气泡、字幕线条与星光符号。
- API Key：独立密码输入窗口、明确的从剪贴板粘贴按钮、加密保存；避免 Morphe 设置列表的长按复制路径行为。

## 整体审查附加修复

去除每帧读取显示样式时解密 API Key 的开销；诊断明确标记双模式引擎；修复补丁列表生成器误选旧构建文件的问题；修复发布后两份元数据 CDN 更新先后不同导致的验证竞态。

## 更新步骤

刷新补丁源到 1.0.3，使用原始支持版本 APK 重新改包并安装（仅刷新源不会升级已安装的 YouTube）。选择官方 Captions 和本源 AI caption translator。不要同时选择旧 AI 翻译、HansFix 的语言重映射或独立 Remember subtitle language；无需删除这些补丁源。

进入设置，用新的 API Key 输入窗口检查配置并运行测试 API。回视频首次选择字幕语言。先选英语原字幕检查零翻译 API 的显示，再选自动翻译下的中文（简体）检查翻译。跨视频检查开启/关闭与语言模式记忆。
