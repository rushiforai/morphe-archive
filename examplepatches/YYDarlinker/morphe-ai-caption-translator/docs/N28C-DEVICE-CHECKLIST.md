# N28C有限手机复验清单

日期：2026-10-02。当前安排：先交付基于官方1.45.0的N28C-R2，再测这一套候选。R1工程已通过，旧B/C不用回测；若R1已经装好，其现象可以登记，但不能代替新基线组合验证。不将未适配的R1直接与官方1.45.0混合打包。

用户只需看播放和显示、提供完整诊断；不需要读懂十四种语言。测试约5–10分钟，有问题随时结束并保留诊断。

## 操作

1. 使用新候选，保留原数据/API profile；启动、进入设置、打开一个熟悉的有英文字幕视频。保持当前应用界面语言和原API设置、标准字号，先选原先常用中文翻译看30–60秒，确认正常播放、字幕没有明显倒退。
2. 同一视频暂停/继续，手动关字幕→等待几秒→再开字幕；再关AI开关→再开。观察不卡、无闪退、关闭后AI字幕不自行复活、再开能恢复。迁移后AI关闭时官方Always show仍可能自动显示原生字幕，这是官方策略，不据此认为AI开关无效；关注关闭AI后是否仍出现AI渲染或新AI请求。
3. 跳到两三个之前没看过的位置；回到刚看过的位置；再换一个视频，切横屏/竖屏各一次。观察是否卡住、是否出现旧视频/旧目标语种字幕、缓存回看是否正常。无需每秒反复跳转，也不要求清cache。
4. 目标改为英文看30秒，只看字有没有裁掉、叠在一起或持续快闪。若原生自动翻译菜单已有阿拉伯语，再看一小段含数字/英文名的内容是否有明显方向错乱；可加已有德/法/日/韩中的一种。缺少菜单项就跳过并说明，不临时加语言，不提前实施第四期。
5. 保存完整诊断。若某处空白持续明显异常或来回切换卡顿，记下视频ID/视频时段、目标语言、横竖屏和具体操作，随诊断发送。

## 发给规划者

- 完整caption-diagnostics文件（不用挑选几行）；设备型号/Android版本，新包名称或SHA。
- 正常也可只写“启动正常、开关/seek/换视频/旋转正常；试了中文+英文+哪些已有语种”。
- 异常写“在哪个视频/几分几秒、哪个目标、做了什么、看到了什么”，不需要解释外语语义。

规划者负责分析Session/退休清理、selection来源/目标、cache冷热、page时间/几何/安全空白reason、远程请求与等待；用户不承担外语校对。诊断不足以判断RTL视觉时再针对具体异常补证，不先要求十四语种截图或大范围测试。已知入口summary/语言适配遗漏/旧诊断中文仍延期，不能当已修复，也不把它们混入这次新生命周期/分页验收。
