# Contributing

Set up the [development environment](docs/DEVELOPMENT.md). Keep contributions focused and run the checks for the behavior you change.

For bug reports, include the YouTube, official patch bundle and add-on versions, the player mode and reproducible steps. Review diagnostic exports for credentials, video identifiers, caption text and provider responses before attaching them.

Keep original APKs, credentials, signing files and private reports out of the repository. Preserve existing licenses, attribution and useful test fixtures. Update the English and Chinese user guides when changing requirements or user-facing behavior. See [full verification](docs/DEVELOPMENT.md#run-checks) for final candidates.
