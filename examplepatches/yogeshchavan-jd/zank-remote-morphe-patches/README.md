## ❓ How to Use

### Method 1: Direct Deep Link (Morphe Manager)
1. Install [Morphe Manager](https://github.com/MorpheApp/morphe-manager) on your Android device or Android TV.
2. Open the following link on your device:
   ```
   https://morphe.software/add-source?github=yogeshchavan-jd/zank-remote-morphe-patches
   ```
3. Select **Zank Remote** and choose the patches to apply.

### Method 2: Manual Source in Morphe Manager
1. In Morphe Manager, navigate to **Settings** $\rightarrow$ **Sources**.
2. Tap **Add Source**.
3. Enter `yogeshchavan-jd/zank-remote-morphe-patches` and tap **Save**.

### Method 3: Desktop Patcher (Morphe Desktop / CLI)
Download the latest `patches-<version>.mpp` from [Releases](https://github.com/yogeshchavan-jd/zank-remote-morphe-patches/releases) and use Morphe Desktop to patch your Zank Remote APK.

## 🌐 Submitting to `morphe-patches.software`

Once the automated release completes:
1. Navigate to [morphe-patches.software](https://morphe-patches.software).
2. Click **Submit a bundle**.
3. Submit repository URL: `https://github.com/yogeshchavan-jd/zank-remote-morphe-patches`.
