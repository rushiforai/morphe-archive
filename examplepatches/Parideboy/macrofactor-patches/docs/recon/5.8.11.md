Pre-whole-dex-R8: RevenueCat and GMS class names are intact, so the name-based fingerprints apply
directly and the shape-based ones are only the fallback for 5.8.13.

CustomerInfoOriginalSource, Z)` survives as:

```
smali/classes6/com/revenuecat/purchases/common/CustomerInfoFactory.smali
public final buildCustomerInfo(...)   // method at line 376
.registers 20
```

- `public final` instance method → the `JSONObject` body is `p1` (5.8.13 turned it static, `p0`).
- Same `.registers 20` and same filter order as the copy described in the
  `BuildCustomerInfoFingerprint` KDoc (`subscriber`, `JSONObject.getJSONObject`,
  `non_subscriptions`, `subscriptions`, `entitlements`).
- The 5-arg overload is the single JDK-side constructor of every `CustomerInfo`: the 1-arg HTTP
  overload and the `$default` bridge both funnel into it, so one hook covers the online,
  offline-entitlement and cached (SharedPreferences) parse paths.
