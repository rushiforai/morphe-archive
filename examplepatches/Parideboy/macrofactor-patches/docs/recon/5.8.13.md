# MacroFactor 5.8.13 (versionCode 893)

## Whole-dex R8 renaming

This release switched R8 to whole-dex class renaming. Consequences:

- RevenueCat's own classes lost their names: `CustomerInfoFactory`, `VerificationResult` and
  `CustomerInfo` are gone, so name-based fingerprints (`BuildCustomerInfoFingerprint`,
  `GetSignatureHashFingerprint`) cannot run on this build. The `wrappers`/`PackageManagerWrapper`
  GMS helpers are renamed too, which kills every filter that references them by name.
- What survives: method shapes, framework type descriptors, string constants and JSON keys, the
  arity, and the access flags. Both patches are therefore resolved by shape first
  (`BuildCustomerInfoShapeFingerprint`, `GetSignatureHashShapeFingerprint`) and fall back to the
  name-based fingerprints for 5.8.11 and older.

## `CustomerInfo` construction — `smali/sob.smali`

The 5-arg overload of RevenueCat's `CustomerInfoFactory.buildCustomerInfo`:

```
Lsob;->b(Lorg/json/JSONObject;Ljava/util/Date;Lw39;Lvo1;Z)Lmo1;
.locals 17
```

- Static (`sob.b` is the renamed `CustomerInfoFactory`), so `p0` is the `JSONObject`; for 5.8.11
  the same method is `public final` with the `JSONObject` in `p1`.
- `.locals 17` means the parameter registers sit past `v15`, so an injected call into a method
  taking byte[] has to use `invoke-static/range`.
- The method is the only one in the app whose parameters start with `(JSONObject, Date)` and that
  references all of `subscriber`, `non_subscriptions`, `subscriptions`, `entitlements`. That
  combination is the fingerprint's `custom` predicate.

## GMS certificate hash — `smali/y6b.smali`

`AndroidUtilsLight.getPackageCertificateHashBytes(Context, String)` after renaming:

```
public static a(Landroid/content/Context;Ljava/lang/String;)[B
.locals 4
```

- The only static `[B` method with that parameter list that references `"SHA1"`.
- Still reads `PackageInfo.signatures` and digests it with `MessageDigest("SHA1")`, which is what
  Firebase App Check / Installations / Auth consume.
