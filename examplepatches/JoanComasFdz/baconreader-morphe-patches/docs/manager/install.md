# How to install

Add the BaconReader patches to Morphe Manager, then let it patch your BaconReader 6.1.4 APK and install it.

- Install [Morphe Manager](https://morphe.software), and have your BaconReader Premium (or BaconReader) 6.1.4 APK on the phone. Use an APK you trust: repackaged "Premium" APKs often carry malware.
- On the phone, open this repository on GitHub and tap **➕ Add to Morphe Manager**, then **Open in Morphe**, then **Add**.
- In Morphe Manager, tap **BaconReader Premium** (or **BaconReader**, the one your APK is), then **No, I already have it**, and pick your APK: Morphe Manager patches it with the newest patches.
- Tap **Install**. The first time, Android says "Permission required": tap **Settings** and turn on **Allow from this source**; Android then asks "Install this app?": tap **Install**, then go back to Morphe Manager. If the original BaconReader is installed, uninstall it first: Android won't install the patched one over it.
- The bottom of BaconReader's left menu shows which patches are installed, such as "Patches 1.8.2 (Morphe)". Settings live in BaconReader → **Settings → Patches**.
