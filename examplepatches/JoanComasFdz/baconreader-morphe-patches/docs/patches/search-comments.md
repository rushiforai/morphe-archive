# Search comments

A search button on posts finds the comments with a text or a user name.

- "Search comments" sits right before "COLLAPSE ALL". Type a text or a user name: the matches are highlighted, and the
  search shows which match is on screen, such as "1/3".
- "Previous match" and "Next match" jump between them, also into collapsed comments.
- "Show only matching comments" lists only the comments that match; tap it again to see all of them.
- While some comments are still behind "load more comments", "SEARCH ALL" loads them first, then searches them too.

No settings.
