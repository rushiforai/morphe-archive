# Hide formatted spoilers

Every spoiler in comments and posts stays hidden until you tap it.

- BaconReader only hid spoilers of plain text: a spoiler with bold or italic text, a link or code showed in plain
  sight. Now it hides behind the spoiler box too, and a tap shows it.
- A tap on a link in a hidden spoiler shows the spoiler; the next tap opens the link.
- Screen readers such as TalkBack read a hidden spoiler as "spoiler", not its text.

No settings.
