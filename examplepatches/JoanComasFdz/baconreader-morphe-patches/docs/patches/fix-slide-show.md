# Fix slide show

The Slide Show View fits the screen again, and a long post text scrolls.

- Each post fits between the toolbar and the bottom bar: its image, its text, a gallery's thumbnails and its border no
  longer hide behind the bottom bar. On newer Android versions (seen on 16 and 17), BaconReader sized each post as if
  the status and navigation bars weren't there.
- An image post's text, once expanded, scrolls inside the post instead of being cut off at its bottom.

No settings.
