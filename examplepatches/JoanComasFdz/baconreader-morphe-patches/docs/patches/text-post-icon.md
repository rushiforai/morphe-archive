# Text post icon

Text posts in the post list get a page icon instead of a button that looks like a video's play button.

- The button that opens a text post's text under its title shows a page with a chevron, in the list and card views.
  BaconReader drew it as a triangle in a circle, which looked like a video that didn't load.
- The chevron flips when the text opens, and flips back when it closes.
- Screen readers call the button "Show post text", or "Hide post text" while the text is open.

No settings.
