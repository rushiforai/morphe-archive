# Patches entry in settings

BaconReader's settings get a "Patches" entry, and the left menu tells which build of the patches is installed.

- **Settings → Patches**, the last entry, opens the patches' own settings.
- The bottom of the left menu shows the patches' version and the patcher, such as "Patches 1.8.2 (Morphe)" or
  "Patches 0.1.18 (Reseam 0.39.1)": tell it when reporting a problem.
