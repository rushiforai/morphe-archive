## Progress reports

- A long-running operation (a build, a run, a wait): report its status, the time elapsed and the time left every minute.
- An e2e run on the NAS ("E2E on the phone"): give the link to its job on GitHub as soon as it starts, so the user follows its live log there, instead of minute-by-minute reports. GitHub's API serves a job's log only once it ended.
