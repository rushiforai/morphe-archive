# Contributing

This collection is intentionally limited to Amazon dark mode, Transit GO enhancements and Niagara weather. Keep Kotlin patches under `patches/src/main/kotlin`, Android helpers under `extensions/extension/src/main/java`, and deterministic tests under `tests/`.

Run the README build/test commands. Never commit APKs, private signing material, user traces, account data or local credentials. Describe live-device limitations honestly. Changes to Transit remain on hold pending the user’s next bus test. No automated pull requests are created by this repository.
