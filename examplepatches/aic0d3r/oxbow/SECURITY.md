# Security Policy

Oxbow is an unofficial open-source patch for the Instagram Android app.

Because this project involves a modified APK and user authentication through Instagram, security reports are taken seriously.

## What to report

Please report security issues such as:

- credential leakage;
- unexpected network requests;
- malicious or suspicious patch behavior;
- unsafe release artifacts;
- signature or build integrity problems;
- vulnerabilities in the patching scripts.

## What not to report

Please do not report general Instagram bugs or account issues that are unrelated to Oxbow.

## How to report

If you believe you found a security issue, please don't open a public issue.

Report it privately through GitHub: [Report a vulnerability](https://github.com/aic0d3r/oxbow/security/advisories/new). Only the maintainer can see it.

## Trust model

Oxbow does not collect, proxy, store, or transmit Instagram credentials.

Users are encouraged to inspect the patches and build the APK themselves.
