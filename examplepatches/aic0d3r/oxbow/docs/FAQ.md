# Frequently Asked Questions

Oxbow is a fork of [Feurstagram](https://github.com/jean-voila/FeurStagram) by Jean Herail (GPL-3.0).

## What is Oxbow?

Oxbow is an open-source Android patch for Instagram that removes distracting features such as feed, Reels, Explore, ads and telemetry while keeping useful features like DMs, stories, profiles, search and notifications. On top of the inherited blocks, Oxbow adds media downloads, HD profile pictures, ghost mode and clean share links.

## Is Oxbow affiliated with Instagram or Meta?

No. Oxbow is an unofficial community project and is not affiliated with Instagram or Meta.

## Does Oxbow collect my password?

No. Oxbow does not collect, store, proxy, or transmit your credentials.

Instagram login still happens through the Instagram app itself.

## Can I build it myself?

Yes. Users are encouraged to build the APK themselves using the documented patching process.

## Why does Android warn me before installing the APK?

Oxbow is distributed outside the Google Play Store, so Android may show warnings before installation. This is expected for APKs installed manually.

Only install APKs from the official Oxbow GitHub releases, or build the APK yourself.

## Classic APK or Clone APK?

The classic APK replaces the regular Instagram app because it keeps Instagram's original package ID.

The clone APK is designed to install alongside the regular Instagram app by using a different package ID.

Use the clone APK if you want to keep the official Instagram app installed at the same time.

## Can my Instagram account be banned?

Oxbow is unofficial and modifies the Instagram Android app. This may violate Instagram's terms of service. Use it at your own risk.

## Why not use a WebView wrapper?

Oxbow patches the real Android Instagram app instead of wrapping the website in a WebView. This allows it to keep the native app experience while removing specific distracting features.

## Why not use an accessibility-service blocker?

Accessibility blockers usually react to the interface after it appears. Oxbow aims to remove or block distracting parts more directly through patches.

## Does Oxbow remove all distractions?

The goal is to remove the most addictive parts while keeping useful social features. Some features may change or break when Instagram updates its app.
