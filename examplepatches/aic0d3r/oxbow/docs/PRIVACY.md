# Privacy

Oxbow is a fork of [Feurstagram](https://github.com/jean-voila/FeurStagram) by Jean Herail (GPL-3.0).

Oxbow is designed to remove distracting and intrusive parts of Instagram.

## Data collection

Oxbow itself does not collect analytics, credentials, personal data, or usage data.

The GitHub Pages site does not load third-party analytics scripts.

## Credentials

Oxbow does not collect, store, proxy, or transmit Instagram usernames, passwords, or session tokens.

Authentication is handled by Instagram inside the app.

## Network behavior

Oxbow may block or modify some Instagram app behavior depending on the active patches.

Where possible, patches related to ads, telemetry, or network behavior should be documented. The README documents the current blocked network paths.

## Third parties

Oxbow is not affiliated with Instagram, Meta, Facebook, or any third party.

## Recommendation

If you do not want to trust a prebuilt APK, build Oxbow yourself from source.
