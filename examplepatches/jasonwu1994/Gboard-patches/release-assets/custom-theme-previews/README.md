# Custom Theme preview releases

Each version directory contains the immutable assets for one Custom Theme preview release.

- Tag and release name: `custom-theme-previews-vN`
- Archive: `vN/custom-theme-previews-vN.zip`
- Manifest: `vN/custom-theme-previews-vN-manifest.json`
- Runtime URL: `https://github.com/jasonwu1994/Gboard-patches/releases/download/custom-theme-previews-vN/custom-theme-previews-vN.zip`

Published versions must not be replaced or removed because patched APKs pin both the release URL and the archive SHA-256. Publish any update as a new version instead.

The preview images originate from Rboard PackRepoBeta and are redistributed with permission. Actual theme packs continue to download directly from the upstream repository.
