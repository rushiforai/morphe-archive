* **TikTok:** Показывать кнопку скрытия на видео и Показывать кнопку блокировки звука теперь рисуют собственные элементы ленты, даже если Показывать кнопку блокировки на видео выключена. Оба работают через Фильтр ленты, поэтому в списке они есть, только когда этот патч включён. На новых установках эти два вспомогательных переключателя выключены, чтобы выбор кнопки блокировки автора не добавлял лишние чипы, пока вы сами не попросите (#95).

Отключённый ярлык остаётся отключённым, обычные нажатия на Главную работают, а собственное действие TikTok при долгом нажатии сохраняется (#89).

* **TikTok:** Настройки на Android 6 используют формы множественного числа поставляемых языков, в том числе русские one, few и many. Недостающие переводы количества переключаются на английский с правильной формой единственного числа. Более новые версии Android сохраняют собственные правила ICU.

* **TikTok:** Что нового хранит всю историю релизов, даже когда текст растёт. Большие заметки и международный текст больше не превышают предел Java на сборку одной строки.

* **TikTok:** Morphe Manager 1.33.0 показывает все 106 патчей в десяти категориях, и ничего не остаётся без категории. Проверки перед каждой сборкой теперь охватывают входные данные с одной ABI для каждой поддерживаемой версии TikTok и отклоняют изменённые нативные библиотеки или пустой результат патча. Опубликованные пакеты можно проверить по аттестациям релизов GitHub или по закреплённому ключу подписи.

* **TikTok:** Ограничение фонового трафика по умолчанию сохраняет настройку push нетронутой, в том числе когда выбрано «Все». Необязательный пункт Пропустить настройку push по умолчанию выключен, а при включении может остановить сообщения и другие уведомления. Существующие APK нужно заново пропатчить из оригинального APK TikTok, чтобы вернуть настройку push. Пауза не может отменить это изменение, сделанное при патчинге (#86).

* **TikTok:** Восстановить настройки теперь сообщает о ключах, которые текущая сборка не может восстановить, отдельно от настроек, отсутствующих в более старой копии. Переносимые настройки по-прежнему переходят между версиями TikTok, локальное состояние устройства остаётся нетронутым, а совместимость Feature Gate Lab и «Отменить» работают как раньше.

* **TikTok:** Раздел Просмотренные видео в Фильтре ленты может импортировать проверенный JSON-экспорт истории просмотров TikTok. Даты просмотров и выбранный аккаунт остаются привязанными к импорту, действует существующий лимит по возрасту, а баннер сообщает о добавленных и пропущенных записях. Повторный импорт ничего не добавляет. Недопустимые или неподдерживаемые файлы и неудачные записи оставляют сохранённую историю без изменений. Файлы ограничены 2 МБ и 10 000 записями, а ссылки никогда не покидают телефон. Импорт, который добавляет историю, завершает «Отменить» для более ранней очистки и объясняет это изменение.
