# A start-call, next-call, sole-call or once-call rule picks its method by every string it names
# and its shape, and exactly one of Pinterest's methods may answer that; name as much as the patch
# itself finds the method by. scripts/test-injected-registers.ps1 builds bad fixtures for every
# rule here, and fails on a rule it has none for.
# The settings patch sends each of these ShortcutManager calls to SettingsEntry, which makes the
# real call and puts the HushPinterest shortcut back in front after it. One left in Pinterest's own code
# could rank Pinterest's shortcuts ahead again and push the HushPinterest one out of the long-press
# menu. A build whose own code makes one of
# these calls fails the rule for it, so each new Pinterest version is checked against them.
