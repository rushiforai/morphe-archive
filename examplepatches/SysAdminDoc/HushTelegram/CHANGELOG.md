# Changelog

Every HushTelegram release, newest first.

## 0.0.21 (2026-10-27)

The twelfth release, with 67 patches for Telegram 13.1.1 from Google Play and 13.1.0 from telegram.org. It's built on Morphe patcher 2.0.1, so update Morphe Manager to 2.2.0 before you patch. Most of what's new came out of your reports. You can hide chats you pick, drop the All Chats tab, keep the text of edited messages and translate into any language Google knows, and the settings are one short list now.

* **Telegram:** The Google Play build is supported at 13.1.1 now (version code 72371), and Play's 13.1.0 isn't. telegram.org's own download is still 13.1.0 (72299), so that one stays where it was.
* **Telegram:** **Also save from chats that don't allow saving** now takes photos and videos too. Telegram hides Save to Gallery in those chats, so before, only files and songs got copied and the pictures stayed stuck in the app. Each photo and video you open or auto-download there goes to Download/Telegram along with the files. Secret chats and self-destructing media still stay in Telegram, and ordinary chats keep using Save to Gallery. (#29)
* **Telegram:** **Hide folder tab counters** has a new switch on the Chat list page, **Hide picked chats**. Tap **Chats to hide** right under it, tick the chats you'd rather not see, and they leave All Chats, your folders and Archived Chats. A new message doesn't bring them back. They still get their messages and notifications, search still finds them, and nothing changes on your other devices or for anyone else in the chat. Each account keeps its own list. A pinned chat you hide stays pinned, even when you pin or move other chats. The folder tab counts and the app badge still count their unread messages. You can also hide chats straight from the list: long-press them, open the three-dot menu and tap **Hide from chat list**. It's off unless you turn it on. (#24)
* **Telegram:** The Chat list page has a **Hide All Chats** switch right under the folder to open at launch. Turn it on and restart, and the All Chats tab is gone, so the chat list opens on the folder you picked there, or on your first folder if you didn't pick one. Locked folders get skipped, and if you delete the folder you're on, the list moves to the next one you can open. An account with no folders of its own keeps All Chats until you make one. Archived Chats moves into the chat list's three-dot menu and the side menu, since its usual spot sat on top of All Chats. Dragging tabs to reorder them is off while the switch is on (you'll get a short note saying so), so turn it off for a moment to change the order. It's off unless you turn it on. (#21)
* **Telegram:** Every HushTelegram title now uses Telegram's blues, from sky blue to periwinkle. The colors drift slowly along the words, with a light shine every few seconds. That covers the settings header, search and pages like Changed switches, the settings dialogs, the screen shown when settings can't load, and HushTelegram's own pop-ups in chats when Telegram is on a dark theme. It keeps moving even with Android's animations turned off.
* **Telegram:** The HushTelegram settings use Telegram's own blue now instead of cyan, so they look like part of the app. Switches, section titles, buttons and the text cursor all match, and everything still reads clearly on the black background.
* **Telegram:** The HushTelegram settings are one short list now. Every section, from Ads down to About, opens right where it is with a tap and folds away with another, so there's no More settings page to dig through anymore. Rows, icons and the header take less room, and the welcome lines at the top are gone. Pause moved to a button at the top of the screen, and the status card only shows up when it has something to tell you, like a pause waiting on a restart. When a switch needs a restart, the restart row appears right under it, and after the restart the sections you had open are still open.
* **Telegram:** **Keep deleted messages** has a new switch, **Keep edit history**. When someone else edits a message, your phone keeps the text it had before, up to five earlier versions for each of the last 500 edited messages. Open the edited message's menu and tap Message details, which shows up for it even with its own switch off. Each earlier text is listed with the time of the edit, oldest first. **Clear edit history** right under the switch forgets all of it, in every account. Your own messages, disappearing messages and messages from chats that don't allow saving are left alone. It's off unless you turn it on, and the kept text never leaves your phone.
* **Telegram:** Translate with an outside service has a **Translate into** row on the Conversations page, right under Translation service. It lists every language Google's web translate knows (about 250, Dari and Cantonese among them), each by its own name, with a search box that finds a language by its own name, its name in your app's language, its English name or its code. Where your phone knows a language by another name, Google's is shown next to it, like Akan (Twi). Pick Persian, or any other language Telegram's own translate list doesn't offer, and Translate here and Translate this chat both write in it. That works with Google and with your own AI service. Pick Traditional Chinese and messages in Simplified get written out in Traditional too, and the other way around. Telegram's language stays the default, pausing HushTelegram goes back to it, and a settings backup carries the choice. Left on Telegram's language, it writes in the language Telegram's own translate bar shows for the chat, so a language you picked there (in that chat, or last time anywhere) is used. (#35)
* **Telegram:** The keyboard doesn't cover Save and Cancel anymore in the Translation service, chat list title emoji and message filter boxes. The box now shrinks to fit above the keyboard, which matters most with a large font size or on a small screen.
* **Telegram:** With Telegram set to Hebrew, Translate with an outside service leaves Hebrew messages alone instead of writing them out again in Hebrew. Google names Hebrew and Javanese by their older codes, and those now count as the same language.
* **Telegram:** Save downloaded files has a **Gallery folder** row on the Playback page. It picks where Save to Gallery puts the photos and videos you save. Telegram's own Pictures/Telegram and Movies/Telegram stay the default. You can put both in DCIM/Telegram instead, or keep them apart in DCIM/Telegram/Photos and DCIM/Telegram/Videos. Pausing HushTelegram sends saves back to Telegram's folders, and a settings backup carries the choice. Photos taken with Telegram's camera and automatic saving still use Telegram's folders. (#30)
* **Telegram:** Save downloaded files has a **Keep Telegram's files in internal storage** switch on the Playback page, under Gallery folder. Since Android 11, Telegram keeps everything it downloads in Android/data, where most file managers can't get in. Turn this on and new photos, videos and files go to Internal storage/Telegram instead, the way Telegram did on older Android. It needs All files access, so turning it on takes you to that Android page, and the row says whether the access is on. Telegram picks the folder up after a restart. Files downloaded before stay in Android/data. With the switch off, the access missing or HushTelegram paused, Telegram stays in Android/data. (#7)
* **Telegram:** If a Telegram build leaves room for a switch but not for one of the extra rows under it (like Gallery folder or Hold automatic downloads on Data Saver), the switch keeps its usual description. Before, it was replaced with a line saying the patched app doesn't change that extra, which made the switch look broken when it worked fine. The row is just missing, and the diagnostic report still names it.
* **Telegram:** With **Voice messages in the music player** on, a voice message open in the full player doesn't show Telegram's Add to Profile button anymore. That button is for songs, and tapping it on a voice message made no sense. Songs keep it, and so does everything while the switch is off or HushTelegram is paused.
* **Telegram:** **Hide new message button** keeps the pencil button hidden now. Telegram brings the button back with its own little grow animation whenever the chat list settles (after a scroll, on opening the app, when you leave a chat), and that animation used to undo the switch. The Done button Telegram shows in the same spot while you pick chats still shows up like before. (#31)
* **Telegram:** **Keep videos muted on volume keys** has a third switch on the Playback page, **Turn videos only from the full screen button**. With auto-rotate on, an open video can swing to landscape the moment you tilt your phone. With this switch on, it stays upright until you tap full screen, and the app goes back to its usual turning when you leave full screen or close the video. It's off unless you turn it on. Whatever the switch says, the diagnostic report now counts whether a video went full screen from its button or from the phone turning, so you can see which one happened. (#27)
* **Telegram:** **Hide channel bar buttons** has a second switch on the Look and feel page, **Hide channel Mute button**. With it on, the bar at the bottom of a channel you've joined is gone, so the Mute button goes, and Search and Info go along with it. Channels you haven't joined still show Join, and other bars like Unblock, Delete chat and Start bot stay too. To mute a channel, open its info. It's off unless you turn it on, and a channel picks it up the next time you open it. (#26)
* **Telegram:** **Hide Telegram Features and Invite Friends** now takes the Telegram Features row out of Settings the moment you flip it, and puts it back the same way. Before, Settings kept the row until Telegram restarted. Contacts already changed right away.
* **Telegram:** Passkeys stay out of the way on a patched install. Android hands Telegram's passkeys only to an app signed with Telegram's own key, so a patched APK signed with your key could never make or use one. The passkey row in Privacy and Security, the "set up a passkey" banner in the chat list and the passkey step at sign-in are hidden on those installs now, the way Telegram turns them off in builds that aren't its own. Signing in with a code or your two-step password works as before, and passkeys already on your account stay there. An install that keeps Telegram's signature (a root mount) still offers passkeys.
* **Telegram:** HushTelegram's settings speak Bulgarian now. Switch Telegram to Bulgarian and every HushTelegram page, switch, search result and message follows. Where it points you to one of Telegram's own settings, it uses the name Telegram shows in Bulgarian, even the few Telegram hasn't translated yet. (Discussion #33)
* **Telegram:** **Folders by chat type** makes its tabs in the same order every time now: Private, Groups, Channels, Bots. Telegram's server can answer the four requests in any order, and the tabs used to line up in whatever order the answers arrived (Bots first, for example).
* **Tooling:** A release walk now has to be a walk of the APK it says it walked. `scripts/walk-app.ps1` leaves `patch-artifact.json` next to the signed APK (its SHA-256 and signing certificate, package and version, the fixture and bundle it came from, the patches picked) and the receipt carries it. Publish turns the walk down when the installed APK's hash doesn't match that record, the APK came from another bundle or fixture or left a patch out, or the package or version is wrong. It also refuses a walk with recorded problems, times that can't be right, or a scenario from `scripts/walk-scenarios.json` that never opened, so a shortened `-SettingsPages` list can't pass as a full walk. A signed-out walk is reported as a settings smoke and a signed-in one as feature acceptance. `-SkipPatch` walks the same APK again by its record.
* **Tooling:** The patch checks (`verify-all-patches.ps1`, `verify-patch-selections.ps1`, the release receipt and `patch-for-device.ps1`) now run the CLI with `--validate`, so a fingerprint that matches more than one method fails instead of patching the first one it finds. A run kept with `-KeepIn` from before this change gets patched again.
* **Tooling:** The patch selection check (`verify-patch-selections.ps1`) no longer fails its broken options file case on morphe-desktop 1.19.1. That version prints its stack lines in italics, and the style codes hid the lines the check reads.
* **Tooling:** The source census reads Jman's Patch Bundle Registry through its catalog API now. The registry dropped the snapshot the audit used to read, so that check answered 404. Preflight also checks that the census is from the last 14 days. Before, only the index stage did, and by then the release was already public.
* **Telegram:** HushTelegram now builds on Morphe patcher 2.0.1, which uses less memory while patching. This release needs **Morphe Manager 2.2.0 or newer**, so update Manager before you patch. On a computer, use morphe-desktop 1.19.1 or newer.
* **Telegram:** The README matches what HushTelegram does today. It covers saving from chats that don't allow saving (self-destructing media still stays in Telegram), names both Telegram builds and their checksums, and is clearer that your own API ID gets you past `API_ID_PUBLISHED_FLOOD` while Telegram still decides which login methods you get. The settings screenshots are new too, taken on Telegram 13.1.0.

## 0.0.20 (2026-10-23)

The eleventh release, with 67 patches for Telegram 13.1.0 from telegram.org and from Google Play. It's built on Morphe's 2.0 patcher, so update Morphe Manager to 2.0.0 before you patch. Four new switches came out of your issue reports.

* **Telegram:** Moved to Telegram 13.1.0, both telegram.org's build (version code 72299) and the Google Play build (version code 72291). Every patch carried over as it was.
* **Telegram:** HushTelegram now builds on Morphe's 2.0 patcher, so this release needs **Morphe Manager 2.0.0 or newer**. Update Manager first, then patch. On a computer, use morphe-desktop 1.19.0 or newer. The patch count is the same, and every patch still applies to both 13.1.0 builds.
* **Tooling:** A release can't go public until the whole app has been walked with that exact bundle on a release phone or an emulator. The publish stage now takes the walk's receipt as `-Walk`, and it stops before the notes, the tag or GitHub if the walk wasn't a full pass, saw a Telegram crash, ran on some other device, or patched with a different bundle. `scripts/walk-app.ps1` runs the walk. It patches Telegram from the bundle and installs it on a leased phone or emulator without touching the app's data, then opens Telegram's own screens and every HushTelegram settings page and reads the crash log. `patch-for-device.ps1 -CliDefaultKeystore` signs with a keystore the desktop CLI made.
* **Telegram:** The HushTelegram settings home page gets you to the settings sooner. The seven pages of switches now sit right under the status card, and the header, the gaps between cards, the section titles and the page rows all take less room. **Quick setups** moved to the Settings backup page and **Lock HushTelegram settings** to the Pause page under More settings. Search finds both, and they work like before. The long press that hid Quick setups is gone, and so is its **Quick setups on the home page** row.
* **Telegram:** Locking the HushTelegram settings by mistake no longer costs you a day. For 10 minutes after you lock them, the row reads **Unlock now** and one tap opens them again. After that, unlocking takes the usual 24 hours. Changing the phone's clock or restarting the phone ends those 10 minutes early. (#23)
* **Telegram:** Save downloaded files has a new switch under it, **Also save from chats that don't allow saving**, and it starts off. With it on, files and songs from chats whose owner turned off saving get a copy in Download/Telegram too. That's for chats where the owner doesn't mind you keeping things. Secret chats and self-destructing media still stay inside Telegram. (#29)
* **Telegram:** Save downloaded files now covers the files and songs Telegram downloads on its own, too. Before, a file that auto-download fetched while its chat was closed stayed in Telegram even with the switch on, and only files downloaded in an open chat got a copy. Those now go to Download/Telegram under their own names, and chats that don't allow saving follow the same switch as everything else. (#29)
* **Telegram:** Keep deleted messages gets a second switch, **Show deleted in red**. Off by default. Turn it on and the word "deleted" next to a kept message's time turns red, so those messages stand out while you scroll. The time keeps its usual color and the bubble stays the same size. (#25)
* **Telegram:** **Hide Contacts tab** has one more switch on the Chat list page, **Hide new message button**. It hides the round pencil button on the chat list. The story camera button, the archive, your folders and search all work as before, and you start a new chat from the menu or from search instead. It's off until you turn it on, and the change shows after a restart. (#22)
* **Telegram:** **Keep videos muted on volume keys** has a second switch on the Playback page, **Full screen videos turn either way**. Telegram puts a full screen video on one landscape side and leaves it there, so turning the phone the other way shows the picture upside down. With this switch on, the video follows your phone to either side, even with auto-rotate off. It starts off. (#27)
* **Tooling:** The release and patch selection scripts read morphe-desktop 1.19.0's results as well as 1.18.1's. The new CLI renamed its list of patching steps, lists applied patches without the rest of their details, and writes a failed patch as just its name and error. It also skips the result file when it can't read the options file. A result with no steps, or with a failed step, is still refused.

## 0.0.19 (2026-10-17)

The tenth release, with 67 patches. It clears up the last release's confusion for anyone who downloaded Telegram from Google Play, and it drops the beta as a target.

* **Telegram:** The Google Play version of Telegram 13.0.3 (`org.telegram.messenger`, version code 71831) can be patched now. That's the APK APKMirror and Uptodown carry, and Morphe Manager used to turn it away with "Wrong package selected" because it only knew telegram.org's build. telegram.org's build still works the same way.
* **Telegram:** **Repair Firebase push registration** also covers the Play build, so its notifications sign up with Google like they do on telegram.org's build.
* **Telegram:** The official Telegram beta isn't a target anymore. **Turn off beta debug logs** is gone with it, and so is the part of **Disable analytics** that only stopped the beta's crash and session reports. If you're on the beta, switch to telegram.org's build or the Play build before you patch.
* **Tooling:** The release's clean-APK check accepts the Google Play build as a vendor baseline. It now asks that the signing certificate the catalog declares for the package be present on the APK, and it allows the extra certificate Google Play App Signing adds. Before, it required every certificate on the APK to be one the catalog declared, so the Play build's Google certificate stopped the release even though the patcher applied every patch to it.

## 0.0.18 (2026-10-16)

The ninth release, with 68 patches for telegram.org's Telegram 13.0.3 and the official Telegram beta 13.0.3.

* **Telegram:** Moved to Telegram 13.0.3, telegram.org's build and the official beta (both version code 71839). Every patch carried over without a change.
* **Telegram:** The descriptions in Morphe Manager now mention the switches that were added inside existing patches, so you can see what **Hide popular apps**, **Faster downloads**, **Repair Firebase push registration** and nine others also bring before you patch. The patch names didn't change, so your saved selection carries over.
* **Telegram:** **Black and white launch logo** shows the white logo on black every time now, with AMOLED black on and your phone in dark mode. Before, Telegram's blue launch screen came back whenever Android reopened a Telegram it had closed in the background, since Android skips the launch screen an app names for itself in that case. The logo now sits in Telegram's own dark launch screen instead. With AMOLED black off you get Telegram's usual launch screen, except after Android has closed Telegram in the background in dark mode, when it's the black one. Reported in #6.
* **Telegram:** HushTelegram settings can drop the cards. **Settings look** at the top of Look and feel switches every page to plain rows with a thin line between them, the text closer to the edge and section titles in the accent color, and dialogs' choices follow. Tap it again for the cards. The status card at the top keeps its card either way. It's only how the settings screen looks, so settings files and Quick setups leave it out and Pause doesn't touch it. Asked for in #18.
* **Telegram:** **Hide phone number** no longer says it covers your number in the side menu, in Morphe Manager or in its settings line. Telegram 13 dropped its side menu, and the new **Side menu** switch shows your name but never your number.
* **Telegram:** **Hide folder tab counters** adds an **Open a folder at launch** switch, off by default, with a **Folder to open** row under it. Pick one of your folders and the chat list opens on it instead of All Chats. Each account keeps its own pick on this phone, and your folder order and the folders on Telegram's servers aren't touched. A folder that's gone, renamed or locked falls back to All Chats (a new folder that takes a deleted one's place doesn't count as your pick), and the chat pickers for sharing and forwarding open as they always have.
* **Telegram:** **Hide popular apps** adds a **Find names in styled letters** switch, off by default. With it on, searching your chats and contacts finds names written in decorative letters (𝐁𝐨𝐥𝐝, 𝘐𝘵𝘢𝘭𝘪𝘤, Ｗｉｄｅ, circled and the like) when you type ordinary ones. Names still show as they're written, numbers and other alphabets aren't touched, and a name found this way isn't highlighted.
* **Telegram:** Export diagnostic report has a third choice, **Preview the report**. It shows the report as it would be shared, with a box for each part, such as hook status or the selected events. Untick anything you'd rather keep to yourself and Copy or Save takes only what's still ticked. Cancel leaves nothing on the clipboard and no file behind. A very long report shows its first 30,000 characters and says how much there is. A file saved with a part left out isn't called the full report.
* **Telegram:** **Open links externally** has a second switch on the Links page, **Keep your location from Mini Apps**. With it on, a Mini App that asks for your location is told it isn't available, the same answer Telegram gives on a phone without GPS, and Android is never asked. A web page opened inside Telegram is refused your location without the dialog. A page you already allowed keeps it until you close it, and any site can still guess a rough area from your connection. Sending your location in a chat works as before. It's off unless you turn it on, and Mini Apps get your location again while HushTelegram is paused.
* **Telegram:** Quick setups can be hidden from the settings home with a long press on its row, and its help line now says so. The **Quick setups on the home page** row on Settings backup brings it back. The choice stays out of settings backups and Quick setups, and Pause leaves it alone.
* **Telegram:** The Support HushTelegram row at the bottom of HushTelegram settings is just its name now. The line under it is gone.
* **Telegram:** When Telegram's server turns down the push sign-up, which is what happens with your own API ID, `Repair Firebase push registration` now turns on Telegram's own `Keep-Alive Service` and `Background Connection`, the same thing Telegram does on phones without Google Play. Messages then come in over Telegram's own connection instead of whenever Android lets it wake up. It only does this when you've never set either switch yourself, and it hands them back if push starts working later. The notification status shows whether both are on and where to turn them on. Related to #5 and #16.
* **Telegram:** When push is turned down, the notification status now says Telegram's own two switches are in Telegram's Settings > Notifications, under Other. In German, Spanish, Indonesian, Portuguese and Turkish it names them exactly as Telegram does in that language. Before, some of those languages used other words for them, so they were hard to find. Related to #16.
* **Telegram:** UnifiedPush notifications now sign up with Telegram as a Web Push address. The old sign-up was accepted, but Telegram's servers only call that kind for a few events, so an ordinary message never woke Telegram through ntfy. Turning the switch off still hands Telegram back to Firebase after an update from 0.0.17. Related to #5 and #16.
* **Telegram:** **Hide Contacts tab** has a second switch on the Chat list page, **Compact bottom bar**. With it on, the bar at the bottom of the main screen is 64 dp tall instead of 72, with less room around its tabs, and it no longer stretches to 320 dp across when its tabs need less. Each tab keeps Telegram's 48 dp height, so taps and swipes work the way they did. It works with the Contacts tab shown or hidden. It's off unless you turn it on, the bar goes back to Telegram's size while HushTelegram is paused, and a restart shows either change.
* **Telegram:** **Hide Contacts tab** has a third switch on the Chat list page, **Side menu**. Telegram 13 dropped the menu that slid in from the left, so this draws one again. With it on, swipe right on your first chat folder and it follows your finger out. It has your name with a **Switch account** row, then My Profile, New Message, Contacts, Calls, Saved Messages, Settings and HushTelegram settings, each opening Telegram's own screen and named in Telegram's own words for your language. Back or a tap beside it closes it, and swiping between your other folders works as before. The menu takes the chat list's colors, or black with AMOLED black on. It's off unless you turn it on, it works the moment you flip it, and swipes are Telegram's again while HushTelegram is paused. Asked for in #14.
* **Telegram:** **Holiday look all year** adds an **Emoji next to the chat list title** row on the Look and feel page. Type an emoji or a few letters and they show after Telegram's name at the top of the chat list, with the New Year look on or off. It's only on this phone, so nothing goes to Telegram and your Premium emoji status stays as it is. Clear the text to get the plain title back. A change shows after a restart, and settings backups carry it.
* **Telegram:** **Hide popular apps** has a second switch on the Ads page, **Search only my chats**. With it on, search still finds your chats, your contacts and messages in chats you're in, but it stops asking Telegram for public accounts, channels and sponsored results. A contact you find by typing a "+" phone number still turns up in the Chats tab, matched on the phone. The Channels, Apps and Posts tabs go away, and the Downloads button above search still opens Downloads. Looking someone up by name anywhere else works the same way, so New Message and the pickers for contacts, forwarding and adding members show only your own contacts and chats. A hashtag still finds messages in your own chats, and a tag like #news@channel still searches a channel you're in. Its public posts, public stories and channels you haven't joined come back empty. It's off unless you turn it on, and search goes back to normal while HushTelegram is paused. Asked for in #17.
* **Telegram:** **Keep searches on this phone** now covers more of search. The Channels and Apps tabs don't ask Telegram about what you type and show no results instead. The media tabs and the Chats tab with a chat or date filter don't search for typed text either, so they keep what they showed. A contact you find by typing a "+" phone number turns up in the Chats tab again with the switch on. The Posts tab and search inside a chat still go to Telegram, and the switch's description now says which parts of the main search stay on the phone. With the switch off or HushTelegram paused, search works the way Telegram's does.
* **Telegram:** The settings home page has a new row under Quick setups, **Lock HushTelegram settings**. Once it's on, every setting on the screen is read-only. Switches, Quick setups (Back to defaults too), Pause, the choosers and settings import all stay as they are and a short note says why. To change something again, tap **Start unlock** and wait 24 hours. The row shows the time left and can cancel the wait, and turning the phone's clock back past the start begins it again. Resume, Debug logging and Export settings still work while it's locked. Asked for in #17.
* **Telegram:** The AI translation service has a **How to translate** box. Write how you want things translated in your own words (keep it casual, leave names alone, a word list) and it goes to your AI service along with each message, up to 1,000 characters. It's optional and stays on this phone with your key. Google's web translate doesn't use it, and it's still there if you switch back to an AI service later. Asked for in #6.
* **Telegram:** **Hide messages by keyword** turns away an expression whose count only makes work, like `/(?:(?=x)){16777215}(?!x)/`, with the same "may be slow" note it gives other slow lines. Large counts are refused now, and so is a count on a look-ahead or right after an open-ended repeat. Short ones like `\d{4}` still work. The lines of one list also share a single budget, so a hundred heavy lines can't add up to a slow chat. A line like that from an older list or a settings file stays in the editor and in backups, but the chat skips it without running it. A repeat that can only stop in one place, like the spaces in `/airdrop\s+0x[a-f0-9]{40}/`, isn't counted as many ways into the count after it, so filters for wallet addresses work. That shortcut isn't taken for a letter written by its number, like `\x61`, or one that matches two letters when case is ignored, like ß or ẞ, so `/\x61+a{1000}!/` is turned away like `/a+a{1000}!/`. Checking that shortcut reads each pair of characters once and keeps the answer, so a list of a hundred wallet lines is ready in a moment instead of holding up the first message after it's saved.
* **Telegram:** A switch you flip while a settings import is running stays the way you left it. Before, the switch and the setting Telegram was running could snap back while your change was still saved, so the next start disagreed with what you saw. Only the switches the file names wait for the import now, and every settings page that's open shows how it ended.
* **Telegram:** A settings import that changes **Use system font**, **AMOLED black**, **Disable pull to archive**, **Hide Contacts tab** or the **Emoji next to the chat list title** now brings up the Restart Telegram row, just like flipping one of them by hand. A file that sets a switch back to what Telegram is running clears that one, and an import that fails doesn't add any.
* **Telegram:** Saving a filter list, the translation service, the sticker size or the emoji next to the chat list title no longer freezes the settings screen while the phone writes it. The dialog dims its buttons until the save is done, so a second tap doesn't start another, and it only closes once the save worked. If it didn't, what you typed stays and the list goes back to the size that's saved. Chats keep using the old value until the new one is actually saved.
