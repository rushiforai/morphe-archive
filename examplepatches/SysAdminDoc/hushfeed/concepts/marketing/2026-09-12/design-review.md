# Hushfeed marketing review

## Decision

Concept A is the selected README hero. It keeps the approved H in the lead, states the product benefit at a glance and uses three current Hushfeed screens as proof. The layout stays legible when GitHub scales the source image to its README column.

The selected hero is 1600 by 900 pixels. It contains no release number. `README.md` references it once, as the first content on the page.

## Approved identity

`source/user-approved-logo.png`, `selected/logo-h.png` and the repository's `patches-bundle.png` are byte-exact copies with SHA-256 `950a4ebd6361b01153abbd44040b6616ceea49344c8ceb55b53425246baedf15`.

The alternate H and shield-card marks remain in `rejected/split-h-concept.png` and `rejected/shield-subtitle-concept.png` for the project record. Neither is used in public artwork.

## Product evidence

The settings, feed filter, downloads and interface images under `screenshots/current-run/` came from the native offscreen Android renderer during this review. Each one matches its checked-in README screenshot byte for byte.
