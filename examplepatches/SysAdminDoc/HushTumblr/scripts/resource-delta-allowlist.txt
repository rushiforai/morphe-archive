# What a run of HushTumblr's patches may change in Tumblr's resource table and the files it names,
# read by ResourceTableCheck.java. Each line is a kind and an item, the way the resource report lists
# it, and allows exactly one change. An added resource and a file only the patched table names leave
# out the id, since the rebuild picks that. An added resource also needs a line for each value it
# holds, per config: a bag its parent and each item. A file only the patched table names carries the
# SHA-256 of its bytes. #{option} stands for the solid color a patch option sets, and #{option+13}
# for that color with 13 added to each channel, as the Dark background color patch raises its
# highlighted surfaces. Those lines pass for any color picked, as long as every one of a run comes
# out of the same color. A @0x0106... value is one of Android's own wallpaper colors, read as the
# framework id it resolves to. Anything a run changes that isn't here fails the run.
#
# [rebuild] is what decoding and rebuilding the table does on its own, whichever resource patch
# asked for it. Every other section is a patch, and applies only when the run selects that patch or
# a patch that depends on it. Retargeting Tumblr means reading a fresh report and redoing the
# [rebuild] lines, and the attr ids in the Dark background color items. Until then a run forced
# onto another build fails at the resource step, on the lines its rebuild changes that aren't here.
