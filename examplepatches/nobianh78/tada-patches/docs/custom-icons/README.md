# Custom icon packs

Example packs for the **Custom icons** option of the `Player icon style` and `Shorts icon style` patches,
made from [Tabler Icons](https://github.com/tabler/tabler-icons/tree/0239805680a36bab4e1070529b6744924402d804) (MIT, see the `LICENSE` file in each zip).

| File | Patch option |
|---|---|
| `tada-player-icons-tabler.zip` | Player icon style, vector drawables |
| `tada-player-icons-tabler-png.zip` | Player icon style, the same icons as PNG images |
| `tada-shorts-icons-tabler.zip` | Shorts icon style, vector drawables |
| `tada-shorts-icons-tabler-png.zip` | Shorts icon style, the same icons as PNG images |

## Using a pack

1. Select a zip in the **Custom icons** option of the patch.
2. Patch and install.
3. Choose **Custom** in the player or Shorts icon style setting of the app.

## Making your own pack

Each icon is a white vector drawable (`.xml`) or a white square PNG image (`.png`, 96x96 pixels is recommended),
named after the icon it replaces. Any icon left out keeps the **Automatic** style.
