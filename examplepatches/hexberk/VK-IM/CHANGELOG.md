# Changelog

## [1.0.1] - 2026-10-25

- Без уведомления «Найдено опасное приложение»: проверка установленных приложений при запуске
  (`checkHijackingApps`) находила сам клон по чужой подписи и отправляла отчёт в аналитику.

## [1.0.0] - 2026-10-25

Первый выпуск для VK Мессенджера 1.332 (`com.vk.im`) на основе патчей VK-Zen 1.1.1.

- Реклама: записи, клипы, видеоплеер, аудио.
- Телеметрия: MyTracker, Firebase Analytics, Crashlytics, выгрузки OK Tracer.
- Клон `com.vk.im.morphe` рядом с официальным приложением, пуши через Firebase на клоне.
- Обход проверок подписи и пакета, нативного антитампера в `libvkmedia.so`.
