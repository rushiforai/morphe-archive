### Quick Setup in Morphe Manager

1. **One-Tap Source Add**: Tap [**Add to Morphe Manager**](https://morphe.software/add-source?github=xboyrex/rex-ig-lite) above, or paste `https://github.com/xboyrex/rex-ig-lite` into **Morphe Manager → Sources → Add patch source**.
2. **Automatic Updates**: Every push or tag release automatically compiles `patches-<version>.mpp`, updates [`patches-bundle.json`](patches-bundle.json) and [`patches-list.json`](patches-list.json), and publishes the latest GitHub Release so Morphe Manager updates in one tap.
3. **Quick Access Gesture**: Long-press the **Home button** in the bottom navigation bar (or long-press the top-left Instagram logo / tap `⬡`) to open the **Quick Access** sheet with tactile haptics.
