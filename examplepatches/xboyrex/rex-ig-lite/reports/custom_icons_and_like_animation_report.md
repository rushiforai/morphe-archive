# Custom Icons & Random Like Animation Report

- **Repository**: [xboyrex/rex-ig-lite](https://github.com/xboyrex/rex-ig-lite)

## Summary
- **Semantic Tabler Icon Registry (`RexIcon.java`, `RexIconRegistry.java`)**: Every preference row, category route (`rex_initial_features`, `rex_cache_cleaner`, `rex_font`, `rex_rec_flags`, etc.), dialog sheet header, and Story 3-dot overflow menu item (`StoryButton.java`) binds to a validated 24x24 vector icon with active/inactive state transitions.
- **Custom & Random Double-Tap Like Animations (`ChangeLikeAnimationPatch.java`, `LikeAnimationPreference.java`)**: Supports custom heart/emoji/sticker double-tap animations with smooth scale/alpha interpolation and respect for system Reduce Motion settings.
