# InstaRex (`v3.16.0`) — Full Source Audit Report

- **Repository**: [xboyrex/rex-ig-lite](https://github.com/xboyrex/rex-ig-lite)
- **Upstream Reference**: [crimera/piko](https://github.com/crimera/piko)
- **Target Instagram Base**: `452.1.0.53.64` (Android 10–17, SDK 29–37)
- **Developer Branding**: `XBOYREX` (`InstaRex` / `com.xboyrex.instarex`)

## 1. Executive Summary
A comprehensive static and runtime audit was conducted across all patches (`patches/src/main/kotlin/app/rex/patches/instagram/**`), runtime extension classes (`extensions/instagram/src/main/java/**`), shared libraries (`extensions/shared/library/**`), and all 10 attached device screenshots (`23482.png`, `23483.png`, `23488.png`, `23486.png`, `23487.png`, `23480.png`, `23479.png`, `23469.png`, `23454.png`, `23473.png`).

## 2. Root Causes Identified & Resolved
| Screenshot / Report | Subsystem | Root Cause | Resolution |
|---|---|---|---|
| `23487.png` | `RecommendedFlags.java`, `RexDialogs.java`, `SettingsActivity.java` | `RecommendedFlags.enableAllBooleanFlagsTransactionally` invoked `onScreenRefresh.run()` (`activity.recreate()`) before showing `RexDialogs.showConfirmDialog`, and `RexDialogs.attachBlurBehind` set a `RenderEffect` blur directly on the Activity's root `decorView`. | Removed `decor.setRenderEffect(...)` from `attachBlurBehind`, added `RexDialogs.clearActivityBlur`, replaced `activity.recreate()` with `SettingsActivity.refreshCurrentScreen(context)`, and added a persistent bottom `Restart Required — Restart Now` bar. |
| `23473.png` | `ActivityHook.java`, `SettingRegistry.java`, `Requester.java`, `IgStr.java` | `ActivityHook.launchFragment` launched `TransparentModalActivity` which crashed in IG `452.1.0.53.64` when `ModalActivity.onCreate` returned early; `SettingRegistry.restartPolicyFor` threw `NPE` on dynamic keys; `IgStr` read `TRANSLATOR_LANGUAGE` (`Arabic`) for UI locale, flipping `Developer Options` to RTL. | Hosted SAF picker fragments (`BackupPrefFragment`, `RestorePrefFragment`, `FolderPickerFragment`) inline on the active `Activity`'s `FragmentManager`; made `SettingRegistry.restartPolicyFor` return `RestartPolicy.NOT_REQUIRED` for dynamic keys; separated `IgStr.KEY_APP_UI_LANGUAGE` from `Settings.TRANSLATOR_LANGUAGE`. |
| `23482.png` vs `23483.png` | `FeedDownloadButtonPatch.kt` | `pinMainFeedToViewUfi` returned `viewVariantField` unconditionally for all feed modules instead of checking `MAIN_FEED_MODULE` (`"feed_timeline"`), suppressing the Litho UFI action row on Own Profile / Creator Insights posts (`23482.png`). | Scoped `pinMainFeedToViewUfi` strictly to `if (module.equals("feed_timeline"))`, restoring the Litho UFI row and InstaRex buttons on Profile / Insights posts. |
| `23486.png` | `StoryButton.java` | Custom Story 3-dot overflow menu items were added as plain `String` entries, causing Instagram's dialog adapter to render them without leading icons. | Wrapped all custom Story overflow entries in `SpannableString` with a 22dp `RexIcon` `ReplacementSpan` (`38dp` total advance) matching native row alignment. |
| `23488.png` vs `23454.png` | `suite/.../Settings.java`, `ActionBarPatch.java` | `GLASS_TAB_BAR_REELS_BEHIND` (`xboyrex_glass_tab_bar_reels_behind`) defaulted to `FALSE`, stopping the Reels viewer above a solid black bar instead of floating over Reels like Home (`23454.png`). | Changed `GLASS_TAB_BAR` and `GLASS_TAB_BAR_REELS_BEHIND` defaults to `TRUE` and synchronized them when `LIQUID_GLASS_NAV` is enabled. |
| `23479.png` & `23480.png` | `ClonePatch.kt`, `rex_ic_launcher_round.xml` | `ClonePatch.kt` defaulted to `false` (`com.instagram.android`), triggering Play Store update prompts (`23479.png`); `rex_ic_launcher_round.xml` was a `<vector>` instead of an `<adaptive-icon>`, shrinking into a tiny red dot inside a white circle on Poco Launcher (`23480.png`). | Set `ClonePatch.kt` `default = true` (`com.xboyrex.instarex`, `InstaRex`) and converted `rex_ic_launcher_round.xml` and `rex_ic_launcher_instarex.xml` into full-bleed `<adaptive-icon>` drawables backed by `rex_ic_launcher_background.xml` (`#F70125`) and `rex_ic_launcher_foreground.xml`. |
