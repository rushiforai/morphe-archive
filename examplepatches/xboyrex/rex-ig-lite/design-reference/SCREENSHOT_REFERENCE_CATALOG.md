## Key conclusions from screenshots

1. Reference uses black background, white title text, muted grey descriptions, white outline icons, simple rows and subtle separators. For Rex, improve this into the new tokenized Rex colour system without copying InstaPrime's logo/branding.
2. Main settings is a long scroll list with a brand header; subpages use a title, back arrow and language/translate shortcut.
3. Each preference has a leading semantic icon, title, secondary description and either switch or chevron/action.
4. Context media menus are vertically scrollable and type-dependent. Carousel menu includes `all N` operations; one screenshot shows 4 items and another shows 10.
5. Native Instagram quick actions already include Save/Remix/Sequence/Download options/More options. Avoid duplicate controls and conflicts.
6. Premium-marked rows in the reference must not be shipped as paywalled features in Rex, per project requirement.
7. Instagram upstream version/base/date visible in changelog are example reference metadata only. Rex must read its own version/base/release data dynamically.
