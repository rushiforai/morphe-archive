# Deep links for rex twitter

xboyrex Twitter provides custom deep links.

To use the deep links, set the xboyrex Twitter app to open x.com links. (App Info > Open by default)

(Last updated: April 16, 2026)

## List of available deep links

Open rex settings:

- https://x.com/i/rex/  
- https://x.com/i/rexsettings/

Open each section of rex settings:

- https://x.com/i/rex/premium
- https://x.com/i/rex/download
- https://x.com/i/rex/flags
- https://x.com/i/addflags
- https://x.com/i/rex/ads
- https://x.com/i/rex/native
- https://x.com/i/rex/misc
- https://x.com/i/rex/customise
- https://x.com/i/rex/font
- https://x.com/i/rex/timeline
- https://x.com/i/rex/pref
- https://x.com/i/rex/info

Open X settings:

- https://x.com/i/settings

Add a feature flag:

Pattern:  
`https://x.com/i/addflags?f=<flag_name>&v=<value>`

value can either be true/false or 1/0

For example:  
https://x.com/i/addflags?f=longform_notetweets_rich_text_timeline_enabled&v=0  
https://x.com/i/addflags?f=xprofile_blocked_by_view_enabled&v=true
