# Chrome menu fallback v1.6.1

Fixes Chrome APKs that do not expose `res/menu/main_menu.xml` or `res/menu/custom_tabs_menu.xml` to the patcher.

The named menu resources are now optional. When they are unavailable, MonkeyScript inserts native-looking manager and installer rows into Chrome's displayed app-menu hierarchy at runtime.

Validated before release with both parser suites, Android extension compilation, Morphe bundle packaging, and artifact upload.
