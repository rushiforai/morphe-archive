# Morphe Patches v1.1.0

## Opera GX

- Replaces the share-only workflow with a visible floating **Download Mod ↓** button inside the patched browser.
- Detects the current GX Store mod URL from Opera/Chromium state, the address bar, intents, or clipboard.
- Opens a paste fallback when Opera does not expose the complete current-tab URL.
- Keeps the Android share target as a backup.
