# MonkeyScript v1.8.0 — Chrome 150 exact integration

Built from direct comparison of the supplied clean and v1.7.1-patched Chrome 150.0.7871.186 APKs.

- Replaces the invalid android.view.Menu reflection path with an exact runtime hook for Chromium's `app_menu_list` ModelList view.
- Explicitly excludes `context_menu_list_view`, so text, link, image, and long-press context menus are not modified.
- Copies native Chrome menu typography, colors, ripple/background, spacing, and row height for the Userscripts and conditional Install userscript rows.
- Preserves resource-valued manifest component attributes instead of qualifying them as class names.
- Follows Chrome's launcher activity alias to inherit the real ChromeTabbedActivity theme for manager, editor, and install screens.

The Android extension and Morphe bundle are compiled in CI. Runtime confirmation remains specific to the supplied Chrome APK and the user's device.
