# Morphe Patches v1.8.1

Repairs the Chrome 150 Userscripts manager and website installation flow after on-device testing.

## Material You manager

- Rejects transparent or low-contrast theme colors that produced white text and invisible button labels on a white surface.
- Uses Chrome/system dynamic colors when they remain readable, with contrast-safe Material You fallbacks.
- Replaces the clipped horizontal pill strip with a responsive two-column action grid.
- Adds clear Installed and Quick actions sections plus a proper empty-state card.

## Greasy Fork and Sleazy Fork installation

- Uses Chrome's page-capable JavaScript execution paths before the WebUI-only fallback.
- Finds the current WebContents through ChromeActivity and ActivityTabProvider access paths.
- Captures current Fork install links, including install-link and data-code-url markup.
- Resolves Greasy Fork scripts through api.greasyfork.org JSON code_url data before HTML fallback.
- Resolves Sleazy Fork script JSON before HTML fallback.
- Retains direct URL review/install as a native fallback independent of website click interception.

## Validation

CI checks the userscript parser, exact Chrome 150 app-menu hook, page-execution ordering, Fork API/link markers, Material contrast implementation, Android extension compilation, Morphe patch compilation, and complete .mpp packaging.

Release build requested after PR #14 passed all checks.
