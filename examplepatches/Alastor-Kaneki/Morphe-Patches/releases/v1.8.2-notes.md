# Morphe Patches v1.8.2

Repairs userscript installation on the supplied Chrome 150 build after the website install button still produced no action.

## Guaranteed native installation

- Adds a Material You **Install userscript** action directly to Chrome while viewing a Greasy Fork/Sleazy Fork script page or direct `.user.js`/`.user.css` URL.
- Opens the native source-review installer without depending on website JavaScript, URL-hash polling, or Chrome's download behavior.
- Registers an exported, package-targeted `monkeyscript-install://install` deep link for website install clicks.
- Retains the native Chrome app-menu **Install userscript** row and manager **Install URL** flow as independent paths.
- Accepts the install URL from either an explicit Activity extra or the deep-link query parameter.

## Interface

- Forces Chrome-style sans-serif typography for injected Material You controls instead of inheriting the incorrect serif family.

## Validation

CI checks all three install paths, deep-link manifest registration, native page action, Greasy Fork/Sleazy Fork resolution, exact Chrome 150 menu safety, Android extension compilation, Morphe patch compilation, and complete `.mpp` packaging.
