# offline-gboard

[![Add to Morphe](https://img.shields.io/badge/Add%20to-Morphe-6B4EFF?logo=android&logoColor=white)](https://morphe.software/add-source?github=Kirkland-Pickles/Gboard-offline-morphe&name=offline-gboard&app=com.google.android.inputmethod.latin)

Morphe patches for Gboard.

- **Offline system voice typing** uses Android’s offline speech recognizer when its language model is installed.
- **Remove network access** removes Gboard’s Internet, account, and Google service permissions.
