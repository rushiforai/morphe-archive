# エッヂの無題フォルダ・オルグ板の名称（2026-11-13）

## 原因と修正

エッヂの板ページをBBSMENUへ変換するBbsMenuHtml.prepareが、見出しと板リンクを同じ行に出力していました。ChMateのHTMLパーサーは改行ごとに処理し、リンクを先に探し、リンクがない行だけをカテゴリ見出しとして扱います。191の原本DEXのr8lambdaiOqLyk77RB2_RO8VkxeQitnNuu4で、この分岐を確認しました。そのため、リンク自体は取り込まれてもカテゴリが空になり、無題のカテゴリに入る状態になっていました。

変換後はhtml/body・カテゴリ見出し・板リンクをそれぞれ別の行に置きます。登録する板は従来どおりliveedgeの1件だけです。

すでに取り込まれたエッヂ行は、空・null・無題のカテゴリを表示用データで「エッヂ」に補正します。既存のJavaScriptカテゴリ補正と同じネイティブモデルの複製経路を使い、板ID・URL・保存DAT・履歴・お気に入りを変更しません。意味のある利用者のカテゴリと他サイトの無題カテゴリは保持します。新しいネイティブフックやレジスター変更はありません。

新版適用後はChMateを再起動し、掲示板設定→エッヂ→「板一覧を取得/更新」を再実行すると、保存されるカテゴリも標準の読取経路で更新されます。

## オルグ板

kenmo.org／00c.orgを含む標準の掲示板設定・サイト別グループの名称を「オルグ板」に変更します。内部provider ID、設定キー、URL、板の固有名はそのままです。設定検索は旧名・ドメイン・オルグ板を同じ語として扱い、表示名の部分検索も保持します。旧名の設定リンクにも別名を用意します。
