# Haiagaru 機能の詳細と用語集

エキスパート設定の各項目は個別に切り替えられます。今回追加した最適化の初期値はオンです。すでに保存されている選択がある場合は、その値を使います。

| 設定 | 何をするか |
| --- | --- |
| 起動中の重複したパッケージ名移行を省く | 一部の設定に保存されている旧アプリの識別子を確認する処理を、アプリの起動中に一度にまとめます。次回のアプリ起動から反映されます。 |
| 履歴の表示件数取得でアプリ情報の再照会を省く | 表示する履歴の上限を読むとき、保存済みの値を直接使います。上限の設定がないときは版ごとの標準値を使います。履歴の表示上限と、履歴を実際に削除する条件は別です。 |
| 通知の連鎖NG判定を引用元のレスに絞る | 通知候補に関係する引用をたどり、連鎖あぼーんの判定に必要なレスを確認します。連鎖あぼーんとは、NGになったレスへの返信にもNGを広げる設定です。 |
| 外部板名の修復でデータベース接続を再利用 | 外部掲示板の名前を読み直すとき、複数の板を同じSQLite接続で処理します。SQLiteは、板名などの一覧を端末に保存するデータベースです。 |
| フィルター・人気レスでスレ情報の取得経路を再利用 | 226／242で、一覧の作り直しに使う情報の取り出し方を記憶し、その時点のレスとフィルター条件を読みます。人気レスの閾値は、何件の返信があると人気レスとして扱うかの境目です。 |
| 5ch形式の登録スレ監視で既読レスの本文解析を省く | DATから新着分を抽出するとき、既読行の本文を読み直す処理を省きます。DATはスレのレスを行単位で格納した掲示板のデータです。この設定はDATの通信量を減らす項目ではありません。 |
| 板別Cookie確認で保存データとCookieの再解析を省く | 板ごとに保存したCookieの読み取り結果を一時的に再利用します。Cookieが変更されたときは読み直し、送信前には期限・送信先のホスト・URLの範囲を確認します。 |
| 認証前のCookie確認を画面スレッドから外す | 認証画面を開く前にWebViewが持つCookieを裏で読み取ります。画面スレッドは、タップやスクロールを処理する場所です。Cookieの準備が完了してから認証画面を開きます。 |
| 画像切替などでアプリ版情報を再照会しない | 起動中に確認したChMateの版情報を画像切替などの処理で再利用します。アプリが更新された場合は次の起動で確認し直します。 |
| 投稿後すぐ元の画面に戻る | 投稿ボタンを押して送信が始まると、入力画面を背面に置き、元の画面へ戻ります。投稿が失敗したりCookie確認が必要になったりすると、入力画面を再表示します。 |

## カードとスクロール位置

Webリンクカードはリンク先のタイトルや概要をスレ内に表示します。X投稿カードはXの投稿を読み込んで枠付きで表示します。後からカードが表示されるとレスの高さが変わるため、位置保持は同じレスが同じ場所に留まるよう補正します。両方のカードがオフのときは補正を止めます。

## NGと投稿者の識別

「レス数が少ないスレを板の一覧から隠す」は、板のスレ一覧の通常枠にあるスレを総レス数で絞ります。総レス数は最初の投稿も含むので、上限1では最初の投稿だけのスレが対象です。板の一覧を開き直すか更新すると反映されます。初期値は機能オフ、上限1です。

NGは、特定の投稿者・文字列・スレを非表示にする条件です。「あぼーん」はNGの行があることを示す表示で、「透明あぼーん」は行ごと隠します。「非表示NGを表示」を使うと、隠れたレスを一時的に確認できます。記者IDは、エッヂのスレを立てた投稿者に付く識別子です。NGThreadsは、レスのNGと別にスレ全体を対象にする条件です。

## 画像判定と追加ファイル

画像検出モデルは画像を判定するためのデータです。ONNX Runtimeはそのモデルを端末で実行するためのライブラリです。Morpheでパッチを選ぶ際には、配布されたZIPを展開せずにファイル選択画面から選びます。一括ZIPと個別ZIPの選び方は[追加ファイルの導入手順](optional-assets.md)を参照してください。

Cookieはサイトが認証や設定などを区別するためにブラウザへ保存する小さな値です。WebViewはAndroidアプリの中でWebページを表示する部品です。

### HOMEの並び替え

HOMEの「並び替える」で編集モードに入り、標準一覧のスレを長押ししたまま上下へドラッグします。指を離すとカテゴリ内・カテゴリ間の表示位置を保存します。「並び替えを終了」で通常操作へ戻ります。★カテゴリの見出しは保持し、ChMateの★登録値を変更せずHOME表示の配置を保存します。

「スレ（板順）」では板見出し右端の正方形ボタンでスレ群を開閉できます。白黒の上向き二重矢印で折りたたみ、下向き矢印で展開します。枠内全体がタップ範囲です。上部の「↓↑ 非表示／表示」で開閉ボタンを切り替えられ、設定は保存されます。初期は表示です。並び替えモードでは板見出しを長押ししてドラッグすると、板ごとのスレをまとめたまま順番を移動できます。見出し本文をタップすると、その板を開きます。

並び替え中の下部「スレをピン留め」から、対象のスレを選択して保存します。選んだスレは★カテゴリより前のHOME一覧先頭へ表示します。チェックを外して保存すると解除できます。★登録値は変更しません。ドラッグ中はつかんだ位置を保ち、一覧の端で自動スクロールします。
