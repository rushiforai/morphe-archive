# Haiagaru設定の分類

Compose版では、用途に合わせて次の9カテゴリに整理しています。

1. スレッド
2. 探す・過去ログ
3. 書き込む
4. 画像・動画
5. NG・ミュート
6. 履歴・コピーした記事
7. バックアップ・機種変更
8. アプリ・通信
9. エキスパート設定

画像を「見る」設定と「投稿する」設定を分け、Xの表示は「スレッド」、アップロードは「書き込む」に配置します。通信や外部板の認証は「アプリ・通信」にまとめます。

ツールバー項目の表示チェックはChMate標準側へ、投稿検索のオン／オフやバックグラウンド検索は検索画面側へ集約しました。数値や詳細設定の保存キーは引き継ぎます。
