# 外部板のスレ作成日時・勢い・情報ポップアップの日付（2026-11-08）

爆サイ・ふたば・あにまんの標準スレ一覧に、最初の投稿の日時と、それを元にした勢いを表示する。仮想スレIDを日時として解釈せず、実ページのOP日時を日本時間で解析する。URL・履歴・キャッシュ・既読判定に使う仮想IDは保持し、表示とその計算の読み出しだけを補正する。スレを開いた状態で上部のスレタイから開く情報ポップアップにも、取得済みの作成日時を反映する。日時を取得できない場合に仮想IDから不正な未来日を作らず、日時欄を補正しない。

画面に必要なスレだけをバックグラウンドで取得し、同時取得2件、待機200件、RAMキャッシュ2,000件、SQLite20,000件に制限。失敗は15分待ってから再試行し、表示更新は500msにまとめる。本文の取得時もOP日時を保存する。取得できない日時をIDや最終レス時刻から推測しない。巨大なSharedPreferencesのタイトルマップは使用しない。

対応する191/226/242のアダプターとフィールド・計算位置は固定。パッチ実行時の全クラス探索は追加していない。表示時の補正なので、勢いによる並べ替えの順序は今回変更・検証していない。
