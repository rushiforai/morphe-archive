# 保存済み画像から表示

Haiagaru設定 → 画像・動画 →「保存済み画像から表示」で設定します。保存画像を読み取るための設定です。

通常の画像キャッシュに加えて、Download/Haiagaru、Pictures/Haiagaru、Pictures/ChMateなどの保存画像を検索します。Androidの保存領域の制限で自動検索できない場合は「既定の画像保存フォルダを指定」で読み取りを許可してください。「追加の検索フォルダを指定」で、移動先のフォルダをもう1つ指定できます。サブフォルダも検索します。

画像の移動・複製・削除は行いません。初回は索引作成に時間がかかることがあります。「保存画像の索引を更新」で手動更新できます。1画像32MiB、最大2万ファイル、深さ8階層を上限とします。索引はバックグラウンドで作成します。

元URLに対応する画像内容のSHA-256を記録するため、その記録があればファイル名を変えても内容から検索できます。巡回保存のURLハッシュ名も利用します。対応情報のない改名済み画像は推測で表示しません。「画像と元URLを関連付ける」で元画像URLを入力し、保存画像を選んでください。この関連付けは索引更新後も維持します。

フォルダを解除すると、自動検索の索引から外れます。個別に関連付けた画像は別の明示指定として保持します。ファイルの移動やアクセス権の失効で読めなくなった場合はフォルダを再選択して索引を更新してください。画像の再圧縮や編集は内容が変わるため、再度関連付けが必要です。

検索をOFFにすると通常のURLへ戻します。保存画像と元URLの対応はアプリ内部に保持し、URLは索引へ平文保存しません。ローカル画像はアプリ内のループバック通信で表示します。ローカル画像の表示経路からインターネットへの取得は行いません。
