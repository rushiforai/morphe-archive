# サポート板・外部板の勢いソート

Haiagaru設定トップの最下部に「サポート板」「ChMate用Morpheパッチ『Haiagaru』」とURLを追加。行をタップすると既存のOpenUrlActivityから `https://jbbs.shitaraba.net/computer/45040/` を開く。

ふたば・あにまん等の外部板は、元サイトの連番をChMateの非日時スレ番号へ変換している。表示では作成日時を補正していたが、ネイティブの勢い比較は未補正のスレ番号／計算済みの値を参照していた。スレ番号が将来の日時に相当するため、242では計算値が0になり、別の並び替えキーでレス数の多い順になっていた。

191／226は各1か所、242は同じ一覧構築メソッド内の2か所のネイティブ板一覧ソートをスナップショット付き処理で包み、勢い比較だけを補正。作成日時が既知の外部スレは「レス数÷作成からの経過時間」で比較し、正逆順・既存の他の比較キーを維持する。通常板だけのリストは元の比較処理を使用する。元比較の命令・レジスター数とスレ番号・URL・保存データを保持する。

比較中は時刻・作成日時・各行の計算値を固定し、非同期の日時取得が比較結果を途中で変えてソート契約を壊すことを防ぐ。ふたばは既に取得する通常一覧ページのOPから作成日時を保存する。追加の通信は行わない。

作成日時が未取得／曖昧なスレの勢いは0相当とし、レス数から日時を推測しない。あにまん等は既存の非同期日時取得を利用するため、初回は日時取得後の再ソート／一覧更新で反映する。全スレの日時を取得済みであることや実サイトの直近数分の勢い指標との一致は保証しない。

検証結果は公式公開前に追記する。先行変更のメニュー・ジェスチャー・検索・動画サムネイル候補も同じMPPへ統合して検証する。

サイト補助テストを現行ソースから再梱包。既存のポップアップ日時のキャッシュ解決があるため、終了判定は「板スコープが解除されること」を直接検査する。再起動で変わるローカルポートの文字列一致ではなく、画像・ギャラリーの両経路が同一の元画像URLへ解決されることを検査した。これらは旧補助テストの前提更新で、アプリ処理を弱める変更ではない。
