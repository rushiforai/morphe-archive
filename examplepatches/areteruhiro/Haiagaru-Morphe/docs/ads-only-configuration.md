# 広告だけの超軽量構成（開発中）

未公開。通常版の更新とは別に検証している構成です。

## アプリ内プリセット

Haiagaru設定の「言語・基本設定」から「広告だけの設定プリセットを適用」を選びます。
広告除去を残し、追加機能・自動取得・検索・追加フィルター・表示位置補完などの設定をオフにします。
文字列置換、追加NG処理、投稿者の強調、自動バックアップ・同期、追加アップロード先、ワッチョイ長押し、追加ツールバー項目も停止します。
変更後は再起動してください。ChMate標準の設定、履歴、NGルール、ログ、認証情報は削除しません。

「プリセット適用前の設定に戻す」で変更対象の設定を元に戻せます。
再適用しても初回の退避値は保持します。更新で対象項目が増えた場合は、その項目を初めて変更する直前に退避します。
適用後に個別変更した対象項目も、復元時は退避値に戻ります。
同じツールバー設定へ適用後に加えた配置変更も復元対象になるため注意してください。

この方法は通常版の追加コードをAPKから削除するものではありません。
個別スイッチがない既存の互換処理・修正は残ります。
エキスパート設定を含むすべての非クラッシュ修正の任意化は、引き続き作業中です。

## パッチ時の専用構成

通常の「Haiagaru」を外し、「Haiagaru 広告だけの超軽量構成（検証用）」を選びます。
通常のHaiagaruやそれを必要とする動画・MEGA・VPNなどの任意パッチとの同時適用は拒否します。
別パッケージで確認する場合は既存の「Change ChMate package name」を併用します。

広告・広告枠除去と、再署名・別パッケージで起動するための互換処理だけを接続します。
追加の設定画面・検索・フィルター・表示位置監視・動画・Compose UIのライブラリは組み込みません。
Image NGやVPNの追加ライブラリファイルも不要です。
通常版に含まれる個別の機能修正をすべて導入する構成ではありません。

配布用MPPは通常版と同じバンドルです。パッチ時の選択で、APKに入る実行部分を分けます。
専用実行部分は独立したextensions/chmate-ads-onlyでビルドし、通常の拡張DEXは使用しません。

## 検証記録

ビルド、適用、端末確認の結果はintegration-status.mdとandroid-installations.mdへ記録します。
APKサイズの比較は利用した任意パッチ・フォントなどで変わり、速度・消費メモリの改善を保証する数値ではありません。
