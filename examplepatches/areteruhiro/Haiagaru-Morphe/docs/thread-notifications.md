# 登録スレの新着通知

スレタイトルを長押しし、「このスレの新着通知」→「通知を登録」を選びます。同じ画面の「登録を解除」から解除でき、登録済みの場合は「保存・監視を再開」で設定を変更できます。ChMate標準のツールバー設定で通知ボタンを追加することもできます。Androidの通知許可をONにしてください。

## 確認間隔

「確認間隔を変更」から日・時間・分を入力します。初期15分、合計1分〜7日で、登録した全スレに共通です。登録上限は100スレです。

1〜14分は終了後に次回を予約する単発Job、15分以上は定期Jobです。アプリを閉じていても確認しますが、Androidの省電力・実行回数制限・通信条件で遅れます。特に1分設定でも正確な毎分実行は保証しません。端末設定からの強制停止中は通常のバックグラウンド確認が動きません。

## 通知の内容

- 手動登録の初回確認は基準レス数の記録のみです。その後の増加を通知します。書き込み後の自動登録では、投稿を確認したレス番号を基準にして、それ以降の返信を確認します。
- タイトルはスレ名、補足は新着件数です。新着レスのうち最後の最大3件を、レス番号と本文付きで表示します。長文は1件あたり最大300文字で省略し、通知を展開するとプレビューを確認できます。
- HTMLタグを除去した本文を表示します。画像や動画の実体は通知のためには取得しません。
- 本文が取得できない場合も、スレ名・件数を通知します。タイトルが取得できない場合はホストとスレIDを使います。
- アイコンはインストール先のChMateのものです。パッケージ名変更時にカスタムアイコンを指定している場合はそのアイコンになります。ステータスバーの小アイコンはAndroidにより単色表示になります。
- 通知をタップすると最初の新着レスを指定してスレを開きます。

同じ板の登録スレはスレ一覧（subject.txt）の確認を共用します。新着があるスレだけ追加でDATを取得します。毎回の全登録スレ本文取得は行いません。本文取得は最大4MiBで、認証・通信エラー時は件数通知へ戻ります。5chの名前欄がHTMLタグで始まるDATや、名前欄が空のDATも解析します。DATの形式に対応しない掲示板では本文を表示できない場合があります。

登録と基準件数は端末内に保存します。掲示板への自動投稿や、この通知機能専用サーバーへの登録は行いません。通知欄に投稿内容が出るため、ロック画面の表示範囲はAndroidの通知設定で調整してください。

## 届かないとき

1. 登録後の初回確認が終わり、さらに新しいレスが増えているか確認します。
2. 対象アプリと「登録スレの新着」通知チャンネルが許可されているか確認します。
3. 通信状態とAndroidのバックグラウンド制限を確認します。使用頻度が低いアプリでは実行枠が制限され、設定間隔を過ぎても待機する場合があります。
4. 認証が必要な板はアプリ内で閲覧認証を確認します。本文が取得できても、subject.txtを取得できなければ新着を判定できません。

通知の確認基準は監視ごとに保存します。新着判定ではChMate標準の既読レス数も参照し、読んだレスが後から新着として通知されることを防ぎます。確認中に既読数が進んだ場合も、通知する件数と本文を絞り直します。巡回で取得しただけの未読レスは通知対象のままです。ChMate標準の既読位置や未読マークを書き換えることはありません。

## したらばと返信通知

したらばの `/bbs/read.cgi/カテゴリ/板番号/スレ番号/` に対応します。subject.txtの件数とrawmodeのレス番号・本文を解析し、削除などで番号が飛んでいても本文と番号を対応させます。

スレごとに「自分の書き込みへの返信だけ通知する」を選べます。この端末の自分の書き込みマーク、または投稿確認時に保存した自分のレス番号へのアンカーを判定します。新着の最後の3レスに返信がなくても、新着範囲全体から該当する返信を探します。本文・マークを確認できなかった場合は、通知済みにせず次回再試行します。

「自分への返信を通知したら定期確認を停止する」は独立した設定で、初期OFFです。ONなら通知に成功した後、そのスレの定期確認を止めます。最後の監視が停止した場合は定期ジョブも解除します。「保存・監視を再開」で再開でき、設定と停止状態はバックアップにも含まれます。

ChMate標準の自分への返信通知とHaiagaru通知は、登録スレの新しく投稿されたレス番号で重複を判定します。先に通知した側を残し、後から同じ返信だけを通知する処理を抑えます。自分の>>10へ>>20・>>21が返信した場合、20と21は別の通知対象です。標準側のまとめ通知に既通知と未通知が混在する場合は、新しい返信を落とさず標準通知を維持します。

## 書き込み後の自動監視

Haiagaru設定内の「スレの新着通知・書き込み後の自動監視」に親設定「書き込み後に自動でスレを監視する」を追加しています。初期OFFです。ONでは投稿成功後、ChMateが投稿したレスを確認したタイミングで、そのスレを監視対象へ登録します。下書き保存や投稿失敗では登録しません。

自動登録の「新規登録時：自分への返信だけ通知」は初期ON、「新規登録時：返信通知後に確認を停止」は初期OFFです。これらは未登録スレの初期設定です。登録済みのスレは「このスレの新着通知」の個別設定を優先し、書き込み後も上書きしません。停止中のスレでも次の新しい投稿確認で監視を再開し、個別設定の期間で期限を更新します。

## 監視スレの管理・期限

Haiagaru設定の「通知の監視スレ一覧・停止・再開」から、登録スレと監視中／停止状態を確認し、個別設定・再開・停止・解除を選べます。スレ名はスレ一覧の取得後に表示し、それまではURLを表示します。

監視期限は登録・保存・再開から1時間・6時間・1日・3日・7日・30日、または期限なしを選べます。新規登録の初期値は7日です。以前からの登録は期限なしを維持します。期限切れのスレは通信せず、全スレが停止した場合は定期ジョブも解除します。停止後も登録は一覧に残ります。

dat落ちは、一時的な一覧取得失敗だけで停止しないよう、他のスレを含む正常な一覧で対象が3回以上見つからず、最初の欠落から30分以上経過し、さらにDAT取得がHTTP 404／410を返した場合に停止します。認証エラー・タイムアウト・空や不正な一覧ではdat落ちと断定しません。掲示板によってはこの条件で判定できないため、期限設定も利用してください。


## バックアップと復元

Haiagaruバックアップで「設定」を選ぶと、通知を登録したスレ・確認間隔・確認済みレス数・返信限定・通知後の停止設定・停止状態・投稿確認済みの自分のレス番号も保存します。ローカル手動・ローカル自動・MEGAの共通バックアップ形式が対象です。復元後は確認処理を再予約します。通知本文や実行中の処理を識別する値は保存しません。

通常復元では保存した通知登録へ戻し、双方向同期では現在の登録・間隔を保って不足するスレを追加します。監視期限と停止理由も保存し、復元によって期限を延長しません。期限情報がない旧バックアップの登録は期限なしになります。通知項目がない古いバックアップを復元しても、現在の通知登録は保持します。Androidの通知許可・省電力設定は復元先の端末で設定してください。
