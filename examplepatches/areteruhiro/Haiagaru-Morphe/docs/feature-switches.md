# Haiagaru機能の設定場所

設定はHaiagaru設定内の目的別カテゴリと、その機能を使う画面にあります。「更新履歴」のバージョンを開くと、上側にその版で追加・変更された機能のスイッチと設定ボタン、下側に詳しい更新内容を表示します。同じ設定値が各カテゴリにも表示されます。一括の「機能のオン・オフを表示／閉じる」欄はありません。

| 変えたいこと | 設定場所 |
| --- | --- |
| 本文・一覧の表示、コピー操作 | Haiagaru設定 → スレッド |
| 記者ID検索、記者ID表示、文字列置換、履歴ポップアップの対象 | Haiagaru設定 → スレッド |
| IDチェッカー、DAT取得経路 | Haiagaru設定 → 探す・過去ログ |
| 入力、スレ立てコマンド、アップロード | Haiagaru設定 → 書き込む |
| 再生、動画サムネイル、スレ一覧サムネイル、自動保存 | Haiagaru設定 → 画像・動画 |
| NG、登録画像あぼーん、コピペ省略レスの透明あぼーん、荒らし省略 | Haiagaru設定 → NG・ミュート |
| 閲覧・書き込み履歴とコピーした文章 | Haiagaru設定 → 履歴・コピーした記事 |
| ローカル保存、復元、MEGA同期 | Haiagaru設定 → バックアップ・機種変更 |
| 言語、広告、接続、設定リンク、外部板サイトの使用 | Haiagaru設定 → アプリ・通信 |
| 投稿検索のオン／オフ | ツールバーから検索画面 → 投稿検索を利用する |
| バックグラウンド検索、検索履歴、検索先の表示 | 検索画面右上 → 検索の設定 |
| 追加ツールバーの表示・配置 | ChMate標準のHOME・板・スレの各ツールバー設定 |
| ツールバー画像の変更 | Haiagaru設定 → スレッド → ツールバーのアイコン画像 |
| 最近の追加機能の切替、更新履歴 | Haiagaru設定 → 更新履歴 |
| レス保存・保存済みレスの表示 | レス長押しのツールバー設定の各トグル |

更新履歴画面では、外部板サイトごとの使用、サイト別板一覧、スレ一覧サムネイル、記者ID検索・表示、登録画像NG、コピペ省略レスの透明あぼーん、ReplaceTxt、対象タブ、投稿後の自動監視、動画サムネイル・横画面表示、既読スレ削除の長押し、IP表示スレの投稿前確認などを切り替えられます。外部板サイトはエッヂ・オルグ板・爆サイ・ふたば・あにまんが初期ONです。登録画像NGの画像・判定レベル・一致枚数は、同画面の「登録画像・判定レベル・一致枚数を設定」から編集します。各項目の詳しい条件や制限はリンク先の機能説明を参照してください。

検索の設定、ツールバーの表示チェック、各カテゴリにある同じ設定と値を共有します。更新履歴画面に項目がない機能は、目的別カテゴリまたは機能を使う画面で設定してください。既存の設定値・保存データは引き継ぎます。

ツールバーの旧全体表示スイッチとレスメニューの「常に表示／常に非表示」は使わず、ChMate標準のチェック状態を優先します。検索をオフにしても入口は消えず、同じ画面で再びオンにできます。オフにしても履歴や保存結果は削除しません。

数値は各項目で検証し、再起動が必要な変更は確認を表示します。設定一覧の検索は項目名・説明を使い、入力した認証情報や保存先の値は検索しません。

この案内は現行のCompose設定画面に対応します。過去版とは項目名や配置が異なる場合があります。[画面変更の詳細・確認範囲](compose-settings.md)

設定の表示名はそのままで、検索時にCookie／クッキー、UA／ユーザーエージェント、サムネ／サムネイル、キャッシュ／cache、ビューア／ビュワーなどを同じ語として扱います。英字の大小、全半角、ひらがな／カタカナの違いも吸収します。ChMate本体とHaiagaruの設定検索が対象です。複数語はすべてを含む設定に絞ります。

Haiagaru設定トップの共有・読み込み・最低限構成のボタンより上に「Haiagaru更新履歴」があります。安定版の変更を新しい順に表示し、バージョンごとに開閉できます。「開発版（dev）の履歴も表示する」で開発版を含め、「GitHubから最新の更新履歴を取得」で最新のCHANGELOGを読み直せます。機能のスイッチと設定ボタンは該当バージョン内に配置しています。1.25.0の項目には画像・NG・履歴・エッヂなど、1.26.0にはオルグ板の切替を表示します。開発版も表示する場合、同じ版の設定は安定版側にまとめ、安定版がまだない場合だけ最新の開発版に表示します。

既存の設定リンク・検索との互換性のため、アプリ・通信内の基本設定にある「更新履歴」からも同じ画面を開けます。

更新履歴の説明は日本語で表示します。過去版の英語のコミット説明も日本語にし、元のコミットへのリンクは保持します。今後のMorphe／GitHub公開文も日本語の説明から自動生成します。

1.27.4の画像取得の項目にはサムネイルの切替、1.27.5の設定表示の修正には各機能の切替を表示します。別バージョンにある同じ設定のスイッチもON/OFFが連動します。Morphe／GitHubの公開文が「最適化」だけの場合も、アプリ内では補足した詳細を下側へ表示します。

「追加された機能をすべて見る」は更新履歴画面から開けます。設定トップの重複ボタンは削除しました。アプリ・通信、表示・検索、画像・動画、NG・文字列置換、履歴・投稿の目的別に設定と短い説明を表示し、下側で1.24.1以降の追加機能20項目の詳しい説明を確認できます。更新履歴の各版では、その版の変更点を表示し、過去版の全差分を繰り返し表示しません。

外部板を含む全板検索では、「高速：保存済みのスレ一覧から検索」と「最新：対象板のスレ一覧を取得して検索」を選べます。初期値は高速です。OFFの管理対象サイトは候補から除外します。[検索方式と保存範囲](global-title-search.md)
