# Haiagaru機能の設定場所

設定はHaiagaru設定内の目的別カテゴリと、その機能を使う画面にあります。「更新履歴」画面上部の「機能のオン・オフ」からも切り替えられ、同じ設定値が各カテゴリにも表示されます。機能の説明・更新履歴は同画面の下部にあります。

| 変えたいこと | 設定場所 |
| --- | --- |
| 本文・一覧の表示、コピー操作 | Haiagaru設定 → スレッド |
| 記者ID検索、記者ID表示、文字列置換、履歴ポップアップの対象 | Haiagaru設定 → スレッド |
| IDチェッカー、DAT取得経路 | Haiagaru設定 → 探す・過去ログ |
| 入力、スレ立てコマンド、アップロード | Haiagaru設定 → 書き込む |
| 再生、動画サムネイル、スレ一覧サムネイル、自動保存 | Haiagaru設定 → 画像・動画 |
| NG、登録画像あぼーん、コピペ省略レスの透明あぼーん、荒らし省略 | Haiagaru設定 → NG・ミュート |
| 閲覧・書き込み履歴とコピーした文章 | Haiagaru設定 → 履歴・コピーした記事 |
| ローカル保存、復元、MEGA同期 | Haiagaru設定 → バックアップ・機種変更 |
| 言語、広告、接続、設定リンク、外部板サイトの使用 | Haiagaru設定 → アプリ・通信 |
| 投稿検索のオン／オフ | ツールバーから検索画面 → 投稿検索を利用する |
| バックグラウンド検索、検索履歴、検索先の表示 | 検索画面右上 → 検索の設定 |
| 追加ツールバーの表示・配置 | ChMate標準のHOME・板・スレの各ツールバー設定 |
| ツールバー画像の変更 | Haiagaru設定 → スレッド → ツールバーのアイコン画像 |
| 最近の追加機能の切替、更新履歴 | Haiagaru設定 → 更新履歴 |
| レス保存・保存済みレスの表示 | レス長押しのツールバー設定の各トグル |

更新履歴画面では、外部板サイトごとの使用、サイト別板一覧、スレ一覧サムネイル、記者ID検索・表示、登録画像NG、コピペ省略レスの透明あぼーん、ReplaceTxt、対象タブ、投稿後の自動監視、動画サムネイル・横画面表示、既読スレ削除の長押し、IP表示スレの投稿前確認などを切り替えられます。外部板サイトはエッヂ・けんも板・爆サイ・ふたば・あにまんが初期ONです。登録画像NGの画像・判定レベル・一致枚数は、同画面の「登録画像・判定レベル・一致枚数を設定」から編集します。各項目の詳しい条件や制限はリンク先の機能説明を参照してください。

検索の設定、ツールバーの表示チェック、各カテゴリにある同じ設定と値を共有します。更新履歴画面に項目がない機能は、目的別カテゴリまたは機能を使う画面で設定してください。既存の設定値・保存データは引き継ぎます。

ツールバーの旧全体表示スイッチとレスメニューの「常に表示／常に非表示」は使わず、ChMate標準のチェック状態を優先します。検索をオフにしても入口は消えず、同じ画面で再びオンにできます。オフにしても履歴や保存結果は削除しません。

数値は各項目で検証し、再起動が必要な変更は確認を表示します。設定一覧の検索は項目名・説明を使い、入力した認証情報や保存先の値は検索しません。

この案内は現行のCompose設定画面に対応します。過去版とは項目名や配置が異なる場合があります。[画面変更の詳細・確認範囲](compose-settings.md)
