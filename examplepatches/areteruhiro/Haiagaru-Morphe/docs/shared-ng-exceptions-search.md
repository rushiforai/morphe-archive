# 共有NGの個別除外検索

「共有NG → 受信した条件・個別解除 → チェックした条件を適用しない」に検索欄を追加。条件の文字列・掲示板名・種類の部分一致で絞り込みます。英字の大小・全角半角を正規化し、「NGワード」「名前」「ワッチョイ」「上4桁」「下4桁」「記者ID」「トリップ」でも探せます。検索欄の下に表示件数／全件数、該当なしの場合はその旨を表示します。

除外の編集中状態は条件IDで保持するため、検索で非表示になった条件のチェックも残します。保存時は非表示条件を含む選択全体を反映し、「戻る」で破棄します。現在の受信一覧にない既存除外IDも保持します。新しい受信一覧の取得や通信は行わず、画面を開いた時点のスナップショットを検索します。

リストはListViewのアダプターと既存Compose表示を使い、全条件のチェックボックスを一度に生成しません。
