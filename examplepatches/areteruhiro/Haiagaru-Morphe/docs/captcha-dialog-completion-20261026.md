# CAPTCHAダイアログと投稿後処理（2026-10-26、未公開）

ユーザー指示: CAPTCHA用の第三者Cookieとサイト認証/投稿許可を常時ONにし、CAPTCHAのみダイアログ表示。続報により黒い背景を修正し、書き込み成功時は認証画面とChMateの書き込み画面を閉じ、送信した本文/保存下書きをクリアする。エラー/キャンセルでは本文を消さない。認証中に編集した新しい本文も保持する。

## 実装

- 捕捉した元HTMLがCAPTCHAの場合、両許可を毎回有効にして直接ダイアログActivityを開く。確認チェックや中間ダイアログを省く。
- 元フォーム、hidden入力、送信先、提供元iframeとサイトスクリプトを保持。フォーム外の既存説明だけCSSで隠す。後から追加された認証フレームは隠さない。自動解答や自動再送なし。
- AndroidはActivityのmanifestテーマから背景の遮蔽を判断するため、透過/浮動テーマをmanifestへ登録する。Window背景も透過し、従来の全面認証は実行時に従来テーマへ戻す。
- 同一originの/test/bbs.cgiに、明示的な投稿成功titleと完了本文があり、form/エラーがない場合だけ成功として扱う。CAPTCHA認証完了だけでは成功としない。非同期判定は対象URLとページ世代も照合する。
- 元の本文はハッシュだけ保持し、成功時に同じActivity/対象/入力欄/本文か確認。変更された新しい下書きは消さない。本文を空にして、native onPauseと同じ下書き保存メソッドを呼ぶ専用wrapperで保存後、RESULT_OKで投稿Activityを閉じる。WebViewの成功判定以外からこのcallbackを呼ばない。後処理失敗時は本文を復元する。
