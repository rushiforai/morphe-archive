# Haiagaru プレリリースの変更内容

## 1.12.0-dev.8以降の修正候補

安価（>>数字）が多い本文の装飾で、文字を編集しないのに編集用データを構築していた処理を軽量化しました。元の本文とリンク位置、投稿者強調のオン／オフを維持しています。合成データでは処理時間の削減を確認しましたが、利用者の環境で起きた表示遅延自体は再現できていません。[検証記録](dense-anchor-render-20261023.md)

「非表示NGのレスを未読件数に含めない」をオンにした際の負荷を減らしました。同じスレのキーの再利用、NGがない場合の走査省略、集計キャッシュの不要な作り直しの削減を行っています。未読件数・既読位置は本体データを書き換えず補正します。ホーム設定の大きな見出しを通常サイズにし、上部余白も詰めました。[検証記録と制限](hidden-ng-unread-perf-20261023.md)

人気レスが存在するのに空になる経路を修正しました。標準表示は本体の現在の結果を使い、過去の判定用レイアウトで置き換えません。後から完全なデータが届いた際も、前回0件だったという理由で更新を止めないようにしています。直接返信数方式の抽出も件数表示・追加項目のオン／オフから独立させました。

ワッチョイ長押しの各検索・NGをオフにしても項目が残る競合を修正し、個別の非表示を優先します。長押し検索・IDからの必死チェッカーも本体タブ設定へ接続し、×の背景・内容との重なりを整理しました。エッヂ検索結果は下へ引いて表示中の条件・ページを再取得できます。hissi.orgのHTTPはHTTPS自動切替から除外します。起動中の絵文字フォント読込を別スレッドへ移しました。

人気レスの修正前／修正後の制御再現と確認範囲は[内部検証記録](popular-stale-layout-20261023.md)を参照してください。自然発生する断続的な表示欠落をすべて解消したという保証ではありません。以前の記録にある無クラッシュ確認はその候補・確認時間に限るもので、今回候補の結果と混同しないでください。

以下はdev.8以前の変更・当時の確認記録です。

いつも不具合の報告やご提案をありがとうございます。今回は、テーマの反映、フィルターとタブ操作、必死チェッカーの表示調整、MEGAログイン画面を改善しています。変更内容と確認範囲を以下にまとめています。

## ご利用にあたって

### 高度なNGの例

以下は「レス本文」に設定するスクリプト例です。`NGワード`を実際に判定したい文字へ置き換えてください。標準NGWordの登録一覧を読み込むものではありません。必要に応じてコピーして利用してください。

```javascript
function (text, options) {
  return {
    match: text.includes("NGワード"),
    samePoster: true,
    chainReplies: true
  };
}
```

フローティングボタンは「ツールバーとフィルターの設定」で「下部フィルターパネルを使う」と「フィルターのフローティングボタンを表示」をオンにすると使えます。非表示でもツールバーからフィルターを開けます。他のアプリに重ねる権限は必要ありません。動画の移動秒数は、専用ビューアの「︙ → 操作設定」から変更できます。

履歴の非表示は対応する3版で確認し、GIFの再生・操作・秒数表示、浮動ボタンの移動・配置保存も確認しました。実際のスレから浮動ボタンで下部パネルを開く操作と、スレ本文・画像の表示も確認しています。共通処理の重複確認は一部省略しています。端末ごとの長時間利用は引き続き確認が必要です。

本体タブ表示は「Haiagaru設定 → アプリ・通信 → 基本設定」から選べます。「画面を新しいタブに追加」で、Haiagaru設定・エッヂ過去ログ検索・投稿を探す・投稿検索・結果・ワッチョイ全文検索を追加できます。すべてのダイアログがタブになるわけではありません。

検索結果の一時キャッシュは、端末や利用者によるキャッシュ削除で消えることがあります。残しておきたい結果は検索履歴も利用してください。検索先のメンテナンスや収録状況によって、見つからない投稿もあります。

確認の詳細は[公開前の確認一覧](release-readiness-20261021.md)をご覧ください。大量履歴・NG設定、タブのプロセス復元、短いスレの更新位置や端末ごとの長時間利用は確認を続けています。バックアップを取ってからお試しください。正式版の配布先は変更しません。
