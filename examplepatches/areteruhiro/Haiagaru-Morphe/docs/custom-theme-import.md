# 自作テーマの取り込み

対応: ChMate 0.8.10.191 dev / 0.8.10.226 dev / 0.8.10.242 dev。

Haiagaru設定 → スレを読む → 「自作テーマをファイル／フォルダから取り込む」。
Android標準のファイル選択画面を使用するので、Downloadや対応するドキュメント提供元から選べる。


1. テキストだけなら「テーマファイルを選択」で複数選択。
2. 背景やアイコンを含むならZIPを展開し「画像素材付きのフォルダを選択」。
   選んだフォルダの直下と、その1段下のファイルを取り込む。二重フォルダにはしない。
3. 件数と同名ファイルの置き換え確認を行ってから取り込む。
4. ChMate標準の「テーマの選択」を開き直して追加したテーマを選ぶ。
   選択中のテーマを上書きした場合も再選択し、必要ならChMateを再起動する。

テーマ名は `任意の名前.day.txt` / `.night.txt` / `.ingrs.txt` / `.gray.txt` /
`.sky.txt` / `.ml.txt` / `.day3.txt`。UTF-8のJSON（ChMateと同じAndroid JSONObjectパーサー）で読み取れるもの。
`ml.txt`だけでも標準ZIPインポートの判定を通さず追加できる。
元のバイト列・名前・相対配置を維持し、テーマ内容を自動変換しない。
単独ファイルはテーマ名のサブフォルダへ、フォルダ直下のテーマは選んだフォルダ名のサブフォルダへ配置する。
既存のテーマ入りサブフォルダは維持する。標準テーマ削除が親フォルダをまとめて削除する仕様なので、
同じフォルダ内の昼・夜などのセットは一緒に削除されるが、他のテーマフォルダを巻き込まない。
画像素材はPNG/JPEG/WebP。テーマ以外の文書・実行ファイルは取り込まない。

一度に256ファイル、テーマ1件2MiB、素材1件16MiB、合計64MiBまで。
素材は縦横8192pxまで。規定外・不正なJSON・読み取り失敗時は既存テーマを書き換えない。

## 取り込み済みテーマの一覧・削除

Haiagaru設定 → スレを読む → 「取り込み済みテーマ一覧・削除」。
取り込み画面内にも同じボタンがある。

一覧には保存先フォルダとテーマファイル名を表示する。対象をタップし、確認画面の「削除」で削除する。
Haiagaru経由の取り込みに加え、同じ保存先へ手動配置した自作テーマも対象。アプリ内蔵の標準テーマは含めない。

- 使用中のテーマは、先にChMate標準の「テーマの選択」で別のテーマへ切り替える。
- この一覧からの削除は選んだテーマファイルのみ。同じフォルダの昼・夜など別ファイルや画像素材、取り込み元のファイルは残す（ChMate標準のフォルダ単位削除とは異なる）。
- 削除後は一覧を更新する。ChMate標準の「テーマの選択」も開き直す。
- 削除は取り消せない。元ファイルが残っていれば再度取り込める。
- 確認中にテーマが更新された場合は削除せず、一覧を開き直して確認するよう案内する。
