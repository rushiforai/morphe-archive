# NGWordから投稿者IDへ広がったNGの返信連鎖

具体的な登録手順と確認用のレス例は[NGWord・投稿者ID・返信連鎖のサンプル](ngword-poster-chain-example.md)を参照してください。

標準のNGWordで、同じルールの「連鎖」と「投稿者のIDもNG」を両方ONにすると、その語句に一致した投稿者の別レスも連鎖の起点として扱います。高度なNGルールの有効化やJavaScriptの追加は不要です。

例:

1. 10番: ID=A、NGWordに一致する本文。
2. 20番: ID=A、NGWordを含まない本文。
3. 30番: ID=B、`>>20`への返信。
4. 40番: ID=C、`>>30`への返信。

20番も連鎖の起点になるため、30番と40番にもChMateの連鎖NGが適用されます。本文にNGWordを含むレスへ直接返信した場合の連鎖も引き続き適用されます。

両方の設定が付いた同じNGWordルールで判定します。「連鎖」だけのルールと「投稿者のIDもNG」だけの別ルールを組み合わせて対象を増やすことはありません。無効・強調・レス番号指定のルール、IDを持たないレスやシステム投稿も対象外です。板の範囲はChMateが現在のスレ用に絞り込んだNGWord一覧に従います。

取得済みの元レス一覧を使って投稿者を調べ、描画用のNG結果が完成する前に、標準の連鎖状態表へ同一IDのレスを登録します。その後のアンカー判定と表示はChMateの処理を使います。NGIDの保存一覧やDATは書き換えません。191／226ではスレ再構築ごとに判定を破棄し、241／242／243では各スレのNG判定オブジェクトごとに保持します。

## 実装と確認範囲

### NGWord-IDへの返信も非表示（追加オプション）

Haiagaru設定の「NG・ワッチョイ」→「NGWord-IDへの返信も非表示」で切り替えます。初期OFFで従来の表示を維持します。変更後はスレを閉じて開き直してください。

ONの場合、同じNGWordルールで「連鎖」「非表示」「投稿者のIDもNG」がすべて有効なとき、その投稿者のNGWordを含まないレスへの返信も、あぼーん行を残さず非表示にします。その先の返信も対象です。「非表示」なし、別々のルールでのチェックの組み合わせ、無効・強調・レス番号指定ルールは対象を増やしません。返信した人の無関係なレスは非表示にしません。

191 dev／226 dev／242 devの透明NG用マップが構築された後、参照数計算・一覧の除外判定より前に対象を追加します。連鎖あぼーん表示用のキャッシュとは別の処理です。保存済みのNG登録・DATは変更せず、再構築のたびに現在のルールとスレで判定します。設定の共有・初期化にも対応します。
