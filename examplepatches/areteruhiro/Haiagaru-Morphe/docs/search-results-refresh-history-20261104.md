# 検索結果の日時除外・更新対象履歴・タイトル操作の背景

スレ内検索は黄色強調・adapterの絞り込み・一致レス番号を作る背景タスクが別経路です。従来の投影フックがなかった背景タスクは、名前・日時・本文・メール・レス番号へ順次findを実行していました。191の旧候補で「火」が本文にないレスも含め3件になることを再現しました。

191 `o.o3.d`、226 `o.setSelectedColor.c`、242 `o.zzadk$IconCompatParcelizer.invokeSuspend` の最初の検索を既存ThreadSearchTextの本文＋任意ID／ワッチョイ／名前の投影へ接続。不一致なら次レスへ進め、日時・メール・番号の追加判定を通らないようにします。元レジスター、他の命令、nativeループと242のキャンセル処理は維持。本文の日付・曜日は検索できます。調査中の共通regex判定器はNGにも共用されていたため変更していません。

標準の履歴ポップアップへ「更新対象のスレ（件数）」を追加。登録スレをスレ名＋板名で並べて開けます。登録集合とnative bookmarks／boardsの読取専用参照から作る一覧で、履歴・お気に入り・通知登録を書き換えません。URLは版別のnative BoardID／BBSUrlInfoで復元。タブレットの画面振分けには本体の経路を利用します。未登録時は登録方法を案内します。

226／242のタイトルメニューはMaterial Surface外のチェック欄が透明なままだったため、チェックと通知等の操作全体を不透明な背景のパネルへまとめました。下端insetsもパネル全体へ適用します。標準領域の重み・操作は保持します。

## 検証

- 通常Lint付きbuild／buildAndroid成功4分6秒。3版へ適用・署名照合更新成功。
- 最終候補で実native検索タスクを8通りの設定×6検索語で実行し、各版48項目成功。ヘッダーのみの火・11/03・09:34を除外し、本文の同じ語と任意対象設定を維持。
- 3版の実履歴ポップアップ、5ch形式／したらばのURL復元、一覧の選択とAndroid起動境界まで各21項目成功。タブレットはResListActivityへの指定を本体がTabletHomeActivityと_dataへ変換し、選択URLを維持することを確認。外部通信は無効、掲示板への投稿なし。fixtureのDB行・登録集合を試験後に復元。
- native検索タスクの元レジスター／他命令保持・次レスへの分岐・履歴popupへの1フックを構造検査。未変更本文・画像・GIF・動画の広範な再検証は利用者指定により省略。
- 242のタイトル操作欄の重なりは完成パッチでの実画面再確認を未完了とします。添付URL取得は429。nativeタイトルfragmentを単独追加した試験では該当sheetを表示できず、別の表示試験の実行は自動承認審査が `blocked by policy`（詳細なし）で拒否しました。成功扱いにせずプレ版の残確認として公開説明へ記載します。

検証資材 `build/search-history-final-*`。最終APK導入原本は公開対象外 `build/local-development-records/search-history-final-installations.json`。初期設定の規約同意は既存の利用者許可に基づき隔離アプリだけで実施。試験スクリプトのFrida型指定・callbackの非同期と本体タブレット振分けに合わせて修正した失敗は製品修正とは区別します。

対象検証アプリの今回の新規crashなし。全crash bufferには前ターンの診断時SIGSEGVとエミュレータのBluetooth hardware errorが残っており、今回のアプリ例外とは区別しました。
