# 投稿上限・残量表示

Haiagaru設定の投稿関連へ「投稿上限・残り文字数・行数と超過部分を表示」を追加。初期ON。OFFでは表示と本機能の赤色装飾を解除する。下書き、選択位置、既存装飾、入力フィルターは変更しない。設定の共有・復元にも対応。

スレタイ（新規スレ作成時）・本文・行数の使用量と上限、残り量を表示。超過した文字以降と超過行を赤色にする。改行はCRLFを1回として数え、絵文字のサロゲートペアを分割しない。5ch互換のバイト上限ではChMate自身のカウンターを使い、送信時の変換・文字コードに合わせる。文字数とバイト数を併記する。

キャッシュされた板設定を即座に参照し、バックグラウンドでSETTING.TXTまたはしたらば設定APIを取得。外部板は既存gatewayのTransportを使って投稿フォームのmaxlength・明示的な行数属性を確認する。あにまん新規スレでは既存投稿アダプターの64／1000／30制限も反映。検索フォームやtextareaの表示行数を上限に使わない。5chのBBS_LINE_NUMBERは2倍、したらばの省略表示行数は投稿制限に使わない。

取得値は10分、未取得は60秒キャッシュ。表示の長押しで再取得可能。上限を公開していない場合は「上限未取得」とし、推測した制限で警告しない。取得処理はGETだけで、本文や下書きを送らない。
