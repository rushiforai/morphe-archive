# 全板検索と複数レス選択（2026-11-15、1.39.0-dev.1 公開）

## 依頼と実装

- 191・226・242のHOME全板検索を、利用者が開始するforeground serviceで実行する。完了通知から標準の全板検索結果一覧を開く。
- 「全板から検索」「取得済みのスレから検索」「過去に取得したスレ一覧を表示（取得日時）」を表示する。同じキーワードの全板検索を押すと保存済み結果を直接表示し、確認ダイアログや再通信を挟まない。結果画面のメニューから最新を取得し直せる。
- バックグラウンド検索、履歴の再利用、途中結果の表示は独立した設定（初期オン）。バックグラウンドOFFでは元の検索に戻す。外部板・bbspinkの対象設定と高速／最新モードは既存設定を使う。
- 標準検索と外部板検索を並行実行し、外部板の保存済み一覧を先に表示する。最新モードは既存の2並列／30秒制限を維持。取得できた板から途中結果を追加する。完了結果は最大50件・圧縮データ合計24MiB、1検索5000スレ・2MiB。
- スレの︙「レス複数選択」で本文の中で選択する。タップで色を付け、再タップで解除する。表示中のネイティブ行とリスナーを変更せず、選択モードの間だけタップを受け取る。ドラッグは元の一覧へ渡す。終了時は元のWindow.Callbackを戻す。
- 複数選択バーの︙「スレ内検索」では、一致したレスをチェックして追加・解除できます。検索結果を閉じると元の一覧に戻り、検索前から選択していたレスと一緒にコピー・保存・NG登録できます。検索では本文と設定で有効にした名前・ID・ワッチョイを対象にし、空白区切りの語をすべて含むレスを表示します。
- ChMateのツールバー設定で「選択（レス複数選択）」を追加すると、スレ画面のボタンからも選択モードを開始できます。
- 選択中のバーから既存のレス長押しメニューを開ける。NG登録・コピー・レス保存は選択したレスを対象とする。複数選択中だけワッチョイの全体／上4桁／下4桁検索を非表示にし、通常メニューは維持。
- NG登録は最大100レス。共通条件／1レスずつの条件を選び、ID・名前・本文（NGWord）・このスレのレス番号を登録する。個別条件のチェックを外すと除外する。最後の確認まで登録しない。標準NGストアと標準DAT索引を使用し、プレビュー中の他操作によるNG変更を検出する。
- コピーはレス番号・名前・本文・レスURL・ヘッダー＋本文。項目を複数選んで内容を編集する「選択」も用意する。コピーは取得済み本文を使い、投稿・追加通信を行わない。
- レス保存は「1レスずつ別々」「選択レスを1件にまとめる」の2通り。保存先は既存／新規の保存用スレ。まとめ保存には各レスのヘッダー・本文・URLを保持し、固有URL識別子により単独レスの保存と衝突させない。画像・動画の実体は保存しない。
- Haiagaru設定の初回表示に、したらばサポート板を開く案内を追加する。既存のNG共有同意とは独立した端末内の表示済みフラグを使う。
- 画像一覧の端でビューアーを閉じる未公開修正 ece18b1b も同じプレリリースへ含める。
