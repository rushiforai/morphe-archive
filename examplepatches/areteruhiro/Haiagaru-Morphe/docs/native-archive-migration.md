# 通常ChMateからのアーカイブ・共有データ移行

## フォルダ・ZIPでアーカイブを復元

「Haiagaru設定 → ローカルバックアップ」またはアーカイブ関連設定の「ChMateのアーカイブフォルダ・ZIPから取り込む」から、フォルダ／ZIPを選びます。通常ChMateの `archive` フォルダ、またはその親の `2chMate` フォルダが対象です。DAT・IDXとフォルダ構造を保持します。

取り込む板フォルダやファイルを個別に選ぶか「すべて選択」を使い、確認後に同名ファイルを上書きします。元フォルダ・元ZIPと未選択の保存内容は変更しません。作業領域で読み込みとZIPのCRC・サイズを検査してから反映し、通常の書き込みエラーでは上書き前のファイルを戻します。移行後は標準のスレッドアーカイブ一覧を開き直してください。

Android 11以降で別アプリの `Android/data` を標準の選択画面から開けない場合は、元のarchiveフォルダをDownloadなどへコピーして選択してください。アプリ内部の設定・認証データを取り込む機能ではありません。

## Shizukuで共有データを上書き移行

パッチ適用時に任意の **Migrate ChMate data with Shizuku** を選択します。Android 7以降・Shizuku v13以降が必要です。Shizukuを使用しない通常構成には追加しません。

Haiagaru設定の「データフォルダを選んで移行 (Shizuku)」から移行元のパッケージ名を入力します。標準は `jp.co.airfront.android.a2chMate` で、別名パッケージも指定できます。対象は `/storage/emulated/0/Android/data/移行元パッケージ/files/2chMate` の共有データです。アプリ内部の設定領域は対象外です。

Shizuku権限を許可した後、フォルダ・ファイルを個別／全選択し、上書き確認で実行します。読み込み失敗時に対象ファイルを途中まで上書きしないよう、各ファイルをAtomicFileで更新します。処理全体を中断した場合、それ以前に完了したファイルは移行済みになるため、失敗時は元データを確認して再実行してください。元アプリのデータは削除しません。移行元ChMateを閉じ、完了後にHaiagaruを再起動して反映します。

Shizukuの起動方式や端末側の制限により、対象領域にアクセスできない場合があります。別アプリの内部設定を取得したり、Androidの権限制限を解除する機能ではありません。
