# 外部板を含むスレ検索

Haiagaru設定の「全板検索に登録済みの外部板・bbspinkも含める」で使用します。「検索対象の外部板を選ぶ」から対象を絞れます。

検索方式を2種類から選べます。

| 方式 | 動作 |
| --- | --- |
| 高速（初期値） | 取得済みのスレ一覧を端末内で検索します。外部板検索の追加通信は行いません。未取得の板や保存後に作成されたスレは含まれません。 |
| 最新 | 対象板のスレ一覧を取得して検索します。2並列・最大30秒とし、間に合わなかった板がある場合は取得できた範囲を表示します。 |

高速モードに使う一覧は、最新モードで取得した際や、あにまん・ふたば・爆サイの板を通常表示した際に保存します。検索時に、保存済み一覧を検索できた板数を表示します。標準の全板検索結果は従来どおり残します。本文の取得は行いません。

一覧はアプリ内部の索引へ圧縮保存し、アプリ再起動後も利用できます。保存容量は圧縮データ約64MiB・最大1万板を目安に古いものから整理します。1板の一覧は最大2MiBです。高速モードの追加処理は8秒を上限とし、件数・容量の上限に達した際も処理済みの範囲を表示します。多数の未取得板を一度に登録しても、高速モードが全板へ通信することはありません。

掲示板設定でOFFにした管理対象サイトは、検索候補と結果から除外します。設定をONに戻しても保存済みログを削除・再作成しません。検索方式は設定の共有・読み込みにも含まれます。
