# 追加画面を本体タブで開く

Haiagaru設定 → アプリ・通信 → 基本設定 → **タブレットで追加画面を本体のスレタブで開く**。

- 初期値はオフ。従来どおり別画面で開く。
- オンにすると、Haiagaru設定、エッヂ過去ログ検索、投稿を探す、投稿検索・結果、必死チェッカーもどき、ワッチョイ全文検索を、本体のスレタブと同じ列に追加できる。
- スマートフォンの通常画面では従来どおり別画面で開く。表示幅やDPIではなく、本体のTabletHomeActivityで開いているかを確認する。
- 切り替えは次に開く画面から反映する。オフにしても、すでに開いているタブを自動削除しない。
- タブ内の設定も、通常画面と同じカード部品で「機能名・スイッチ → 説明」の順に表示する。検索画面も別画面と同じControllerを使い、タブごとに状態を分ける。
- 設定のカテゴリ、検索条件・位置をタブごとに保存する。保存データが8Ki文字を超える場合は結果一覧を省き、復元時に再取得する。極端に長い条件は初期条件へ戻す場合がある。
- `.haiagaru`の設定共有にもオン／オフを含める。

### 画面の個別選択とタブ追加

基本設定の「画面を新しいタブに追加」から画面を選ぶ。ChMateの新規タブ画面の上に置いていた独立ボタンは撤去し、標準の新規タブ画面自体は変更しない。

「タブ表示する画面」のスイッチは各画面それぞれに用意する。全体スイッチがOFFの場合はタブ追加しない。スマートフォン表示では、タブレット表示の本体画面から設定を開くよう案内する。

追加したHaiagaru画面の右上の「×」で、その画面のタブを閉じる。通常のChMateタブには×を重ねない。191ではネイティブのtype-4ページ削除メソッドへ接続し、226/242の削除経路は版ごとのランタイム確認が必要。

投稿検索の条件・スクロール位置はタブごとに保存する。結果の一時キャッシュはActivityの復元Bundleとは分け、通信なしで復元する。キャッシュの削除・OSによる整理で一時結果は消える場合がある。通常の検索履歴とは別管理。

以下は以前の実装・検証記録。最新の変更状況は[設定内のタブ追加・検索タブ](tool-tabs-settings-20261022.md)を参照。
