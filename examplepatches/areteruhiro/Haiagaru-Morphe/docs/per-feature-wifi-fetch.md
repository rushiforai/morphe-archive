# 機能別のWi-Fi自動取得

一括mobilePreviewPolicyを廃止し、画像・スレ一覧画像・Webカード・Xカードはそれぞれ「取得／取得しない／Wi-Fi時のみ自動取得」の独立設定へ変更。未設定の初期値はWi-Fi時のみ。旧画像OFFは維持。動画とGIFは既存の取得内容選択を維持し、第5選択肢としてWi-Fi時のみ（画像＋動画／画像＋GIF）を追加、未設定の初期値を第5選択肢へ変更。既存の明示選択は保持。スレ一覧・カードの機能有効スイッチも保持し、OFFを自動でONにしない。

判定はアクティブ回線のWi-Fi transportで、携帯回線・未接続・種別不明は自動取得しない。VPNにWi-Fi transportが引き継がれない端末も自動取得しない。設定画面は回線に依存しない保存値を表示し、実効値だけを取得時に計算。手動URL操作、ChMate標準の画像取得は別。取得済みキャッシュは削除しない。既に開始済みの通信は停止保証しない。

更新履歴の追加機能一覧にも6設定を追加。1ファイル上限設定は保持。
