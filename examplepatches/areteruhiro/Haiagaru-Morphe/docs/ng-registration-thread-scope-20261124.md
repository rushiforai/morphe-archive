# スレ限定NGの反映修正

検証用242で指定train/1794303138の1002件、同じIDの100件を確認。保存後の照合は成功しているが透明NG用の専用IDマッチャーがスレ限定ルールを除外していた。

元APKのNGWord.Item.board参照を調査し、共通NGWord以外にもID系・数値系の専用クラスが独自に板一致を判定していることを確認。既存patchNgBoardScopesは共通2メソッドだけを変更していたため、191／226／242の専用2メソッドにも同じNgBoardScope.matchesを適用。各版とも該当メソッドと比較箇所を一意に照合し、構造が異なれば適用を失敗させる。

Fridaで登録済みのルールから新しいネイティブマッチャーと判定エンジンのコピーを構築し、専用クラス内のスレ限定比較だけを補正した場合と補正しない場合を比較。透明NG側の一致は0/100から100/100へ改善。通常の表示用フラグが0でも透明NG用マッチャーに一致している場合があるため、その値だけでは非表示の成否を判断しない。元のNG登録内容は変更していない。試験 scripts/frida-ng-specialized-scope-check.js、結果 build/ng-specialized-frida242.log。

実機計測ではNativeNgStore.updateAndVerify最大19ms、ThreadScopedNg.interceptRegistration最大81ms。今回の登録では長時間停止は再現しておらず、連投NG登録の全ての遅延を解決したとは扱わない。

表示設定は既存threadScopedNgEnabledを共用し「NG登録時に『このスレのみを対象にする』を表示」へ名称変更。OFFはID／名前／ワードの対象選択確認を省略し、ﾜｯﾁｮｲ上下4桁にも非表示を適用。既存の限定NG・板限定・スレ削除時の限定NG削除は保持。Fridaで設定のON/OFF判定は191／226／242各4項目成功、元設定へ復元。

修正版MPPのbuildAndroid成功。元APK191／226／242へ適用し、全てunsigned検証APKの再構築成功。実機へのAPK更新は行っていない。
