# 板・スレのツールバーショートカット

## 登録した板へ1タップで移動

HOME・スレ内のツールバーカスタマイズ候補に「登録板へ直接移動」を8個追加。既存の「板・スレ」選択ボタンとは別に配置できる。移動先は番号ごとに独立し、初期は未設定。未設定時に押した場合だけその番号の登録画面を開き、設定後は一覧・確認画面を挟まずChMateの板画面へ移動する。

Haiagaru設定の「直接移動ボタンの移動先を設定（8個）」で番号を選び、登録済みの板を選ぶか、板名・板トップURLを手入力する。各アイコンは「ツールバーのアイコン画像」の同じ番号で個別変更できる。新しく入力した板は既存の板・スレ登録一覧にも追加する。同じURLを繰り返し登録しても増やさない。移動先は変更・解除でき、解除しても板・スレ一覧の登録自体は保持する。スレURL、実行可能スキーム、不正な設定データは拒否する。

名前を省略した場合、`kenmo.org`／`00c.org` は「オルグ」、`bbs.eddibb.cc`／`.net`／`.org` は「エッヂ」を補う。登録済みデータがURLそのままの表示名でも同じ補完を行う。手動の表示名は優先し、他のドメインはURL表示を維持する。標準ツールバーの文字表示・選択候補では番号の代わりにこの登録名を表示し、他の標準ボタンの文字には影響しない。

設定キー `directBoardToolbarTarget`（1個目）、`directBoardToolbarTarget1`～`directBoardToolbarTarget7`（2～8個目）をローカルバックアップの検証対象へ登録。更新履歴にも設定ボタンを追加した。表示／非表示と位置はChMate標準のツールバー設定で切り替える。独自アイコン差し替えの項目も追加し、既存アイコンの番号は変更しない。

`scripts/frida-direct-board-shortcut.js` で初期未設定、保存検証、8個の独立した板画面向けIntent、アクションID範囲、ラベル・アイコンリソース、個別解除を確認する。実通信や画面遷移は行わず、試験後は登録設定を復元する。
