# 2026-11-10 検索・あにまん表示・保存操作の修正

## 履歴のOOMログ

報告は2026-11-07 / 191 / Samsung SM-S921Q / Android16で、`EdgeReporterHistory.metadataTitle` から `SharedPreferences.Editor.apply` が呼ばれ、512MiBヒープ上限付近でMap複製に失敗したものです。この呼び出しは既存のe93a25ffで変更済みです。今回、重複投入・並行処理・保存OOM注入14項目、履歴/板ごとの永続化41項目、32MiBヒープでの5入口の退避を再確認しました。既存のNGや履歴を削除して回避する処理は追加しません。

3版の候補APKについても、履歴タイトルの3入口に同期 `Editor.apply` が残らないことを検査しています。プロセス全体の別要因によるOOMまで防ぐ保証ではありません。詳細は[既存のメモリ修正](history-memory-preview-archive-20261107.md)。

## スレ内検索

検索用のワッチョイ投影が裸の `abcd-EF12` だけだったため、直後の閉じ括弧と元の `(ﾜｯﾁｮｲ …)` 表記を含めるようにしました。表示本文・保存DAT・元の名前フィールドは書き換えません。IPを含む追加ヘッダーを検索対象へ混入させず、本文に実際に書かれた文字は従来通り検索できます。

3版のフィールド形式、ON/OFF、日時除外、本文/名前/ID、AND、正規表現、括弧を含む指定を含め、ホスト266項目が成功。実アプリ3版のレスオブジェクトでも同じ5通りの検索とIP除外が成功しました。

## あにまんの本文

- サイト側の `.row.g-0` 形式のリンクカードを、元URLのリンクへ変換。カードの見出し・説明を本文として複製しません。HTTP/HTTPSの通常リンクを保持します。
- `.reply` の被返信ナビゲーションを除外。投稿者が本文に書いた `.reslink` の `>>番号` は保持します。
- 段落の前後へ機械的に改行を足す方式をやめ、段落間の区切りを一つだけ追加。既存の `<br>` と重複させず、投稿者が入れた空行・先頭改行は保持します。画像だけのレスにも先頭の空行を足しません。
- 添付画像のリンク文字列を元URLにし、拡張子のない画像をChMateが取得するためのローカルhrefは保持。コピー処理では元の画像URLへ戻します。

報告URL `https://bbs.animanch.com/board/7585502/` は調査環境からHTTP403で取得できませんでした。同じサイトの保存済み実HTML（`.row.g-0` と `.reply` の実構造）と再現用HTMLを使用しています。保存実ページ79レス/34画像/360スレの228項目、新しいカード/画像/段落/返信14項目が成功。元の実スレ1レス目そのものの現行再取得は未確認です。

初回のアプリ試験では、画像URLの変換を `localUrl` に誤接続していたことを検出し、コピー用の `originalUrl` へ移しました。未公開の失敗候補は `build/nov10-followups/before-copy-fix.mpp` と `before-copy-fix191.apk`、失敗ログは初回gateway191の記録です。成功数には含めません。

さらに、ChMateの標準画像抽出がリンクの表示文字列を使用するため、拡張子のない元URLを表示するだけでは画像一覧から漏れることを検出しました。既存の添付画像getterの拡張入口で、登録済み・有効なあにまん画像だけを既存のローカルjpg経路へ戻します。表示本文・コピー結果は元URLのままです。不要な配列コピーを避け、低ヒープ時は元配列へ退避します。新しい全クラス走査は追加しません。

失敗候補は `before-attachment-routing.mpp` / `before-attachment-routing191.apk`。汎用プレビュー抽出器でlocalhostを検証した初期プローブは同抽出器の仕様に合わないため、実レスの標準添付getterと製品の全レス画像一覧収集器 `ThreadMediaUrls.collect` を検証する方式へ修正しました。実際の標準添付配列から画像が漏れた失敗は別に保持し、製品の接続を修正して3版で再確認しました。

## 専用ビューアの保存

動画/GIFの「保存」操作では、通信量・保存容量の注意確認を挟まず保存処理へ進みます。URLの対応形式チェックと、Android旧版で必要な保存権限の要求は元の処理を使用します。保存開始・進捗・完了は従来の通知/トーストで確認できます。
