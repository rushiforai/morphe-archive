# 標準UAをAndroid14へ更新

BrowserUaTemplatesの標準Dalvikテンプレートと先頭選択肢を4.0.3から14へ更新し、選択肢は14（標準）/15/16とする。4.0.3の旧出荷テンプレートと完全一致する保存値だけを既存resolve経路で14へ移行する。独自UA・15/16・有効/無効は保持し、全体UAやCookie/SessionIDを書き換えない。191/226/242の共通拡張処理で、新規バイトコードフックは追加しない。

通常Lint付きbuild/buildAndroid成功2m19s、64tasks。NativeUserAgentIdentityTest19項目成功。最終APKを191/226/242の既存隔離packageへ既知旧hash・署名照合してinstall-r成功。emulator-5580で各21項目成功。旧値の永続化移行、GET/POST/browserAgentの14、off維持、15/16/独自値保持、未接続HttpURLConnectionでChMate識別名・版と他ヘッダー保持、実設定カテゴリからテンプレート画面起動・3ラベルと選択callback保存を確認。新規対象app crashなし。設定復元、wm size reset/WiFi ON/mobile OFF、AVDデータ保持停止。実機/GAS/投稿未操作。変更外のスレ本文・画像/GIF/動画の広範な再検証は既存利用者指定で省略。公開確認は完了後に追記する。

初回のUI試験はFridaでshow()を捕捉できず停止。最適化後の経路に依存する捕捉方法を避け、表示中の本番dialogを取得して再検証した。製品例外と混同しない。

公開説明は既存の利用者指定（docs/integration-status.mdの2026-10-27記録）に従い、UAの具体的な変更内容を列挙せず、設定テンプレート更新と確認範囲を記載する。正式版1.22.1を維持し、既存Semantic Release CIからdevプレ版を公開する。
