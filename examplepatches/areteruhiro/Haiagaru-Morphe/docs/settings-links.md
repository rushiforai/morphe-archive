# 書き込みから設定を開く・切り替える

Haiagaru設定 → 言語・基本設定 →「設定リンクを作成」で設定を検索できます。対応するオン／オフ項目は「設定を開く」「オンにする」「オフにする」を、数値・文字列・選択肢・操作ボタンは「設定を開く」を選択できます。通常設定・エキスパート設定の実際の項目を使い（現在無効・非表示のものも区別して表示します）、設定画面にないキーを自由に書き換える方式にはしていません。

191・226・242で本文中の「書き込み用文字列」をタップして設定を開けます。対応する文字列は[設定リンク一覧CSV](settings-links-list.csv)で確認できます。X投稿プレビューのオン・オフには依存しません。

URL、書き込み用文字列、AndroidインテントURLの形式をコピーできます。URLや文字列に現在の入力値・パスワードは含めません。リンクに使う設定名とカテゴリ名は日本語で表示します。AndroidインテントURLはコピーしたアプリのパッケージを指定します。複数のパッケージで共用する場合は通常の設定リンクURLを使ってください。

例（スレ内検索のID対象設定）：

```
Haiagaru.設定.スレ内にIDを含める.true
Haiagaru.設定.スレ内にIDを含める.false
Haiagaru.設定.画面・文字の表示.スレ内検索にIDを含める.開く
Haiagaru.設定.スレ内検索にIDを含める.開く
```

最初の2つは要望された省略名です。実際の表示名「スレ内検索にIDを含める」も使えます。単なる文章として表示されただけでは設定を変更しません。本文のリンクをタップすると現在値・変更後の値を示し、「適用」を押した場合に元の設定画面のスイッチを操作します。「閉じる」では変更しません。「開く」は設定画面を検索状態で開きます。

1リンクで1項目を扱います。複数候補がある場合は適用せず、カテゴリ付きリンクを作り直す案内を表示します。現在の版・パッチ構成にない項目、オン／オフ項目でないものへのtrue/false指定、無効状態の項目には変更を適用しません。各設定の再起動案内・権限要求・反映方法は元の設定操作に従います。バックアップやログインなどの操作ボタンは、その設定画面を開くリンクに対応します。

一般の本文は同じ文字列オブジェクトを返し、設定文字列がある場合だけリンクを付与します。設定項目の収集はリンクを開いた後に行います。既存の投稿編集欄にはリンクを付けません。
