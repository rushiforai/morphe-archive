# レスから共有NGを除外する

共有NGが有効な場合、レス長押しメニューに「共有NG条件確認」を追加します。191／226のレスメニュー、242の通常レスメニューと本文シートの既存フックを利用します。

選択レス1件とそのレスの板だけを取得し、共有NGで現在有効な条件のうち一致する条件をバックグラウンドで調べます。一致した条件だけを検索・複数選択できる画面で表示し、除外したい条件にチェックして保存します。除外はこの端末の個別除外IDへ追加し、他の既存除外も保持します。キャンセルでは変更しません。個人NGの登録・本文・DAT・サーバー配信条件は変更しません。

保存後はスレを開き直してください。別の共有NG・個人NG・連鎖NGでも隠されている場合は、その表示が残ります。直接一致する有効な共有NGがなければ、その旨と個人NG・連鎖NGの確認案内を表示します。共有NGによる非表示かどうかを、見かけの「あぼーん(NG word)」という文字列だけで判断しません。

判定には本番のSharedNgIndexを条件ごとに使い、報告数・板・種類・配信停止・個別除外・正規表現を本来の適用条件とそろえています。ID・ワッチョイ・名前・キーワードを対象にし、別レスへの連鎖原因は推測して除外しません。メニューには共有NG有効時に入口を表示し、一致の有無は実行時に調べます。
