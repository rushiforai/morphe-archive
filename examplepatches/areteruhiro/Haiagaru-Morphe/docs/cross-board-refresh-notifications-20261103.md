# 板をまたぐ更新と返信通知（2026-11-03）

スレタイトルメニューの「更新対象に含む」で登録したスレは、別の板・スレの更新操作でも本文を取得します。標準の巡回処理を利用し、専用WorkManager名とKEEPで重複実行をまとめます。通常巡回の対象は変更しません。

新着通知はしたらばに対応し、スレごとに「自分の書き込みへの返信だけ通知する」「自分への返信を通知したら定期確認を停止する」を選べます。親設定「書き込み後に自動でスレを監視する」は初期OFF。投稿成功を標準処理で確認してから登録し、次の投稿で停止した監視を再開します。設定と監視登録はHaiagaruバックアップに含まれます。

標準通知とHaiagaru通知は先に通知した経路を優先します。重複判定はスレと新しく投稿されたレス番号で行います。同じ自分のレスへの別々の返信は、それぞれ通知対象です。通知履歴は端末内だけで保持します。

242のタブレット設定では、Haiagaru行のタップを本体のセーフモード選択処理より前に処理するよう修正しました。
