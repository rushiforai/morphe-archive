# ツールバーの表示・アイコン画像

対応: ChMate 191 dev／226 dev／242 dev。ここでは開発中のCompose版の操作を案内します。

## 表示・非表示と配置

ChMate標準のHOME・板のスレ一覧・スレ内、それぞれのツールバー設定でチェックを変更します。

対象の追加項目は、エッヂ過去ログ、フィルタ、すべて既読、長押しコピー、ワッチョイ下4桁・上4桁検索、★スレのみ巡回です。各ツールバーの選択状態と並び順をそのまま使います。

Haiagaru側の全体表示スイッチは廃止しました。過去の「全ツールバーで非表示」指定で標準チェックが無効になることもありません。検索機能をオフにしても検索ボタンは残り、検索画面から再びオンにできます。

## 画像だけを変える

Haiagaru設定 → スレを読む → ツールバーのアイコン画像。

- 「画像を選択」からAndroidのファイル選択画面で指定します。元の画像は変更しません。
- 最大16MiB。PNG／JPEG／WebPなどを、縦横比を保ち透明な余白を付けた256×256 PNGとしてアプリ内へ保存します。
- カスタム画像の色は維持します。標準画像のプレビューはComposeの明暗テーマに合わせます。
- 「標準のアイコンに戻す」で、その項目の取り込んだコピーだけを削除します。
- 画像を変更すると再起動の確認を表示します。配置順やチェック状態は変更しません。

アイコン編集画面もComposeで表示します。カスタム画像専用のバックアップ対応はありません。

必死チェッカー専用ビュワーでは「スレ立て件数」の表示を廃止しました。ビューア上部の「調整」から、文字サイズ・レスの上下余白・上部操作バーの高さをその場で変更できます。Haiagaru設定 → 同じIDの投稿を調べる にも同じ項目があります。
