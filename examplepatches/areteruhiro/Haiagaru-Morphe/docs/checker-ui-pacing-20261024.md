# 必死チェッカーの結果表示と走査間隔（未公開）

- 既存の検索・コピー・表示調整を維持し、結果ナビゲーションを本文の上へ移動。「レス／スレ／名前」の選択状態をMaterialタブで表示する。
- Hissi結果の投稿ヘッダー・本文・スレ／名前一覧の余白と区切り線を独自CSSで整理。AA用フォント・既存リンク・投稿DOMを維持する。
- 「探す・過去ログ」の必死チェッカー設定へ、Hissi／Kyodemoそれぞれの走査間隔を追加。整数秒で1〜3600秒、初期値はHissi3秒／Kyodemo10秒。前面／バックグラウンド／並列走査で接続先単位の待機を共有する。
- 前回通信開始時刻から待機時間を計算し、250msごとの待機再評価で実行中の設定変更にも追従する。wwwあり／なしを同一接続先として扱い、設定共有の数値検証・初期値にも登録。
- 403／429／5xxで停止する既存処理とキャッシュ優先は維持する。

初回の固定間隔版で通常Lintを含むAndroidビルド成功（4分）。設定可能版でホスト上の設定範囲・待機・別名ホストの並列間隔を確認。Androidの実SharedPreferencesの画面操作とは区別する。

設定可能版の最終Android build成功（`:patches:buildAndroid`, 1分29秒、89タスク）。ビルド中に別のGradle buildと重なった試行はR8へ不完全な同時出力を渡して失敗したため破棄し、単独buildで成功を確認した。APK導入・端末表示確認・公開は未実施。
