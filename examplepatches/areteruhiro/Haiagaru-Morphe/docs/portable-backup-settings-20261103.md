# 通知・バックアップ設定の移行補完（1.21.0で公開）

## 通知

「設定」にthreadNotificationsを追加し、登録スレURL・確認済み件数・1分〜7日の確認間隔を保存。通知本文とworkerの操作tokenは除外する。通常復元は登録集合を置換し新tokenを発行、期限切れworkerの書戻しを防ぐ。次回Jobを再予約、空集合は取消。双方向同期は既存登録/件数/token/間隔を保持し不足分だけ追加。同一同期で新規変更がなければJobを作り直さない。旧ZIPは端末側の登録を保持。100件上限/URL/重複/整数範囲を検査し、超過時の切捨てはしない。内容確認画面へ件数と間隔を表示する。

## ローカル保存設定・自動バックアップ

ローカル手動バックアップのcategoriesが保存対象外だったため、初期OFFを含む対象選択が新規インストールへ戻らなかった。保存対象へ追加し、MEGAの対象/方向/間隔/差分確認もallowlistで保存。クラウド自動実行・削除設定は対象外。

自動バックアップは従来hours/keep/categoriesだけ保存していた。enabled/treeも保存し、新規インストールへ指定状態と保存先候補を戻す。アンインストールで失われるSAF権限をZIPで付与したとは扱わず、ON状態のままアクセス許可待ちと表示し、許可まで自動/手動の書込みを停止。保存先選択へ初期URIを指定、再選択後は保存されたONで再開可能。既存の許可済み保存先は維持。保存先が変わる場合だけ旧所有記録/成功時刻/状態を無効化し、同一保存先のローカル所有記録は保持。別インストールの削除権限/所有記録は移さない。古いZIPにON/保存先がない場合は推測せず維持し、新規環境に限りcategoriesから手動の保存選択を補う。
