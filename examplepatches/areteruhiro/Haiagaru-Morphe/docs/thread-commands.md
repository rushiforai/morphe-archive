# スレ立てコマンド

対応: ChMate 191 dev / 226 dev / 242 dev。

スレ立て画面の本文付近に「コマンド」ボタンを追加。1.8.13から通常の返信画面には表示しません。
投稿先のURLにより5ch・エッヂ・けんも板・おーぷん2chの候補を切り替えます。したらば・AfternoonTea・その他は自由入力と仕様案内です。
候補を選択して編集し、「本文に追加」で先頭に追加します。自動送信はしません。
ワッチョイ候補（IP／レベル付きも含む）の初期値は同じコマンド3行です。投稿時に1行消費される場合の次スレ用に残せます。自由入力を含め改行可能で、4096文字まで入力できます。
編集内容は板・候補ごとに端末内へ保存し、「初期値」で戻せます。以前のサービス単位の編集内容も引き継ぎます。
同じ内容は再度追加できます。異なる設定の同系統コマンドが本文や入力内にあれば編集を案内します。古い1行の初期値を保存していた場合は3行に移行し、独自に編集した内容は保持します。「初期値」で3行に戻すこともできます。

5ch: ワッチョイ / ワッチョイ＋IP（公開に注意）/ ID・SLIP / どんぐりのレベル・表示・大砲設定。名前欄用の `!donguri`・`!point`・`!nosoubi` は本文ではなく名前欄へ追加します。必要レベルなどは追加前に編集してください。
エッヂ: ワッチョイ / ワッチョイ＋レベル / レベル。
けんも板: `!id` / `!noid`、`!slip` / `!noslip`、`!ip` / `!noip`、`!chid`、`!ipid`、`!longid` / `!longslip`、`!nushi` / `!nonushi`、`!piyo` / `!nopiyo`、`!yuruyuri`、`!reauth:秒数`、`!max:最大レス数`、`!notitlechange`。再認証間隔は60秒、最大レス数は1000を編集用初期値とし、追加前に必要な数値へ変更できます。候補はスレ立て本文用です。[公式のコマンド説明](https://kenmo.org/commands)も参照してください。
おーぷん2ch: スレ立ての `!jien`、返信の `!aku{レス番号}`・`!kaijo{レス番号}`。レス番号は追加前に置き換えてください。権限が必要です。事前アク禁の引継ぎはWeb側の次スレ作成フォームの機能で、本文コマンドではありません。
5chの「板設定を取得」では `SETTING.TXT` の関連項目を読み取り専用で表示します。`BBS_USE_VIPQ2` が2以上かを案内しますが、候補や下書きを自動変更しません。設定取得は手動・HTTPSのみです。
「仕様・使い方」でサービス別の参照先や注意点を確認できます。したらば／AfternoonTeaでは未確認のコマンドを初期登録していません。
掲示板の設定・実装によってコマンドが無効な場合があります。
