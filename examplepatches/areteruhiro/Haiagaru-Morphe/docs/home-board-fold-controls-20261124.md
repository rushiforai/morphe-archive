# HOME「スレ（板順）」板名タップ

## 修正内容

- HOMEの描画元として、グローバルに保存された次回用の並びではなく、画面上のListView／RecyclerViewが現在表示している行を使うようにしました。242の差分更新中に古いモデルと新しい画面行が混ざり、開閉マークが別の行へ出たり消えたりする状態を避けます。
- HOMEの再開時点で一覧がまだ作られていない場合に備え、画面レイアウト完了後にも見出しボタンを取り付けます。履歴一覧の再構築後も取り付けを確認します。
- 板名の矢印ボタンを削除しました。「HOMEの★・ラベル・板名見出しをタップして開閉」が有効なとき、板名ラベルのタップで開閉します。上部または︙メニューの切替ボタンから、板名タップの有効・無効を変更できます。
- 191／226のListViewと242のRecyclerViewで、表示中の行を取得して並び替え・開閉対象を決めます。

## 実機確認

Mi Note 10（Android 11、ADB `d5497008`）に署名を照合した隔離版191／226／242を導入し、Fridaで確認しました。

| 版 | 旧仕様での初回ボタン表示 | 旧仕様での表示切替時の行高／見出し高 |
| --- | --- | --- |
| 191 | 冷起動直後に表示 | 88 px／56 pxで一定 |
| 226 | 冷起動直後に表示 | 88 px／56 pxで一定 |
| 242 | 冷起動直後に表示 | 90 px／56 pxで一定 |

この測定は板名タップへ変更する前の候補で行いました。各版で「表示／非表示」を5回切り替えても、行高・見出し高・幅・最小高さは変化しませんでした。191での修正前は、ボタン表示時に見出しが56 pxから110 px、行が88 pxから142 pxへ拡大していました。

旧仕様のローカル候補MPPのSHA-256は `dcbbcbb4a5de481f15156b0cc90e08900eb7eecc57373e0d9e5fc08fd73ff91e` です。APKごとのSHA-256と署名照合結果は [android-installations.md](android-installations.md) に記録しています。
