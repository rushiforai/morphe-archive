# 外部板の名前・URL編集

ChMate標準の「設定 → 掲示板／BBSMENU → 登録した外部板の名前・URLを編集」から、追加済み外部板を選択します。対応は191 dev・226 dev・242 devです。エッヂ（`https://bbs.eddibb.cc/liveedge`）はHaiagaruの標準サイトとして「掲示板 → 掲示板設定」から使用を有効にして追加できます。サイトを無効にすると標準の板一覧へ加えません。サイトの使用切替はHaiagaru設定 → 更新履歴でも行えます。

画面上部の「板名・URLで検索」へ入力すると一覧を部分一致で絞り込めます。英字は大文字・小文字を区別しません。URLを変更済みの板は、現在設定しているURLで検索します。入力を空にすると全件へ戻ります。「BBSMENUの板も表示」と併用できます。検索のための通信や登録内容の変更は行いません。

追加済みの板が見つからない場合は「BBSMENUの板も表示」をオンにしてください。ChMateの登録経路によっては外部板フラグが付かないため、フラグ0の外部ホストも表示対象にしています。BBSMENU由来の板も含めた一覧から編集できます。

- 板名と板のベースURLを変更できます。スレURL・認証情報付きURL・重複する接続先は登録できません。
- 同じ板の改名・移転に使う機能です。別の板への付け替えには使わないでください。掲示板の通信方式が変わる移転は別途板を追加してください。
- 保存後にChMateを終了・再起動してください。再起動までは読み込み中の接続先は変更しません。
- ネイティブの板ID、ブックマーク、NGの板指定、ログ保存ディレクトリは変更しません。移転先URLから生成される板IDも元の識別子に対応付けます。
- 元の板URLも保持し、そこから作られる通信先を移転先へ補正します。板名はChMateのboardsテーブルへ保存します。BBSMENU由来の板名は板一覧再取得で戻ることがあります。
- 認証設定は接続先ごとです。別ホストのCookie・認証情報はコピーしません。移転先で必要なら再認証してください。
- 本機能がないChMateへバックアップを移すと、URL補正は使えません。元の板IDとログは残ります。

編集画面は非公開Activityへの明示Intentで起動します。パッケージ名変更パッチ利用時も同一アプリ内で開きます。

## 検証

- URL入力ルール19項目。
- 191／226／242のAPK生成と、ネイティブ掲示板設定内の項目・明示Intentのパッケージ名・Activity登録を検査。
- エミュレータ上のネイティブモデルで191: 30項目、226: 32項目、242: 30項目。元URL／移転先URLの同一ID化、ハッシュ・Parcel、読み書き用URL、DAT・スレURL、無関係な板を変更しないこと、再起動までルートを固定することを確認。
- 191の標準設定から実際に編集画面を開き、入力検証・板名／URL保存・再起動後の反映・既存ブックマークのID維持を確認。
- 242のCompose版「掲示板・BBSMENU」でも、項目表示とタップによる編集画面の起動を確認。
- 移転検証には架空の `.invalid` ホストを使用。実際の外部サイトへの投稿・認証は実施していません。
- 外部板フラグ0の取りこぼし修正（未公開）：URL・登録分類25項目と、226のAndroid実行環境の一時DBで一覧・URL復元・板名保存・ID不一致の拒否・板ID／フラグ保持の7項目を確認。実際の登録板DBは変更していません。
