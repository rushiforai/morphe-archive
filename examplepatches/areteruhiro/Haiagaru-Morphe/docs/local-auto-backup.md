# ローカル自動バックアップ

Haiagaru設定 → バックアップ・機種変更 → ローカルバックアップ・復元（MEGA導入時は「バックアップ・復元」）→ ローカル自動バックアップから設定します。191／226／242で共通です。MEGAは不要です。

1. 端末内の保存先フォルダを選びます。フォルダ選択後は端末の戻る操作で設定に戻れます。
2. 実行間隔（1〜8760時間）、保持件数（1〜100）、保存する項目を選びます。
3. 自動バックアップをオンにします。初期状態はオフ、間隔24時間、保持3件です。

ChMateを開いたとき（バックグラウンドから戻ったときも含む）と、画面を開いている間は約1分ごとに確認し、前回成功から指定間隔を過ぎていれば別スレッドで保存します。初回は次の確認時に実行します。「今すぐバックアップ」から手動実行もできます。バックグラウンド・終了中は新しい自動バックアップを開始しません。すでに開始した保存は続行しますが、Androidにプロセスを終了されると中断される場合があります。失敗が続く場合の再試行は最低5分間隔です。確認時刻はAndroidの動作状況によって遅れる場合があります。

端末名・端末の現在時刻入りのZIPを作ります。復元には既存の「端末のバックアップファイルから復元」を使います。保存先はAndroidのフォルダ選択画面で許可した場所です。ローカル保存には端末内フォルダを指定してください（クラウドプロバイダーを選ぶとそのサービスに送信されます）。

保持件数を超えた分は、新しいZIPの保存成功後、この機能が同じ保存先に作成し記録した古いZIPだけを完全削除します。ゴミ箱には入りません。保存先を変えた場合、以前のフォルダのファイルは残します。権限が失われた場合は失敗として記録し、既存バックアップは削除しません。前回成功日時・実行結果は設定を開き直すと確認できます。

ZIPは暗号化されません。Cookie・認証セッション・端末依存の暗号化済みデータ・アップロード削除用情報は初期オフです。必要な場合だけ選び、共有や保管場所に注意してください。Android Keystoreの秘密鍵は移せず、別端末では再ログインが必要なことがあります。大量のDATやアーカイブは時間・空き容量を使います。端末故障時には端末内のバックアップも失うため、重要なものは別の場所にも保管してください。

## 1.9.3: 保存先と復元項目の反映

- フォルダ選択後、開いている設定画面の保存先を更新します。設定を閉じて開き直す必要はありません。
- パーセントエンコードされたcontent URIの代わりに、デコード済みのフォルダIDを表示します。端末内の保存先は「内部ストレージ/…」で表示し、日本語・空白・プラス記号・文字としてのパーセント表記を保持します。アクセス用URI自体は変更しません。
- 保存先設定を同期保存してから完了表示を出します。同じフォルダを選び直した場合は、保存済みZIPの管理記録・前回成功日時を保持します。
- 「端末のバックアップファイルから復元」は、選んだバックアップ内の保存項目を初期選択します。現在の端末の保存項目設定には左右されません。「内容・注意事項」から戻った場合も、変更したチェックを保持します。
- 復元の確認と機密情報の追加確認は従来どおりです。バックアップ内容の自動復元は行いません。

実際のフォルダ選択・保存・復元を通した端末上の再検証は、今回は未実施です。

## 保持件数と設定保存の改善（未公開）

- 保持件数は、同じ保存先についてこのアプリが作成・記録した自動バックアップが対象です。手動保存や別アプリが作ったZIP、管理記録を失ったZIPを名前だけで判定して削除しません。フォルダ内のZIP総数とは一致しない場合があります。
- 新しいバックアップの保存後、重複・削除済みの管理記録を整理し、古いものから削除します。同じURIを複数回記録していた場合は最新側として扱い、新しいバックアップを保護します。
- 削除失敗や所有を確認できないファイルがある場合は、結果欄に警告を表示します。保存自体の成功と古い世代の整理成功を区別し、確認できないファイルを強制削除しません。
- 同じフォルダを異なるURI表記で選び直した場合も、管理記録と前回成功日時を保持します。違うフォルダへ変更した場合は従来どおり以前のフォルダを削除しません。
- 自動バックアップのオン／オフは同期保存し、保存できなかった場合はエラーを表示します。保存先を推測して自動でオンへ戻す動作は行いません。

1.12.1の191に対する「上書き後に保存先が未選択・自動設定がオフ」という報告は、上記の改善だけで解消したとは確認できていません。保存先・権限・アプリのデータがすべての環境で保持されると保証するものではありません。

## 一括設定から独立して保持（未公開）

「最低限構成」および「広告だけの設定プリセット」は、ローカル自動バックアップのON/OFF・保存先・実行間隔・保持数・保存対象を変更しません。過去のプリセット退避情報に自動バックアップ設定が含まれていても、プリセットの復元時は現在の値を維持します。バックアップのON/OFFは、この画面で明示的に切り替えます。

以前のプリセットなどで既にOFFになった設定を推測でONにする動作はありません。必要に応じて保存先を確認してからONにしてください。アプリデータの削除や別パッケージへの新規インストールまで設定を保持するものではありません。

## 保存先によって保持件数が反映されない問題の修正（未公開）

保存先が返すファイルURIにフォルダ情報が含まれない場合も、選択したフォルダの直接の子一覧とファイルIDを照合して古い世代を整理します。削除時は選択フォルダのアクセス権付きURIを組み直します。同じファイルの異なるURI表記も一つの記録にまとめ、最新世代を誤って削除しないようにします。

保持件数の整理は次のバックアップ保存成功後です。管理記録を失った過去のZIP・別フォルダ・手動保存は自動削除しません。削除に失敗した場合は結果欄に警告を出します。


## 書き込みマークと設定の保存補完（未公開）

書き込み履歴の保存に、取得済みスレの索引（dat配下の.idx）も含めます。DAT本文を選ばなくても、索引内の自分の書き込みマークなどを保存・復元できます。DAT本文を選択しない復元では本文を上書きしません。既存のマークが保存されていない古いバックアップからは、この変更だけで欠落した情報を復元できません。

設定の保存対象に、自動バックアップの実行間隔・保持件数・保存対象の選択を追加します。復元先の保存フォルダ・ON/OFF・前回成功時刻・作成済みファイルの管理記録は維持します。Androidの保存先アクセス許可や、別のインストールが作成したバックアップの削除権限を移すものではありません。
