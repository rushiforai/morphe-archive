# Webサイトのリンクカード（開発版）

Haiagaru設定 → **スレを読む → リンクカード・Xのプレビュー**にある「Webサイトのリンクカードを表示」をオンにします。初期値はオフです。設定検索からもオン／オフできます。X投稿プレビューの設定とは独立しています。

## 表示できるサイト

Yahooニュース専用ではなく、Webページ共通の情報を順に利用します。

| 表示内容 | 優先する情報 |
|---|---|
| 見出し | `og:title` → `twitter:title` → HTMLの`title` |
| 説明 | `og:description` → `twitter:description` → HTMLの`description` |
| サムネイル | `og:image:secure_url`／`og:image` → `twitter:image`等 |
| サイト名 | `og:site_name`と元URLのドメイン |

これらの情報を配信するニュース・ブログ等は、サイトごとの登録や追加パッチなしで表示できます。相対画像URLはページURLを基準に解決します。見出しだけのページもカードにできます。

添付例の `https://news.yahoo.co.jp/pickup/6599370` は、ページ内に見出し・説明・サイト名・画像のOpen Graph情報を持つことを取得HTMLから確認しました。

## 操作と通信

- 1レス最大2つの異なるURLをカードにし、元の本文・リンクも残します。カードをタップすると元URLを開きます。
- 「サイトカードにサムネイルを表示」をオフにすると文字だけになります。
- 画面のレス幅に合わせてカード幅を調整し、見出し・説明は各2行まで表示します。本文の文字サイズと明暗に合わせます。
- メタ情報の取得は表示するレスに対して行います。JavaScriptの実行やログインCookieの送信は行いません。
- X／Twitterは既存のXプレビューを使います。YouTube、本体対象の5ch URL、画像・動画・PDF等への直接リンクは汎用カードの対象から除きます。
- HTMLの取得上限は512KiB、画像は2MiB。リダイレクトは3回まで。非公開ネットワークのアドレスへの自動取得は行いません。
- 同時取得は2件、待機32件。取得できなければ元リンクを維持し、5分間は同じ失敗を繰り返し取得しません。
- メタ情報は24時間・最大128件をアプリのキャッシュへ保存します。画像は最大8MiBのメモリキャッシュを使います。キャッシュ削除ボタンも用意しています。表示中のカードは削除後に再取得する場合があります。

## 取得できない場合

ログイン必須、JavaScriptでしかメタ情報を作らないページ、アクセス制限、画像が大きすぎる場合などは、画像やカードを表示できないことがあります。画像だけの取得失敗なら見出しと説明を表示します。すべてのサイトの表示を保証する機能ではありません。

サイト独自の処理を増やすより、共通メタ情報を優先する構成です。将来、共通情報を配信しない特定サイトへの対応が必要になった場合も、メタ情報取得側を追加し、カード描画・キャッシュ・レスへの組み込みを共用できます。
