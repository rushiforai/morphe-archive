# 保存画像・動画の一覧管理

「アプリ・通信」の基本設定側に容量確認／保存画像・動画一覧のボタンを追加。画像・動画一覧は非公開の専用Activity。検索はローカルのファイル名・保存パス、種類のチェックで画像／動画を切替。全選択は現在の検索と種類の絞り込み結果だけが対象。個別チェックと確認付き一括削除。削除はStorageUsageの既存キャッシュ許可範囲に限定し、設定・メモ・DATは対象外。

拡張子が数字だけのChMateキャッシュにも対応するため、ファイル先頭32バイトからJPEG/PNG/GIF/WebP/MP4/WebM等を判定。サムネイルはローカルのみ、単一ワーカー・待ち40件・メモリ約6MiB。Android8(API26)は通常フレームから縮小、API27以降は縮小フレーム取得。画像タップは拡大、動画タップはアプリ内VideoView再生。ネットワークURLは渡さない。GIF拡大は静止画表示。走査10万項目・表示1万件が上限。公開URLとファイル名の対応表がないキャッシュはURL検索できない。

通信量は別機能で初期OFF、今日・今月・日別に93日、Wi-Fi／モバイル合算。Fridaは191／226／242各10条件成功。

## 日付・容量・名前の並び順と配色

容量大→小／小→大、日付新→古／古→新、名前昇順／降順の6種類を追加。日付はファイル更新日時。選択はファイルの正規パスで保持し、並び替えによる取り違えを防ぐ。並び順を専用Activity設定へ保存。HaiagaruUi.toolTabHeaderColorsの共通テーマ配色・文字色、余白、角丸枠の操作ボタン、戻る見出しを使用。先行版の実機一覧操作8項目が成功（477件検出、検索・選択・種類・サムネイル設定、実ファイル削除なし）。

一覧右端のAndroid標準fast scrollつまみを常時表示し、ドラッグ移動を有効化。検索・種類・並び替え後のリストに追従。
