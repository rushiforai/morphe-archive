# 外部板の板一覧表示

191／226／242の「外部板をサイト別に板一覧の最上位へ表示」は初期OFFです。Haiagaru設定の「アプリ・通信」または「更新履歴」からONにすると、標準のサイト分類に一致しない外部板をサイト別の項目として最上位に表示します。OFFでは従来どおり「その他」に表示します。板一覧のキャッシュへ反映するため、変更後はChMateを再起動してください。エッヂ、オルグ板、したらばは名称で、それ以外はホスト名で分類します。標準分類のある5chなどはそのままです。エッヂ・オルグ板は爆サイ・ふたば・あにまんと同じ標準providerで分類するため、この任意スイッチがOFFでもサイト名の項目になります。内部板IDのHTTP表記と取得URLのHTTPS表記の両方を認識します。各サイトの中は通常のChMateのカテゴリ表示・板表示を使用します。

エッヂ（`https://bbs.eddibb.cc/liveedge`）、オルグ板（`https://kenmo.org/bbsmenu.html`）、爆サイ、ふたば、あにまんは、Haiagaru設定 → アプリ・通信と更新履歴の両方から個別に使用を切り替えられます。5サイトとも初期ONです。無効なサイトはChMate標準の掲示板設定・追加メニューのprovider一覧および板一覧へ追加しません。再度有効にすると標準の掲示板設定から追加できます。登録済みの板データはこの切替で削除しません。エッヂとオルグ板は公開BBSMENU／2ch互換のsubject・DATを直接利用し、爆サイ・ふたば・あにまんは外部板ゲートウェイを利用します。

板ページをBBSMENUのURLに登録した場合は、本文中のスレリンクを多数の板として取り込まず、その板を1件として扱います。HTMLのscript・style・コメントはネイティブのBBSMENUパーサへ渡す前に除去します。JSON形式の板一覧はこのHTML処理を通しません。板URLから1件を取り込む場合だけ、標準の2件以上という検証条件を緩和します。0件や通常のメニューURLの検証は維持します。

既存の不正なJavaScriptカテゴリは表示用データで取り除き、該当カテゴリしかない場合はサイト名を使用します。この破損があるエッヂのliveedge板の表示名は「エッヂ」に戻します。板ID、保存済み本文、お気に入り、閲覧履歴、NG条件を変更しません。表示用の補正で保存レコードは書き換えず、板一覧を再取得した場合は標準の取り込み処理が正しい板名・カテゴリを更新します。

エッヂのカテゴリ見出しと板リンクは別の行として標準パーサーへ渡します。過去に空・無題で取り込まれたエッヂのカテゴリも「エッヂ」に補正します。新版適用後はChMateを再起動し、掲示板設定→エッヂ→「板一覧を取得/更新」を再実行してください。

調査に用いた実機は191、画面「板一覧 > その他」で `gtag(...)`、`});`、`return text.toLowerCase()...` がカテゴリ名となっていました。実機の読み取りコピーで、bbsMenuUrlがエッヂの板ページ、liveedgeのtitleがスレタイトル、categoryがJavaScriptの重複であることを確認しました。実機のデータ書き換えは行っていません。

パッチ処理は各版の固定BBSMenuUpdateWorkと固定グループ生成クラスだけに接続し、全クラス走査を追加しません。検証結果はintegration-status.mdとandroid-installations.mdに記録します。
