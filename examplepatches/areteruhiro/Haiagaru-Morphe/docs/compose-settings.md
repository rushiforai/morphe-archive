# Compose版の設定・投稿検索画面

Composeへの移行は[1.10.0-dev.1](https://github.com/areteruhiro/Haiagaru-Morphe/releases/tag/1.10.0-dev.1)からの変更です。このページのカテゴリ名は現行ソースに合わせています。公開版の差分は[最新リリース](https://github.com/areteruhiro/Haiagaru-Morphe/releases/latest)で確認してください。

## 設定を探す

Haiagaru設定を、使いたいことから選べる9カテゴリに整理しました。

| カテゴリ | 内容 |
| --- | --- |
| スレッド | 文字・一覧、並び方、コピー操作、Xプレビュー |
| 探す・過去ログ | IDチェッカー、DAT取得、保存レス |
| 書き込む | 入力、送信、スレ立てコマンド、画像・動画の投稿 |
| 画像・動画 | 閲覧、再生、サムネイル、自動保存、キャッシュ |
| NG・ミュート | NG編集、高度なNG、コピペ・荒らし省略 |
| 履歴・コピーした記事 | 閲覧・書き込み履歴、保存件数、コピー履歴 |
| バックアップ・機種変更 | ローカル保存・復元、MEGA同期、移行 |
| アプリ・通信 | 言語、広告、接続、外部板認証 |
| エキスパート設定 | 個別の動作・互換設定の細かな切り替え |

カテゴリと各設定項目はComposeで表示します。検索は項目名から設定を直接操作でき、入力済みの認証情報や編集欄の値は検索対象にしません。変更は自動保存、再起動が必要な変更は確認を表示します。

設定を検索した結果のスイッチ、またはその項目の行をタップすると、その場でオン／オフを変更できます。カテゴリを開き直す必要はありません。保存後のチェック状態と、連動する項目の有効／無効を検索結果へ反映します。切り替え時は検索語と結果の行を保持し、検索語が変わらない場合は入力待ちの200msを挟みません。ツールバー表示や投稿検索の専用画面へ移した設定は、この検索へ重複追加しません。

Material 3 Expressiveのテーマ・モーション、丸みのあるグループ、Materialのスイッチ・入力欄を使用します。端末の明暗とAndroid 12以降のダイナミックカラーに対応します。文字サイズが大きい場合も項目や検索先を折り返します。カテゴリ内のヘッダーはコンパクトにし、設定項目を広く表示します。

戻る操作でカテゴリから一覧へ戻れます。ChMateの設定済みジェスチャーによる戻る・閉じる・先頭／末尾への移動も接続しています。

## ツールバーとの役割分担

「探す・過去ログ」の「ワッチョイ長押しに『ワッチョイ検索』を表示」から、長押しメニューの「ﾜｯﾁｮｲで検索」をオン／オフできます。設定検索からも操作できます。このスイッチを変更した場合、その項目の表示についてChMate側のチェックより優先します。長押しメニューを開き直すと反映します。上4桁・下4桁検索など他の項目には影響しません。

DAT自動取得経路の書式・変数・部分取り出しの説明は、経路入力欄の外に全文表示します。入力欄は6行以上で表示し、長い設定も縦に編集できます。説明文も選択してコピーできます。

エッヂ過去ログを開くボタン、長押しコピーのオン／オフ、ワッチョイ検索やツールバーの表示スイッチを、本体設定に重複して置きません。HOME・板・スレそれぞれのChMate標準ツールバー設定で表示と順序を変更します。

旧Haiagaru全体表示スイッチやレスメニューの強制表示指定は表示判定に使いません。標準のチェック状態は上書きせず、既存の順序を保持します。アイコン画像のカスタマイズは「スレッド」に残し、表示チェックは分離しました。

## 投稿を探す

1. 検索画面の「投稿検索を利用する」でオン／オフを変更します。オフでも画面を開け、再びオンにできます。
2. Hissi／エッヂ／ZZZSearchを選びます。その検索先で使う条件だけを表示します。
3. Hissiは板・日付とワッチョイ、エッヂは投稿ID／ワッチョイ上側／下側・スレ名・レス本文を指定します。エッヂではスレ名だけ、本文だけでも検索できます。
4. エッヂでは過去ログ・現行スレを選べます。走査・通信上限は詳細欄で調整します。
5. 開始・停止・続きから再開の操作は画面下に置きます。結果はスクロールしながら開けます。長い本文は全文表示へ切り替えられます。

Hissiで開始した検索をキーワードの有無で自動的にZZZSearchへ切り替えません。ZZZSearchは検索先として明示して選びます。Hissiの板一覧も、板の選択を開いたときに取得します。全板検索の条件を復元する場合は、復元した条件を使えるよう板一覧を取得します。

右上の「検索の設定」にバックグラウンド検索、履歴保存、検索先の表示、履歴・キャッシュの保持上限と削除を集約しました。日付選択・保持上限・削除確認もComposeで表示します。通知から戻ったときは、入力条件に加え検索先も復元します。条件の復元だけでは検索を開始しません。

## 引き継ぐもの

設定キー、保存先URI、バックアップ、検索履歴・結果、キャッシュ、通知・検索サービス、通信回数と再開位置の処理は維持します。データ消去や設定初期化は不要です。検索をオフにしても保存データは削除しません。

専門的な機能の詳細ダイアログ、バックアップ・NG編集・専用ビューア等の各画面は、それぞれ既存の実装を使用します。

## 実装メモ

- Kotlin Compose Compiler 2.3.21、Compose 1.8.3、Material 3 1.4.0-alpha18。Expressiveの公開APIを使い、既存のminSdk 21を維持します。
- 設定の既存リスナー・検証・再起動処理をデータの書き込み元として利用します。表示にAndroidViewは使用しません。
- UIリソースはChMateの0x7fと競合しない0x7dの専用テーブルとして、整列したリソース専用APKを配布物へ同梱します。API 30以降はResourcesLoader、それ以前は独立したAssetManagerを使います。
- AndroidXのApache 2.0ライセンスとNOTICEをMPPとパッチ後APKに含めます。
- バージョン・JSON・CHANGELOG・公式ReleaseはSemantic Release CIの生成対象のため、今回のローカル作業では更新しません。
