# 非表示NG未読補正：スレ再計算時の追加軽量化

## 対象と変更

「非表示NGのレスを未読件数に含めない」の前回修正後も開閉時に少し遅延するとの報告。

- レスごとの設定確認は、SharedPreferencesインスタンスを再利用する。boolean自体は毎回読むためUI・設定共有による切替は即時に反映し、判定を固定しない。
- 191/226の再計算開始と242のDAT関連付けで、全HOME行のキーキャッシュを破棄しない。既存の板・スレID・明示Intent URLによる再利用検証と、設定変更時のclearを維持する。
- 242のNGマップと取得レスの積集合は、RandomAccessリストでレスnが位置n-1に実在することを確認できれば、そのNG候補だけを調べる。欠番・並び替え・LinkedList・範囲外候補は厳密な走査へ戻す。元のNGマップ・レスリスト・既読位置・DBは書き換えない。
