# Haiagaru設定の使い方（Compose版）

ChMate標準の設定一覧で「セーフモード」の直前にある「Haiagaru設定」をタップします。旧版の浮動ボタンは設定画面内の入口へ置き換わります。開いた画面から、変えたいことを選びます。

- スレッド：文字・一覧・コピー・Xプレビュー。
- 探す・過去ログ：IDチェッカー・DAT取得・保存レス。
- 書き込む：入力・送信・画像や動画の投稿。
- 画像・動画：再生・サムネイル・保存。
- NG・ミュート、履歴、バックアップ、アプリ・通信はそれぞれ独立しています。

カテゴリの中では関連項目をまとめて表示します。トップでは全カテゴリ、カテゴリを開いた状態ではそのカテゴリ内を検索します。折りたたまれた設定も対象で、検索結果から直接操作できます。検索中の戻る操作はまず検索語を消し、その次にカテゴリからトップへ戻ります。設定名は長押しでテキスト選択でき、右上の「階層をコピー」でカテゴリ全体の設定名と階層をコピーできます。入力値やAPIキーはコピーしません。変更は自動保存し、必要な場合だけ再起動を確認します。戻る操作ではカテゴリから一覧へ戻ります。ChMateの戻る・閉じる・先頭／末尾ジェスチャーも利用します。

ツールバーの表示・配置はChMate標準のツールバー設定、投稿検索のオン／オフや履歴保存は検索画面で変更します。本体設定には同じ入口・表示スイッチを重ねません。

[設定カテゴリの詳細・確認範囲](compose-settings.md) ／ [機能ごとの設定場所](feature-switches.md)

「最低限構成を選び直す」では「おすすめプリセット」か「広告削除だけのプリセット」を選べます。両プリセットとも「5ch.netのリンクを5ch.ioに変換」を有効にします。おすすめは広告削除のほか、記者ID、過去ログ取得・検索、専用ビューアー、URLサムネイルなどを有効にします。広告削除だけを選ぶと、URL変換以外のプリセット対象の追加機能、URL動画・GIFの自動取得、Haiagaruの追加ツールバーボタンをまとめてオフにします。「アプリ・通信」の広告だけのプリセットも同じ設定を適用し、同じ場所から適用前の設定へ戻せます。

この案内は現行のCompose設定画面に対応します。過去版の画面とは項目名や配置が異なる場合があります。


Haiagaru更新履歴の「機能の設定」から、全板検索、画像の自動検出・常時モザイク、専用ビューアーの戻る操作、添付時のアップロード先選択、NG返信通知を切り替えられます。通常設定と同じ値を保存します。自動検出のスイッチは画像検出ZIPをパッチで導入した場合に使えます。


HOMEの︙と「Haiagaru設定 → スレッド → キーワードの表示名を設定」から、登録済みのキーワードに短い名前を付けられます。名前には「|」「,」「"」も使えます。検索条件の文字列はそのまま保持し、空欄か「元の表示に戻す」で解除します。

スレタイトル長押しの「スレの名前を変更」は、「スレッド → スレタイトル長押しの追加項目」で表示を切り替えられます。HOMEとスレ一覧で使うローカルの表示名です。キーワード・スレの表示名はローカル／MEGAバックアップの「設定」に含まれます。

表示名を変更したあとは一覧を更新すると反映されます。
