# 表示崩れ・お気に入りが見えない場合

お気に入りが空に見えても、表示条件の変化と登録データの消失は区別して確認してください。確認するまではアプリのデータ削除・アンインストールを避けてください。

「Haiagaru設定 → アプリ・通信 → 基本設定・言語 → 表示崩れ・お気に入りが見えない場合の診断」で、保存済みスレ・板情報と、お気に入りの件数を読み取ります。通常のファイル管理アプリでは見られないアプリ内部の `/data/user/0/<パッケージ名>/databases/roidon.sqlite` が対象です。`bookmarks` がスレ、`boards` が板で、`flag` に★の登録情報があります。件数だけでは消失の原因は確定できません。

「スマホ表示に戻す」はタブレット表示・自動折りたたみをオフにし、HOMEのお気に入り除外条件を解除します。DB・お気に入り・履歴・並び順は変更しません。「前の表示設定に戻す」で操作前の値へ戻せます。これは削除済みデータを復元する操作ではありません。

以前に保存したバックアップがある場合は、既存の「バックアップ・機種変更」からローカルまたはMEGAの復元機能を使ってください。削除済みデータをスキャンして救出する機能は追加していません。

初めてHaiagaru設定を開くと、自動定期バックアップを案内します。「ローカル」はフォルダ・間隔・対象を指定する自動バックアップ設定、「MEGA」は追加パッチがある場合にクラウド設定を開きます。「あとで」で閉じられます。案内から保存先を選ぶだけでは自動バックアップは有効になりません。どちらの自動処理もアプリを開いている間に間隔を確認する方式です。

2026-11-15のSM-S721Q / Haiagaru 1.25.0の報告は、別の利用者の端末です。端末DB・ログ・バックアップの現物は未確認です。確認したX・フィルター設定の処理にお気に入り削除処理は見つかりませんでしたが、原因・復旧可否は確定していません。
