# 読書位置補助保存とタブレット操作

「更新・画面切替時の読書位置を補助保存する」を有効にした場合の処理を軽くする修正。

- AtomicFileの書き込み・同期を、メインスレッドから順序を保つ単一の背景処理へ移動。
- 保存直後に別画面から同じスレへ戻った場合も最新位置を参照できるよう、直近128スレの保存内容をメモリで保持。
- 復元確認が済んだセッションは、スレ変更確認を250ms間隔から1秒間隔へ。復元中は従来の短い間隔を維持。
- スクロール中・非表示のペインでは定常時の位置調査を省略。スクロール停止後の保存と画面切替時の保存は維持。
- アダプターが変わるまで行取得メソッドを再利用。スレ情報は毎回そのセッションの本体モデルから解決し、別スレのキャッシュを流用しない。

191の隔離エミュレータで実ListView・ネイティブレスモデルを使った試験を実施。定常時500回の描画コールバックでアダプター調査1回、スクロール中100回・非表示50回では調査なし。連続保存後に最新位置がメモリ・ファイルの両方へ残り、2回のAtomicFile書き込みがいずれも背景スレッドで行われることを確認。

これは処理経路の確認であり、報告端末の実スクロールFPSの改善測定ではない。設定ONでの実機再確認は未実施。本文・DAT・ChMate標準の位置保存は変更しない。未公開。

再現用の試験は `scripts/reading-position-trip-runtime.js`。隔離bindings191だけで動作し、作成した位置ファイル・一時ビューを除去し、強調設定も元へ戻す。
