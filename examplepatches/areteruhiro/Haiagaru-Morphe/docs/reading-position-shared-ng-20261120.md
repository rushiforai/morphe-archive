# 2026-11-20 既読位置と共有NG

## 変更

- 既読スレを開いた直後、表示中の「ここまで読んだ」行を上端へそろえます。リンクカード・画像の非同期更新では、見えているレスと画面内オフセットを保ちます。ユーザーのスクロール、レス移動、フィルター操作を優先します。
- 共有NGを有効にする初回確認ダイアログをなくしました。共有NGの受信設定と、個人NGを審査用に送る同意を分離しています。個人NGの送信は専用設定での明示同意が必要です。
- 個人NGを送信する前にChMateの最新板一覧を読み、保存済みNGの対象板を再解決します。以前「その他」扱いだった条件も、板を特定できれば板別条件へ更新します。板一覧を読めない場合は既存の送信待ち・スナップショットを保持して再試行します。板が特定できない条件は共有側から削除し、全板NGへ広げません。端末内のNG一覧は変更しません。この同期処理は個人NG送信に同意した場合だけ行います。
- 共有NGの一致レス表示を設定可能にしました。「共有NGの一致レスを『あぼーん』で表示」は初期ONで、通常の「あぼーん」行を表示します。OFFでは透明あぼーんです。変更後にスレを開き直すと反映されます。

## 動作確認

- 191／226／242の隔離reporter APKをMi Note 10（Android 11）へ署名を照合して導入。通常のChMateアプリは変更していません。
- Frida 17.18.0で各版の合成位置テスト10項目を確認し、native `ListView` への既読境界整列要求を観測しました。実サイトの非同期リンクカード表示を使った目視確認は行っていません。
- 191／226／242で、共有NG表示設定の未保存値が通常「あぼーん」表示になること、OFFで透明あぼーんになること、ONで戻ることを確認しました。ネットワーク要求はテスト中遮断しました。
- 191では共有NG初回設定UIを確認し、初回同意ダイアログが出ないこと、受信設定だけでは個人NG送信に同意されないことも確認しました。板一覧の再取得・板別再解決・未解決条件の削除判定は191／226で確認しました。242はFrida実行中にFirebase CrashlyticsのバックグラウンドスレッドでSIGBUSが発生し、板カタログ確認を完了できませんでした。242の共有NG表示切替確認と既読位置テストは完了しています。
- いずれのテストでも実際の個人NG送信、配信NGへの投票、端末内NG一覧の書換えは行っていません。
