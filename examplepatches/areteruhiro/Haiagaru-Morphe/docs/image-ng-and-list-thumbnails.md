# 画像判定とスレ一覧サムネイル

「画像・動画」では、ChMate標準の「画像は常にモザイク」にモノクロを追加できます。モザイクの強度も変更できます。

「Image NGの検出とサムネイル表示」は「画像・動画 → セーフティ」へ、「スレ一覧画像表示」の関連設定は「スレッド → スレ一覧・HOME・履歴の表示」へ移動しました。設定トップの検索やカテゴリ内検索でも探せます。

成人向け画像とグロ画像の追加判定はそれぞれオン／オフでき、任意の追加モデルとONNX Runtimeを使用します。Android 7以降が対象です。モデルとライブラリをまとめたZIP、または個別の2つのZIPをMorpheで指定してください。[追加ファイル](optional-assets.md)

判定は端末内のサムネイルに対して行います。画像を外部の判定サービスへ送りません。追加判定をスレ一覧画像にも適用するか選べます。ChMate標準のImage NGによる登録画像の照合も一覧画像へ適用でき、一致した場合は「画像のみ非表示」「スレを非表示」「画像にモザイク」「そのまま表示」から選びます。

スレ一覧画像の「画像取得・表示の対象」は初期状態で折りたたまれています。中に、サイトごとの取得レート制限と、画像を表示しない板の選択をまとめています。設定値は従来のまま引き継ぎます。

191の元のTensorFlow Lite JNIでクラッシュする実機ログを確認したため、修正ライブラリがない場合は標準Image NGの推論を保護停止します。`haiagaru-image-ng.zip` を選択して修正するか、191用修正を含む一括画像判定ZIPを指定してください。個別のモデル・Runtime ZIPには191用標準Image NG修正を含めないため、必要なら旧修正ZIPも指定します。追加モデルの判定とは独立しています。

生成画像によるモデル実行、加工、登録画像の照合、行の再利用時の表示復元を確認しています。実写・イラストの正例を使った分類精度の評価、動画全体の判定は実施していません。誤検出・見逃しがあり、危険な画像を完全に防ぐ保証はありません。


ふたばのスレ一覧用画像は、元の画像に対応するサイト提供のサムネイルがある場合、その小さい画像を取得します。3MBを超える元画像でも一覧に表示でき、画像を開く際のURLは元画像を使います。img・may以外のふたば板にも適用します。本文内に書かれたHTTP画像URLはHTTPSへ変換して抽出し、5chなどでも1レス目の本文内URLを画像候補に含めます。
