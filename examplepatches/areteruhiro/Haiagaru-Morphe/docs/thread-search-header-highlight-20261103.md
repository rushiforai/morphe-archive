# スレ内検索で日時・曜日を強調しない

実機191で検索語「03」に対し、ヘッダーの`11/03(火)`が黄色く強調される状態を確認。絞り込み用の検索文は既に日時を除いていたが、ChMate本体の一致箇所を色付けする処理が表示文字列全体を対象にしていた。

191／226／242それぞれのネイティブ色付け処理のMatcher.reset／find呼び出しを置換し、ヘッダーの日時範囲と重なる一致を飛ばす。検索式・元テキスト・日時の表示・本文中の一致は維持する。本文の引用日付を消す処理は追加しない。IDの色付けも維持する。

233項目の単体試験成功。各版の実ネイティブ色付け処理で15項目を確認する試験を追加し、本文の「火」「03」は色付き、ヘッダーの「火」「03」「11/03」「09:34」は色が付かないこと、正規表現、IDの色付け、表示文字列不変を確認。追加フックは2呼び出しの置換だけで、元命令・レジスター数・分岐は維持する。

実機に入っていたAPKも読み取り専用で照合し、絞り込み用ThreadSearchText.resetは既に接続されていたことを確認。報告端末への修正版導入・再確認は未実施。未公開。
