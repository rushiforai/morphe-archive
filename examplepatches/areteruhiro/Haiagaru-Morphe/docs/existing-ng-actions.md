# 登録済みNGの操作

> 2026-11-05更新（未公開）: 利用者の要望により、以下の追加ダイアログとその呼び出しを廃止しました。標準NG画面は通常の編集画面を直接表示します。ワッチョイ追加画面の操作ボタンも削除し、重複時は入力欄へ案内を表示します。NGルール自体の削除・変更は行いません。以下は過去版の実装・検証記録です。

ChMate 191／226／242の標準NG編集画面で、登録済み条件を開くと「NGを削除する」「有効にする」「無効にする」「登録画面に戻る」を選べます。新規条件の場合は通常の登録画面を開きます。

Haiagaruのワッチョイ上4桁・下4桁の追加画面では、同じ文字列・対象板・一致方式の条件があると、対象板のすぐ下に「登録済みNGの操作（削除・有効／無効）」を表示します。入力文字列・一致方式・対象板を変更すると対象を再判定し、保存時に重複を検出した場合も同じ操作を選べます。既存の正規表現への追記機能は維持します。部分一致するだけの正規表現全体を削除対象にしません。

未登録の場合は操作ボタンを作成・追加しません。入力変更で登録済み条件に一致した場合に追加し、一致しなくなった場合は画面構成から取り除きます。

削除は条件と対象板を示して確認してから実行します。有効／無効はネイティブの無効フラグだけを変更し、登録文字列・対象板・一致方式・連鎖・非表示・登録日時を維持します。既に指定状態なら保存し直しません。操作後は元の編集画面を閉じ、古い入力内容の再保存を防ぎます。

別の板・一致方式の条件は対象にしません。同じ文字列・板・一致方式で複数の設定違いがあり、完全一致する項目もない場合は推測して選びません。操作前に登録内容を再確認し、操作画面を開いてから条件が変更・削除されていた場合は更新せず開き直しを促します。

保存にはChMateの既存NGストアと変更通知を使います。ファイルへ直接書き込みません。個人NG送信は既存の同意設定に従います。

高度なNGルールでは、従来から各ルールの編集画面で有効／無効・削除を設定できます。

検証には `scripts/existing-ng-actions-runtime.js` と隔離エミュレータを使用します。実際のネイティブNGストアに一時条件を作成し、各試験後に元の一覧を復元します。UIの確認手順・候補APK・導入記録は `build/existing-ng-*` に保存しています。通常アプリ・実機のNGは変更していません。
