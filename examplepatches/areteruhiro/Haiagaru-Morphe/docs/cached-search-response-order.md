# 取得済みスレ・アーカイブ検索のレス日時による混合表示

2026-11-01。利用者の追加回答は「全スレのレスを混ぜ、レスの投稿日時で並べる」。従来の作成日時順はスレURLの時刻で並べていたため、同じスレのレスがまとまる動作だった。

並び順へ以下の2つを追加する。既存の標準/スレ作成日時順は保持し、保存値0〜2の意味を変更しない。

- 全レス混合：レス投稿日時の新しい順（保存値3）
- 全レス混合：レス投稿日時の古い順（保存値4）

取得済みスレとアーカイブの結果をまとめて扱い、板やスレの所属をソートの優先条件にしない。nativeが結果本文へ付けた先頭行のレスヘッダーから日時を読み、JSTの日時と小数秒で比較する。本文中に引用された日時を使わず、不正な日付・日時不明のレスは末尾で元の順を保持する。同日時も元の順を保持する。スレ名だけに一致した結果は、投稿日時がないため末尾に残す。

nativeの結果は「タイトル行＋複数レス行」。混合ソートではレス行だけをソートし、表示スレが変わる箇所へ元のタイトル行を再配置する。レス行自体・強調表示付きCharSequence・URL・archive等のフラグはそのまま使う。DATや検索インデックス、保存条件を書き換えず、検索件数とqueryも保持する。標準へ戻すと元の行並びを復元する。設定プロファイルの検証範囲を0〜4へ拡張する。

実装はCachedResponseOrder、呼出は既存CachedSearchOrder.sortedのmode3/4分岐だけ。191のadapterと226/242の表示stateへの既存hookを使い、パッチ時のnative命令は追加変更していない。

host: 3版のrow形状、5ch/pink/エッヂの交差、同一スレの離れた日時、ミリ秒、本文の偽日時、不正日付、日時不明、タイトルのみ、元行identity保持、大量結果の昇降順で4027項目成功。既存スレ作成日時順2014項目も成功。通常LintVital/R8付きbuild/cached-response-final-build.logは3m11s成功。
