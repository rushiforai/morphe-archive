# 本文の文字列置換（外部TXT）

[READMEへ戻る](../README.md)

対応するChMateは191 dev／226 dev／241／242 devです。243 devは対象外です。Haiagaru設定 →「更新履歴」の「ReplaceTxtによる文字列置換（正規表現対応）」、または「画面・文字の表示」→「本文の文字列置換（外部TXT）」でON/OFFできます。TXTの作成・選択・再読み込みは後者から行います。初期状態はOFFです。

サンプルは `Download/Haiagaru/ReplaceStr.txt` に作成します。既存ファイルは上書きしません。UTF-8・タブ区切りで編集してください。ファイルを置き換えた場合やパッケージ名を変更した場合は、ファイル選択画面から再選択してください。

```text
; [TAB]で示す位置に実際のタブ文字を入力します（[TAB]という文字列は入力しません）。
<ex2>https://example■.com/ [TAB] https://example.com/ [TAB] msg
<rx>(https://example)■(\.com/) [TAB] $1$2 [TAB] msg
```

1行に2～4列を指定します。1列目が検索文字、2列目が置換後の文字です。3列目は `msg`（本文）または `all`（現状は本文のみ）を指定でき、省略時は `msg` です。置換後を空にすると削除します。ルールは上から順に適用します。`;`、`'`、`//` で始まる行はコメントです。

- `<ex>` は通常の文字列置換で、大文字・小文字を区別しません。`<ex2>` は区別します。指定を省略した場合も `<ex>` と同じです。
- `<rx>` は正規表現で、大文字・小文字を区別しません。`<rx2>` は区別します。置換文字列では `$1` や `${name}` でキャプチャグループを参照できます。
- 4列目のURL・タイトル条件は未対応です。値を指定すると、その行はエラーになります。

正規表現の処理時間と置換後の文字数には上限があります。TXTは128KBまで、ルールは256件まで、検索パターンは1～1024文字、置換文字列は4096文字までです。TXTが不正な場合や読み込みエラー、正規表現のタイムアウト、出力上限超過では、TXTのルールによる置換をせず本文を表示します。

表示用の本文をリンク認識前に置換するため、置換後のURLをリンクとして認識します。保存DAT、投稿本文、元のNG判定は変更しません。全体の `■` を一律削除するようなルールはURL以外にも適用されるため、URLを含む具体的な文字列を指定してください。掲示板の投稿規約に従って利用してください。

絵文字の異体字セレクタ除去と文字化け記号（`�`）の非表示も同じ設定画面で切り替えられます。これらはTXT選択不要の別設定で、初期ONです。保存DAT・入力中の下書きは変更せず、表示に反映するにはスレを開き直してください。
