# 投稿者の強調（1.8.11）

## 開発版：登録ごとの色指定

191／226／242では、条件を選んだ後の登録画面で「この登録の背景色」を選択できます。黄・青・緑・赤・オレンジ・ピンク・紫・水色・青緑・黄緑・茶・グレーの12色と、「共通設定の色」を用意しています。見本を確認してから登録してください。画面はスクロールできます。

登録済みの条件の色は「Haiagaru設定 → スレを読む → 投稿者の強調」の登録一覧でも変更できます。従来の登録は共通色を引き継ぎます。複数条件が一致した場合は最後に登録した条件を優先します。個別色はオン／オフを切り替えても保持されます。この追加機能は公開済み1.8.14には含まれません。

191 dev／226 dev／242 devに対応します。ChMate標準の「VIPでスレ主を強調」とは別の、表示専用の強調機能です。

## 登録する

レス本文を長押しし、「投稿者を強調」を選びます（メニューの形式によっては「この人の書き込みを強調」）。
条件を選択し、適用範囲を「このスレ／この板／すべての板」から選んで登録してください。登録すると強調機能もオンになります。

- **スレ主**：そのスレのレス1とIDが一致する投稿。レス1にIDがなければ、トリップ、ﾜｯﾁｮｲ全体の順に使用します。
- **ID**：選択したレスのIDと完全一致。
- **ﾜｯﾁｮｲ**：`bbbb-cccc` 全体が一致。`ﾜｯﾁｮｲ`／`ｽｯﾌﾟ`など、呼び名の違いは区別しません。
- **ﾜｯﾁｮｲ下4桁**：`-cccc`の4文字が一致。先頭4文字や呼び名が違う場合も強調します。
- **トリップ**：名前欄の`◆`に続くトリップが一致。誰でも入力できる`◇`は対象外です。

登録前に文字列を編集できます。`+`や`/`、`|`などは正規表現として解釈せず、そのまま比較します。英大文字／小文字も区別します。
対象の識別情報が取得できない条件は登録できません。スレ主は、レス1そのものや識別情報を取得できない場合に推測しません。

## オン／オフ・解除

「Haiagaru設定 → スレを読む → 投稿者の強調」を開きます。

- 機能全体のオン／オフ（初期オフ）
- 登録ごとのチェックによるオン／オフ
- 背景色（黄／青／緑）
- 登録を選択して削除

変更はこの画面で即時保存されます。強調は名前や本文の背景色と太字で表示し、元の文字色やリンク先・下線範囲は変更しません。
画面内の既存行も更新しますが、キャッシュされた行やスレ主の取得状態によって反映されない場合はスレを開き直してください。

## 注意事項

- ID・ﾜｯﾁｮｲは本人認証ではありません。同じ識別子を使う別人も一致する可能性があります。「このスレ」が初期選択です。
- IDの日付変更や、ﾜｯﾁｮｲの切替をまたいで同一人物を追跡する機能ではありません。スレ主のIDが変わる場合も同様です。
- NG判定、保存DAT、投稿本文は変更しません。NGで非表示のレスを再表示する機能でもありません。
- レス本文の引用・URL内に書かれたIDやﾜｯﾁｮｲでは判定しません。ネイティブの投稿者情報のみを使います。
- 登録は最大500件。追加のネットワーク通信や通知は行いません。

## 検証

識別子・適用範囲の単体テスト34項目と、合成レスを使ったAndroid上の文字装飾・リンク位置・設定保存・オン／オフ・クリック処理等47項目に合格しています。
191／226／242の元APKへのパッチ適用と、DEX内の描画・メニュー接続も確認しました。
ネイティブのアイコン／ComposeメニューがMenuItemのクリックリスナーを通さない場合も、
共通のディスパッチから選択したレスの投稿者情報へ接続するよう修正しています。
191／226／242の実画面で、レス長押し→条件選択→ID登録→名前欄の背景色・太字まで確認しました。
191は保存された有効な登録と表示中の強調Spanも読み取り専用のFridaで確認しています。
242では通常のComposeメニューのタップを使用しました。検証途中にエミュレータ全体が応答しなくなりましたが、
データを保持したコールド起動後、フックなしで条件選択・登録・名前欄への表示反映を再確認しています。
これは合成レスのテストとは区別します。本文全体への強調反映は別途確認が必要です。


## 2026-11-01 色見本の復旧（未公開）

Composeへ移行した設定描画が、native TextViewの背景色を引き継がず、色見本も通常の説明文として扱っていた。投稿者強調専用の色見本タグを追加し、設定描画で選択色を背景にした太字の見本を表示する。見本は説明文へ統合しない。タグの色をモデル更新判定と行の比較に含め、同じ文字列でも色変更を再描画する。他の説明文・入力欄の背景は変更しない。

登録画面の見本を復旧し、設定一覧でも共通色・登録ごとの色の直下に見本を追加。共通色を変更すると継承中の見本だけ追従し、個別色は保持する。個別色から共通色へ戻す場合も即座に追従する。色の保存形式、既存登録、表示用span、標準NG/DATは変更しない。検証結果はintegration-status.mdへ記録する。
