# 廃止したレス番号による新着件数計算

2026-11-25、利用者から191／1.54.0-dev.2で更新の重さ、その後「投稿後の更新が0件になり、HOMEへ戻ると＋1になる」と報告があったため、機能自体を撤去する指示を受けた。

製品から全レス番号の採取、ThreadLocal、番号集合、設定、バックアップ定義、更新履歴のトグルを削除し、通常時は更新前後の件数差分を使う。既存の「新着件数から非表示NGを除く」設定は独立して維持する。保存済みの旧オプションがONでも参照しない。

その後、手動更新でも「新着0件」と出る一方でHOMEへ戻ると未読が+1されるとの追加報告があった。原因は、ChMateのトーストがレス総数の差、HOMEの未読数がレス番号と既読位置を基準にしていることによる不一致と判断した。全件スキャン方式は戻さず、トーストの件数差が0のときだけ更新前の最大レス番号と更新後の新しい範囲を照合する軽量フォールバックを実装中。更新前は通常順のリスト端から最大番号を取り、更新後はその番号を超えた範囲だけを調べる。並べ替え済みのリストでは重複回避を含む安全な全件フォールバックを使う。ユーザー向け設定や常時番号走査は復活させない。

このフォルダの `.txt` は将来の調査用資料で、ビルド・パッチ・試験スクリプトとして使用しない。撤去前の最適化済み実装、nativeフック、Frida試験、生成APK検査を保存した。軽量化の計測記録は [比較資料](../../new-arrival-performance-20261125.md) を参照。

1.54.0-dev.4の軽量化は合成データで番号計算の負荷を減らしたが、実投稿後の0件表示問題を解決した証明にはならない。この実装を再利用する場合は、投稿成功・データ取得・本文反映・トースト表示の実際の順序を先に調べること。
