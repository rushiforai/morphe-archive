# エッヂ過去ログ検索の区切り線

検索結果は囲み枠ではなく横線で区切る。先頭行のみ上線、全行に下線を描き、隣り合う行の境界線を二重にしない。

- 左右の線・角丸の囲み・カード背景は使用しない。
- 行内は左右12dp・上下は初期16dp。「表示」で上下余白を0〜32dp、結果の文字サイズを70〜150%に変更でき、次回起動にも保持する。検索欄の文字サイズとは独立している。
- 余白を最小にしてもタップ領域は最低48dpを確保する。設定は別画面と本体タブの双方へ反映する。
- 専用ビューアの操作案内は削除し、使い方はHaiagaru設定に集約する。検索条件・エラー・注意事項は残す。
- Composeではテーマのoutline色70%、本体タブのnative表示では明暗に応じたグレーを使用する。
- 結果間の追加8dp余白をなくし、境界を一本の横線で共有する。他の設定フォームの余白・枠は変更しない。
- タップ先、検索条件、文字倍率、スクロール・復帰処理は変更しない。

実装はModelUi.ktの結果タグ分岐とEddiArchiveSearchUi.ResultRules。ビルドと実画面の確認状況はintegration-statusへ追記する。公開は別途判断し、未解決GIF・191 lifecycle等の確認を省略しない。
