# エッヂの公開レベルによる自動NG（開発中）

2026-11-01。利用者の最終指示により、認証日の記録・Cookie観測・認証日共有・認証日からの推定レベルNGを実装から削除した。今回のReleaseに認証日共有は含めない。

## 残す機能

HaiagaruのNG設定から、公開スレの名前欄で確認したエッヂのレベルによる非表示を選べる（初期OFF）。閾値は初期5、任意変更可能。ID除外一覧・自動同期ON/OFF・同期間隔15〜1440分（初期30分）・手動同期を備える。

クロール元は利用者指定 https://bbs.eddibb.cc/test/read.cgi/liveedge/1793457978/ 。GASが30分ごとにまとめて取得し、配信GETごとにはクロールしない。同一ホスト・板・スレの正確な過去ログパスへの転送だけを追う。本文やエスケープ済みのバッジはレベルと扱わず、名前欄末尾のサーバー生成バッジだけを解析する。

板区分・投稿日・IDをキーに照合し、同一IDの新しい投稿のレベルを優先。不明IDは非表示にせず、他日や5chへ持ち越さない。標準NGやDATを編集せず、native表示用マップへ非表示フラグを加える。NG無効時と標準の非表示NG表示を維持。OFF後はスレ再表示で復帰する。

DAT上限4MiB/10000レス、配信最大10000件、7日分。端末キャッシュはAtomicFile、接続先と投稿日を検証する。

## 認証日共有の除去

EdgeLevelNgの認証記録・fingerprint・自身投稿収集・送信キュー・同意・推定計算を削除。ExternalBoardAuth/Activityの追加hookとExtraQuickFilters.index公開変更も元へ戻す。推定/認証の設定とprofile項目を削除。サーバーのedgeLevelAuth受付・認証日配信・報告検証も削除した。

既存GASデプロイを2026-11-01 02:05 JSTにversion10へ更新し、URL/実行者/アクセス範囲は維持。配信キャッシュのキーを更新し、旧形式を返さない。以前の実認証日報告は0件で、廃止したシートのデータはアプリから参照しない。
