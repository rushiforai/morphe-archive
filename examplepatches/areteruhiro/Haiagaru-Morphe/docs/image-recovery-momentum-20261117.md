# 画像NG自動復元・勢い順・表示設定の修正

## 変更

- 「登録画像によるあぼーん」を開くと、SAF設定済みの場合は旧アプリ内保存先に残る `.img` をバックグラウンドで照合し、不足画像だけコピーする。URL登録も同じ画像保存方式のため対象。元画像は保持し、画像内容のダイジェストによる重複防止・80枚上限・設定画面から明示削除した画像の除外を適用する。SAF未設定なら従来のアプリ内画像をそのまま使う。
- 移行の案内ダイアログは `migrationNoticeShown` で初回だけ表示。その後も自動照合は行い、結果は画面内へ表示する。アクセス権不足でも元画像を変更せず、後の設定表示で再試行する。
- 元データそのものが失われた画像のURL再取得は行わない。利用者の指示により実端末の旧画像探索は終了した。実画像の復元成功件数を主張しない。
- 191／226の前回の勢い修正は検索用Filterのsortだけを捕捉し、通常一覧の主sortが対象外だった。明示バインディングに通常一覧の所有クラスを追加し、勢い比較器を構築する処理も対象として、3版とも通常一覧／フィルターの2箇所を必須化した。
- 一覧応答時に表示外のスレも作成日時の取得対象にし、画面に出たレス数の多い行だけに日時取得が偏る状態を避ける。取得は既存の2ワーカー・待機数上限200・失敗時15分抑制を使う。比較中の日時スナップショットと時計は固定。応答済み一覧から板を一意に特定して同番号の別板混同を防ぎ、件数はsubjectの総レス数を使用する。242で日時未取得時に元のレス数由来の勢い表示へ戻る経路は0へ変更。
- 投稿者強調の登録時にIDは24時間、ﾜｯﾁｮｲ／末尾4桁は1週間の自動削除を選べる。初期は期限なし、選択を種別ごとに記憶。従来の期限なし登録を保持し、起動時と期限到来時に期限切れ登録を除く。
- 独立したUI Resourcesが画面回転時に起動時の向きを保持する問題を修正し、専用動画ビューアの横画面没入表示へ反映。Android 11以降のsystemBars制御も追加。
- Xプレビューは取得データの明示的な省略と、全文を取得できていない可能性を区別して表示。ローカル140文字表示にも省略表示を加える。文字数だけで省略を断定しない。
- 展開項目は閉じた状態で下向き、開いた状態で上向き、画面遷移項目は右向きの矢印を表示する。

## 検証と範囲

証跡は `build/highlight-immersive-x-20261117`。Lint/R8付きMPPビルド成功。Mi Note 10 Android 11（ADB d5497008）の隔離reporter191／226／242へ署名照合後に更新した。署名と各APK／MPPは導入台帳に記録。

模擬画像を用いた実SAF入出力の自動復元・破損画像削除テスト14項目に合格。URL登録と同形式の旧画像、再表示時の重複防止、元画像保持、明示削除の復活防止、意図的な再登録、上限、無効な移行先を確認。初版の補助ProviderはAndroidのMANAGE_DOCUMENTS要件を満たさずテストアプリだけが起動失敗したため、文書URI操作を実装する補助ContentProviderへ修正して再実行成功。製品アプリのクラッシュではない。

期限計算のホストテスト14項目、期限切れ登録の実際の自動削除・X省略通知・実画面回転の実機テスト12項目が成功。通常一覧の主sortとフィルターsortの挿入位置、比較器の元命令・レジスター保持、日時表示フックを3版で照合。並び替えテストは実ChMate行と実比較器を使用し、総レス数と保持済み件数の差、比較中の日時変化、降順／逆順、未知日時、次回ソートでの更新反映を含む各13項目に合格。

本文・画像経路は模擬通信で検証する。利用者のスクリーンショットの全スレを実サイトから再取得して同一順序まで比較した検証ではない。日時未取得・削除済み・認証画面等のスレは日時を推定せず、取得完了後の再ソートで反映する。サポート板リンクの追加クリック確認は利用者の指示により実施しない。

最終MPP SHA-256は `0b76909c4762783917557356586394e2fa31cd819634c6968097e4db2e4f1fbe`。最終版を3版へ再適用・署名照合後に更新し、主sort／フィルターの位置・勢い各13項目・HOME起動を再確認。本文・画像経路は共通処理を変更していない先行候補で191／226／242各649／655／652項目成功。最終追加の破損画像削除とX省略通知は242で確認。製品reporter3版の新規クラッシュ記録なし。
