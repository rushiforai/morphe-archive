# VPN取得の対象ドメイン

Haiagaru設定の画像・動画カテゴリにある「VPN取得の対象ドメイン」で、1行1ドメインを登録できます。URLやパスではなく、`example.com` のように入力してください。完全一致で判定し、サブドメインは別途登録します。登録は最大128件です。

初期登録は `tools.yajuvideo.st`、`www.activetk.jp`、`loggerip.web.app` です。これは危険サイトと断定する一覧ではなく、ユーザーがVPN経由で取得したいと指定した接続先です。

画像のVPN取得には任意のVPNパッチと対応ライブラリを導入し、設定で有効化する必要があります。登録先のリンクカードは、VPNがオフ・未導入・失敗時には自動取得しません。VPN失敗時に直接接続へ切り替えません。カードのHTML、リダイレクト、カード内の別ドメインのプレビュー画像にも保護を引き継ぎます。Cookie・認証トークンは送りません。

この機能は端末全体のVPNではありません。外部ブラウザや、すべての追加機能の通信を一括で保護するものではありません。画像VPNをオフにした場合、ChMate本体の通常画像取得は従来の直接通信になります。登録ドメイン設定は `.haiagaru` の設定共有対象です。

VPNでも固有URLやアクセス時刻による識別は防げません。VPN運営者には接続元IPが見え、通信が記録される可能性があります。完全な匿名性を保証する機能ではありません。

指定サイトへの実アクセスは検証に使わず、ドメイン判定テストと、専用の仮想ネットワーク内でDNS・HTTPを処理する模擬サーバーを使います。実際のVPN接続・端末画面の検証とは区別します。
