# エッヂ過去ログの検索先

エッヂ過去ログ検索画面の「過去ログの検索先」から選択する。

- エッヂ過去ログ（従来）：eddiarchive3rd.boy.jp。従来の詳細条件を維持。
- Kyodemo（現行＋過去ログ）：www.kyodemo.net のエッヂ板内検索。スレタイと開始日・終了日を指定可能。現行スレも含み、サイトの収録状況に左右される。

KyodemoではOR／曖昧検索・除外語・最小レス数・並び順を指定する同等の方式が確認できていないため、その入力項目は隠す。検索先へ送る文字はWindows-31Jで符号化し、表現できない文字は置換せず案内する。サイトの順序と「次へ」のリンクを使用し、全件数が取得できない場合は「このページ」の件数として表示する。

検索先・条件・結果・位置は既存の保存経路に含める。切替時は前の検索応答と結果を無効化し、利用者が「検索」を押してから取得する。旧サーバーが502などを返しても無断で別サイトへ問い合わせない。自動巡回や全スレ本文の収集は行わない。

結果タップはKyodemoの表示URLではなくChMateで開ける元スレURLへ接続する。元スレのDATが取得できることや、Kyodemo掲載本文をChMateへ取り込めることを保証する変更ではない。「元サイトの表示に切り替える」では選択中の検索先を表示する。
