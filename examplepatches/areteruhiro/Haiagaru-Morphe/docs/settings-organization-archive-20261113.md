# 設定画面の整理・エッヂ過去ログの表示調整

## 設定画面

- スレッド設定を「画面・文字・テーマ」「スレの操作・更新」「ツールバー・絞り込み」
  「スレ一覧・HOME・履歴の表示」「スレ内検索・記者ID」へ整理した。
- 基本設定・外部板・追加画面タブ・設定ジェスチャーを分け、追加画面タブの6画面を
  「自動でタブ表示する画面」へまとめた。先頭スイッチは機能の有効/無効ではなく
  追加先ペインの選択なので、ラベルを「ホーム側（オフはスレ側）」へ明確化した。
- WebサイトのリンクカードとX/Twitterカードを別々の折りたたみにし、詳細項目は
  親の表示設定がOFFなら操作不可にする。保存してある子の値は変更しない。
- 追加フィルターも親子関係を表示。AA/自分/返信の個別設定は親OFF時に操作不可。
  下部パネルの高さ調整は、一時表示または常時表示が有効なときだけ操作できる。
- 通常一覧に重複していたフィルター設定を「ツールバーとフィルターの設定」へ集約。
  旧設定リンクのカタログ用コントロールは保持し、通常画面と検索結果には重複させない。
  検索は折りたたみ状態に関係なく子項目を対象にし、AA/自分/返信/件数/下部/高さ/
  つまみ/フローティングなどから設定入口を表示する。入力値は検索対象にしない。
- 内側の丸カードを廃止。外側の1枚のカード内を字下げと区切り線で整理し、
  ListItemの背景は透明にして親カードと色を合わせた。

折りたたみ対応はGENERAL/DISPLAY/SOCIALとフィルターダイアログ。
POSTING/UPLOAD/MEDIA/CHECKER/ARCHIVE/NG/HISTORY/BACKUP/ADVANCED/EXPERTの
内部は従来の並びを維持している（別画面を開くボタンや既存の表示切替はある）。

## エッヂ過去ログ

- 検索結果カードのURL行を削除。タイトルと日時を表示し、タップでアプリのスレ表示へ、
  長押しでURLなどをコピーする経路を保持する。
- 検索欄と結果一覧の間につまみを追加。検索欄は画面の3〜70%で調整でき、ドラッグ終了時
  に保存する。キャンセル時は保存値へ戻す。キーボードやペインサイズの変化に追従する。
- 「表示」に高さ固定（つまみ非表示）を追加。保存した高さは保持する。
- 「元サイトで開く（次回から）」を表示設定とHaiagaruの過去ログ設定へ追加。
  元サイト表示では不要な「戻る／投稿検索・結果」の外側ヘッダーを省く。
  元サイト内のスレリンクも既存のWebViewClient経由でOpenUrlActivityへ渡す。
- 新しい保存キーは`haiagaru_eddi_search`の`searchPanePercent`と`searchPaneLocked`、
  Haiagaru共通設定の`eddiArchiveOriginalSite`。設定リセットの対象に含める。

## 検査と導入

通常Lint/R8を含む`:patches:buildAndroid`を使用。検索の既存49項目と設定入口の関連語12項目、
高さの既定値・保存・上下限・固定19項目、既存Hissi/エッヂ等のスレURL判定が成功した。
高さのホスト検査はSharedPreferencesを模擬化したもので、物理ドラッグの検査ではない。

最初の191候補をXIG05（730eae72）の`jp.co.airfrt.android.chMate.haiagartu`へ利用者指定で
install-r更新。初回導入日時2026-11-09 10:22:01は保持され、HomeActivity起動成功。
設定カテゴリのグループと、過去ログ結果のURL非表示・高さ調整つまみを実画面のUI階層で確認。
最初の候補と最終調整版の導入記録を区別し、絶対パス・APK/MPP/証明書SHA256・鍵所在は
非公開`build/local-development-records/`へ記録する。

最終調整版は通常Lint/R8 build3分28秒成功、191への適用・署名成功。
2026-11-13 23:20:19 JSTに同じ実機・packageへ再度install-r Success、初回導入日時保持、
端末上APKのSHA256と候補が一致。設定画面cold起動成功、実検索「AAフィルター」で
「ツールバーとフィルターの設定」が1件表示され、画面撮影でも背景色の統一と内側丸カード
の撤去を確認した。`build/settings-archive-191-final/`に最終成果物・UI階層・画面撮影を保存。

ユーザーが実機上で確認を進めているため、設定変更を伴う自動タップは限定した。
親子設定の全組合せ、実ドラッグとロックの往復、元サイト設定からのスレリンクの通し操作、
報告OPPO端末での人気レススクロール改善は未確認。公式Releaseは行っていない。
