# 履歴のDAT落ち非表示・GIFコントロール

2026-10-22。未公開。今回の依頼ではリリース操作・版名変更をしない。

## 変更

- HOME履歴で1件のURL解決失敗がフィルター全体を取り消していた。URLの補助判定と行単位の失敗を隔離し、他の行のnative DROP判定を継続する。
- 同一URLの履歴コピーにあるゼロフラグを「生存確認」と扱わず、プロセス内で取得済みのnative DROPの正の証拠を共有する。上限4096件は維持。未確認のHTTPエラーだけでは非表示にしない。
- 元の履歴リスト・DB・DAT・nativeフラグは変更しない。設定OFFで元データを返す。
- XのGIF（MP4）のMedia3代替再生時にもコントロールを接続する共通MediaPlayerControlを追加。VideoViewによる再接続時にも未使用プレーヤーへの差し戻しを防ぐ。
- コントロールを表示する際に動画のTextureViewより前面へ出す。これまで︙で隠れたVideoViewの時間・再生状態を表示していた問題に対応する。
- 戻る／進むボタンの表示と移動幅を既存の移動秒数（5/10/15/30/60秒）へ統一し、変更を監視する。クリック時の実再生位置から計算し、先頭・末尾で範囲を制限する。
- 秒数の設定はダブルタップOFFでも変更可能にする。

## 追加依頼：フィルターのフローティングボタン

「ツールバーとフィルターの設定」に初期OFFの「フィルターのフローティングボタンを表示」を追加する。既存の下部パネルがONのときだけ表示。通常タップはフィルター、長押ししてドラッグで位置変更。画面サイズが変わっても収まるよう正規化した位置を保存する。OFFでも標準ツールバーの入口は維持する。

外部アプリへ重ねる権限は使わず、アプリ画面内のViewとして表示する。所有スレ画面のdetachで監視とボタンを除去し、常駐ポーリングはしない。バックアップには既存設定全体の仕組みで含まれる。共有設定には表示ON/OFFだけを追加し、端末別配置は共有対象外。

フローティングボタンを含む最終候補 `build/floating-filter-controls-final.mpp` SHA256 `2FC10BC780FC8B8889E7A1B01558B4734AD7BCF75CBAF772B37CA8ED74DEE123`。`build/floating-filter-controls-final-build.log` で成功（2分52秒、既知ローカルLint3工程除外）。242へ署名照合更新し、同じ最終候補で履歴5項目、フローティング9項目、GIF実再生／controller／メニュー復帰が成功。30秒設定で画面の両ボタンが30秒へ即時変更されることをXMLと画像で確認し、試験設定を復元。
