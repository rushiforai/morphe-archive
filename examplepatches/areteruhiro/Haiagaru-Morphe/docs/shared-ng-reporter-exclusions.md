# 共有NGのレポーター除外

レス長押しの「共有NG条件確認」で、条件に加えてその報告者を除外できます。

1. 「このレポーターをすべて除外（今後も）」を押す。
2. 条件が複数ある場合は条件を、その条件の報告者が複数いる場合は報告者を選ぶ。
3. 「除外する」で保存し、スレを開き直す。

この端末では、そのレポーターが報告した現在・今後の条件への票を数えなくなります。同じ条件に別のレポーターの票がある場合は、その票を残し、設定した「必要な報告数」で適用を判定します。全員を除外した条件は適用しません。運営側のBANや他の利用者の設定は変更しません。

解除は「オンライン共有NG」→「除外するレポーター（今後の報告にも適用）」でチェックを外して保存します。検索で表示を絞っても、他の行の選択は維持します。キャンセルでは変更しません。

除外設定はHaiagaruバックアップの「設定」に含まれます。報告者情報を持たない古い配信条件からは除外できないため、最初に共有NGを同期してください。個人NGや別の共有条件にも一致するレスは、その条件で引き続き隠れる場合があります。

「必要な報告数」の初期値は1です。保存済みの値は更新しても維持します。
