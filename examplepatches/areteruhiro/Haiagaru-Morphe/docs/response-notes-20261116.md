# レスメモ（実装・検証中）

「メモを追加」と「メモ」は統合し、レス長押しツールバーの「メモ」1ボタンから対象レスのメモ作成／表示／編集へ入る。スレ本文を変更せず、元URL・レス番号・抜粋と独立したメモを端末内SQLiteに保存する。同じレスでは既存メモを開く。

画面はComposeの一覧・検索と編集画面。新規作成時は本文へフォーカスし、タイトル任意・本文30,000文字まで。本文・タイトル・元レスの抜粋を検索可能。検索は150ms待機後にIOで実行し、最大500件を表示。元レスを展開／スレで開く、保存、削除確認、未保存変更の保存／破棄確認を備える。自由なメモも作成できる。

追加先:

- レス長押しツールバー／242のレスシート。「並び替える」カタログで配置可能。
- Haiagaruのレスメニュー設定に「レス長押しにメモを表示」のON/OFF。非表示でもメモは削除しない。既存の項目別表示設定にも「メモ」を追加。
- HOMEの3点メニューとHOMEツールバーの編集候補。「HOMEの3点メニューにメモを表示」の個別切替を用意。
- Haiagaru設定内の「メモの一覧・検索」。他のボタンを隠しても開ける。
- ChMateのジェスチャー設定に「メモ」（初期未割当）。一覧・検索を開く。既存ジェスチャーと重複すると既存操作を優先し、認識プレビューにメモと表示する。

メモDBはアプリ内の専用保存先で、認証・共有NG・ネイティブ本文検索とは独立。現時点ではHaiagaruの共有設定ファイルやMEGA個別同期へのメモ本文の追加は行っていない。
