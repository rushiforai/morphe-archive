# 専用ビューアOFF時のimgpile動画

利用者報告: Haiagaru設定で専用動画ビューアをOFFにすると `https://cdn.imgpile.com/f/O5cw4e6.mp4` が再生できない。実機の再生先はMi ビデオ。Android標準MediaPlayerのURL直接取得と一時ファイルの両方は、15,086ms・842×1920として準備できた。通常GETもHTTP200、video/mp4、7,310,958 bytes。Mi ビデオ固有の失敗理由は未確定だが、動画形式自体が端末で非対応という結果ではない。

利用者が「動画を一時取得して外部プレイヤーに渡す」を選択したため、専用ビューアを使わないときのimgpile動画だけを一時取得へ接続。動画再生は外部アプリで行う。明示した別アプリ宛てIntentは変更しない。専用ビューアONで通常使用する場合も変更しない。

Haiagaruのメディア設定に「外部プレイヤー用にimgpile動画を一時取得」のON/OFFを追加（初期ON）。取得はバックグラウンドで行い、キャンセル・再試行可能。HTTPS、最大5リダイレクト、128MiB、60秒。確認ページはMP4として渡さない。Cookieは使用せず、別オリジンへ認証情報を転送しない。保存名はランダムUUID。24時間経過または全体256MiB超の一時ファイルは次回取得時に古いものから整理する。

外部アプリには非公開Providerの読み取り専用content URIを一時許可して渡す。完了したMP4以外・余分なパス・書込みは拒否する。ダウンロードした動画を既存の隔離デコーダーへ渡し、サムネイルを登録してスレ・一覧の表示を更新する。動画サムネイルOFF／自動取得しない設定は尊重する。

検証候補はローカル242の隔離パッケージ。公開版への反映と区別する。
