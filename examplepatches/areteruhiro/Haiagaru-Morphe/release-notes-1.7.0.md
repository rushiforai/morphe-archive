# Haiagaru 1.7.0

Haiagaru 1.5.2からの変更点をまとめた正式リリースです。
1.5.3～1.6.11の先行版での改善と、今回のワッチョイ検索・文字列置換・リンク表示の修正を含みます。
配布するMPPはAndroid版Morphe向けです。

## 対応するChMate

- 0.8.10.191 dev
- 0.8.10.226 dev
- 0.8.10.241
- 0.8.10.242 dev（1.5.2から追加）
- 0.8.10.243 dev：一部機能未実装のため非推奨。今回追加の外部TXTによる本文置換は対象外です。

## 1.5.2からの主な変更

### 必死チェッカー・KyodemoをChMate内で使いやすく

- hissi.org／KyodemoをChMate内の専用ビュワーで表示。対応する外部板でもID検索メニューを利用できます。
- 検索先を自動／hissi.org／Kyodemo／両方から選択でき、前回の選択も記憶します。自動選択ではBBSPINKもhissi.orgを使います。
- 検索結果内の書き込みURLから、元の掲示板のスレをChMateで開けるようにしました。
- 端末設定／ライト／ダーク／AMOLEDブラックの配色、縦持ちでの本文折り返し、上部の表示領域を改善しました。
- レスを長押しして、レス番号・名前・ID・本文・レスのURL・ヘッダー＋本文のコピーや文字選択ができます。「全レス」と「本文」のコピー内容も区別しました。
- 更新ボタン、左右スワイプの戻る／進む、方向の設定、戻る履歴がない場合の終了に対応。ツールボタンの表示も選べます。
- 専用ビュワーを使わない設定・パッチ適用時オプションを追加しました。
- ワッチョイ長押しの検索メニューと、選択したレスからのID／ワッチョイ引き継ぎを改善しました。
- ワッチョイはラベル・全文・大小文字・記号を保持して渡します。固定桁数・英数字制限を緩和し、`+`／`/`が欠落する問題も修正しました。
- ワッチョイ長押しからの検索は、毎回の入力確認を省いて直接開きます。手動の「ID/ﾜｯﾁｮｲ」入力は引き続き利用できます。
- Kyodemoの傾向表示と、利用可能な分析リクエストへの導線を改善。分析後に自動リクエストを繰り返すループを抑止しました。通信失敗時は「しばらくしてもう一度お試しください」と表示します。

### バックアップ・復元・起動時同期

- MEGAへのバックアップ／復元と、同期元→同期先・双方向の不足分補完を追加しました。
- お気に入り、NG設定、表示履歴、設定、書き込み履歴（postDataList.json／kakikomi.txt）、Cookieなどから対象項目を選べます。
- 分／時間／日単位の間隔設定、起動時のバックアップと最新バックアップの確認に対応しました。アプリを閉じている間のバックグラウンド同期は行いません。
- 復元前に変更箇所を確認するダイアログを追加。確認表示は設定で切り替えられます。
- Androidのファイル選択画面を使ったローカルバックアップ／復元も追加しました。

### エッヂ過去ログ・記者ID

- エッヂ過去ログサイトを利用したアプリ内検索・結果一覧を追加しました。
- タイトルのAND／OR、除外語、半角全角の曖昧検索、レス数、並べ替え、開始日・終了日の詳細条件を利用できます。
- ホーム、板カテゴリ一覧、板のスレ一覧のツールバーに「エッジ過去ログ」を追加しました。
- 元サイト表示のダークモードと、ステータスバーに重なる表示を改善しました。
- 記者IDの編集・NG登録の互換処理を改善。スレタイをコピーする際は表示用の記者IDを除外します。
- 過去ログ画面を開けない場合のエラーコードと診断ログを追加しました。

### スレ表示・フィルター・絵文字

- フィルターをツールバーから開けるようにし、上部の元のフィルター行を隠す設定を追加しました。
- スレの先頭を一度も表示していない場合にフィルターが開けない問題や、旧行を隠した際の余白を改善しました。
- チェックボックス形式でフィルターを切り替え、画像項目の長押しから画像一覧を開けます。
- 「未読数を0にする」でスレ一覧が空になる問題と、新着バッジが残る問題を修正しました。
- レスが少ないスレを上詰めにする設定、既読スレを優先する並べ替えを追加しました。
- 絵文字の表示補正とフォント設定を改善しました。
- 191／226で古いBEアイコンの重複と、URL・`ttp://`形式のリンク下線がずれる問題を修正しました。
- 191／226／241／242に、外部TXTによる本文の文字列置換を追加しました。Haiagaru設定からON/OFFでき、初期状態はOFFです。
- `Download/Haiagaru/ReplaceStr.txt`のサンプル作成、TXT選択、再読み込みに対応。通常置換をリンク認識前に適用し、保存DAT・投稿本文・元のNG判定は変更しません。正規表現・名前やタイトルの置換は未対応です。

### 安定性・パッチ適用

- Talk投稿、UPLIFT利用時、パッケージ名・再署名に関係する0除算／不正な添字／null参照などの互換処理を改善しました。
- パッケージ名やアプリ名を変更した際の起動時クラス名復号、同期設定などでのクラッシュを改善しました。
- 191の自動NG画像判定でTFLite実行に関連するクラッシュ対策を追加。適用はオプションで切り替えられます。
- 191以外でパッチ適用が重くなる処理を絞り込み、負荷を低減しました。
- クラッシュログ保存は初期状態ON。Android向けMPPとバンドルメタデータの配布を更新しました。

## 更新時の注意・確認範囲

- 既存データをバックアップし、**元のChMate APK**に1.7.0のパッチを適用してください。パッチ済みAPKへの重ね掛けは推奨しません。
- 専用ビュワー、上部フィルター非表示、MEGA同期、文字列置換などはHaiagaru設定を確認してください。
- Kyodemoが未取得のレス・ワッチョイは検索できません。分析処理の成功や、Shift_JISで表せない文字のUTF-8検索対応はサイト側にも依存し、サーバー側のエラーまで解消するものではありません。
- 複数端末・実アカウントでのMEGA同期を含む、全機能の網羅的な実機検証は完了していません。同期はまずバックアップを取ってからお試しください。
- 元の本文に`...`を含む省略済みURLは、省略前のリンク先を復元できません。
- 通常版・プレ版用のパッチソースは、今回どちらも正式版1.7.0へ揃えています。
