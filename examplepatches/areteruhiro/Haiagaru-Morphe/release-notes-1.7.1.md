# Haiagaru 1.7.1

1.7.0からの互換性修正を含む正式リリースです。配布MPPはAndroid版Morphe向けです。

## 主な変更点

- 専用必死チェッカービュワーをOFFにした場合、必死チェッカーURLをChMate内WebViewへ固定せず、Androidの通常のURL処理に戻すよう修正しました。
- ChMate 0.8.10.191 devで、Talkの旧形式スレURLから書き込みフォームを開けない問題を修正しました。
- Talkの読み込み処理中だけ通信種別を一時的に変更し、読み込み後に元の種別へ戻すことで、書き込み先判定への副作用を防ぎます。
- エッヂの記者IDや記号を含むスレタイの表示・編集処理を修正しました。

## 対応するChMate

- 0.8.10.191 dev
- 0.8.10.226 dev
- 0.8.10.241
- 0.8.10.242 dev
- 0.8.10.243 devは一部機能未実装のため非推奨です。

## 配布物

- `haiagaru_patches-1.7.1.mpp` と `patches-1.7.1.mpp` は同一のAndroid向けMPPです。
- パッチ適用時は元のChMate APKを使用し、事前に必要なデータをバックアップしてください。
