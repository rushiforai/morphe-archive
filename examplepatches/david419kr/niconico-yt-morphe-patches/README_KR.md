# Niconico YT Comments

> **이제 공식 Morphe Patches에 포함되어 있습니다.**
>
> 이 저장소에서 제공하던 니코니코식 라이브 채팅·채팅 다시보기 기능은
> **Morphe Patches 2.0.0 이상**에 포함되어 있습니다.
> 별도 패치 번들이나 이 저장소의 원격 소스를 추가할 필요가 없습니다.

새로 설치하거나 업데이트할 때는
[공식 Morphe Patches](https://github.com/MorpheApp/morphe-patches)를 사용해 주세요.

## 공식 패치 사용 방법

1. Morphe Manager와 공식 **Morphe Patches** 소스를 최신 안정 버전으로 업데이트합니다.
2. 기존 별도 **Niconico YT Comments Patches** 소스는 비활성화하거나 삭제합니다.
   개인 테스트용 **Niconico YT Integration Test** 소스를 추가했다면 해당 소스도 비활성화하거나 삭제합니다.
3. 공식 소스에서 지원하는 수정되지 않은 YouTube APK를 선택합니다.
   **Niconico comments**가 선택되어 있는지 확인합니다. 기본 패치 선택에 포함됩니다.
4. 공식 소스로 YouTube를 패치하고 생성된 APK를 설치합니다.
5. 패치한 YouTube에서 **설정 → Morphe → Player → Niconico comments**를 열어
   기능을 켜고, 안내에 따라 앱을 재시작합니다.

플레이어의 댓글 아이콘을 누르면 댓글 표시를 켜고 끌 수 있습니다.
길게 누르면 빠른 설정을 열 수 있습니다.

**패치 소스만 업데이트해도 이미 설치된 YouTube 앱이 바뀌지는 않습니다.
공식 구현으로 전환하려면 APK를 다시 패치하고 설치해야 합니다.**
전환 후 니코니코 댓글 설정도 확인해 주세요.

## 이 저장소에 대하여

이 저장소는 최초의 별도 Morphe 패치 번들을 보관하는 기록용 아카이브입니다.

이 기능은 [PR #4080](https://github.com/MorpheApp/morphe-patches/pull/4080)을 통해
2026년 10월 27일 공식 Morphe Patches에 머지되었으며,
[Morphe Patches 2.0.0](https://github.com/MorpheApp/morphe-patches/releases/tag/v2.0.0)에 처음 정식 배포되었습니다.

이후 공식 구현에는 추가 개선이 이루어지고 있습니다.
현재 지원 버전, 업데이트 및 문의는
[공식 저장소](https://github.com/MorpheApp/morphe-patches)를 확인해 주세요.

기능을 통합하고 개선해 주신 Morphe 메인테이너 여러분께 감사드립니다!
