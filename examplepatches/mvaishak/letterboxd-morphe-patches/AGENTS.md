# Letterboxd Morphe patches

Before making any UI change, read [the Morphe UI design playbook](docs/design/MORPHE_DESIGN_PLAYBOOK.md).
Identify the closest native Letterboxd reference and follow the playbook for
the whole flow, including every menu, dialog, preview, and form it opens.
Use the playbook’s verification guidance within the scope the user requests.
Add new reusable design patterns to the playbook after the user approves them.
