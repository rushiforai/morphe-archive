# 🔁 Shorts to Subscriptions

Replaces the **Shorts** button in the YouTube app's bottom bar with a **Subscriptions** button, so one tap opens the feed of channels you're subscribed to.

## Details

- The new button sits where Shorts was and uses the same icon style as the rest of the bar.
- If the bar already has a Subscriptions button, Shorts is just removed.
- Shorts are still reachable from the Home feed and channel pages; only the bottom-bar button changes.

## Setup

1. Patch **YouTube 21.30.216** and enable **Shorts to Subscriptions** together with the official Morphe
   YouTube patches (they're needed for signing in).
2. Install and open the app. The swap shows once the bottom bar has loaded from YouTube.
