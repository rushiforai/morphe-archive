## How to use these patches

1. **Using Morphe Manager:**
   - Open Morphe Manager
   - Go to Settings → Patch sources
   - Add this repository URL: `https://github.com/dumketo/multi-app-patches`

2. **Direct link:**
   Click here to add directly: `https://morphe.software/add-source?github=dumketo/multi-app-patches&name=Multi-App%20Patches`

## FAQ

### What apps are supported?
This repository includes patches for popular productivity, utility, and content apps. Current supported apps include Wallverse, AccuBattery, AdGuard, and Adobe Acrobat. More apps will be added over time.

### Are these patches safe to use?
These patches are created following the Morphe patch development guidelines. However, always make sure to:
- Use them at your own risk
- Keep backups of your original APK
- Only download from trusted sources
- Test on a non-primary device first

### Will these patches work on future versions?
Patches may need to be updated for newer versions of the apps. Check the repository for updates when apps update. You can also open an issue to request updates for specific app versions.

### Can I request new apps or patches?
Yes! Feel free to open an issue or discussion to request support for new apps or specific patches. Please include the app name, package name, and Play Store link when possible.
