# VocaColle v1.1 Completion Implementation Plan

> **For Hermes:** Use subagent-driven-development and strict RED → GREEN → REFACTOR for every production change.

**Goal:** Complete v1.1 with persistent display-language selection, English UI localization, and reusable fail-closed network/cache foundations while preserving the existing Korean patch names and exact VocaColle 7.40.0 compatibility.

**Architecture:** Keep Japanese resources as the APK fallback and install separate `values-ko`/`values-en` overlays. Convert the existing hardcoded/server Korean hooks into locale-aware presentation-boundary translators so system/Japanese/English/Korean can be selected without touching request values. Add an extension-owned HTTPS-only bounded client and atomic file cache; neither performs remote calls until a later feature explicitly uses it.

**Tech stack:** Kotlin Morphe patches, Java Android extension, framework Preferences, SharedPreferences, `HttpsURLConnection`, atomic files, GPT-5.6 Luna low for reviewed English catalog generation, Gradle/JUnit, AAPT2/DEX/APK smoke checks.
