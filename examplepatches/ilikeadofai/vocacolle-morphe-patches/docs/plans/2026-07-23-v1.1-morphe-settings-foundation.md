# VocaColle v1.1 Morphe Settings Foundation

> **Execution note:** Implement this plan on `dev` using RED → GREEN → REFACTOR and verify against the original VocaColle 7.40.0 APK.

**Goal:** Add the first v1.1 vertical slice: a native Morphe entry in VocaColle settings, an extension-owned settings screen, persistent runtime-feature configuration, visible Morphe patch-version information, and optional launcher branding that preserves the Japanese original by default.

**Architecture:** Patch the existing `SettingFragment` `MenuProvider` callbacks rather than the fragile Compose tree. Add a `Morphe` overflow item, route its selection through an extension launcher, and use a marker Intent to repurpose the already-registered `OssLicensesMenuActivity` as a framework `PreferenceFragment` host. This avoids relying on MPE manifest/resource merging, which is not provided. Store runtime settings in the app's default `SharedPreferences`; compile-time localization patches remain unaffected.

**Compatibility boundary:** `jp.nicovideo.nicobox` 7.40.0 only. The existing exact-version compatibility contract remains fail-closed.
