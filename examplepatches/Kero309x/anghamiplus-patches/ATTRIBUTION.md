# Project Architecture & Credits

**Kero309x Patches** is an independent, modular extension patch bundle engineered for Android bytecode manipulation using the [Morphe](https://morphe.software) framework.

## Maintainers & Authors
* **[Kero309x](https://github.com/Kero309x)** — Project Creator, Lead Reverse Engineer & Architecture Lead
* **[Ahmed Ramzy](https://www.facebook.com/ahmd.ramzy.101)** — Project Contributor & Research Helper

## Framework & Dependencies
* The project utilizes the open-source **Morphe Patches Development Scaffolding** (<https://github.com/MorpheApp/morphe-patches-template>), licensed under the **GNU General Public License v3.0**.
* Bytecode analysis and transformations are executed using the standard ASM and Morphe patch pipelines.
