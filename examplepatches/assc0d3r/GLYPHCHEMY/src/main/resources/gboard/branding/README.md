# Gboard branding artwork

Six PNG images supplied for these patches (the parakeet artwork is the default icon) are resized with Lanczos resampling:
192×192 for the legacy launcher and 432×432 for the adaptive foreground.
Adaptive foregrounds use an 18dp inset in the 108dp icon canvas. Their
background color comes from the source image's top-left pixel, or white when
that pixel is transparent. The bundled `sources.json` records each original
filename and SHA-256 digest.

The Google and Gboard names and marks belong to Google LLC. These choices are
user-selected launcher artwork for a patched copy and do not imply affiliation.
