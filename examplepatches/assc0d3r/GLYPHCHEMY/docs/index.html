GET STARTED

Start with Morphe.
Make it yours.

Choose the patches you want, keep the ones you don't off, and build your own Gboard setup.

Add GLYPHCHEMY to Morphe ↗
  1. 01

    Add the source

    Open Morphe → Settings → Sources → Add Source. Use the one-tap button or the repository URL.

    https://github.com/assc0d3r/GLYPHCHEMY
  2. 02

    Choose your Gboard build

    Open the Patcher tab and select the exact Gboard build installed on your device.

  3. 03

    Select your patches

    Review each patch's description, default state, dependencies and compatibility before enabling it.

  4. 04

    Patch and install

    Run the patcher, install the generated APK and follow Android's signing/package requirements.

!

Important: A patched APK is re-signed and does not carry Google's signing key. Do not assume it can update stock Gboard in place. The Change package name patch changes package identity and has additional setup implications—read its patch description before using it.

A NOTE BEFORE YOU MIX

Power deserves
a little care.

Some patches change more than appearance. Several are disabled by default because they can alter package identity, network access, permissions, background sync or shell-level behaviour.

  • Read every disabled-by-default patch description before enabling it.
  • Check dependencies and the target Gboard build in Morphe.
  • Download dictionaries before choosing offline-only operation.
  • Understand the implications of disabling Play Services or removing permissions.
