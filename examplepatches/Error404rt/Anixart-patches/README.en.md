## 🚀 Installation

1. Install the original Anixart 10.0.
2. Open Morphe Manager.
3. Click [Open in Morphe](https://morphe.software/add-source?github=Error404rt/Anixart-patches).
4. Select **Remove ads** and the options you need.
5. Build and install the patched application.
