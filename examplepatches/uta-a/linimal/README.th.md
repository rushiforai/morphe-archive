# Linimal

[English](README.md) | [日本語](README.ja.md) | [繁體中文](README.zh-TW.md) | **ภาษาไทย** | [Bahasa Indonesia](README.id.md)

Linimal คือชุดแพตช์ Morphe สำหรับแอป LINE ทางการบน Android (GPL-3.0) ช่วยซ่อนโฆษณาและฟีเจอร์ที่ไม่ได้ใช้ และควบคุมการส่งสถานะอ่านแล้วได้ ทุกฟีเจอร์เปิดหรือปิดแยกกันได้จากหน้าการตั้งค่าของ LINE และเมื่อปิดไว้ LINE จะทำงานเหมือนแอปทางการ

![วิดีโอแนะนำ Linimal (32 วินาที ไม่มีเสียง)](docs/media/linimal-promo.webp)

ชื่อและเนื้อหาแชทที่ปรากฏในวิดีโอแนะนำเป็นเรื่องสมมติ

Linimal เป็นโปรเจกต์อิสระ ไม่ใช่โปรเจกต์ทางการของ LINE หรือ Morphe

## สิ่งที่ทำได้

- **ซ่อนโฆษณา**: Smart Channel ในรายการแชท โฆษณาในหน้าหลัก และโฆษณาใน OpenChat
- **ซ่อนทางเข้า Agent i และ LINE AI**: 9 ตำแหน่งในหน้าหลัก Wallet ช่องค้นหาของรายการแชท แชท เมนู + ในแชท หน้าดูรูปภาพและวิดีโอ และหน้าการตั้งค่า
- **ซ่อนสิ่งที่ไม่ได้ใช้**: แท็บด้านล่าง ไอคอนด้านบนของรายการแชท เมนู + ในแชท และส่วนต่างๆ ในหน้าหลัก
- **อ่านโดยไม่ขึ้นอ่านแล้ว**: อ่านแชทที่เปิดจากเมนูกดค้างหรือจากการแจ้งเตือนได้โดยยังคงเป็นยังไม่อ่าน เมื่ออ่านเสร็จแล้ว กด "ทำเครื่องหมายว่าอ่านทั้งหมด" เพื่อให้ขึ้นอ่านแล้วได้
- **ดูว่าใครอ่านแล้วในกลุ่ม**: แสดงจำนวนผู้อ่านและไอคอนของสมาชิกข้าง "อ่านแล้ว" หรือบนข้อความของผู้อื่น และเปิดรายการสมาชิกที่อ่านแล้วและยังไม่ได้อ่านได้ด้วยการแตะ "อ่านแล้ว" หรือจากเมนูกดค้าง
- **โหมดมืดสีดำสนิท**: ทำให้พื้นหลังและแท็บด้านล่างเป็นสีดำ (`#000000`) สำหรับจอ OLED
- **อื่นๆ**: ซ่อนการแจ้ง LINE Premium ปิดตัวอย่างแชทหรือทำให้เลื่อนได้ เปิดลิงก์ในเบราว์เซอร์ภายนอก และรองรับการแจ้งเตือน การเข้าสู่ระบบ Google และการสำรองข้อมูล

โฆษณา Premium และ Agent i / LINE AI จะถูกซ่อนจากหน้าจอเท่านั้น ไม่ได้เปลี่ยนการส่งโฆษณา การเรียกเก็บเงิน หรือการสื่อสารของ LINE

## การติดตั้ง

### Morphe Manager (Android)

เปิดลิงก์ด้านล่างบนอุปกรณ์ Android เพื่อเพิ่ม Linimal เป็นแหล่งแพตช์ใน Morphe Manager โดย Morphe จะตรวจพบรุ่นใหม่โดยอัตโนมัติ

[**➕ เพิ่ม Linimal ใน Morphe**](https://morphe.software/add-source?github=uta-a/linimal)

หากต้องการเพิ่มจากไฟล์ `.mpp` ให้แตะ `+` ในหน้าแหล่งแพตช์ เลือก `Local` แล้วเลือก `patches-*.mpp` จาก[หน้ารุ่นที่เผยแพร่](https://github.com/uta-a/linimal/releases) วิธีนี้จะไม่อัปเดตอัตโนมัติ

เลือกไฟล์ APKM ของ LINE แล้วใช้แพตช์ `Linimal`

### Morphe Desktop (CLI)

ต้องใช้ Java 21 ขึ้นไป

```sh
java -jar morphe-desktop-*-all.jar patch \
  --patches patches-*.mpp \
  --out line-linimal.apk \
  <APKM ของ LINE>
```

### การย้ายจาก LINE ทางการ

LINE ที่ติดตั้งแพตช์แล้วมีลายเซ็นต่างจากแอปทางการ จึงติดตั้งทับแอปทางการไม่ได้ ให้ย้ายตามลำดับต่อไปนี้

1. [เตรียม MicroG-RE](#ใช้-microg-re-สำหรับการเข้าสู่ระบบ-google-และการสำรองข้อมูล) ให้เรียบร้อย
2. ในแอป LINE ทางการ สำรองแชทไปยัง Google ไดรฟ์
3. ถอนการติดตั้ง LINE ทางการ แล้วติดตั้ง LINE ที่ใช้แพตช์ Linimal
4. เข้าสู่ระบบ แล้วกู้คืนข้อมูลจาก Google ไดรฟ์

## วิธีใช้

`Linimal` จะถูกเพิ่มไว้ที่ด้านล่างสุดของหน้าการตั้งค่า LINE การตั้งค่าแบ่งเป็น 7 หน้า ได้แก่ `โฆษณา` `Agent i และ LINE AI` `ซ่อนรายการ` `อ่านแล้ว` `ผู้ที่อ่านแล้ว` `ธีม` และ `ทั่วไป`

หน้าการตั้งค่า ข้อความแจ้ง และการแจ้งเตือนของ Linimal จะแสดงเป็นภาษาญี่ปุ่น อังกฤษ จีนตัวเต็ม ไทย หรืออินโดนีเซีย ตามภาษาที่แสดงใน LINE ส่วนภาษาอื่นจะแสดงเป็นภาษาอังกฤษ

ค่าเริ่มต้นคือค่าเมื่อติดตั้งใหม่ เมื่ออัปเดต การตั้งค่าเดิมจะยังคงอยู่ ฟีเจอร์ที่หาเป้าหมายไม่พบ เช่น เพราะ LINE มีการเปลี่ยนแปลง จะถูกปิดใช้งานโดยอัตโนมัติและเปลี่ยนในหน้าการตั้งค่าไม่ได้

การตั้งค่าด้านการแสดงผลที่ซ่อนองค์ประกอบบนหน้าจอจะมีผลหลังรีสตาร์ทแอป เมื่อเปลี่ยนการตั้งค่า จะมีหน้าต่างถามว่าจะรีสตาร์ทหรือไม่

## อ่านโดยไม่ขึ้นอ่านแล้ว

ระงับการส่งสถานะอ่านแล้วและการล้างสถานะยังไม่อ่านในเครื่อง เฉพาะในเซสชันการอ่านของแชทปกติที่เปิดจากเมนูกดค้างเท่านั้น

### วิธีเปิด

ใน LINE 26.16.0 บัญชีที่ใช้ตัวอย่างแบบเลื่อนได้ เมื่อกดค้างที่แชทจะเปิดหน้าตัวอย่างแทนเมนู ในกรณีนี้ Linimal จะเพิ่มแถวเดียวกันไว้ที่ต้นเมนูด้านล่างของตัวอย่าง หากเปิด "ปิดการแสดงตัวอย่างแชท" ในหน้า "ทั่วไป" แล้วรีสตาร์ท การกดค้างจะเปิดเมนูแบบเดิม และแถวเดียวกันจะแสดงในเมนูนั้น เมื่อแตะ ตัวอย่างจะปิดลงและแชทจะเปิดขึ้นโดยไม่ขึ้นอ่านแล้ว โดยค่าเริ่มต้น การเลื่อนตัวอย่างได้หรือไม่จะเป็นไปตามการทำงานของ LINE เอง หากเปิด "ให้เลื่อนตัวอย่างแชทได้" ในหน้า "ทั่วไป" แล้วรีสตาร์ท จะเลื่อนได้ การตั้งค่านี้ไม่ได้เพิ่มหน้าตัวอย่างให้บัญชีที่ไม่มีตัวอย่าง และไม่เปลี่ยนการเรียกเก็บเงินหรือการสื่อสาร การระงับจะไม่ถูกยกเลิกเมื่อแอปไปอยู่เบื้องหลังชั่วคราว ล็อกหน้าจอ ดูรูปภาพหรือวิดีโอ หรืออ่านเป็นเวลานาน เมื่อหน้าจอถูกสร้างใหม่เพราะการเปลี่ยนแปลงการกำหนดค่า เซสชันจะดำเนินต่อเฉพาะเมื่อเครื่องหมายของเซสชันที่บันทึกไว้ตรงกัน

### สิ่งที่แสดงระหว่างอ่านและ "ทำเครื่องหมายว่าอ่านทั้งหมด"

ขณะที่ปิดสถานะอ่านแล้ว จะแสดงข้อความ "ขณะนี้ปิดสถานะอ่านแล้ว เมื่อส่งข้อความจะขึ้นว่าอ่านแล้ว" ไว้ใต้ส่วนหัวที่มีชื่อแชทตลอดเวลา ตำแหน่งของส่วนหัวไม่เปลี่ยน ข้อความจะแสดงอีกครั้งเมื่อกลับมาจากเบื้องหลังหรือหน้าจอล็อก และจะหายไปเมื่อการส่งข้อความทำให้สถานะอ่านแล้วกลับมาทำงาน หรือเมื่อออกจากแชท ข้อความนี้ไม่แสดงในแชทที่เปิดตามปกติ

ปุ่ม "ทำเครื่องหมายว่าอ่านทั้งหมด" จะลอยอยู่เหนือช่องพิมพ์ข้อความ
ด้านล่างของรายการจะเว้นพื้นที่ตามความสูงของปุ่ม เพื่อไม่ให้ปุ่มบังข้อความล่าสุด

เมื่อแตะ จะเรียกการทำเครื่องหมายว่าอ่านแล้วและการล้างสถานะยังไม่อ่านของ LINE เอง เมื่อสำเร็จจะจบเซสชันการอ่านและกลับสู่ LINE ตามปกติ
หากถูกขัดจังหวะก่อนส่ง เซสชันจะดำเนินต่อ หากการสื่อสารล้มเหลว การทำเครื่องหมายว่าอ่านแล้วของ LINE เองจะเก็บคำขอไว้และส่งใหม่ จึงกลับสู่ LINE ตามปกติได้ทันที
ใช้ได้แม้จะเปิด "ไม่ขึ้นอ่านแล้วแม้ส่งข้อความ" หรือ "หยุดการขึ้นอ่านแล้วอัตโนมัติในแชท" ไว้

ไม่มีวิธีทำเครื่องหมายว่าอ่านแล้วเฉพาะถึงข้อความที่ต้องการ เนื่องจากยืนยันบนอุปกรณ์จริงแล้วว่า แม้จะส่งเฉพาะตำแหน่งที่แตะ LINE เวอร์ชันเว็บทางการของอีกฝ่ายก็ยังขึ้นอ่านแล้วทุกข้อความ จึงได้ยกเลิกฟีเจอร์นี้

### เมื่อส่งข้อความ

โดยค่าเริ่มต้น เมื่อส่งข้อความระหว่างอ่าน การระงับจะสิ้นสุด และ LINE จะใช้การทำงานที่มีอยู่เพื่ออัปเดตสถานะยังไม่อ่านในเครื่องและสถานะอ่านแล้วที่ส่งถึงอีกฝ่าย ณ ขณะนั้น ครอบคลุมการส่งข้อความ สติกเกอร์ รูปภาพ และอื่นๆ ที่เข้าคิวส่งจากส่วนของ UI แชทที่ตรวจสอบแล้ว การยกเลิกการพิมพ์หรือความล้มเหลวก่อนเข้าคิวจะไม่ยกเลิกการระงับ และไม่รอให้การส่งผ่านเครือข่ายเสร็จสิ้น แม้จะเปิด "หยุดการขึ้นอ่านแล้วอัตโนมัติในแชท" ไว้ ก็อนุญาตให้อัปเดตสถานะอ่านแล้วนี้หนึ่งครั้ง หลังจากนั้นจะเป็นไปตามการตั้งค่าเดิม

"ไม่ขึ้นอ่านแล้วแม้ส่งข้อความ" มีค่าเริ่มต้นเป็น OFF เมื่อเปิด แชทที่เปิดโดยไม่ขึ้นอ่านแล้วจากเมนูหรือการแจ้งเตือนจะยังคงระงับและคงป้ายยังไม่อ่านไว้แม้หลังส่งข้อความ และข้อความแจ้งด้านบนจะเปลี่ยนเป็น "ขณะนี้ปิดสถานะอ่านแล้ว แม้ส่งข้อความก็จะไม่ขึ้นว่าอ่านแล้ว" ไม่เปลี่ยนสถานะอ่านแล้วของแชทที่เปิดตามปกติ ค่าการตั้งค่าเดิมจะยังคงอยู่ และการอัปเดตจะไม่เปิดการตั้งค่าใหม่นี้เอง

**ข้อควรระวัง: แม้คุณอ่านหรือตอบกลับแล้ว อีกฝ่ายจะยังเห็นว่ายังไม่อ่าน การสนทนาจริงจะไม่ตรงกับสถานะอ่านแล้ว ซึ่งอาจทำให้เกิดความเข้าใจผิดหรือปัญหาได้ โปรดเปิดใช้เฉพาะเมื่อจำเป็น**

### เมื่อจบการอ่าน

การระงับจะสิ้นสุดเมื่อปิดแชท สลับไปแชทอื่น หรือปิดการตั้งค่าอ่านโดยไม่ขึ้นอ่านแล้วที่ใช้เปิดแชทนั้น การเปิดแชทเดิมใหม่ตามปกติจะไม่ทำให้การระงับเดิมกลับมา หากปิดเฉพาะ "ไม่ขึ้นอ่านแล้วแม้ส่งข้อความ" สถานะอ่านแล้วจะถูกอัปเดตเมื่อส่งข้อความครั้งถัดไป เฉพาะการจองสำหรับหน้าจอแชทที่ยืนยันไม่ได้ว่าถูกสร้างขึ้นเท่านั้นที่จะถูกทิ้งหลัง 30 นาทีตามนาฬิกาแบบ monotonic หากตรวจสอบเจ้าของหรือตรวจจับการสิ้นสุดไม่สำเร็จ จะกลับไปใช้การทำเครื่องหมายว่าอ่านแล้วของ LINE เอง

### เปิดจากการแจ้งเตือน

เมื่อเปิด "เปิดจากการแจ้งเตือนโดยไม่ขึ้นอ่านแล้ว" การระงับแบบเซสชันการอ่านเดียวกันจะใช้กับแชทปกติที่เปิดจากการแจ้งเตือนข้อความด้วย การได้รับการแจ้งเตือนเพียงอย่างเดียวจะไม่เริ่มการระงับ การเปิดแชทตามปกติ เช่น จากรายการแชท และการตอบกลับหรือการทำเครื่องหมายว่าอ่านแล้วจากการแจ้งเตือน ไม่อยู่ในขอบเขตของการตั้งค่านี้ เส้นทางอื่น เช่น OpenChat ก็ไม่รวมด้วย หากปิดการตั้งค่าฝั่งการแจ้งเตือน จะยกเลิกเฉพาะเซสชันที่เริ่มจากการแจ้งเตือน

## ผู้ที่อ่านแล้ว

รายการสร้างจากบันทึกการอ่านที่ LINE บันทึกไว้ในอุปกรณ์นี้เพื่อแสดง "อ่านแล้ว N" จำนวนคนจึงตรงกับ "อ่านแล้ว N" Linimal ไม่บันทึกสถานะการอ่านเองหรือส่งสถานะอ่านแล้วแต่อย่างใด

- ใช้กับกลุ่มและแชทหลายคน ไม่แสดงในแชทแบบตัวต่อตัวและ OpenChat
- สมาชิกที่ยังไม่ได้อ่านคือสมาชิกปัจจุบันที่ไม่รวมสมาชิกที่อ่านแล้ว ตัวคุณและผู้ส่งจะไม่อยู่ในรายการ
- ชื่อที่แสดงจะใช้ชื่อที่คุณตั้งไว้ก่อน ไอคอนจะดึงภาพขนาดย่อจาก CDN สาธารณะเดียวกับที่ LINE ใช้ (`profile.line-scdn.net`) และเก็บไว้ในหน่วยความจำเท่านั้น
- เมื่อเปิด `ซิงค์กับเซิร์ฟเวอร์เมื่อเปิดรายการ` ทุกครั้งที่เปิดรายการ จะเรียกการซิงค์สถานะการอ่านแบบเดียวกับที่ LINE ทำเป็นระยะ เฉพาะแชทนั้น แล้วแสดงรายการใหม่ เมื่อปิด จะใช้เฉพาะบันทึกในอุปกรณ์และไม่มีการสื่อสารเพื่อซิงค์

## การแจ้งเตือนและการเชื่อมต่อกับ Google

### รับการแจ้งเตือนแม้ปิดแอป

LINE ที่ติดตั้งแพตช์แล้วมีลายเซ็นเปลี่ยนไป หากไม่ตั้งค่าใดๆ จะไม่ได้รับการแจ้งเตือนขณะปิดแอป การตั้งค่านี้จะแทนที่ข้อมูลลายเซ็นที่ส่งให้ Google เมื่อลงทะเบียนการแจ้งเตือนด้วยข้อมูลของ LINE ทางการ ไม่ต้องเตรียมการใดๆ เพิ่มเติม

### ใช้ MicroG-RE สำหรับการเข้าสู่ระบบ Google และการสำรองข้อมูล

หากไม่ตั้งค่าใดๆ LINE ที่ติดตั้งแพตช์แล้วจะเข้าสู่ระบบด้วยบัญชี Google และสำรองหรือกู้คืนข้อมูลกับ Google ไดรฟ์ไม่ได้ การตั้งค่านี้จะใช้ [MicroG-RE](https://github.com/MorpheApp/MicroG-RE) เฉพาะสำหรับการยืนยันตัวตนดังกล่าว ก่อนใช้งานต้องเตรียมการดังนี้

1. ติดตั้ง[รุ่นทางการของ MicroG-RE](https://github.com/MorpheApp/MicroG-RE/releases) รุ่นที่ไม่ใช่รุ่นทางการ (fork อื่นหรือที่บิลด์เอง) จะไม่ถูกใช้
2. เพิ่มบัญชี Google ที่ใช้เข้าสู่ระบบและสำรองข้อมูล LINE ลงใน MicroG-RE ในการสำรองข้อมูล จะมีให้เลือกเฉพาะบัญชีที่เพิ่มไว้ใน MicroG-RE หากเคยตั้งค่าการสำรองข้อมูลอัตโนมัติด้วยบัญชีอื่น โปรดเลือกบัญชีใหม่ในการตั้งค่าการสำรองข้อมูล

หากพยายามเข้าสู่ระบบด้วยบัญชี Google สำรองข้อมูล หรือกู้คืนข้อมูลโดยไม่มี MicroG-RE จะมีข้อความและการแจ้งเตือนแนะนำการติดตั้ง ข้อความจะแสดงแม้ยังไม่ได้อนุญาตการแจ้งเตือนหลังติดตั้งใหม่

หากการสำรองหรือกู้คืนข้อมูลล้มเหลวด้วยข้อความ "ไม่สามารถเข้าถึง LINE ได้" จะแสดงความล้มเหลวในการเชื่อมต่อกับ MicroG-RE หรือข้อผิดพลาดที่ MicroG-RE ส่งกลับมา (เช่น `NetworkError`) ในการแจ้งเตือน "การยืนยันตัวตนกับ Google ไดรฟ์ล้มเหลว" การแจ้งเตือนยังระบุเวอร์ชันของ MicroG-RE, LINE และ Android ด้วย (ไม่มีอีเมลของคุณ) เมื่อรายงานปัญหา โปรดแนบเนื้อหาของการแจ้งเตือนนี้ หากล้มเหลวโดยไม่มีการแจ้งเตือน ให้ตรวจสอบก่อนว่าอนุญาตการแจ้งเตือนของ LINE แล้ว (รวมถึงหมวดหมู่ "Linimal: ข้อผิดพลาดการยืนยันตัวตนสำหรับการสำรองข้อมูล") หากอนุญาตแล้วแต่ยังไม่มีการแจ้งเตือน อาจล้มเหลวในขั้นตอนอื่นนอกจากการรับ token เช่น การสื่อสารกับ Google ไดรฟ์

> [!WARNING]
> ฟีเจอร์การแจ้งเตือนและการเชื่อมต่อกับ Google นี้จะแจ้งลายเซ็นของแอปต่อ Google อย่างไม่ถูกต้องว่าเป็นของแอปทางการ ซึ่งอาจขัดต่อข้อกำหนดการใช้งานของ Google หรือ LINE และไม่อาจตัดความเป็นไปได้ที่จะส่งผลต่อบัญชี Google ของคุณ นอกจากนี้ยังอาจใช้งานไม่ได้เนื่องจากการเปลี่ยนแปลงฝั่ง Google หรือ MicroG-RE

## การพัฒนา

การบิลด์ต้องใช้ Java 17 และข้อมูลรับรองสำหรับอ่าน GitHub Packages ของ Morphe ให้ตั้งค่า `gpr.user` และ `gpr.key` ใน `~/.gradle/gradle.properties` หรือส่งผ่านตัวแปรสภาพแวดล้อม `GITHUB_ACTOR` และ `GITHUB_TOKEN` อย่าเก็บข้อมูลรับรองไว้ในรีโพสิทอรี

```sh
./gradlew test buildAndroid
```
