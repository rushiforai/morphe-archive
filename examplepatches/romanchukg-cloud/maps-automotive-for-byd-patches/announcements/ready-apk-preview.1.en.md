🗺 Maps Automotive for BYD — preview 1 / build 26 (TEST)

Ready-to-install Maps Automotive for Android head units: this APK targets confirmed BYD BEVs using CCS2. Phone Maps can stay installed.

• Instrument cluster controls and map settings.
• Optional live BYD battery/range, automatic reader startup and charging-stop planning.

Requires MicroG-RE (tested: 7.2.1): https://github.com/MorpheApp/MicroG-RE/releases
Sign in separately; allow Contacts/Location.

For EV data, enter your battery capacity, enable both reader options, authorize ADB and allow Maps background/startup in BYD settings.

Car results are from build25 on one Tang; build26 has packaging checks. Driving predictions and other firmware remain unverified.

Same project key as earlier Automotive. A different signer requires reinstalling, clearing local Automotive data. No in-app APK auto-update.
