# Tasks.org #2838 Morphe acceptance

Use Java 21, the existing SDK and an explicitly named disposable rooted AOSP
emulator. Never run this with personal task data or sync accounts. The runner
rejects other AVDs, foreign installations/certificates and non-fixture tasks.
It preserves existing app data, using same-package/same-key updates without
uninstall or data clearing. APKs, keys, private databases, full logs and images
stay ignored under `.scratch/`. Under separate explicit user authorization,
reviewed copies of four raw screenshots and curated provenance were published
as [evidence only](https://github.com/pengusto/penguin-patches/tree/f837da057badfccef1ea7b34d4db039e67c16239/tasks-2838/2026-10-24/).
The patch source and MPP are released; APKs and signing material remain private.

## Build and metadata

With normal GitHub Packages read credentials, run `:patches:buildAndroid`,
`:extensions:tasks:lintRelease` and `:patches:generatePatchesList` using version
`1.0.0-dev.7` and
`-PpatchListOutput=.scratch/tasks-2838/patches-list.json`.
Never manually edit generated metadata. The task explicitly selects the built
MPP and ensures it contains Android patch DEX; other old local MPPs may coexist.

On the current host the verified official plugin/API fallback is already at
`.scratch/tasks-2838/build/local-build.init.gradle`, generated by
[`build_local.py`](../kvaesitso/build_local.py). Reuse it without installing a
second environment:

```sh
export JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home'
export ANDROID_HOME="$PWD/.scratch/android-sdk"
export GRADLE_USER_HOME="$PWD/.scratch/gradle-cache"
./gradlew -Dorg.gradle.jvmargs=-Xmx3g \
  -Pkotlin.compiler.execution.strategy=in-process --max-workers=2 \
  -Dpenguin.root="$PWD" -Dpenguin.plugin="$PWD/.scratch/morphe-gradle-plugin" \
  -Dpenguin.repository="$PWD/.scratch/tasks-2838/build/repository" \
  -I .scratch/tasks-2838/build/local-build.init.gradle \
  -Pgpr.user=local -Pgpr.key=unused-local-build \
  -Pversion=1.0.0-dev.7 \
  -PpatchListOutput=.scratch/tasks-2838/patches-list.json \
  :patches:generatePatchesList :extensions:tasks:lintRelease
```

The explicit heap and worker limit avoid the observed small-heap compiler
failure; they are invocation flags, not machine configuration changes.

## Original regression and patched native UI

```sh
python3 tests/tasks/acceptance.py \
  --original .scratch/tasks-2838/downloads/tasks-fdroid-15.13.apk \
  --mpp patches/build/libs/patches-1.0.0-dev.7.mpp \
  --desktop .scratch/android-tests/artifacts/morphe-desktop-1.18.1-all.jar \
  --sdk .scratch/android-sdk --java-home "$JAVA_HOME" \
  --keystore .scratch/android-user/debug.keystore --key-alias androiddebugkey \
  --serial emulator-5580 --avd-name penguin_kvaesitso_api35 \
  --artifacts .scratch/tasks-2838/acceptance --baseline --disposable-emulator
```

`--baseline` explicitly replaces only the owned synthetic fixture tasks before
the suite. It verifies the original APK hash, identity, certificate and unchanged
re-signed payload, reproduces the absent parent action, then applies the Morphe
patch to the **original** APK. The suite uses fresh accessibility nodes for real
Compose edits, arrow clicks and native dialogs. Reflection observes native
state and lifecycle; it does not substitute fake editor or save implementations.
SQL writes only seed owned synthetic fixtures or simulate a vanished parent.

Same-key update snapshots compare every table in both native databases, raw
shared preferences and datastore files. Native title saves must preserve notes,
parent/date/settings and other-task rows. Results, runtime logs and raw emulator
screenshots (`before.png`, `after.png`, `parent.png`, `draft-dialog.png`) remain
in the given artifacts directory. Screenshots are not generated mockups.

## Bundle, metadata and negative inputs

```sh
mkdir -p .scratch/tasks-2838/tools
TASKS_CP=.scratch/android-tests/artifacts/morphe-desktop-1.18.1-all.jar
"$JAVA_HOME/bin/javac" -cp "$TASKS_CP" -d .scratch/tasks-2838/tools \
  tests/tasks/VerifyTasksBundle.java tests/tasks/ModifiedFixture.java
"$JAVA_HOME/bin/java" -cp "$TASKS_CP:.scratch/tasks-2838/tools" VerifyTasksBundle \
  patches/build/libs/patches-1.0.0-dev.7.mpp \
  patches/build/libs/patches-1.0.0-dev.7.mpp
"$JAVA_HOME/bin/java" -cp "$TASKS_CP:.scratch/tasks-2838/tools" ModifiedFixture \
  .scratch/tasks-2838/downloads/tasks-fdroid-15.13.apk .scratch/tasks-2838/modified-negative.apk
python3 tests/tasks/reject_inputs.py --java "$JAVA_HOME/bin/java" --desktop "$TASKS_CP" \
  --mpp patches/build/libs/patches-1.0.0-dev.7.mpp \
  --original .scratch/tasks-2838/downloads/tasks-fdroid-15.13.apk \
  --patched .scratch/tasks-2838/acceptance/patched.apk \
  --modified-bytecode .scratch/tasks-2838/modified-negative.apk \
  --artifacts .scratch/tasks-2838/negative
python3 tests/tasks/verify_metadata.py --java "$JAVA_HOME/bin/java" --desktop "$TASKS_CP" \
  --mpp patches/build/libs/patches-1.0.0-dev.7.mpp \
  --expected-version 1.0.0-dev.7 --metadata patches-list.json --artifacts .scratch/tasks-2838/metadata-check
```

Never install the deliberately modified negative fixture. Wrong package/version
must select no patches and retain identical DEX; modified/repatched inputs must
fail before output. The bundle verifier rejects app stubs/runtime libraries and
requires all four earlier MPEs to remain byte-identical. Metadata checks compare
the generated version/list with the exact Android MPP and Desktop's inventory.
Compatibility and verification limits are in [docs/TASKS.md](../../docs/TASKS.md).
