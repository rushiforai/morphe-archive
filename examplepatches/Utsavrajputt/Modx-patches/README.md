## 📖 About

**Modx-Patches** is an open-source Android patch development project built on the **Morphe** framework, created and maintained by **Utsav Rajput**.

The project focuses on a clean development workflow, automated releases, and high-quality patch development — powered by modern tooling and continuous improvements.

Whether you're learning how Android patch projects are organized or looking to contribute to an open-source workflow, Modx-Patches gives you a structured foundation to build on.
