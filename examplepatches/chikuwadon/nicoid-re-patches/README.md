nicoid Reは、nicoidを現在のニコニコ動画の再生形式に対応させ、再生・コメント・検索・動画管理の機能を拡張するパッチです。nicoid 6.49の元APKにMorphe Managerでパッチを適用すると、nicoid Reとして利用できます。

---

<a id="installation"></a>

## 導入・更新

nicoid **6.49**の元APKと、Android端末にインストールした**Morphe Manager**を使用します。

### 初めて利用する

1. [Morphe Managerへの追加リンク](https://morphe.software/add-source?github=chikuwadon%2Fnicoid-re-patches&name=nicoid%20Re)を開きます。
2. ソース名とURLを確認し、「追加」をタップします。
3. nicoid **6.49**の元APKを選び、パッチを適用します。
4. 生成されたアプリをインストールします。

### 更新する

「Sources」でnicoid Reの更新ボタン（↻）をタップします。ホーム画面のカードに「Update」が表示されたら、案内に沿って再パッチしてください。

ソースの更新だけでは、インストール済みのアプリには反映されません。アプリにも新しいパッチを適用する必要があります。

### 手動でソースを追加する

追加リンクが開かない場合は、Morphe Managerで「Sources」→「＋」→「Remote」を選択し、次のURLを入力して「Add」をタップしてください。

```text
https://github.com/chikuwadon/nicoid-re-patches
```

<a id="features"></a>

## 機能

<a id="playback"></a>

### 01　再生・操作

- **再生方法**：通常再生・バックグラウンド再生・ポップアップ再生に対応。
- **速度・画質**：通常再生とポップアップ再生で変更可能。再生速度は0.1〜3.0倍のスライダーで調整でき、モバイル通信時の画質も指定可能。
- **アクション**：上下スワイプで音量・輝度を調整。動画の左右をダブルタップしてシーク可能。通常再生・ポップアップ再生で、長押し中だけ指定した再生速度に変更可能。
- **再生動作**：再生位置の保存と、アプリ切替時や再生中に「戻る」を押した際の動作を設定可能。通常再生中に画面をOFFにしても音声を継続する設定に対応。
- **常時表示**：再生中の操作部を常時表示するモードに対応。
- **コメントの盛り上がり**：取得済みコメントの時間分布を、通常再生・ポップアップ再生のシークバーに半透明のグラフで表示。設定で表示を切り替え可能。
- **ポップアップ**：ピンチイン・アウトによるサイズ変更と、縦向き通常再生への専用復帰ボタンに対応。復帰ボタンは操作ボタンのカスタマイズから表示可能。
- **メディアコントロール**：Androidのメディアコントロールから再生を操作可能。
- **タップ領域のカスタマイズ**：操作部を開閉する領域を画面全体・左右端・上下端・中央・最大3つの自由な矩形から選択可能。通常再生・全画面・ポップアップで設定を共有。
- **再生キュー**：次に再生する動画の追加、順序変更、削除に対応。
- **Google Cast**：fMP4形式のHLS再生とテレビ側のコメント表示に対応。
- **イヤホン切断時**：再生を一時停止し、自動再開を抑止。
- **関連動画**：選択メニューからポップアップ再生・バックグラウンド再生・キャッシュ取得を実行可能。
- **複数タブ**：検索・履歴・プレイリストなどを最大64タブまで管理。連続再生・シャッフル再生の設定をタブごとに保存可能。
- **ジェスチャー**：タブの開閉・切替、更新、検索、先頭・読み込み済み末尾への移動、左メニューの各画面やアプリ操作を割り当て可能。

<a id="comments"></a>

### 02　コメント

- **表示調整**：文字サイズ10〜300%、太字、不透明度、影の大きさ、最大行数、表示時間を設定可能。表示時間の変更でスクロール速度を調整可能。
- **コマンド**：コメントコマンドによる色指定・上下固定・文字サイズに対応。
- **描画設定**：描画上限を25・30・60・90・120fpsから選択可能。実際のフレームレートは端末性能と画面の更新頻度に依存。
- **再生速度との連携**：動画の再生速度を変更しても、流れるコメントの速度を等倍に維持。
- **コメント取得**：標準のコメントに加え、過去コメントを含めて最大10,000件または無制限の取得目標を設定可能。実際の取得数は配信元や端末の状態に依存する。
- **一覧操作**：再生位置に合わせた自動スクロール、自動追従の切り替え、並べ替えに対応。コメントのダブルタップで、そのコメントの再生時間へ移動可能。
- **ニコる**：コメント一覧からニコる操作が可能。ニコる数の表示と、ニコる数順の並べ替えに対応。

<a id="filters"></a>

### 03　NG・コンテンツフィルター

- **NGコメント**：一覧から追加・削除・複数削除が可能。
- **動画の非表示**：動画タイトルのキーワードや投稿者・チャンネル名を条件として設定可能。
- **一致方法**：部分一致・完全一致・正規表現から選択可能。
- **ルール管理**：有効・無効の切り替え、個別削除・複数削除に対応。
- **長押し操作**：NGルールの長押しで個別削除可能。動画操作メニューから投稿者NGを登録可能。

<a id="discovery"></a>

### 04　ランキング・検索

- **ランキング**：ジャンルの並べ替え・非表示に対応。最大1,000位まで追加読み込み可能。
- **カスタムランキング**：ジャンルとタグ条件を組み合わせて作成・編集可能。
- **検索条件**：投稿日・動画時間・再生数の範囲を指定可能。再生数の範囲を指定した場合はスナップショット検索を使用する。
- **検索操作**：入力サジェストと、検索結果の先頭でのスワイプ更新に対応。
- **ショート動画**：ニコニコショートの視聴に対応。
- **一覧表示**：有料動画にラベルを表示。各項目で情報配置を統一。
- **視聴進捗**：動画のサムネイル下端に再生位置を示すバーを表示可能。設定から表示を切り替え可能。

<a id="library"></a>

### 05　キャッシュ・プレイリスト

- **キャッシュ管理**：保存先の変更と、容量・取得率・取得状態の確認に対応。
- **ローカルプレイリスト**：アカウントから独立して管理し、フォルダーの作成・名前変更・移動・削除で整理可能。動画URL・動画IDからの追加にも対応。
- **再生方法**：連続再生・シャッフル再生に対応。
- **MP4保存**：動画をMP4形式で保存可能。保存したMP4は外部アプリで再生可能。
- **一覧操作**：動画リストの長押しで操作メニューを表示。複数選択による動画管理に対応。

<a id="following"></a>

### 06　フォロー・動画情報

- **フォロー管理**：動画情報から投稿者をフォロー・解除可能。公開マイリストのフォロー・解除にも対応。
- **フォロー一覧**：ユーザー・チャンネル・マイリストの確認が可能。
- **ニコレポ**：投稿者や活動の種類による絞り込みに対応。
- **マイページ**：プロフィールとアカウントページへのショートカットを表示。カスタマイズ可能なジェスチャー操作に対応。
- **いいね**：動画へのいいね操作に対応。
- **関連作品**：動画情報にシリーズ・親作品・子作品を表示。
- **ニコニ広告**：動画情報から内部ブラウザで表示可能。

<a id="live"></a>

### 07　ニコ生

- **生放送の再生**：ニコ生を通常再生・ポップアップ再生・バックグラウンド再生で視聴。画質切替・全画面表示・Androidメディアコントロールに対応。
- **番組の検索・管理**：放送中・ランキング・番組表・フォロー・視聴履歴・タイムシフト予約の6画面で番組を探して管理。
- **コメント**：リアルタイム表示、コメント投稿、184（匿名）投稿、コピー、NGユーザー・NGワードに対応。
- **視聴機能**：有料・会員無料・一部無料の番組表示、視聴条件の案内、予約の登録・取消、並べ替え、番組表の日付移動に対応。
- **再生の安定性**：暗号化HLSの完成セグメントを優先し、配信情報更新時の不要な再生停止を抑制。ニコ生の通信・再生情報をデバッグログに出力可能。

<a id="settings"></a>

### 08　テーマ・設定

- **テーマ**：ライト・ダーク・AMOLEDダーク・Material Youに対応。
- **デザイン**：フラットなUI。
- **アンビエントモード**：映像色に応じた周囲の発光効果を通常・全画面・ポップアップで設定可能。発光方向、強さ、広がり、色の応答速度などを調整可能。
- **設定管理**：設定検索、起動時画面の選択、設定のエクスポート・インポートに対応。設定カテゴリの折りたたみが可能。
- **表示・操作**：動画メニューの項目を表示・非表示・並び替え可能。タブ切替アニメーションの有無を設定可能。
- **配色**：アクセント・上部バー・背景・文字の色を個別に設定可能。
- **履歴・起動**：ローカル視聴履歴の保存件数と、起動時に前回のタブを開くかを設定可能。
- **ログイン**：Cookie手動入力によるログインと、設定からのログアウトに対応。
- **補助機能**：メニューからのアプリ再起動と、設定からのデバッグログ保存に対応。
- **対応環境**：Android 16に対応。
- **言語**：日本語・英語・繁體中文に対応。
- **広告**：広告バナーと広告リクエストを削除。

## 使い方

### ニコ生（β版）

> **ニコ生機能は現在β版です。** 番組や通信環境によって、再生・コメント・タイムシフト操作などが正常に動作しない場合があります。

1. 左メニューから「ニコ生」を開きます。画面下部の「放送中」「ランキング」「番組表」「フォロー」「視聴履歴」「タイムシフト予約」で画面を切り替えられます。
2. 「放送中」では、番組タイトル・番組ID・URLで検索でき、放送種別の絞り込みや並べ替えも可能です。
3. 番組をタップすると、設定に応じて通常再生・ポップアップ再生を選択できます。再生中は画質切替、コメントの表示・投稿、バックグラウンド再生などを利用できます。
4. 「タイムシフト予約」では予約の確認・取消ができます。有料・会員限定などの番組は、視聴条件を満たしている必要があります。

ニコ生の表示・非表示、起動時の画面、番組タップ時の動作などは、設定の「ニコ生」から変更できます。

### コメント取得数

設定の「コメント取得数」で、「標準（追加取得なし）」、500〜10,000件（500件単位）、または「無制限」を選べます。500〜10,000件は、最初に取得したコメントを含む合計件数の目標です。変更は次回の再生から反映されます。

動画の再生直後は通常のコメントだけを表示します。「標準」以外では、その後バックグラウンドで過去のコメントを追加取得し、重複を除いて統合します。追加分は1,000件ごとを目安に段階的に表示し、更新は3秒以上の間隔にまとめます。取得が遅い場合は500件以上・5秒以上の間隔でも反映し、取得終了時には残りをまとめて反映します。

追加取得では、サーバーへの負荷やリクエスト制限を抑えるため、通信頻度を自動的に調整します。「無制限」でも、配信元の制限、通信状況、端末のメモリ状況などによって取得が途中で終了する場合があります。設定した件数や動画の全コメントを必ず取得できるわけではありません。

### Cookieでログイン

WebViewでログインできない場合は、設定の「ログイン」から「Cookie手動入力」を選択します。

1. 別の端末・PCでニコニコにログインし、ブラウザの開発者ツールでCookieを確認します。
2. `user_session`の値をコピーし、nicoid Reに貼り付けて保存します。`user_session=値`の形式や、`user_session`を含むCookieヘッダーも入力できます。
3. 動画再生やアカウントのマイリストで動作を確認します。

Cookieの保存だけでは認証の成功は確認できません。期限切れやログアウトで利用できなくなった場合は、Cookieを再取得してください。

> Cookieはログイン情報です。他の人に渡したり、Issueやログに貼り付けたりしないでください。

### デバッグログ

設定の「デバッグ」→「デバッグログの保存」を選び、確認画面で「保存」をタップします。Downloadフォルダーに次のファイル名で保存されます。

```text
nicoid-re_log_yyyyMMddHHmmss.txt
```

## 開発

リポジトリのルートで次のコマンドを実行します。

```sh
./gradlew :patches:buildAndroid --no-daemon
```

生成されるパッチファイルは`patches/build/libs/*.mpp`です。ビルドには、MorpheのGitHub Packagesを読み取るための認証が必要です。
