## Morphe Managerへの追加と更新

### Morpheへリポジトリを追加する

Morphe ManagerをインストールしたAndroid端末で、次のリンクを開きます。Morpheの確認画面でソース名とURLを確認し、「追加」をタップしてください。

[Morpheへnicoid Reを追加](https://morphe.software/add-source?github=chikuwadon%2Fnicoid-re-patches&name=nicoid%20Re)

リンクを開けない場合は、Morphe Managerで次の手順を行います。

1. ホーム画面下部の「Sources」をタップします。
2. 「＋」をタップし、「Remote」を選びます。
3. 次のURLを入力して「Add」をタップします。

```
https://github.com/chikuwadon/nicoid-re-patches
```

### パッチを更新する

リポジトリを追加すると、Morphe Managerが新しいパッチを定期的に確認します。すぐに確認する場合は、「Sources」を開き、nicoid Reのソースカードにある更新ボタン（↻）をタップします。

新しいパッチを適用するには、ホーム画面でnicoid Reのカードに「Update」が表示されたときにカードを開き、画面の案内に沿って再パッチしてください。ソースの更新と、アプリへのパッチ適用は別の操作です。

## 変更点

- Android 16に対応しました。

- アプリ名を「nicoid Re」に変更しました。
- ポップアップ再生の速度・画質選択画面にMaterial Youテーマを適用しました。
- 関連動画の選択メニューに「動画再生」「動画情報」「ポップアップ再生」「バックグラウンド再生」「キャッシュの取得」を追加しました。動画をタップした際の既定動作は元APKの設定を引き継ぎます。
- 再生速度に0.5、0.75、1.0、1.15、1.25、1.4、1.5、1.75、2.0倍を追加しました。
- プレイヤー設定にデフォルト再生速度を追加しました。
- アプリ切替時の動作を「何もしない」「バックグラウンド再生」「ポップアップ再生」から設定できるようにしました。初期値は「何もしない」です。
- 再生位置の保存を設定できるようにしました。初期値はOFFです。
- 再生中に「戻る」を押した際の動作を「何もしない」「バックグラウンド再生」「ポップアップ再生」から設定できるようにしました。初期値は「何もしない」です。
- イヤホン切断時に再生を一時停止するようにしました。
- ポップアップ画面で2本指による拡大・縮小を追加しました。従来の移動と角を使ったサイズ変更にも対応し、画面内での位置とサイズを保存します。
- コメントサイズを5段階（60%、80%、100%、120%、140%）から設定できるようにしました。
- Google Castの接続・切断設定をコメント設定の下に移動しました。
- ポップアップ画面に画質・再生速度・ループ再生の操作ボタンを追加し、各ボタンの配置や大きさを調整しました。
- 画質変更後に再生位置と再生・一時停止の状態を引き継ぐようにしました。
- 投稿画面、操作画面、コメント一覧の色や表示をライトテーマ・ダークテーマに合わせました。
- 広告バナーと広告リクエストを停止しました。

## ビルド方法

リポジトリのルートで次のコマンドを実行します。

```sh
./gradlew :patches:buildAndroid --no-daemon
```

生成されるパッチファイルは`patches/build/libs/*.mpp`です。ローカルでビルドする場合は、MorpheのGitHub Packagesを読み取るための認証が必要です。
