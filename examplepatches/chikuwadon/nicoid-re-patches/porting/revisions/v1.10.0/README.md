# nicoid Re 1.10.0

一覧の動画メニュー・長押しダイアログ・再生画面の「MP4で保存」から画質を選び、外部アプリで利用できるMP4を保存する。

- 右メニューの「ダウンロード」から、進行中・保存済み・エラーを確認できる。MP4とキャッシュの種別、進捗、取得済み容量、算出可能な総容量を表示する。
- MP4の取得は既存キャッシュと同じ待ち行列で順番に処理する。既存のキャッシュリストは独立して利用できる。
- キャッシュ設定の末尾にある「MP4の保存先フォルダ」で保存先を選択する。未設定の場合は初回保存時に選択する。
- 保存したMP4は本アプリ内での再生対象ではない。ダウンロード一覧から外部アプリで開く・共有する・削除することができる。
- ダウンロードはキャンセル・一時停止・再取得に対応する。一時停止後の再取得は先頭から行う。
- 動画データの取得後にMP4を作成し、保存先へ書き込む。H.264/AACの分割MP4はアプリ側でサンプルを読み出して結合する。ライブ配信・不連続な配信・非対応の暗号化形式はエラーとして通知する。

- 下線付きのタブはタップまたは左右スワイプで切り替えられる。
- 保存済みの表示中は保存先を定期確認し、外部で削除されたMP4を一覧から除く。保存先へアクセスできないときは履歴を保持する。
- エラー・キャンセルの項目は長押しから履歴を削除できる。タップで開く操作一覧からも選択できる。
