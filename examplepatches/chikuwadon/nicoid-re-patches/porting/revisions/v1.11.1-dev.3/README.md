# nicoid Re v1.11.1-dev.3

Development-only fixes for normal-playback ambient rendering and the ambient
toggle, following v1.11.1-dev.2. Normal and fullscreen light remains outside the
video, while popup retains its limited inner edge. The normal exterior halo
uses a decor-scoped drawable that preserves comment and control colors.
The playback toggle updates visually on touch, defers resource-heavy refresh
and re-arms the sampler after being enabled. The tablet layout and existing
ambient presets remain unchanged.

No tag, main update, official release, or public release artifact.
