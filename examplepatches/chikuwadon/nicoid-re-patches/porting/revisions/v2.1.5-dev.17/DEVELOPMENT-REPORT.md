## 目的

タブそのものの選択ではなく、検索結果・ランキング・関連動画・公開マイリスト等、タブ内で開いた**動画一覧**から複数動画をまとめて登録できるようにする。プレイリスト・アカウントマイリスト・視聴履歴などの複数選択導線も短縮する。

## 画面ごとの選択仕様

| 画面 | 選択開始 | 選択中の主要操作 |
|---|---|---|
| 検索結果、ランキング、関連動画、公開マイリストの共通動画一覧 | \`︙ → 複数選択\` | **登録のみ**（削除は出さない）、全選択・全解除・完了 |
| 本体視聴履歴／アカウント視聴履歴 | ソートバー右の常設アイコン | **削除 + 登録 + 完了** |
| ローカルプレイリスト／アカウントマイリスト／とりあえずマイリスト | ソートバー右の常設アイコン | 既存の**削除 + 移動 + 完了**を維持。「登録」は重複追加しない |
| キャッシュリスト | ソートバーの既存選択処理と専用アイコン | 既存の保存・選択操作を保持 |
| 下部の「キャッシュリスト」タブ | タブ名の**左側**に保存を示すアイコン | 選択モードのボタンとは別のタブ装飾 |
| ニコレポ | 対象外 | \`︙\` に**更新のみ** |

選択をメニューから開始する場合は既存のネイティブメニューID \`1\` に合わせ、項目は**再生キューの下**に置く。ソートSpinnerと既存のソート・カスタム順は保持する。

## 選択ボタン・フッター

- 通常時はチェック付きリスト、選択中は終了を示す「×」のアイコンを表示。どちらも**30dp**、タップ領域は**48×48dp**。アクセントカラーと読み上げ説明を同期。
- 1回押すと選択開始、選択中に再押下で解除。長押しから選択した場合も状態を同期。
- 視聴履歴の「登録」は塗りつぶしではなく既存の「移動」と同種の**文字型**で、削除との左余白は**20dp**。
- 探索系リストでは削除ボタンを登録に差し替えるため、動画を誤って削除するUIは出さない。
- プレイリストの削除確認本文は、数字だけではなく「何件削除するか」、最大3本のタイトルと「ほかN件」を表示。既存の確認処理は維持。

## 登録先と実装

選択済み動画に対して次の3つから登録先を選べる。

1. **ローカルプレイリスト**: 既存のフォルダー選択 \`LocalPlaylists.choose\` と \`LocalPlaylists.change\` を利用。既存データ管理の重複判定を維持。
2. **アカウントのマイリスト**: 一覧取得 \`GET /v1/users/me/mylists\`、既存リスト選択（または新規作成）。追加は \`POST /v1/users/me/mylists/{id}/items\` を動画ごとに逐次呼び出す。
3. **とりあえずマイリスト**: 同登録APIで \`deflist\` を指定。

動画IDは \`sm\` / \`nm\` / \`so\` / \`ss\` 等を確認、選択済み行からタイトル・URL等を収集し、重複IDは抑制する。登録処理はワーカーで順番に実行し、同じActivityでの多重開始を防止。「登録／スキップ／失敗」件数を通知する。オンライン側の成功／失敗は個別に発生し得る。

## 多言語・ニコレポ

日本語・英語・**繁体字中国語**の三言語に対応。追加辞書には「再生キュー」「再生待ちの動画はありません」「再生キューから削除しますか？」「複数選択」「一括登録」「全選択」「全解除」「移動」「完了」「登録」を含む。新規UIは既存の \`UiStrings\` のアプリ内言語設定に従う。

- 動的タイトル \`◯◯の投稿動画\` は、投稿者名を維持して英語 \`◯◯'s uploaded videos\` / 中国語 \`◯◯ 的投稿影片\` に変換。
- ニコレポの専用「更新」と共通タブ「更新」の二重生成を防止。
- 別タブの三点メニュー表示後にニコレポへ切り替えると直前のメニューが残る問題を修正。保存済み \`LocalPlaylists.PAGES\` だけでなく、現在の \`nicoid_local_playlists\` 表示状態によりプレイリストメニューの生成を判定。プレイリストデータは保持。
