# v2.1.5-dev.6 — コメントFPS計測と重なり防止ON時の表示見送り

Base: v2.1.5-dev.5 (`26206205239773bd0739160cd94968a849753e9c`)

- 既存のMedia3再生フリーズ対策、コメントサイズ切替処理、Morphe/MPP構造を保持
- 重なり防止ONでは空きレーンを短時間待ち、100ms後も衝突する新着コメントのみ表示見送り
- 大きな先頭コメントが詰まっても後続8件を最大限調査し、表示可能なものを投入
- OFFでは描画間引きを行わない
- コメントの既存位置・移動速度・寿命を変更しない。画面切替時に待機期限を延長しない
- 10秒間隔の軽量なフレーム処理診断（draw callback、索引走査時間、表示中/待機数、見送り数）を追加
- 描画コールバックFPSは実表示FPSではない。Surface/TextureのCanvas取得・投稿時間は含まない
- 元データを削除せず、コメント一覧のデータを維持

## 注意・残課題

- 今回の版ではネイティブの全入力更新経路を網羅していないため、`CommentSource280.sameEntries()`の全件照合は安全性のため維持
- 既存コメント描画ループが使用する高精度Q16周期の実MPP確認とTextureView/VSYNC追加調査は次の段階
- コメント表示見送り数と描画FPSはユーザー端末で要実測
- 正式リリースではなく実機検証用devのみ
