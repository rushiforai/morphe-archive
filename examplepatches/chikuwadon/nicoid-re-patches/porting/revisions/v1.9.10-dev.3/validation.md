# v1.9.10-dev.3 verification revision

Popup window width is authoritative for native corner resizing and pinch. The previous native corner code changed child dimensions while control layout restored the old WindowManager width. Popup media height and optional control-row heights are now separate. PopupControls193 delegates layout to PopupLayout236, posts coalesced layout notifications outside the current pass, and fills the VideoView parent viewport instead of publishing competing absolute dimensions. Direct mini sessions bypass popup control layout. Native drag and existing double-tap/seek/button routes remain in use outside corner resize streams. Terminal-frame capture is retained and now uses the corrected viewport. Terminal capture and final window bounds have diagnostic entries.

Both normal retained sessions and direct Service sessions use MiniChrome236. This restores matching thumbnail/title/author/button geometry and vertically centered loading text. Metadata uses native tickerText/M/infodata/FeedbackMedia and thumbImage, rather than only the wrong thumbnailUrl key. Direct sessions bind before native cleanup, discover the created player without depending exclusively on the prepared callback, preserve the Service decoder, and enable the video renderer when hosting it. Touch streams request interception protection and animate continuously; cancel, detach and close remove animations/listeners. Restore uses the existing Service-to-normal transfer, so decoder continuity/reloading during that transfer remains unverified on hardware. It is not the retained-Activity restore path.

Validation: 60 Robolectric tests passed on SDK 28/34, with runtime-helpers.jar regenerated from the candidate helpers-final.dex. Tests include repeated actual popup-layout delegation, separated controls/media geometry, all four corners, saved window bounds, shared native metadata presentation, direct-service binding/discovery, continuous drag and cancelled-session teardown. 49,294 invocation argument-word checks and 11,798 defined-target dispatch checks passed. All 800 PNG contracts/28 icon families retained. Original extension payload and accepted dev.2 resources retained byte for byte. Accepted tab Java sources are unchanged. PlaybackRulesTest (139 checks), RankingRules190Test and ContentHistoryRulesTest passed.

Physical-device popup movement/scaling, native ExoMedia/TextureView output, terminal PixelCopy and subjective responsiveness remain unverified. This is a verification branch only, not an official release.

Rebuild: use the same baseline staging/toolchain as dev.2, apply native-overrides to native, retain helpers-overrides, run build.py, regenerate runtime-helpers.jar with dex2jar, then run verify.py with runtime-classpath.txt pointing at the candidate classes and runtime helper JAR.
