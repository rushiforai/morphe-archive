# v1.10.6 — Stable release source

Production build source for the approved v1.10.6 patch release.

- Centered tab list with gesture entry, drag sorting, last-closed-tab restore, and a combined tab-bar-button visibility setting
- Optional audio focus and opt-in recognition for vertical-only gestures; improve gesture sensitivity explanations
- Popup seek bar and control touch reliability and account watch-history tab restoration
- Avoid duplicate tabs for identical ranking categories/periods; update ranking periods in-place without Activity recreation
- Retain v1.10.5 fixes and compatibility with nicoid 6.49
- Security and lifecycle audit, JVM model regressions, dex/MPP version integrity and packaged-payload parity checks

Full user-facing changes are in `.github/release-notes/v1.10.6.md`.
