# nicoid Re v1.11.1-dev.9

Development-only ambient layout correction.

Normal portrait light continues behind the current video-info page after the
tab strip, keeping text, thumbnails, and icons above the glowing background.
The landscape right-side video-info page draws a matched right halo and soft
right-upper/right-lower corners in its own background instead of tinting
front-facing controls.

Normal-only fade now preserves the selected preset's full reach (including
Vivid), with no change to the native fullscreen or popup draw profile.
The stable Ambient ON/OFF toggle and tablet fullscreen-exit fix are retained.

All changes are unverified on physical devices until user testing. Do not
publish or update the stable v1.11.0 release.
