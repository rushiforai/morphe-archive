# nicoid Re v1.11.0

Production release candidate based on verified v1.10.7-dev.19.
Includes ambient lighting, custom single-tap control regions, ranking tabs,
gesture shortcuts, retained playback/notification return, and portable
settings backups with no-light capture suppression.

The release remains manual: GitHub Actions Release workflow requires
workflow_dispatch on main plus the explicit APPROVE confirmation.
No tags, releases or issue states are changed by staging this source.

The release workflow will generate CHANGELOG.md and patch metadata on
publication, attach patches-1.11.0.mpp and provide GitHub source
code archives (ZIP and tar.gz).
