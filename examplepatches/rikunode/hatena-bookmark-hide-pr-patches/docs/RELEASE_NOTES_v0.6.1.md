# Hoshiori v0.6.1 — 設定入口の修正

Hatena Bookmark 5.80（versionCode 58000）専用。

- 元アプリの設定画面にHoshioriが表示されない不具合を修正しました。対象APKで存在しないPreference.setKey()の呼び出しを削除し、既存のsetIntent()による遷移を利用します。
- 設定項目追加時の失敗をログに記録するようにしました。
- エミュレータで元アプリの設定画面を開き、最下部のHoshioriをタップして専用設定画面の4グループが表示されることを確認済みです。

パッチは9件のままです。他の機能の仕様変更はありません。各機能の実行時切り替えや実機での動作は今回の検証範囲外です。
