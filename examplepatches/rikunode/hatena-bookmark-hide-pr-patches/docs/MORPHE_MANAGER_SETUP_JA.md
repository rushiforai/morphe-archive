# Hoshiori — Morphe Manager導入ガイド

このガイドは、はてなブックマークAndroidアプリ向けの非公式パッチ集「Hoshiori」をMorphe Managerで追加・適用するためのものです。

**現在の公開版はv0.4.5、対象APKはHatena Bookmark 5.80（versionCode 58000）だけ**です。ほかのバージョンに適用しないでください。

## 事前に用意するもの

- Morphe Manager
- 対象バージョンのHatena Bookmark 5.80（versionCode 58000）のAPK
- パッチを適用するAndroid端末

APK本体はこのリポジトリでは配布していません。第三者配布の古いAPKは、署名が正しくても安全性を保証できないため、入手元を慎重に確認してください。

## 1. パッチソースを登録する

Morphe Managerの「Sources（パッチソース）」から、以下のURLを追加してください。

```text
https://github.com/rikunode/hoshiori
```

[パッチソースを追加するリンク](https://morphe.software/add-source?github=rikunode/hoshiori)からも登録できます。

登録後、ソースを更新します。**v0.4.5のパッチが5件表示されること**を確認してください。0件やエラーの場合は、ソースURLとリストの更新状態を確かめ、正常に表示されるまで適用しないでください。

## 2. 対象APKにパッチを適用する

1. Morphe Managerのパッチ適用画面で、Hatena Bookmark 5.80（versionCode 58000）のAPKを選択します。
2. 次の5件から必要なパッチを選択します。初期設定では5件とも有効です。
   - PR記事の非表示
   - 「今週のブクマ数ランキング」のお知らせ非表示
   - アプリ内ブラウザの広告ブロック
   - 記事サイトのCookie・Webストレージ保持
   - 元アプリと併用するためのクローン化
3. 必要に応じてオプションを変更し、パッチを適用します。
4. 生成・署名されたAPKを確認してからインストールします。
5. まず記事一覧と記事の表示を確認し、機能ごとに動作を試してください。

クローン化を選ぶと別パッケージ名でインストールできます。元アプリは削除せずに残せますが、アカウントや設定は引き継がれません。クローン化してもライセンス確認などの理由で起動できない場合があります。

## 3. 主なオプション

| オプションキー | 初期値 | 役割 |
|---|---|---|
| `hideWeeklyRanking` | ON | ランキングのお知らせを非表示にする |
| `blockInAppBrowserAds` | ON | 記事WebViewで広告関連の通信・表示を抑制する |
| `updateAdBlockLists` | ON | 広告ブロックのフィルターリストを最大24時間に1回更新する |
| `preserveArticleWebStorage` | **ON** | 記事終了時のCookie消去と起動時のWebストレージ消去を抑止する |

**Cookie保持はNHK ONE専用ではありません。** 他サイトのログイン情報や追跡用Cookieも残る可能性があります。保持を望まない場合は `preserveArticleWebStorage` をOFFにしてください。

広告が残る場合もあります。サイトの表示が崩れた場合は、`blockInAppBrowserAds` をOFFにして比較してください。

## 確認済みの範囲と注意点

- PR記事の除外は利用者が実機で確認しています。ただし全画面、全タブ、ログイン状態を網羅した検証ではありません。
- ランキング非表示の旧版v0.3.0は実機でDEXガード不一致となり、v0.3.1で修正されています。修正版の実機確認は限定的です。
- CookieとWebストレージの保持・削除の違いはエミュレータ上で確認されています。
- 広告フィルターは自動更新しますが、すべての広告を防ぐ保証はありません。
- Androidの安全保護を無効化することは推奨しません。エラー時は適用を中断して原因を確認してください。
- このパッチ集は個人制作の非公式プロジェクトであり、はてな公式とは無関係です。

より詳しい仕様と配布情報は、[README](../README.md)を参照してください。
