# v0.5.0 — ブックマーク詳細から記事を開く

Hatena Bookmark 5.80（versionCode 58000）専用。Hoshioriに6件目のMorpheパッチ「Open article from bookmark card」を追加しました。

- ブックマーク詳細画面の記事カード（タイトル・サムネイル・余白）をタップすると、既存のアプリ内ブラウザで記事を開きます。
- 「◯◯ users」、ユーザー名・アイコン、フォローボタン、スター領域には既存の操作があり、変更しません。
- `openArticleFromBookmarkCard` の初期値はONです。OFFにすると元の動作に戻ります。
- URLが存在しない、またはHTTP(S)以外の場合は何もしません。対象メソッドのDEX構成が異なる場合は安全にパッチ適用を失敗させます。
- 既存の5パッチ、ほかの画面、対応APKは変更していません。

新機能についてはビルド・APK適用・DEXガード検証を実施します。ログインが必要な画面でのタップ操作がエミュレータで再現できない場合、記事カード／users表示／スターなどの最終動作確認は利用者の実機で行う必要があります。
