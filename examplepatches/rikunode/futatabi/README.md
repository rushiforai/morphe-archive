# futatabi

**ふたったー 3.1.1（`com.Nanasaki.ftutter`、versionCode 65）専用のMorpheパッチセット。** GPL-3.0。

## 現行プレリリース v0.4.0-beta.3

めぶきログイン実機実験用。正式版は v0.3.0 のままです。

| パッチ | 既定 | 内容 |
| --- | --- | --- |
| Block banner ads | ON | マージ済み ARM64 APK の上部広告バナーと余白を除去 |
| Clone app | ON | 元アプリと共存できるパッケージ名に変更 |
| Local board bridge | ON | 板一覧の補完、Bridge閲覧・拡張投稿画面 |
| Restore launcher icon | OFF | 公式アダプティブアイコンの不足前景をAPK内公式原画から補完 |

初回起動時に二次元裏（img)、二次元裏（may)、あいもげ、あにまん、めぶきを登録します。旧版で移行済みの場合も不足板を補完し、img/mayの名前を正規化します。独自板と既存の板設定は保持します。標準5板を削除した場合も次回起動時に再追加されます。純正「ねこ」の削除は未移行かつ純正構成の場合のみです。

## ログインと書き込み

閲覧は通常のふたったーの板一覧から行います。Bridge板への書き込みは、別のランチャー入口 **futatabi 投稿** を開き、板ごとの操作を選びます。純正ふたば板の投稿には干渉しません。

| 板 | ログイン | 新規スレ | レス | 画像添付 |
| --- | --- | --- | --- | --- |
| あいもげ | PKCE・ブラウザ承認 | 対応 | 対応 | 新規1枚／レス3枚まで（任意） |
| あにまん | 専用ログインなし・PHPセッション自動保持 | 対応 | 対応 | 新規1枚必須／レス1枚任意 |
| めぶき | X／Discord（実験中） | 未対応 | テキストのみ実験中 | 未対応 |

### あいもげ

1. 拡張ホームの「ログイン（PKCE）」を押し、開いたブラウザの公式認証・承認画面を本人が操作します。承認後はアプリへ戻り、ホームを開き直してログイン状態を確認します。
2. 「新しいスレを立てる」または「スレ一覧から返信」を選びます。返信時は対象スレを選択します。
3. 本文（1〜4,000字）、削除キー（自動生成・編集可）、必要に応じて「画像を追加」で画像を指定し、「投稿内容を送信」を押します。添付合計は20MiB以下。対応画像形式はJPEG／PNG／GIF／WebP／HEICです。
4. 投稿結果を確認します。投稿履歴と削除キーは端末内の「自分の投稿履歴」で確認できます。削除を実行するUIは未実装です。ログアウトは拡張ホームの「ログアウト」を使用します。

認証の有効期限はサーバー応答に従います。期限切れ時は再ログインしてください。新規スレ60秒・レス10秒のクールダウンと新規スレ毎時60件の注意表示があります。投稿はサーバーの制限に従ってください。PKCE・投稿・添付は[ローカルフィクスチャE2E](docs/write-flow-v03-e2e-observation-20261123.md)で検証済みですが、実サイトの最終検収は未実施です。

### あにまん

専用ログイン画面や資格情報の入力はありません。Bridgeがサイトから取得したPHPセッションを端末内に保持します。

1. 「あにまん：新規スレ」または「あにまん：スレ一覧から返信」を選びます。
2. 新規スレはタイトル・カテゴリID・本文・画像1枚が必須です。返信は対象スレを選び、本文を入力します。名前は省略可、本文は1,000字まで、返信時の画像1枚は任意です。
3. 「あにまんへ送信」で送信し、結果を確認します。画像アップロードが失敗した場合、本文だけ投稿済みの可能性があるため、再送前に確認してください。

投稿前確認→本文投稿→画像アップロードを独立実装しています。[公開HTMLとmain.js](https://bbs.animanch.com/main.js)を参考にし、他パッチのコードは流用していません。ローカルフィクスチャE2EはPASS、実サイトの最終検収は未実施です。

### めぶき（実験用）

1. 「めぶき：X／Discordログイン（本人操作）」を開き、公式ページでXまたはDiscordを選択します。**Googleは対象外**です。
2. 正規の認証画面で本人が認証・承認します。めぶき公式サイトへ戻った後、「ログイン済みセッションを確認して端末内へ保存」を押します。
3. 拡張ホームへ戻り、状態を確認します。AUTHENTICATEDはセッション確認応答に基づく状態です。NOT_SAVED／ANONYMOUS／UNVERIFIEDの場合はログイン成功扱いにしません。
4. 「めぶき：一覧からレス投稿」から、おためしカタログのスレを選びます。本文は1〜5,000文字・100行以内。返信先メッセージIDは任意、投稿者ID表示・スレ主表示は選択可能です。
5. 「レス投稿を送信（本人検収向け）」を押した場合、応答が返っても「送信応答を受信・成功未確定」と表示します。実サイトで投稿が成立したとは判定しません。安易な再送は避けてください。

おためしカタログは5分遅延。認証済みカタログ／スレ本文の変換、新規スレ、画像添付は未対応です。X入口はエミュレータで不安定、HTTPエラー表示は未確認、実認証・実投稿の成功は未確認です。認証中止や保存情報の消去はログイン画面から行えます（保存情報の消去はサイトのログアウトとは別です）。[本人検収手順](docs/v04-mebuki-owner-login-gate-20261124.md)／[返信フィクスチャ検証](docs/v04-mebuki-reply-and-board-retention-20261124.md)。

## 導入

1. **ふたったー3.1.1** のスプリットXAPKを、必要な全スプリットを含む単一APKにマージします。
2. [Releases](https://github.com/rikunode/futatabi/releases) から使用するバージョンの .mpp と SHA256SUMS を取得し、ハッシュを照合します。
3. Morphe Managerにパッチソースを追加し、マージ済みAPKへ適用します。Restore launcher iconは選択式・既定OFFです。アイコン補完は不足するネイティブライブラリ等を補うものではありません。
4. 署名・インストール後、通常アプリで板一覧を開きます。Bridge板の投稿は拡張ランチャー入口から操作します。

**クローンを使わない場合:** パッチ選択画面で **Clone app** をOFFにする。Morphe Desktopでは `--disable="Clone app"`。クローンの既定パッケージ名は `com.Nanasaki.ftutter.morphe` で、元の `com.Nanasaki.ftutter` とアプリデータを共有しない。

**再インストールの注意:** パッケージ名や署名鍵が変わると、Android側で上書きインストールできないことがある。アプリを削除すると、そのパッケージのデータも失われる。重要な板・お気に入りなどは事前にバックアップすること。元アプリは不用意に削除しない。
