# v0.4.0-beta.28

あにまんの純正スレ立てカテゴリをタップ選択方式へ変更。

- 純正書き込みボタンからアプリ内の非公開 Android Activity を開き、全32カテゴリをスクロール一覧で表示。先頭は「その他話題（既定）」ID 7。項目の1タップで送信する。
- 題名・本文・画像をメモリ内で引き継ぎ、再入力不要。選択前は未送信。キャンセル・無効カテゴリ・二重選択では投稿しない。送信中は一覧操作を無効化し、受理・画像添付・スレ読取の照合後のみ完了と表示する。
- beta.27 のメール欄入力方式は廃止。メール欄は空欄のまま使用する。
- Flutter AOT の純正書き込み UI 自体は変更せず、既存ブリッジから選択画面を開く。元の純正フォームには未送信案内を返すため、結果画面で完了を確認後は再送せずカタログを更新する。
- 選択肢は beta.27 で公式取得済み HTML と照合した全32項目（ID 5 は除外）。最新フォームの再取得は前回 HTTP 403。カタログ・返信・拡張ホーム・他板・表示名・設定に変更なし。

## 検証

- オフラインビルド PASS。全7パッチ適用 PASS。生成APKで非公開 Activity の登録と新規クラスの DEX 同梱、既存ランチャー名を確認。
- StockNewThreadContractTest PASS：全32選択肢、既定値、選択前に通信しないこと、カテゴリ選択後の本文・画像送信、無効値・キャンセル・二重選択、画像送信失敗時の未確定扱い、既存投稿契約。
- AnimanchPostContractTest PASS：既存のセッション・返信アンカー・送信ペイロード契約。

実投稿・実ログイン・共有エミュレータの使用なし。端末上の画面操作は所有者検証待ち。
