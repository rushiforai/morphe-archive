# ふたたび v0.4.0 — 正式版

ふたったーの操作感を保ちながら、ふたばの3板と外部3板を一つのアプリで利用できる非公式 Morphe パッチセットです。所有者実機確認済みの beta.43 を基準に、機能コードを変更せず正式版として公開します。

## 対応環境・導入

- 対象：ふたったー 3.1.1（com.Nanasaki.ftutter、ARM64、versionCode 65）。
- **推奨：[ふたたびをMorpheに追加](https://morphe.software/add-source?github=rikunode/futatabi)**。Morphe公式案内では、リンクからManagerにリポジトリを渡し、確認画面で追加できます。直接開けない場合は Sources → + → Remote に https://github.com/rikunode/futatabi を入力します。URLはHTTP 200を確認済みですが、実端末でのリンク追加からインストールまでの操作は今回未検証です。
- 予備：配布 .mpp を取得し SHA256SUMS と照合したうえで、Managerの Sources → + → Local から追加します。既定では Clone app が有効で純正版と共存できます。改造済みAPKは配布しません。
- 導入手順・各機能の詳細は [README](https://github.com/rikunode/futatabi#導入) を参照してください。署名・パッケージを維持した上書き更新を推奨します。

## 対応板・投稿

標準6板：**may → img → jun → めぶきちゃんねる → あいもげ → あにまん**。既存の独自板の位置と設定を保持しつつ、不足する標準板を補完します。

| 板 | 閲覧・レス・スレ立て |
| --- | --- |
| img / may / jun | 純正経路 |
| あいもげ | 純正画面から閲覧・投稿。公式PKCE認証・承認。スレ立ては画像必須 |
| あにまん | 純正画面から閲覧・投稿。スレ立ては題名・画像・カテゴリ選択が必要 |
| めぶきちゃんねる | 純正画面から閲覧・レス。スレ立ては公式WebViewフォームで本文・タグ・本人確認・送信。成功照合後に作成した純正スレッド画面へ自動遷移 |

めぶきのログインはアプリ内WebViewでのX／Discord認証に対応し、Google認証は対象外です。あいもげ・あにまんの新規スレ自動遷移は未対応です。結果が不明な場合は更新して確認し、重複投稿を避けてください。自動再送はしません。

## 主な機能

- 上部広告バナーと余白の除去（リワード広告は変更しない）。
- ランチャー名 futatabi、独自アイコン、ホームタイトル「ふたたび」、統計情報と端末情報へのパッチ版表示。
- 未設定時のみダークモード。デザインのメインカラーパレット末尾を #1192C9（ARGB 0xFF1192C9、純正の白い双葉マーク付き）へ置換。元の #800000 を選択していた場合は新色として読み替えます。初期色 #2196F3 と残り18色は維持。
- 純正スレ画面内の静止画表示を全6板で長辺280論理px上限に統一。画面幅・既存の小さい設定上限・縦横比を尊重。寸法不明時は正方形の表示枠を使用。拡大用画像とカタログの取得経路は変更しません。
- めぶきのスレ画像は公式原画像を利用（安全なURL・取得サイズ・画素数の制限あり）。
- 閲覧キャッシュ管理（Android 8.0以降）：起動時の古い孤立ファイル回収、確認済み2領域の合計1 GiBを目安にした整理と診断。1 GiBは常時の厳密上限ではありません。安全性を確認できない場合は整理を見送り、再取得が必要になる場合があります。
- 追加板の配色設定、純正設定バックアップとの互換、[GitHub Issues](https://github.com/rikunode/futatabi/issues) へのフィードバック導線。

## 既知の制限

- **1a：純正 Flutter 投稿経路は送信先のプロセスを検証しません。** ローカルブリッジの127.0.0.1:18765が競合すると、投稿内容が同一端末上の別プロセスへ渡る可能性があります。このリスクは未修正です。
- 純正設定バックアップの対象は FlutterSharedPreferences.xml。認証情報・別ファイルの投稿履歴・仮想ID対応表は対象外です。機種変更などで古いお気に入り等の仮想IDを移行する機能は未対応です。実機バックアップ／復元は未検証です。
- junの実投稿、肥大した実機データでのキャッシュ効果測定など、すべての組み合わせの実機確認を完了したわけではありません。旧赤色再出現の報告については発生条件が未確定です。
- 対象APKのハッシュ・変更前命令を検証し、想定外の版を拒否します。公式サイト側の仕様変更によって外部板の機能が利用できなくなる可能性があります。
