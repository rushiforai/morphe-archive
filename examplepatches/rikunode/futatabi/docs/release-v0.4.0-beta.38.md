# v0.4.0-beta.38 — 所有者実機フィードバックへの修正

**beta.37 の所有者実機フィードバックへの修正。** 対象はふたったー3.1.1 / ARM64 / versionCode 65。正式版ではなくプレリリース。

## F1: 板順序
所有者の訂正後の順序は may → img → jun → めぶきちゃんねる → あいもげ → あにまん。
FutatabiProvider.completeBoards の補完順を変更し、既存リストでも補完後に既知6 URL のレコードが占める位置だけを安定ソートする。独自板の位置・順序とレコードの文字列を保持する。既知板のカウンター・お気に入り・投稿設定も保持し、従来の既知名称正規化と初回ねこ移行の挙動は変更しない。重複を削除しない。起動時の補完処理で適用するため既知板を手動で別順序にしても次回補完時にこの相対順序になる。jun は純正経路のまま。

## F2: フィードバック画面
案内文を「不具合のご報告やご要望はGitHub Issuesへ。\nお手数ですが、再現手順もあわせてお知らせください。」、ボタンを「GitHub Issuesを開く」に変更。ボタンは固定長のUTF-16スナップショットのため短い同義表現を採用した。既存のフィードバック画面とブラウザ起動処理を維持し、beta.35以降の固定Issues URL https://github.com/rikunode/futatabi/issues （パラメータなし）への遷移処理を保持する。
旧ベータテスト画面の非表示済み設定項目から参照されていた定数Textを再利用し、案内文の参照命令だけを変更。旧ベータ画面へ別経路から到達した場合は再利用した文言が表示される可能性がある。実際の画面表示・ブラウザ遷移は所有者確認待ち。

## F3: 統計情報のパッチ版
既存統計情報のホスト版とアイコンを維持し、androidの直後に改行して「パッチ：ふたたび <パッチ版>」を表示する。A10と同じ .mpp 内 futatabi-patch-version.txt を読み込み、Gradle project.version に追随する。AOTの既存Text生成を、非表示済みベータテスト画面の別の定数Text参照へ置換し、元のローカル変数へ格納。新規Dart呼出しやスナップショットサイズ変更はない。固定長を超える将来の版数は拒否する。実画面の改行・配置は未検証。
