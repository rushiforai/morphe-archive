# futatabi v0.4.0-beta.6 — めぶきログイン実機実験用

正式リリースではありません。

- 独立パッチ Default dark mode（既定ON）を追加。アプリのテーマ未設定時のみ通常のダークモードを既定にします。ブランディングパッチとは独立しています。
- 対象3.1.1のFlutter AOT命令列とオブジェクトプールを解析。Setting_Designの設定画面と読み書き処理から、themeModeは0=ライト（純正未設定時の既定）、1=ダーク、2=ダーク（＋背景真っ黒）と確認。Android側はFlutterSharedPreferencesのflutter.themeModeをLong型で保存します。
- 非公開ContentProviderがFlutter起動前に未設定のflutter.themeModeへ1を保存します。旧設定移行前かつテーマ関連キーが未設定の場合だけ、移行処理が1を保持できるよう旧flutter.theme=2も補完します。既存値を上書きせず、旧テーマ設定が残る未移行状態は純正移行に任せます。純正移行自体の挙動は変更していません。アプリ内でテーマを変更できます。パッチをOFFにしても既に保存された設定は消去しません。
- ホストJavaで保存データ13ケースPASS。ベースAPKへの単独適用、マージ済みAPKへの全6パッチ同時適用、aapt badging、Manifest、DEXのキー・putLong・値確認PASS。Flutterのlibapp.soは既存の広告パッチによる4バイト以外変更なし。テーマの実機画面・操作は未検証です。
- beta.5の確定アイコンと選択式ブランディングを維持。Adボタンのログイン化は未実装。
