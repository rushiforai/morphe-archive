# futatabi v0.4.0-beta.2 — めぶきログイン実機実験用

正式リリースではありません。めぶきログイン（X／Discord）の実機実験用プレリリースです。

## 追加

- アイコン補完パッチ `Restore launcher icon`（選択式・既定OFF）を追加。ベースAPK単体でパッチした場合の汎用アイコン化への対策です。
- APK内の公式前景画像だけから不足する5密度の前景を生成します。既存の密度は維持し、公式白背景、背景＋前景の2要素構造、16% inset、レガシーアイコンを変更しません。
- ベースAPKとマージ済みAPKへの単独適用、5密度のリソース解決、既存画像・アダプティブXMLのバイト一致、aapt badging、原画欠落時の明示的失敗をPC上で確認しました。端末での表示確認は未実施です。既存3パッチの既定設定は変更していません。
- アイコン補完は不足するネイティブライブラリなど、その他のスプリット構成を補う機能ではありません。
