# futatabi v0.4.0-beta.7 — bridge routing fixes

正式リリースではありません。

- あいもげの画像ルートを修正。純正Flutter AOTのカタログ画像取得は設定に応じて thumb/ と cat/ を使い分けますが、従来は cat/ が未対応でした。既存のサムネイル取得・JPEG変換を cat/ でも利用できるようにしました。あにまん・めぶきも同じ純正クライアントの画像ルートに対応します。
- あにまん・めぶきのカタログ404対策。純正は futaba.php?mode=cat に &sort=1/2/3/4/6/8 を追加します。従来の完全一致ルートは追加クエリ付きURLを404にしていたため、mode=cat をクエリの独立した項目として判定します。ソート指定による上流の並べ替えを新たに実装するものではありません。
- PCから実上流を取得し、修正したJavaアダプターで変換を確認。あいもげカタログ・cat/・thumb/・スレ本文・本文サムネイル・原画像ルートはHTTP 200、あにまんは6種類のソート付きカタログでHTTP 200、めぶきもJavaによるソート付きカタログ取得でHTTP 200。PCの別クライアントではめぶき上流のCloudflare 403も観測しています。アクセス制限の回避処理は追加していません。
- PC検証ではAndroidの画像処理をPillow/ImageIOによる代替実装で検証しました。実機リクエストログは未取得であり、報告された3症状の解消は所有者の端末で再確認が必要です。
- futatabi branding を既定ONに変更。表示名 futatabi と確定アイコンを既定で使用します。他の5パッチの既定値は変更なし。
- 全6パッチ同時適用、aaptのラベル・アイコン参照、出力DEXの修正ルートを確認済み。
