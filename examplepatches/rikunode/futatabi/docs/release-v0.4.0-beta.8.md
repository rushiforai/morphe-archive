# futatabi v0.4.0-beta.8 — 板別ログインボタン

正式リリースではありません。

- 新規パッチ Board login button（既定ON、Local board bridge に依存）を追加。純正カタログ右上のAdボタンをログインアイコンへ変更します。あいもげ・めぶきの正規ローカル板URLに完全一致する場合だけ表示し、あにまん、img／may、その他の板では非表示にします。
- 純正Flutter AOTの表示条件Providerを openingCatalogUrlProvider の監視へ置換。Dartの1バイト／2バイト文字列を厳密に比較します。既存のAppBar、監視呼び出し位置、ボタンのレイアウトは維持します。
- Ad専用タップクロージャの広告ダイアログ呼び出しを、既存の非広告URL起動ヘルパーへ置換。予約した相対アセットパスだけAndroid側で捕捉し、フォーカス中のMainActivityから FutatabiHomeActivity を明示的に起動します。通常のURL起動処理を維持し、広告SDK／事前読み込みは変更しません。この予約文字列は外部ブラウザーへ渡しません。
- ARM64 libapp.so は純正または既存バナーパッチの検証済み完全ハッシュのみ許容。バナーパッチ側も純正またはログインパッチのみの検証済み完全ハッシュを許容し、両方の適用順に対応します。未知のハッシュはPatchExceptionで拒否。SVG原本のハッシュも照合します。
- 実際のARM64命令をPCのUnicornで実行（Dartランタイム呼び出しは模擬）：板判定30ケースとタップ処理PASS。Androidスタブによる起動処理11ケースPASS。単独選択および全7パッチ適用、aapt、出力DEX、SVG、libapp.soハッシュ照合PASS。1バイト変更した検証用入力は拒否され出力APKなし。
- Flutterの実描画、Riverpodの再描画タイミング、Dartの非同期チャネル送信、実端末のActivity遷移は未検証です。所有者による板切替・表示・タップ・先読み時の誤起動有無の実機確認が必要です。
- beta.7のcat/画像ルート・ソートクエリ対応・ブランディング既定ONを維持。既存6パッチの既定値は変更していません。

## 注意点
- X入口はエミュレータで不安定、HTTPエラー表示は未確認。
- めぶきはX／Discordのみ。Google対象外。ログインは実験用です。
- めぶきは未ログインのおためしカタログのみ対応。ログイン後も認証済みスレ本文変換は未実装で、スレ表示は実装待ちです。実認証・実投稿成功は未確認、新規スレ・画像添付は未対応。
- あいもげ／あにまんの投稿はローカルフィクスチャ検証済み、実サイト最終検収は未実施。
- beta.7の画像・カタログ修正、確定アイコンと既定ダークモードの独立した実機検収は所有者確認待ちです。
- 実ログイン・実投稿・エミュレータ操作なし。
