# futatabi v0.4.0-beta.10 — あいもげ認可ページのWebView化

正式リリースではありません。

- あいもげのPKCEログイン導線を既定ブラウザへのACTION_VIEWから、非公開のAimogeLoginActivity（アプリ内Android System WebView）へ変更。公式認可ページのHTTPS URLをそのまま表示し、JavaScriptとDOMストレージを有効化します。公式ページへのJS注入・改変、入力記録、TLS検証の無効化は行いません。
- 既存の公式API契約とコールバック http://127.0.0.1:18765/ext/login/aimoge/callback を維持。メインフレームのGET遷移だけ捕捉し、ネイティブ側でローカルブリッジに渡します。コールバックのホスト・ポート・パスを厳密に制限し、WebViewのHTTPサブリソース読み込みを拒否します。その他のトップレベル遷移は公式HTTPSホストだけ許容。
- beta.9のPKCE状態保持を維持。送信前の公式API DNS失敗と確認できた場合のみ、期限内の手動再試行を提供します。曖昧な通信失敗は再送せず、ホームからの再開始を案内します。成功時は資格情報を従来のアプリ専用ストレージに保存し、ログイン画面を閉じてホームが状態を再取得します。
- WebViewでの認可画面表示を確認できたため外部ブラウザへのフォールバックは追加していません。読み込み不良時は再試行またはホームへ戻る操作を提供します。
- めぶきは既にMebukiLoginActivityでWebViewを使用しているため変更なし。
