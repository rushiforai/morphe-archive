# v0.4.0-beta.35

beta.34（めぶきの原画像・確認後の専用リーダー遷移、純正バックアップ互換性、追加板の配色）を維持し、ふたたび branding に設定画面の調整を追加する。先行公開済み beta.34 のタグ・配布物は変更しない。

## A5〜A7

- 設定画面の「有料オプション・広告」「ベータテストについて」の2行を非表示にする。対象 ARM64 3.1.1 の設定リスト生成処理のみ変更し、購入行と隣接区切りを除外して後続6要素を詰め、最後のベータ行と区切りを追加せずに既存 ListView を構築する。残りの行の順番・処理は維持する設計。購入・広告の処理自体や他画面は変更しない。
- 統計情報画面の Image.asset が参照する assets/images/icon.png を、選定済み futatabi-r3-01-black-diagonal.png と同一の512×512 PNGへ置換する。
- 「ご意見、要望、バグ報告」の既存画面に「不具合・要望はGitHub Issuesへ／再現手順もお願いします」と表示する。既存URL起動処理は固定の https://github.com/rikunode/futatabi/issues を使う。旧Google Forms向けの値連結を実行せず、URLのパラメータや個人情報を付けない。
- 3件とも既定ONの futatabi branding に含む。OFFの場合は純正設定画面・純正統計アイコン・純正フィードバックのまま。
- 対象libapp.soの既存8種の厳密SHA-256検証に加え、変更前命令・文字列の一致を要求する。未対応版では適用を拒否する。既存タイトル変更と同じ finalize で行い、既存AOTパッチとのハッシュ順序を維持する。

## 検証と制限

- 実APKへ全7パッチを適用。beta.34 の libapp.so とのバイト差分、変更命令の分岐先、固定URL・案内文字列、統計アイコンが選定済み素材とバイト一致することを確認。
- A5/A7の実機UI未検証。設定の他項目と区切り、Issuesの実際の起動とパラメータなし、統計アイコン表示は所有者検収待ち。
- beta.34 の既知の制限は継続（あいもげ・あにまんの自動遷移、旧仮想ID移行は未対応）。実投稿・実ログイン・共有エミュレータ操作なし。
- めぶきログイン画面のGoogleボタン非表示はこの版に含まない。
