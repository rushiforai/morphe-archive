# futatabi v0.4.0-beta.1 — めぶきログイン実機実験用プレリリース

**本配布物は、所有者の実機でめぶきログイン導線を実験するためのプレリリースです。正式リリースではありません。** 正式リリースはログイン対応の完成後に行います。

## 実験対象

- めぶきログインの **X** と **Discord** の2種類。
- **Googleログインは対象外**です。

## 既知の注意点

- **Xの入口はエミュレータで不安定でした。** 診断ビルドでは「Email or username」入力画面まで到達した一方、通常ビルドではX入口から遷移しない結果がありました。原因は未特定です。
- **HTTPエラー表示は未確認**です。
- Discordは資格情報入力画面までの到達を確認していますが、このプレリリース作成作業で実サイトへの実ログインは行っていません。

## 実機実験時の注意

- 本版は実機での導線確認を目的とした試験版です。動作・ログイン成功を保証しません。
- 実験対象はX／Discordのみです。Googleを選択しないでください。
- 正式リリースではないため、既知の注意点を理解したうえで使用してください。
