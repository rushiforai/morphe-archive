# v0.4.0-beta.26

- ランチャー名は `futatabi` のまま、ホーム左上のタイトルのみ「ふたたび」へ変更（Flutter AOT の文字列長を維持するため末尾にゼロ幅空白）。パッケージ識別子・既存のアイコン・既存レス投稿経路は維持。
- あいもげ：純正書き込み画面からスレ立て。画像必須。題名は本文先頭へ結合。公式資格情報・添付アップロード・作成後の読取照合を利用。
- あにまん：純正書き込み画面からスレ立て。題名・画像必須。公式 HTML の通常スレ／その他話題（カテゴリ ID 7）を自動指定し、メール欄へのカテゴリ入力は不要。既存 preCheck・投稿・画像添付経路を使用。カテゴリ別の指定は拡張ホームを利用。
- めぶきちゃんねる：純正フォームの題名・本文・画像を認証済みアプリ内 WebView の公式 `/app/new` フォームへ引き継ぐ。本人が画像・タグ・スレ落ち設定を確認し、公式 Turnstile を通過して公式作成ボタンを押す。認証トークンを抽出・再利用せず、外部ソルバーや自動送信なし。アカウント一致確認と作成後の読取照合を行う。引き継ぎ時は未送信の案内を返すため、公式画面で送信した後に元のフォームで再送しないこと。
- 既知の制限：純正 Flutter 投稿経路は送信先のプロセスを検証しないため、ポート競合時に投稿内容が同一端末上の別プロセスへ渡る可能性があります。
