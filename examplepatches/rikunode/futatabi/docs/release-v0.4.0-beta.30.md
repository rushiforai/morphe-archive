# v0.4.0-beta.30

めぶきの新規スレ作成画面が反応しないという beta.29 の実機報告への修正候補。

- 成功実績のある beta.26 と同様、WebView を最初から表示する。beta.29 で追加された非表示状態での初期化・重複したPWA設定イベントを廃止。公式の非表示設定は変更が必要な時に一度だけ適用する。
- 純正本文→公式スレタイ、別の公式本文欄という対応は維持。値が既に一致する場合（空欄を含む）の不要な input/change イベントを送らない。
- 画像の drop イベントの発行だけで完了とせず、公式Reactコンポーネントの画像プレビューを確認。確認後に入力ゲートを解除し、未確認時は明示。再選択が必要な場合は公式画像欄からOSの画像ピッカーを利用可能。自動再送・再dropはしない。
- 公式コードの送信ボタンはアカウント状態・入力エラー・送信中状態で無効になる。タグは1つ以上必須。画面上部をタップすると、ボタン有効状態・タグ未入力・入力エラー・公式作成POST観測有無を表示する。観測はHTTPメソッド・公式ホスト・パス・エラーコードに限定し、リクエストの内容、認証情報、Turnstileトークンは読み取らない。
- 公式フォームは multipart POST、公式SPAのルーターが /app/new.data へ送信する構造。ブリッジは下書きを渡すまで。WebViewのリクエスト観測はレスポンスを差し替えず、公式送信・本人確認・バリデーションを変更しない。
- 原因の断定は未達。beta.29 の具体的な回帰候補を除去し、公式フォームの入力条件と実際の送信経路を区別できるようにした。実機でどの段階が停止していたかは未確認。
