# Hoshiori v0.7.0 — PR記事専用タブと設定入口の配置改善

Hatena Bookmark 5.80（versionCode 58000）専用です。

- 設定画面の「Hoshiori」を「アプリ設定」グループ内へ移動し、既存の設定項目と左位置を揃えました。
- 「PR article tab」パッチを追加しました。アプリ内の「PR記事専用タブを表示」（`showPrTab`、既定OFF）をONにすると、ホームの通常タブと同じ行にPRタブが追加されます。
- 読み込んだ通常フィードに含まれるPR記事を、除外前に収集します。重複を除いた最大300件をプロセス内で一時保持します。PRタブがONの間は通常タブからPR記事を除外します。独立した全PR記事取得APIや永続保存は使用しません。
- OFFに戻すとPRタブが消え、元のPR非表示設定に従います。既存のタブ並び順や他のパッチの設定は維持しています。

Managerでは計10件のパッチが既定で有効です。PRタブ自体はアプリ内設定で既定OFFです。

エミュレータで設定入口の位置・左揃え、PRタブのON/OFF、2カテゴリの混合試験データを純正のフィード変換処理に通した結果の通常タブ／PRタブへの振り分けを確認しました。公開フィードが読み込みエラーとなったため、サーバーから実配信されたPR記事による確認は未実施です。
