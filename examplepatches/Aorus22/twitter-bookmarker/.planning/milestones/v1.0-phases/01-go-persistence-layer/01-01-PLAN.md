<task type="auto">
  <name>Task 4: main.go startup + graceful shutdown</name>
  <files>backend/cmd/server/main.go</files>
  <action>
Implement `main()`:
1. `config.EnsureStorageDir()` — on error print a clear message to stderr and `os.Exit(1)`.
2. Open/rebuild the index and log indexed count (calls into the `index` package; wire the call now, implement in plan 01-02).
3. Build the API handler (plan 01-03) and create `http.Server{Addr: config.Addr(), Handler: h}`.
4. Listen with `net.Listen("tcp", config.Addr())` first so a port-in-use error is reported clearly before serving; on error print `Port 43121 is already in use` (or similarly clear) and exit 1.
5. Serve in a goroutine; wait on `signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)`; then `srv.Shutdown(ctx)` with a bounded timeout.

Use a `run() error` shape so `main` only handles exit codes.
