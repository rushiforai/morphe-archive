<task type="auto">
  <name>Task 1: Injection point + root element</name>
  <files>extension/src/content/ui-injector.ts</files>
  <action>
- `injectOrganizer(article, { categories, displayMode, saved, callbacks })`:
  - find the article's action bar (`div[role="group"]`, the one containing the native bookmark control);
  - create exactly one root `<div data-twitter-bookmarker-root>` and append it to the action area (or immediately after the action bar within the article if the bar cannot accept children cleanly);
  - make the article positioning-safe for the popover (set `position: relative` only if computed position is `static`);
  - if `saved` is true, render `✓ Saved` (with an `aria-live` label) and NO category controls;
  - if there are zero categories, render nothing (return without a root).
- `removeOrganizer(article)`: remove the root and restore nothing else.
- `rerenderAll(categories, settings, savedIds, callbacks)`: update every existing `[data-twitter-bookmarker-root]` in place without duplicating.
  </action>
  <verify>Manual: controls appear in the action bar row; zero categories → no controls anywhere.</verify>
  <acceptance_criteria>
    - XI-08 satisfied
    - Root element is unique per tweet and clearly marked
  </acceptance_criteria>
  <done>Injection point stable.</done>

<task type="auto">
  <name>Task 2: Popover + inline modes</name>
  <files>extension/src/content/organizer.ts</files>
  <action>
- Popover mode: render a single `[Organize]` trigger button; on click open a panel listing all categories sorted by `order`, each row showing a color dot + name. Toggle on repeat click. Close on: category selection, click outside the panel, `Escape`, or the article leaving the DOM (observer/DOM check). Only one popover open at a time.
- Inline mode: render all category buttons directly in the action area, sorted by `order`, each with its color as a visible indicator (dot or left border). No overflow strategy required.
- Both modes use `displayMode` from settings and are re-rendered when it changes.
- Buttons carry `data-category-id` so the saved/callback plumbing can find them.
- Tactile: hover/active styles, accessible button semantics, no layout breakage of X's action bar.
  </action>
