  <action>
Implement `unbookmarkTweet(article: HTMLElement): Promise<"removed" | "failed">`:
- Find the native bookmark control inside the article's action bar: prefer `[data-testid="removeBookmark"]`, else `[data-testid="bookmark"]`.
- Record the pre-click bookmarked state (`document.contains(article)` and control testid).
- Dispatch a real user-like click (`element.click()`; add `pointerdown`/`pointerup` + `MouseEvent` fallback if needed for X's handlers).
- Verify the change with a scoped `MutationObserver` on the article plus a timeout (~2s):
  - success if the control flips to `[data-testid="bookmark"]` (unbookmarked) or the article detaches from the document,
  - failure otherwise.
- Disconnect the observer and clear the timeout in a `finally`.
- Never throw; return the outcome.
  </action>
  <verify>Unit-test the verifier against a fake DOM with a flipping testid and against a non-flipping DOM (assert `failed` after timeout). Manual: on a real tweet, confirm the tweet leaves the bookmarks timeline.</verify>
