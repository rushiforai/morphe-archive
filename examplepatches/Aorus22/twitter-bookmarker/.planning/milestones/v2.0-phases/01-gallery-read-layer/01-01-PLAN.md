<objective>
Build the read-only gallery layer as a transport-free Go package: CSV discovery, header-name-based row parsing with fault tolerance, collection summaries, search, two inclusive date filters, four sort modes, and opaque cursor pagination.

Purpose: phase 2's `/api/gallery/*` handlers must be a thin transport over already-tested gallery logic (PRD §71), and the CSV must remain the only source of truth.
Output: `backend/internal/gallery/` plus table-driven tests. Library only — no HTTP, no routes, no server wiring, and no edits under `backend/internal/api/`, `backend/cmd/server/`, `extension/`, or `web/`.
</objective>

<task type="auto">
  <name>Task 2: CSV discovery, parsing and collection summaries</name>
  <files>backend/internal/gallery/reader.go, backend/internal/gallery/collection.go</files>
  <action>
Implement `Reader.listCollections`, `Reader.Collections` and `Reader.readRows`:
- Discover `os.ReadDir(dir)` entries that are regular files and pass `storage.ValidateFilename`; a missing dir yields zero collections, an unreadable dir errors. Never include `index.json`, `*.csv.bak`, temp files, dotfiles, directories or symlinks (GAL-01).
- Open each file through `storage.SafeJoin`, parse with `encoding/csv` (`FieldsPerRecord = -1`, `LazyQuotes = true`), resolve columns by header name with a `-1` sentinel per column, and tolerate a UTF-8 BOM on the first header field (GAL-05).
- Support the current `storage.Header` and the legacy `storage.LegacyHeader`; a missing `media` column means `media = []` (GAL-05).
- Required per row: non-blank `url`, `author`, `username`, `tweet_date`, `saved_at`, a record whose field count equals the header's, RFC3339-parseable timestamps, and a URL that `storage.NormalizeURL` accepts. Anything else is skipped with a `logging.Logger.Slog()` warning naming the file, line and reason; parsing continues (GAL-07, GAL-08). `text` and `media` may be empty.
- `media` is a JSON string array: empty cell -> `[]`; invalid JSON or a non-array -> `[]` plus a warning; the post is still returned (GAL-06).
- `Collections()` summarizes each readable file: `post_count`, `media_count`, `last_saved_at` = max `saved_at` (UTC RFC3339), `cover_media` = up to four URLs from the newest-by-`saved_at` rows, newest first, non-nil empty slice when there is no media (GAL-04). A file that cannot be read is skipped with a warning rather than failing the whole homepage.
- `DisplayName(filename)` strips `.csv`, collapses `-`/`_` runs to a space and title-cases each word; `ai` and `llm` are the PRD §7 initialism exceptions (`ai-and-llm.csv` -> `AI And LLM`) (GAL-02).
- Sort summaries by `last_saved_at` DESC, timestamp-less last, filename ascending as the deterministic tie-break (GAL-03).
- No cache: every call re-reads the files from disk (GAL-14).
  </action>

  <name>Task 3: Search, date filters, sort, and cursor pagination</name>
  <files>backend/internal/gallery/query.go, backend/internal/gallery/cursor.go</files>
  <action>
Implement `Reader.Posts(filename string, q Query) (Page, error)` in exactly this order (GAL-13):
1. normalize/validate the query (defaults + `*storage.ValidationError` for invalid sort/limit)
2. `readRows` (validating the filename via `storage.SafeJoin` first, so `../`, `/`, `\`, `~` and non-`.csv` error — GAL-15; a valid-but-absent name returns `ErrCollectionNotFound`)
3. search: `strings.TrimSpace(q.Q)`, skip when empty, else case-insensitive substring over `author`, `username`, `text` (GAL-09)
4. tweet-date filter, then saved-date filter, both inclusive (`!t.Before(from)` / `!t.After(to)`) and independently combinable (GAL-10)
5. sort with a total order per `SortMode`: primary timestamp (`saved_at` for saved_*, `tweet_date` for tweet_*) then `tweet_id` tie-break (descending ids for the desc modes), using `sort.SliceStable` (GAL-11)
6. cursor paginate: decode the opaque cursor, skip every row that is not strictly after the cursor position in the same total order, return at most `limit` items, set `HasMore` when more remain and `NextCursor` to the last returned row's key (GAL-12)
- `cursor.go`: `encodeCursor`/`decodeCursor` over `base64.RawURLEncoding` of `<RFC3339Nano timestamp>|<tweet_id>`; a malformed cursor is a `*storage.ValidationError`. Never emit a numeric offset.
- `Page.Items` is always non-nil.
