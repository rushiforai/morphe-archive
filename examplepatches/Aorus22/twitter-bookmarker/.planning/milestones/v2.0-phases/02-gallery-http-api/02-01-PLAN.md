<task type="auto">
  <name>Task 1: Gallery handlers and DTOs</name>
  <files>backend/internal/api/gallery.go</files>
  <action>
Create the transport file. Keep it a thin adapter over the read layer; do not reimplement filtering, sorting or pagination.

- `galleryCollectionsResponse{Collections []gallery.Collection \`json:"collections"\`}` and `galleryPostsResponse{Items []gallery.Post \`json:"items"\`; NextCursor *string \`json:"next_cursor"\`; HasMore bool \`json:"has_more"\`}`. The pointer cursor is what makes an exhausted page serialise as `null` instead of `""`.
- `handleGalleryCollections`: build a reader per request with `gallery.NewFromConfig(s.log)` (so a changed `TWITTER_BOOKMARKER_DIR` and newly appended CSVs are visible without a restart), call `Collections()`, normalise a nil slice to `[]gallery.Collection{}` and a nil `CoverMedia` to `[]string{}`, then `writeJSON(200, ...)`.
- `handleGalleryPosts`: build the reader the same way, take `r.PathValue("filename")` verbatim (never decode or expand it again), build `gallery.RawQuery` from `r.URL.Query()` for `q`, `tweet_from`, `tweet_to`, `saved_from`, `saved_to`, `sort`, `cursor`, `limit`, and call `RawQuery.Parse()` — never hand-construct a `gallery.Query`, because a zero `Query.Limit` means "default" and `?limit=0` must fail.
- Map `Parse()` errors with a shared helper: `errors.As(err, &*storage.ValidationError)` → 400 with `model.ErrorResponse{Status:"error", Reason: invalid.Reason}`; anything else → sanitised 500.
- Map `Reader.Posts` errors the same way and additionally `errors.Is(err, gallery.ErrCollectionNotFound)` → 404 `{"status":"error","reason":"collection not found"}`. The 400 branch must also run on the `Posts` error, which is where a malformed cursor surfaces.
- Sanitised 500 helper: log the real error with `s.log.FilesystemError(op, err)` and return exactly `{"status":"error","reason":"internal error"}`. Never echo `err` — wrapped `*os.PathError` values embed the absolute storage path (PRD-2 §54).
- Normalise `Items` nil → `[]gallery.Post{}`, each `Media` nil → `[]string{}`, and set `NextCursor` only when `page.NextCursor != ""`.
  </action>
  <verify>Compiles; the handler test file covers every branch.</verify>
  <acceptance_criteria>
    - No gallery handler writes to disk (read-only, PRD-2 §70/§80.23)
    - No code path returns a reason derived from a raw error
    - `media` and `cover_media` always encode as arrays
  </acceptance_criteria>
  <done>Both handlers implemented with the exact status/body contract.</done>
</task>
