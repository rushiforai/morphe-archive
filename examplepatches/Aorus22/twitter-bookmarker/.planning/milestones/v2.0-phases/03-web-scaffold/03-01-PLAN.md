<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Vite dev server | dev-only proxy forwards `/api` to the loopback backend |
| SPA → backend API | untrusted `filename` route param crosses into a URL path segment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `fetchPosts` filename | mitigate | `encodeURIComponent` on the path segment; the backend re-validates and rejects traversal (Phase 2 GAL-15) |
| T-03-02 | Information disclosure | API client base URL | mitigate | relative URLs only; no host/port literal in `src/`, so no environment/port leakage into the bundle |
| T-03-03 | Spoofing | dev proxy target | accept | proxy target is fixed loopback `127.0.0.1`; dev-only, replaced by the Go static server in Phase 9 |
| T-03-04 | Denial of service | theme provider media listener | mitigate | media-query listener is attached only in `system` mode and removed on cleanup |
| T-03-05 | Information disclosure | third-party font CDN | mitigate | self-hosted `@fontsource` bundles; no external font request leaks visitor IPs |
</threat_model>
