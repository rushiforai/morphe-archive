# Woorden uit deze handleiding

| Begrip | Betekenis |
| --- | --- |
| Analytics | Metingen van app-gebruik, zoals artikelen lezen of video’s bekijken. |
| Advertentienetwerk | Een dienst die advertenties levert. |
| Attributie | Een installatie, actie of aankoop toeschrijven aan een campagne of herkomst. |
| Publieksmeting | Het bereik en gebruik van inhoud tellen of schatten. |
| Consent management platform (CMP) | Een dienst voor het tonen van privacykeuzes en opslaan van voorkeuren. |
| Event | Een registratie van een actie, soms met context of een identificatiecode. |
| Identificatiecode / ID | Een label voor een sessie, installatie of account. |
| Pushmelding | Een bericht aan een app-installatie, bijvoorbeeld een weermelding. |
| SDK | Een herbruikbaar softwareonderdeel in een app. |
| Sessie | Een periode van app- of dienstgebruik. |
| Telemetrie | Informatie over activiteit, werking of prestaties die wordt doorgegeven. |
| APKS / APKM | Een archief waarin een app over meerdere APK-bestanden is verdeeld. Behoud het volledige originele archief om te patchen. |
