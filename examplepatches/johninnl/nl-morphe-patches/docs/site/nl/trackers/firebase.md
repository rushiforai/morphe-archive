# Firebase

Firebase bevat meerdere Google-diensten met verschillende doelen. Analytics meet activiteit; Crashlytics verzamelt foutrapporten. Authentication, Remote Config en Cloud Messaging ondersteunen inloggen, app-instellingen en pushmeldingen. Analytics of Crashlytics beperken verwijdert deze functionele diensten niet automatisch.



Bekijk de [app-pagina](../apps/index.md) voor de veranderingen en eventuele gevolgen voor functies. De algemene mogelijkheden van een dienst betekenen niet dat iedere app ze allemaal gebruikt.
