# Patches kiezen

Patchnamen komen overeen met de opties in Morphe Manager. Begin met de standaardkeuzes op je [apppagina](../apps/index.md) en pas daarna aan wat je nodig hebt.

| Optie | Wat kun je verwachten? |
| --- | --- |
| Hide ads | Verwijdert de ondersteunde advertenties voor die app. |
| Disable tracking | Stopt de ondersteunde optionele metingen en identificatoren. Noodzakelijke onlinediensten blijven beschikbaar. |
| Skip consent screens | Slaat ondersteunde automatische vragen over. Sommige apps weigeren optionele toestemming; andere laten keuzes ongewijzigd. Lees de apppagina. |
| Hide Premium banner / Hide Pro notices | Verbergt de genoemde aanbiedingen en labels. |
| Fix Google services / Fix Google Maps / Fix PairIP startup | Houdt ondersteunde functies werkend na het patchen. Laat deze aan wanneer Manager ze selecteert. |
| Read full articles / Unlock Plus / Unlock Pro / Unlock Premium playback | Verandert de lees-, afspeel- of lokale functies op de apppagina. Maakt geen aankoop of abonnement aan. |

## Keuzes die functies beïnvloeden {#two-choices-that-deserve-attention}

- **Buienradar:** de optionele Swrve-/locatiepatch schakelt ook alle weerpushmeldingen uit.
- **RTL Nieuws:** de Swrve-expertpatch schakelt push uit. Standaard trackingbescherming behoudt push.
- **Flitsmeister:** Disable partner services verwijdert Parkeren, Tol en Carwash. Navigatie gebruikt nog steeds live locatiediensten.
- **Marktplaats:** ThreatMetrix uitschakelen kan beveiligde login- of betaalfuncties beïnvloeden.
- **De Tijd:** Hide Mijn Tijd is optioneel. De servicebanner verbergen verwijdert ook berichten die daarin staan.
- **De Morgen en Humo:** trackingbescherming stopt het delen van de wachtrij en afspeelstatus tussen apparaten.
- **Podimo:** gebruik beide afspeelpatches samen. De dienst bepaalt nog steeds wat beschikbaar is.

Manager kan vereiste patches samen selecteren. Schakel bij het verwijderen van een patch ook opties uit die daarvan afhankelijk zijn. Meldingsinstellingen overslaan kan waarschuwingen uit laten staan totdat je ze handmatig aanzet.

Trackingbescherming garandeert geen anonimiteit of een app zonder netwerkverkeer. Lees op de apppagina wat wordt beperkt.
