## Patches

| Patch | Default | What it does |
| --- | --- | --- |
| **Disable Swrve and location upload** | Off | Stops Swrve marketing and background location sharing. Also disables all weather push alerts. |
| **Disable tracking** | On | Stops the supported optional usage statistics, advertising identifiers and diagnostics. |
| **Hide Premium banner** | On | Hides automatic subscription offers and Premium promotions. |
| **Hide ads** | On | Removes ads between weather cards and before weather videos. |
| **Skip consent screens** | On | Skips automatic advertising-consent screens; manual privacy choices remain available. |

## Advertising and tracking services

The ad and tracking controls cover the supported optional activity from: Google Mobile Ads, Snowplow (RTL / DPG), Kantar/NMO, Firebase, Smartocto, Bitmovin, Usabilla.

Blocking measurement does not block every function from the same provider. Essential app services can still connect.

## Before using

Standard tracking protection keeps weather push alerts and their Swrve service. The optional Swrve patch disables all push alerts as well as background location sharing.
