## Patches

| Patch | Default | What it does |
| --- | --- | --- |
| **Disable tracking** | On | Stops the supported optional usage statistics, advertising identifiers and diagnostics. |
| **Hide ads** | On | Removes supported page and video ads, recommendation promotions and the newsletter signup block. |
| **Skip consent screens** | On | Keeps region selection, skips other startup prompts and hides cookie settings. Notifications start off; manual notification settings remain. |

## Advertising and tracking services

The ad and tracking controls cover the supported optional activity from: Pinch advertising, Outbrain, Start.io, Blue Billywig, Piano / NMO, Firebase / Google measurement.

Blocking measurement does not block every function from the same provider. Essential app services can still connect.

## Before using

Region selection remains. Notifications start off and can be enabled manually. Privacy choices for embedded content you open yourself remain available.
