## Patches

| Patch | Default | What it does |
| --- | --- | --- |
| **Disable Swrve (expert)** | Off | Stops the remaining Swrve marketing activity. Push notifications stop working. |
| **Disable tracking** | On | Stops the supported optional usage statistics, advertising identifiers and diagnostics. |
| **Hide ads** | On | Removes the supported advertising placements while keeping ordinary content available. |
| **Skip consent screens** | On | Skips automatic advertising-consent screens; manual privacy choices remain available. |

## Advertising and tracking services

The ad and tracking controls cover the supported optional activity from: Snowplow / DPG, NMO / FocalMeter, Smartocto, Bitmovin, Firebase, Usabilla; Swrve campaigns.

Blocking measurement does not block every function from the same provider. Essential app services can still connect.

## Before using

Standard controls keep push available; enable notifications manually. The optional Swrve expert patch also disables push.
