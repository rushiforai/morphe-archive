| Patch | Default | What it does |
| --- | --- | --- |
| **Unlock Premium** | On | Enables the launcher's local premium features and saves that setting on startup. |

## Before using

Use the original 1.2 build 19 APK. This patch does not create a purchase or entitlement on an external service. The old 0.99 PairIP control is unnecessary for this build and is not included.

Validated with build and APK output checks, plus a clean install and launcher restart in an Android 16 TV emulator. Physical TV hardware has not been tested.
