## Patches

| Patch | Default | What it does |
| --- | --- | --- |
| **Disable tracking** | On | Stops the supported optional usage statistics, advertising identifiers and diagnostics. |
| **Hide Premium banner** | On | Hides automatic subscription offers and Premium promotions. |
| **Hide ads** | On | Removes supported web ad spaces and newspaper pages containing only advertising. |
| **Hide newspaper tab** | On | Removes the Krant tab and opens Nieuws for newspaper shortcuts. |
| **Read full articles** | On | Displays complete article text when the publisher supplies it. Does not create a subscription. |
| **Skip consent screens** | On | Skips automatic advertising-consent screens; manual privacy choices remain available. |

## Advertising and tracking services

The ad and tracking controls cover the supported optional activity from: Chartbeat, Parsely, Comscore, Piano/Cxense, Firebase, Mediahuis, Sophi; known website collectors.

Blocking measurement does not block every function from the same provider. Essential app services can still connect.

## Before using

Reading improvements show article text already supplied by NRC. The hidden newspaper tab does not grant newspaper access.
