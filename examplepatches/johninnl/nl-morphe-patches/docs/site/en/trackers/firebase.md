# Firebase

Firebase includes several Google services with different roles. Analytics measures activity; Crashlytics collects failure reports. Authentication, Remote Config and Cloud Messaging support sign-in, app settings and push notifications. Reducing Analytics or Crashlytics does not necessarily remove these functional services.



See your [app page](../apps/index.md) for the changes and any feature tradeoffs. A service's general capabilities do not establish that every app uses all of them.
