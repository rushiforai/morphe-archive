# Insider

Insider supplies marketing profiles, campaigns and messages. Events and profile properties can be used to select an audience. Its products also support location-based marketing; the available functions depend on the app.



See your [app page](../apps/index.md) for the changes and any feature tradeoffs. A service's general capabilities do not establish that every app uses all of them.
