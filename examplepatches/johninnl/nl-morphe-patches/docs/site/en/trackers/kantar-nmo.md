# Kantar / NMO

NMO (Nationaal Media Onderzoek) coordinates Dutch media audience research. Kantar performs online and viewing research. Audience measurements can describe content use and duration alongside device or session information.

Buienradar names `nmortlendpoint.2cnt.net` for this measurement. The app pages describe coverage for each app.

See your [app page](../apps/index.md) for the changes and any feature tradeoffs. A service's general capabilities do not establish that every app uses all of them.
