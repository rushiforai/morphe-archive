# Meta / Facebook

Meta App Events measures app activity; Audience Network provides advertisements. Meta also supplies account and content features. Using an app without signing into Facebook does not by itself rule out optional Meta measurement.



See your [app page](../apps/index.md) for the changes and any feature tradeoffs. A service's general capabilities do not establish that every app uses all of them.
