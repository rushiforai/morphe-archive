# Trackers and services

Named services can serve advertising, measurement, consent or useful app features. The app page explains which are affected by its patches.

| Service | Main role |
| --- | --- |
| [Snowplow](snowplow.md) | App and publisher activity measurement. |
| [Contentsquare and Heap](contentsquare-heap.md) | Screen and interaction analytics. |
| [Meta/Facebook](meta.md) | Advertising and app events. |
| [Swrve](swrve.md) | Push notifications, campaigns and profiles. |
| [Insider](insider.md) | Marketing profiles and messages. |
| [Usabilla/GetFeedback](usabilla.md) | Feedback, surveys and related measurement. |
| [Kantar/NMO](kantar-nmo.md) | Audience research. |
| [Bitmovin](bitmovin.md) | Video playback and separate analytics. |
| [Other measurement services](additional-services.md) | Audience, editorial, media and publisher analytics. |
| [OneTrust](onetrust.md) and [Didomi](didomi.md) | Privacy choices. |
| [RevenueCat](revenuecat.md) | Subscriptions and optional customer analytics. |
| [Firebase](firebase.md) | Analytics, crash reports and functional app services. |
