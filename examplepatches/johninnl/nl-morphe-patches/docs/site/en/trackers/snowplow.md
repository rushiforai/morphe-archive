# Snowplow

Snowplow records app and website activity, such as screen views, clicks and playback. Events can include installation or session identifiers and information about the content being used.

Named destinations include `c.dpgmedia.net`, `nl-rtl-prod1.collector.snplow.net` and `tracking-module.api.dpgmedia.cloud`. Coverage differs by app.

See your [app page](../apps/index.md) for the changes and any feature tradeoffs. A service's general capabilities do not establish that every app uses all of them.
