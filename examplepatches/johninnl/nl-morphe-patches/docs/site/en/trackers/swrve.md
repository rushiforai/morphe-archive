# Swrve

Swrve provides push notifications, marketing campaigns and audience profiles. These functions can share information about an installation, device and app use.

In [Buienradar](../apps/buienradar.md), the standard tracking patch keeps Swrve and background location uploads for weather alerts. **Disable Swrve and location upload** is off by default. Selecting it stops those exchanges and disables all weather push alerts.

In [RTL Nieuws](../apps/rtl-nieuws.md), standard controls suppress promotional campaigns and optional usage measurements while keeping push notifications. **Disable Swrve (expert)** is off by default; it also stops push notifications and followed-channel synchronisation.

Check these feature tradeoffs before selecting the optional patches. Other app services can still exchange data.
