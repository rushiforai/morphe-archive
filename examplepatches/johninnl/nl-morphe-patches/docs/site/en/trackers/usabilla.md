# Usabilla / GetFeedback

Usabilla/GetFeedback provides feedback forms and surveys. It can also use app activity and profile properties to select automatic surveys. Blocking automatic usage measurement can be separate from submitting a form deliberately. Manual feedback remains available in some apps and is unavailable in others.

Buienradar names `sdk.out.usbla.net` for this service.

See your [app page](../apps/index.md) for the changes and any feature tradeoffs. A service's general capabilities do not establish that every app uses all of them.
