# Words used in this guide

| Term | Meaning |
| --- | --- |
| Analytics | Measurement of app use, such as reading articles or watching videos. |
| Advertising network | A service that supplies advertisements. |
| Attribution | Associating an installation, action or purchase with a campaign or source. |
| Audience measurement | Counting or estimating the reach and use of content. |
| Consent management platform (CMP) | A service for displaying privacy choices and saving preferences. |
| Event | A record of an action, sometimes with context or an identifier. |
| Identifier / ID | A label for a session, installation or account. |
| Push notification | A message delivered to an app installation, for example a weather alert. |
| SDK | A reusable software component included in an app. |
| Session | A period of app or service use. |
| Telemetry | Information reported about activity, operation or performance. |
| APKS / APKM | An archive containing an app split across several APK files. Keep the complete original archive for patching. |
