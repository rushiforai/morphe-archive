# Brand asset sources

These files come from the Dutch App Patches Brand Kit 1.0 supplied by the
project owner on 28 October 2026. The original source and SHA-256 digest of
each copied asset are recorded in `source-manifest.json`. Artwork, proportions
and PNG exports are unchanged. `release-banner.png` is the supplied dark
1600 × 480 README banner, following the release presentation used in CueRithm.

The patch-corner artwork and layouts were created for the supplied kit.
They do not contain Morphe or app publisher logos. The repository's code
licence does not choose a new licence for the original brand artwork.

Space Grotesk, Inter and IBM Plex Mono are self-hosted in `../fonts/` with
their supplied SIL Open Font License notices. The kit describes them as
reused from an earlier supplied brand kit; it supplies no more specific
font download provenance. No external font, analytics or tracking service
is loaded by these assets or the site stylesheet.

The stylesheet maps the kit's semantic light/dark colours to Material's
`default` and `slate` schemes. Compatibility and release states must always
have text labels in addition to colour.
