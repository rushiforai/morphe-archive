# Waze phase-two implementation plan

> **For agentic workers:** Use the executing-plans workflow, with test-first
> implementation and an independent final code review.

**Goal:** Build and release all five additions approved in this session for
Waze 5.26.90.901 / 1030746.

**Architecture:** Extend existing native configuration locking and Customization.
Use exact-version bytecode hooks for recent-history reads and the display-mode
ceiling. Keep Waze's native history function and all unrelated callers intact.

**Spec:** Approved additions: native camera/hazard choices, independent speed-bump
map/warning controls, projection reconnect grace period, recent-destination hiding,
and optional phone display support up to 120 Hz.

## Constraints and decisions

- Five new patches, all default off in Manager; preserve all existing 35 patches.
- Credit Forsigh in both public language guides and NOTICE. Keep the 24 bearinmind
  ports and five project additions separately attributed.
- Native camera controls cover phone-use, bus, carpool/HOV and noise cameras plus
  raised/highway crosswalks. They need Waze data and do not replace OSM alerts.
- Give speed-bump map visibility and warning suppression separate switches.
- Reconnect grace applies to Android Auto projection only: default 2 minutes,
  range 1–10 minutes; phone background and Android Automotive flags stay untouched.
- Hide only the recent-list read, leaving favorites, future events and stored
  history intact. Switching off resumes the original native fetch.
- Display ceiling defaults to 90 Hz, adjustable 60–120 Hz; off restores 60 Hz.
  Retain resolution filtering and hardware-supported mode selection.
- Refresh and reconnect changes may require restarting Waze/reconnecting.
- Preserve the dirty primary checkout. Use johninnl for all Git identities and
  authenticated pushes. Release only through main automation; do not assign versions.

## Review focus

- Native notification and sound gates must accompany camera map gates.
- Warning suppression must not hide speed-bump map markers or alter other alerts.
- Reconnect units/ranges must match native milliseconds and UI minutes.
- The recents hook must affect one call in the merged synthetic class, preserving
  every other branch and keeping the original JNI declaration unmodified.
- The display hook must preserve wide register pairs and all unrelated mode logic.

live camera coverage, reconnect behavior in a vehicle, or phone power/thermal gains.
Report those separately; never advertise a guaranteed rendering frame rate.
