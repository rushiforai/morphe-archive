# 変更履歴

このプロジェクトのバージョンは、バンドル全体に対する独立したセマンティックバージョニング（`vX.Y.Z`）で管理します。上流（crimera/piko、ryykitty/twitch-patched）のバージョンとは連動しません。方針は [docs/UPSTREAM.md](docs/UPSTREAM.md) を参照してください。

## [1.5.0] - 2026-11-06

- **KakaoTalk のパッチを追加**（本家 [AmpleReVanced/revanced-patches](https://github.com/AmpleReVanced/revanced-patches) v1.5.0 ベース）。広告の除去、タブの非表示、削除・非表示・編集されたメッセージの表示、既読確認の表示、ゴーストモード、各種の整合性チェック回避など、KakaoTalk 向けパッチ全76件を収録。対応 KakaoTalk バージョンは 26.9.0。同じ本家の他アプリ（DC Inside、AfreecaTV/SOOP、Naver ゲームコミュニティ、Onyx Note、Flexcil、Naver Map、Samsung Keyboard、Chzzk、StarNote）向けパッチは収録していません。なお、KakaoTalk の「Disable Sentry」が依存する共通パッチ「Disable Sentry telemetry」も併せて収録しています。
- パッチの説明（全76件＋共通パッチ1件）と、KakaoTalk の設定画面に追加される「Morphe設定」の設定 UI（文字列リソース全187件）を日本語化。パッチ名は恒久ルールどおり本家の英語名のままです（実行順序を本家と一致させるため）。
- 方式は X / Twitch / LINE と同じ「本家をクローンし、言語だけを日本語にする」で、翻訳済みソースのコピーを `sources/kakao/` に保持します。本家へは読み取り専用の一方向のみで、書き込みは一切しません。
- 本バージョンはまずプレリリースとして公開し、本人の実機確認を経てから正式版にします。

## [1.3.1] - 2026-11-05

- **「Ayufa: Startup tab」が選んだタブで開かない問題を修正**。v1.3.0 では、ホーム画面の引数が無い場合の既定値を差し替える方式でしたが、実際の起動では「既定のホームページ」を返す専用メソッドからページが明示的に渡されるため、このフックは一度も動作していませんでした（実機報告を受けて実APKで再調査し判明）。
- 修正後は、その「既定のホームページ」取得メソッドの戻り値を差し替えます。起動時・下部ナビのホーム・ホームボタンはすべてこのメソッド経由で、深リンクやプッシュ通知は経由しません。パッチ設定でタブを選んでいない間は Twitch の既定動作のまま、選んだ場合だけ差し替わります。

## [1.3.0] - 2026-11-05

- **Twitch に Ayufa 独自パッチ「Ayufa: Startup tab」を追加**（本家 twitch-patched には無い新機能）。アプリ起動時に最初に開くタブを、パッチ設定の「Ayufa」セクションで フォロー／ライブ／クリップ から選べます。初期状態は未選択（おすすめでは選択されません）で、選ぶまで Twitch の標準動作（ライブで開く）のままです。
- 仕組み: ホーム画面の初期ページは、引数でページが指定されていない場合にだけ Twitch 側が「ライブ」を既定値として組み立てます。このパッチはその既定値の組み立て箇所だけを差し替えるため、ディープリンクや画面復元で明示されたページはそのまま優先されます。
- パッチ名は恒久ルールどおり英語のまま、説明と設定 UI は日本語です。対象は Twitch 31.8.0 で確認済み（31.9.0_BETA は本家同様に実験的扱い）。

## [1.2.1] - 2026-11-05

- **パッチ名（タイトル）を両アプリとも本家の英語名に戻した**（X 全52件・Twitch 全13件）。パッチの説明とアプリ内 UI は日本語のまま。
- 理由: Morphe のパッチャーはパッチを名前の文字列順に実行するため、名前の日本語化で実行順序が本家と入れ替わり、X 12.39.0-prod.01 で「Set default media tab」が失敗していた（1.2.0 の「既知の問題」は本家側の未検証ではなく、こちら側の名前変更が原因だったと判明し訂正）。名前を本家に戻したことで実行順序が本家と完全一致する。
- パッチ名を翻訳しないことを恒久ルール化した（本家が追加する新しいパッチも、名前は英語のまま、説明のみ日本語化する）。

## [1.2.0] - 2026-11-05

- 構成を「クローン＋翻訳のみ」に戻した。v1.1.x の傘パッチ構成（アプリごとに1パッチ表示）は、内包する機能パッチが1つでも失敗すると全体が適用されなくなるため廃止し、本家のパッチを機能ごとに個別収録する方式に回帰。

- X 側のパッチ名・説明（全52件）を日本語化。これまでは Piko 設定 UI の文字列のみ日本語で、一覧の名前・説明は英語だった。
- v1.1.x の傘に含まれなかった4機能（NewX: クローン／Twitterブランディングに戻す／HLS音声レンディションのログ、Twitch: 再生の診断）が、通常の任意選択パッチ（本家の初期状態）として復帰。
- 既知の問題: 「正規URLを直接開く」（本家 CanonicalUrls）は本家側の未検証により X 12.39.0-prod.01 では失敗する。個別収録のため、このパッチだけを外して適用できる。（※この帰属は誤りでした。原因は本家ではなく、パッチ名の日本語化による実行順序の変化です。1.2.1 の項と docs/UPSTREAM.md の訂正を参照。）
