# 変更履歴

このプロジェクトのバージョンは、バンドル全体に対する独立したセマンティックバージョニング（`vX.Y.Z`）で管理します。上流（crimera/piko、ryykitty/twitch-patched）のバージョンとは連動しません。方針は [docs/UPSTREAM.md](docs/UPSTREAM.md) を参照してください。

## [1.8.0] - 2026-11-26

### 削除

- LINE パッチ（全39件）の収録を終了しました。本家 andrewliang25/morphe-patches が v4.0.0 で設定画面「Andrew's Patch Setting」の公式日本語訳を提供し始めたためです。LINE のパッチが必要な方は、本家を Morphe のパッチソースとして直接追加してください。X、Twitch、KakaoTalk のパッチに変更はありません。

## [1.6.1] - 2026-11-18

### 修正

- X: v1.6.0 で「NewX: Inline download button」の適用に失敗する問題を修正しました。カード情報のモデル解決で、アプリ側の toString の作り（コンパイラが append をヘルパー呼び出しにまとめる形式）にラベル照合が対応しておらず、bindings フィールドを特定できていませんでした。解決方法をその形式に合わせて変更しています。カード動画のダウンロード機能そのものに変更はありません。

## [1.6.0] - 2026-11-18

### 追加

- X: 「NewX: Inline download button」で、カード（unified card）で参照された動画もダウンロードできるようにしました。これまではポスト本体に付いたメディアだけが対象で、カード内の動画はダウンロードボタン自体が出ませんでした。カードの動画も通常のメディアと同じく、画質（ビットレート）の選択や長押しでの一括ダウンロードが使えます。新しいパッチや設定項目は増えていません（既存のダウンロードボタンの常時拡張です）。

## [1.5.9] - 2026-11-16

### 修正

- Twitch: 「チャットに再接続しました」の行の表示位置を変更しました。「〜さんのチャットルームにようこそ！」の後ではなく前に出るようにし、再接続中→再接続しました→ようこそ、の順で表示されます。

## [1.5.8] - 2026-11-16

### 修正

- Twitch: 「チャットに再接続しました」の表示方式を変更しました。従来はスナックバーで出していましたが、実機では「チャットに再接続中…」はチャット欄の中の行として表示されるため、復旧時に同じ場所・同じ見た目で「チャットに再接続しました」の行がチャット欄に追加されるようにしました（「UI settings」パッチの常時修正）。

## [1.5.7] - 2026-11-16

### 修正

- Twitch: サムネイル対策がフォロー一覧に効いていなかった問題を修正。「UI settings」パッチの常時修正に、プレビュー URL を props で受け取って React Native 標準の Image で直接描く部品（フォロー一覧の `FollowingRowThumbnail` とホーム背景の `SkylineThumbnailBackground`）の props 境界でのキャッシュキー付け替えを追加しました。この2部品は共有ヘルパーも CoreImage も経由しないため、従来の対策（v1.5.4〜v1.5.6）が一度も届いていませんでした。
